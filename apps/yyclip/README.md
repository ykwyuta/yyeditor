# yyclip

yy シリーズとは独立した Windows 用のクリップボード履歴常駐アプリです。

```powershell
cargo build -p yyclip --release
```

`target\release\yyclip.exe` を起動すると、紫色の「YY」とクリップボードを描いたアイコンが通知領域に出ます。起動中は、どのアプリからコピーしたテキストでも 1 MiB 以下なら `%APPDATA%\yyclip\history\` に UTF-8 の `.txt` ファイルとして保存します。画像やファイル一覧など、テキストを含まない内容は対象外です。

Control キーを押して離し、500 ミリ秒以内にもう一度押すと、タブと一覧だけの選択画面を開けます。開いたときは一覧の一番上の項目が選ばれ、キーボードのフォーカスも一覧にあるので、そのまま矢印キーで操作できます。左右の矢印キーでタブ、上下の矢印キーで候補を移動できます。「クリップボード」と「定型文」のタブでは、Enter またはマウスのダブルクリックで選ぶとクリップボードへ戻ります。「お気に入り」タブでは、登録したファイルを既定のアプリで、フォルダをエクスプローラーで開きます。Ctrl+Tab でもタブを切り替えられます。Esc または画面外のクリックで閉じます。

定型文の登録は、通知領域にある `yyclip` アイコンを右クリックして「定型文を登録...」を選び、入力画面の「メモ」に何に使う定型文か（例: 「会社の住所（請求書用）」）を、内容の欄に任意の文字列を入力して「保存」を押します。メモは一覧と右クリックメニューに「【メモ】本文の先頭」の形で出ます（なくてもかまいません。クリップボードへ戻すのは本文だけです）。複数行に対応します。同じ右クリックメニューの「定型文を編集」「定型文を削除」から既存の項目を変更・削除できます。最大 20 件、同じ内容の重複登録はできません。定型文は `%APPDATA%\yyclip\templates\` に UTF-8 の `.txt` ファイルとして残ります（メモは同じ番号の `.memo.txt`）。画面の文字には他の yy アプリと同じ Windows メッセージフォントを使います。

お気に入りは、同じ右クリックメニューの「お気に入りファイルを登録...」「お気に入りフォルダを登録...」から選択画面を開いて登録します。「お気に入りを編集」「お気に入りを削除」で後から変更できます。ファイルとフォルダを合わせて最大 20 件で、同じ場所の重複登録はできません。登録情報は `%APPDATA%\yyclip\favorites\` に残り、移動・削除された対象は開く際にエラーを表示します。

通知領域のアイコンを左クリックしても選択画面を開けます。右クリックの「終了」で常駐を終了します。

サインイン後も使う場合は、`yyclip.exe` へのショートカットをユーザーのスタートアップフォルダに配置してください。履歴は終了後も残ります。
