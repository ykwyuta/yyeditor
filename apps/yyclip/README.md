# yyclip

yy シリーズとは独立した Windows 用のクリップボード履歴常駐アプリです。

```powershell
cargo build -p yyclip --release
```

`target\release\yyclip.exe` を起動すると、紫色の「YY」とクリップボードを描いたアイコンが通知領域に出ます。起動中は、どのアプリからコピーしたテキストでも 1 MiB 以下なら `%APPDATA%\yyclip\history\` に UTF-8 の `.txt` ファイルとして保存します。画像やファイル一覧など、テキストを含まない内容は対象外です。

Control キーを押して離し、500 ミリ秒以内にもう一度押すと、タブと一覧だけの選択画面を開けます。「クリップボード」と「定型文」のタブを選び、矢印キーと Enter、またはマウスのダブルクリックで選ぶとクリップボードへ戻ります。Ctrl+Tab でもタブを切り替えられます。Esc または画面外のクリックで閉じます。

定型文の登録は、通知領域にある `yyclip` アイコンを右クリックして「定型文を登録...」を選び、入力画面に任意の文字列を入力して「保存」を押します。複数行に対応します。同じ右クリックメニューの「定型文を編集」「定型文を削除」から既存の項目を変更・削除できます。最大 20 件、同じ内容の重複登録はできません。定型文は `%APPDATA%\yyclip\templates\` に UTF-8 の `.txt` ファイルとして残ります。画面の文字には他の yy アプリと同じ Windows メッセージフォントを使います。

通知領域のアイコンを左クリックしても選択画面を開けます。右クリックの「終了」で常駐を終了します。

サインイン後も使う場合は、`yyclip.exe` へのショートカットをユーザーのスタートアップフォルダに配置してください。履歴は終了後も残ります。
