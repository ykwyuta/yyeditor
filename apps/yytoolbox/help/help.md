# yytoolbox ヘルプ

開発用の変換・生成・計算、画面録画、画像処理をローカルで行うWindowsアプリです。
入力・結果を外部サービスへ送信せず、入力履歴の記録も行いません。録画・画像処理は実行時に保存先を選びます。
「入力を開く」でUTF-8ファイルを読み、「入力を保存」で定義等を保存できます。
「結果をコピー」「結果を保存」は明示操作で行います。保存先はその都度選択します。

## 操作

上部でツールを選び、条件と入力を設定して「実行」（Ctrl+Enter）を押します。
「入力例」は現在のツール・ダミーデータの分野に対応する例を読み込みます。
「中止」またはEscで処理を止めます。F1でこのヘルプを開きます。
右上の「−」「＋」で画面全体を75〜200%に拡大・縮小できます。倍率ボタンで100%に戻します。
Ctrl＋/−、Ctrl+0、Ctrl+マウスホイールでも変更できます。WindowsのDPI倍率と組み合わせて文字と余白が拡大されます。
幅が狭い場合は条件・入出力が縦に並び、入りきらない部分は画面右端のスクロールバーで移動できます。Tabで移動した入力欄は自動で表示範囲に入ります。
録画・画像処理では不要な入力ファイル操作を表示しません。中止ボタンは処理中に表示します。
テキスト入力は1 MiB、条件の合計は1 MiB、テキスト出力は16 MiBまでです。録画・画像には以下の専用条件を適用します。
ツールの切り替え・クリアで以前の入力と結果は画面から消えます。

## 開発ツール

- 正規表現: Rust regexの構文です。i/m/s/x/Uフラグ、番号・名前付きグループ、UTF-8バイト位置を表示します。後読み・後方参照は非対応。一致は最大10000件です。
- Base64: 標準／URL-safeを選択できます。エンコード入力はUTF-8テキスト。デコードではASCII空白を無視します。バイナリは16進表示し、保存では元のバイト列を書きます。
- ハッシュ: MD5、SHA-1、SHA-224/256/384/512、BLAKE3、CRC32。入力欄のUTF-8バイト列が対象です。元ファイルのバイナリ全体のハッシュではありません。
- JWT: 3区画のJWSをデコードします。署名・発行者・有効期限は検証しません。暗号化JWEは非対応です。
- JSON: 整形／圧縮。数値の原文、文字列のエスケープ、キー順序を維持します。JSONの深さはパーサーの上限に従います。
- SQL: Generic／PostgreSQL／SQL Server、キーワードの大文字・小文字を選べます。フォーマットのみで、DBへの接続・実行・完全な構文検証はしません。入力128 KiBまで。負荷を抑えるため括弧の深さを64までに制限し、この判定では文字列内の括弧も数えます。

## QRコード・URL変換

QRコードはUTF-8テキストを符号化し、結果欄に表示します。「結果を保存」でSVGまたはPNG、「結果をコピー」でSVGをコピーできます。
誤り訂正L/M/Q/H、PNGの1マス4〜16画素を選べます。余白は四辺4マスです。最大容量は訂正率・文字数で変わり、UTF-8で2953バイトを超える入力はエラーになります。
密なコードは小さい画面では読みにくいため、画面を広げるか保存した画像を使ってください。

URLはエンコード／デコード、URL部品・フォーム・URI全体を選択できます。
URL部品は予約文字も変換し、フォームは空白を `+`、URI全体は `:/?#[]@!$&'()*+,;=` を維持します。
フォームのデコードだけ `+` を空白にします。不正な `%`、UTF-8として不正なデコード結果はエラーです。URLには接続しません。

## XML・YAML・CSV・INIの相互変換

「入力形式」「出力形式」と「構造の扱い」を指定します。「入力を開く」でUTF-8ファイルを読み、「結果を保存」で選択した形式に保存できます。
初期値の「構造保持」は配列・入れ子・null・真偽値・数値・文字列・空コンテナを保持します。
YAML以外にはyytoolbox専用の中間表現を使います。通常の業務ファイル形式で出力したい場合は「標準形式」を選択してください。

- 構造保持CSV: 見出し `yytoolbox-tree-v1,type,value`。pathはJSON Pointerで、各要素を型付きの行にします。
- 構造保持INI: `[yytoolbox-tree-v1]` セクションに `n000000=[path,type,value]` のJSON配列を連番で記述します。
- 構造保持XML: `<yytoolbox-tree-v1>` の子に `<node path="..." type="...">value</node>` を記述します。
- これらの専用表現は入力時に自動認識します。生成後、どの出力形式へも再変換できます。専用マーカーは一般データの名前に使わないでください。
- 標準CSV入力: 先頭行が空欄・重複のない見出し。各行を文字列のオブジェクト配列として読みます。
- 標準CSV出力: 同じキーを持つ1件以上のオブジェクト配列。値は文字列・数値・真偽値で、CSVにすると文字列です。
- 標準INI入力: 全体のkey=valueと `[section]`。値は文字列。引用符付きの値ではJSON文字列のエスケープを使います。行頭の `;`・`#` はコメントです。重複のキー・セクションは拒否します。
- 標準INI出力: 全体のキーと1階層のセクション。深い入れ子・配列・nullはエラーになります。
- 標準XML入力: ルート要素が最上位キー、属性は `@名前`、本文は `#text`、同名の子は配列です。名前空間も変換します。
- 標準XML出力: ルート1個のオブジェクトを同じ規則で変換します。数値・真偽値もXML上では文字列になります。
- XMLのコメント・処理命令・元の子要素の並び順や余白は保持しません。文字列と子要素が交互に現れる混合内容は拒否します。DTD・外部実体は読みません。
- YAMLのキーは文字列にしてください。独自タグ・NaN・無限大は非対応です。

共通の上限は深さ64・100000要素とテキストの入出力上限です。元のコメント・見た目・列順序を保持するための形式変換ではありません。
相互変換のCSVでは元の値を保持するため数式対策を加えません。ダミーCSV生成の数式対策とは別です。

## HTML・CSS・JavaScript整形

字下げ1〜8、折り返し幅40〜240を指定できます。入力256 KiB、構文の深さ128まで、HTMLは4096タグまでです。
HTMLはmarkup_fmt、CSSはMalva、JavaScriptはBiomeのPure Rustパーサーとフォーマッターを使います。コードを実行せず、外部のNode.jsも必要ありません。
HTML内のscript/styleのコードは専用のJavaScript/CSS整形で整形してください。HTML整形ではそれらの本文をそのまま扱います。

## 画面録画

1. 全画面（メイン）・全画面（すべてのディスプレイ）・矩形選択から範囲を選びます。
2. 録画時間1〜3600秒、毎秒1〜30フレーム、最大録画幅320〜7680pxを指定します。初期値は60秒・15fps・最大幅1920pxです。
3. PC再生音とマイクを必要に応じて「あり」にします。初期値は両方「なし」です。
4. 「実行」でMP4の保存先を選びます。矩形選択なら、続けて画面上で範囲をドラッグします。
5. 指定時間後に保存して画面へ戻ります。Escは他のアプリが前面でも録画を中止し、今回の録画を破棄します。

yytoolbox自身とヘルプは録画中に非表示になり、録画終了・中止・エラー時に戻ります。
既存ファイルを保存先に選んだ場合、正常完了時だけ置換します。中止やエラーでは既存ファイルを維持します。
最大幅で縮小するときは縦横比を維持し、H.264用に縦横を偶数に調整します。最大3200万画素です。
録画終了後の結果欄・コピー・結果保存は録画の情報です。MP4本体は最初に指定した場所へ保存済みです。

WindowsのGDI、Media Foundation、WASAPIを使用し、FFmpeg・ImageMagickには依存しません。
MP4はH.264、音声を有効にした場合はAACです。PC再生音は既定の再生デバイス、マイクは既定の録音デバイスから取得し、両方を選ぶと混合します。
音声デバイスがない・許可されていない場合はエラーにし、音声なしへ黙って切り替えません。Windows設定のマイク許可も確認してください。
Windows Nなどでメディア機能がない場合はWindows側のメディア機能が必要です。保護された動画・セキュアデスクトップは録画できません。
録画中に画面構成や既定音声デバイスを変更しないでください。CPU負荷などで指定fpsを保てない場合があります。

## 画像の一括リサイズ

「実行」でPNG/JPEG/WebP/BMPを1〜1000個選び、出力フォルダを指定します。
外部コマンドを使わずに処理します。入力は1枚64 MiB・3200万画素まで。JPEGの回転情報は反映します。

- 縦横比維持: 指定した最大幅・最大高に収め、実際の出力寸法は画像の比率に合わせます。
- 背景補完: 比率を維持して枠内に収め、中央に配置し、指定サイズの余白を補います。
- 引き伸ばし: 指定した幅・高さにします。比率は変わります。
- 「拡大を許可」は縦横比維持・背景補完の縮小／拡大に適用します。初期値は拡大なし。
- 背景色は `#RRGGBB`。透明な背景はPNG/WebPで指定できます。JPEG/BMPは透明を保存できないため、透明指定時はエラーです。
- 背景補完の余白と、JPEG/BMPへの透明部分の合成に指定した背景色を使います。PNG/WebPの画像自体の透明部分は維持します。
- 出力はPNG/JPEG/WebP/BMP、幅・高さ各1〜8192px、枠は3200万画素までです。アニメーションの維持やメタデータの引き継ぎは行いません。

名前は `元の名前-resized.ext`。既存ファイルがあれば番号を付け、元画像・既存出力を上書きしません。
結果欄には入力・出力・結果・寸法のCSVを表示します。途中で中止しても保存済みの画像は維持します。

## パスワード候補

文字数4〜256、件数1〜1000。小文字・大文字・数字・記号の最低数を指定します。
最低数0の文字種は使いません。最低数の合計は文字数以下にしてください。
指定記号はASCII記号のみです。除外文字は全種類に適用します。
OSの安全な乱数で文字の選択と並べ替えを行い、同じ結果内の候補を重複させません。
条件が厳しく異なる候補を指定数生成できない場合はエラーにします。

## ダミーCSV

「定義例の分野」で個人・企業・EC注文・医療・金融・物流・ITログ・IoTを選び、「入力例」を押します。
入力欄のYAML列定義を編集できます。定義は「入力を保存」で `.yaml` に保存し、「入力を開く」で再利用します。
生成件数は画面の「行数（1〜100000）」で指定します。初期値100件で、CSVの見出し行は数えません。YAMLは列定義のみです。
行数は1〜100000、列数は1〜64です。seedが同じなら同じ定義・条件の結果を再現できます。空欄ならOS乱数からseedを作ります。
生成結果のステータスに使用したseedを表示します。パスワードとは異なり、ダミーデータの乱数は再現用で、暗号用途には使えません。

列定義例（インデントには半角スペースを使います）:
```yaml
# テスト用CSVの列定義
columns:
  - name: ID
    type: sequence
    prefix: TEST-
    width: 6
  - name: 氏名
    type: person_name
  - name: 金額
    type: decimal
    min: 0
    max: 100000
    scale: 2
  - name: 状態
    type: choice
    values: [受付, 完了]
    null_percent: 10
```

YAMLのコメントや複数行文字列を使用できます。電話番号・郵便番号・"001"・"true"など、文字列として扱う値は引用符で囲んでください。
1ファイルに列定義を1つ記述します。YAMLの複数ドキュメントや未知の項目、同じ項目の重複はエラーになります。

共通項目: nameは必須で重複不可。null_percentは0〜100、空欄を生成する割合です。
`unique: true` は空欄以外の値の重複を防ぎます。有限な選択肢の不足、同じliteralだけを複数回要求する等はエラーになります。

データ種:
- sequence: start（初期値1）、prefix（初期値空）、width（0埋め幅）。行番号に応じた連番です。
- integer: min/max（初期値0/100）。両端を含む整数。
- decimal: min/max、scale（0〜6、初期値2）。小数桁に合う最小値〜最大値から生成します。
- date: from/to（YYYY-MM-DD、両端を含む）。初期値2000-01-01〜2030-12-31。
- datetime: from/to（タイムゾーン付きISO8601）。初期値2026-01-01T00:00:00Z〜2026-12-31T23:59:59Z。UTCで秒単位です。
- choice: values配列から選択。
- boolean: true/false。
- literal: valueの文字列をそのまま使用。
- uuid: UUID v4形式の再現可能なテスト値。
- person_name/company_name/company_id/email/phone/postal_code/address/department/job_title/product_name/ip_address/url。

個人・企業の文字列はテスト用の架空値です。メール・URLはexample.invalid、IPは文書用範囲、電話・郵便番号は000始まりです。
公的な番号・実際の連絡先・住所検証に合格する値の生成を目的にしていません。
実データや外部の名簿は取得しません。業務上の列間制約（数量×単価=金額等）は自動補完しません。
CSVはカンマ・引用符・改行をエスケープします。UTF-8 BOMの有無を選択できます。
「文字列の数式対策」の初期値は「表計算ソフト向け」です。文字列の先頭が =、+、-、@、タブ、改行の場合に ' を付けます（数値型を除く）。原文が必要な試験では「原文のまま」を選択できます。

## 複利・返済

複利は名目年率÷年の複利回数を各期の利率に使います。毎期の積立を期末／期首から選択できます。
元金・積立額は0〜1兆、年率0〜100%、年数1〜100です。年ごとの元金・積立合計、運用益、残高をCSV表示します。
税金・手数料・物価変動を含まない一定利率の試算です。

返済は月払い、固定名目年率÷12。元利均等／元金均等を選択できます。
回数は1〜1200。金額の小数桁は0または2。利息は各回で四捨五入し、最終回の元金を調整します。
税金・手数料・端数処理方式や実際の商品条件によって実際の返済額とは異なります。

## 和暦・年齢・時差

和暦: 明治・大正・昭和・平成・令和。元年、M/T/S/H/R、小文字、全角数字を使えます。
年だけを入力すると改元年の期間も表示します。明治元年〜5年は年の対応のみです。日付変換は1873年以降のグレゴリオ暦です。旧暦変換は行いません。
年齢・学年: 基準日と生年月日から誕生日基準の満年齢、標準進級の学年、各学年の生年月日範囲を表示します。
2月29日生まれの非閏年の年齢表示は3月1日で切り替えます。学年区分は4月2日〜翌4月1日。大学は4年制の目安です。
時差: 基準日時はnowまたはタイムゾーン付きISO8601。地域はAsia/Tokyo等のIANA名。*で同梱DBの全地域です。
同じ瞬間に対応する現地日付・時刻、UTCオフセット、基準地域との時差、略称を表示します。
指定時点の夏時間を反映します。同梱IANA DBの版をステータスに表示し、制度変更の反映には依存DBの更新が必要です。
