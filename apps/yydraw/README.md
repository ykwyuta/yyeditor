# yydraw

yy シリーズと同じ同梱フォント（UDEV Gothic）を使う、Windows の構成図エディタです。

```powershell
cargo run -p yydraw
.\target\debug\yydraw.exe diagram.yyd
```

- 方眼紙と吸着、基本図形、複数選択・移動・サイズ変更・グループ・整列。
- 図形・アイコン・線のグループ化（Ctrl+G）と解除（Ctrl+Shift+G）。グループ単位の選択・移動・複製、6方向の整列・縦横の均等配置、選択範囲／ページの基準切替。配置メニューと右クリックから操作できます。
- 編集できる基本図形60種。演算子6種、吹き出し5種、かっこ・星・ハート・ドーナツ、10種のブロック矢印、書類・開始終了などのフローチャート記号を分類して選択できます。新図形の接続点は輪郭に沿い、吹き出しの本文は尻尾を避けます。
- AWS 859・Azure 714・Google Cloud 261 の公式アイコン全 1,834 個を収録。選んだカテゴリ内だけを画像と名前で表示し、ドラッグして配置できます。初期表示は基本図形です。
- システム構成図・業務フロー・コンサルティング資料向けの[業務・ITアイコン376種](../../docs/yydraw-business-icons.md)も収録。38カテゴリで、日本語名・英語検索に対応します。モバイル端末、開発言語、データベース製品、AI、顧客対応・メール、人物、ファイル・帳票、広告・メディア、衛星も選べます。メッセージング製品、キュー・トピック、バックアップ・復旧、暗号化・データ保護、クラスタ・可用性・ストリーム連携も収録しています。OpenAI・ChatGPT・Gemini・Claude・Claude CodeなどのAIサービスも選べます。人物・役職・医療・教育・外交・安全保障など70種を追加し、経営責任者も正式な日本語名付きで選べます。全カタログは2,210種です。
- SVG／PNG 素材・素材フォルダの追加、名称・カテゴリ検索、XY 軸と原点表示。
- 図形に追従し障害物を避ける直交線、各辺5点の接続ハンドル、途中点の編集、明示的な接続点、矢印・破線・交差時のアーチ。
- マウス位置を中心に滑らかに追従するズーム。補間中は描画済み画像をGPUで再利用します。
- Shiftで線を上下左右に固定し、Shift+Tabで折れ点を追加、Backspaceで戻せます。尖角・丸角と角の半径を編集し、保存・SVG・PNGにも反映します。
- 日本語 IME と複数行ラベル、図形・線のプロパティ、Undo／Redo、文書タブ。
- 塗り・線・出力背景のカラーパレット。矢印を引く操作と拡大縮小では描画済みの背景を再利用します。
- 独自の `.yyd` に素材・接続関係・文字を保存。素材を追加していない PC でも再編集できます。
- ページ管理、整列ガイド、別ウィンドウへの図形コピー、PNG／SVG としてコピー。
- SVG（文字のパス化／テキスト保持）・PNG 出力。ページ／全要素／選択範囲、背景色・余白・格子・PNG 倍率を指定できます。
- 保存・読込・出力・素材追加の非同期処理と取消、素材パックの版管理、ユーザー単位のファイル関連付け。

操作は [ヘルプ](../../crates/yy-win/help/draw.md)、設計と検証状況は
[提案書の実装状況](../../docs/proposal/21-draw.md#9-実装の状況)を参照してください。
draw.io・Visio 形式のインポート／エクスポートは提供しません。

クラウドのアイコンは各提供元の素材です。[出典・利用条件](../../crates/yy-draw/assets/NOTICE.md)を参照してください。
追加パックを取り込む場合も、提供元の利用条件を確認してください。
同じ絵柄のサイズ違いは一つにまとめ、Google Cloud の旧版は区別して掲載しています。
カタログは実行ファイルに同梱され、文書には実際に使った素材だけを追加します。
公式配布物の取得・カタログ再生成は `python tools/cloud-icons/fetch.py`、
取得 URL・SHA-256・収録数は [取得記録](../../crates/yy-draw/assets/catalog-sources.json)で確認できます。

「素材・設定 → 素材パックを追加」では次のような TOML を読み込みます。
`file` は TOML と同じフォルダ以下の SVG／PNG への相対パスです。

```toml
id = "my-services"
version = "1.0"
source = "社内で作成"
terms = "社内利用可"
[[icons]]
name = "API サーバー"
file = "icons/api.svg"
```

同じ ID・版の内容は変更できません。版を切り替えても配置済みの図は保持されます。
性能測定の再現方法は [性能の記録](../../docs/yydraw-performance.md)を参照してください。

保存・出力のサンプルは次で生成できます。

```powershell
cargo run -p yy-draw --example sample -- target/yydraw-sample
```
