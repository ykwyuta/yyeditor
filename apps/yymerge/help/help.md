# yymerge ヘルプ {#top}

yymergeはYYシリーズ共通のUDEV Gothicとエディターを使う、ファイル比較・3方向マージツールです。GUIはWindows専用、CLIと比較コアはWindows / Linuxに対応します。

## はじめに {#start}

`yymergew.exe`を起動し、[ファイル] → [2方向比較を開く] でLEFTとRIGHTを選択します。入力は読み取り専用です。黄色の範囲が変更行です。右側の差分一覧を選ぶか、F7 / Shift+F7で移動できます。マウスホイールで縦スクロール、Shift+ホイールで横スクロールします。

比較は文字の正規化をせず、改行（CRLF / LF）、終端改行、BOM、文字コードも対象にします。表示上同じでもBOMや文字コードだけが違う場合は「相違あり」となります。

この初期版では左右の表示を独立してスクロールします。差分選択で左右の該当位置に移動します。挿入行に合わせた空白行による整列、行内差分の色分け、ドラッグによる範囲選択、セッション保存は未実装です。

## 3方向マージ {#merge}

1. [ファイル] → [3方向マージを開く] を選択します。
2. BASE（共通祖先）、LEFT（自分側）、RIGHT（相手側）の順にファイルを指定します。空のBASEも有効ですが、存在しないBASEはエラーです。
3. 独立した変更と両側の同じ変更は自動統合します。同じ場所への異なる挿入や削除対変更は競合です。変更境界の挿入も保守的に競合とする場合があります。
4. 右側の競合一覧で対象を選び、[マージ] メニューでLEFT / RIGHT / BASE / 両方を採用します。「両方」はLEFT→RIGHTの順です。
5. RESULTを直接編集することもできます。未解決の競合が残る手動編集では、[マージ] → [手動編集の完了を確定] を明示的に選択してください。マーカーを消すだけでは解決済みになりません。この操作は人が内容を確認したという宣言です。残ったマーカーも確認してください。
6. [結果を保存]（Ctrl+S）で入力とは別のファイルへ保存します。未解決の競合があれば保存できません。

[マージ操作を取り消す / やり直す] は競合の選択・手動編集開始・完了確定を戻します。RESULTでのCtrl+Z / Ctrl+Yはテキスト編集の取消・やり直しです。手動編集後に競合選択へ戻るには、先に[マージ操作を取り消す]を使います。編集内容が自動生成で消えないための制限です。

マージ操作の履歴には内容の合計64 MiBの上限を設け、古い履歴から破棄します。1操作だけで上限を超える場合、その操作のマージ履歴は残りません。これはRESULT内のテキスト編集履歴とは別の上限です。

入力と出力の保存直前の内容を再検査し、一時ファイルを同じディレクトリーに書いてから置換します。入力自体への保存やリンクへの出力は拒否します。保存先が他プロセスで変更されていたら中止します。ただし再検査と置換の間で第三者が書く競合を完全に排除するものではありません。

## 文字コードと制限 {#encoding}

BOM付きUTF-8 / UTF-16 / UTF-32を認識し、BOMなしはUTF-8として開きます。CP932等はCLIの`--encoding CP932`で明示します。GUIにも起動時の同じ指定が使えます。エンコード→デコードで元のバイト列に戻らない入力、不正文字、NULを含むバイナリーは拒否します。保存時に表現できない文字を置換せずエラーにします。マージでは3入力の文字コードとBOMを揃えてください。保存にはBASEの文字コードとBOMを使います。

初期版の上限は各テキストと保存出力32 MiB、比較する2入力の合計100万行、厳密比較の追跡400万セルです。上限超過は「比較未完了」のエラーです。近似結果でマージを続行しません。[停止]で比較を取り消せます。ファイルの読み込みと比較は画面とは別のスレッドで処理します。OSのファイルI/O待ちの中断時間は保証しません。巨大入力のディスク索引・ストリーミング表示は今後の実装です。

## CLI {#cli}

```powershell
yymerge diff left.txt right.txt
yymerge diff left.txt right.txt --format json --report changes.json
yymerge diff left.txt right.txt --format unified --report changes.patch
yymerge diff old.txt new.txt --encoding CP932
yymerge merge --base base.txt --left ours.txt --right theirs.txt --output merged.txt
yymerge merge --base base.txt --left ours.txt --right theirs.txt --output conflict.txt --conflict-markers
yymerge folders before after --recursive --format json --report folders.json
yymerge gui --left left.txt --right right.txt --wait
yymerge gui --base base.txt --left ours.txt --right theirs.txt --output merged.txt --wait
yymerge --help
yymerge merge --help
```

既存出力を置き換えるには`--overwrite`が必要です。競合のあるCLIマージは既定で出力を変更しません。`--conflict-markers`を指定したときだけBASEを含む競合マーカー付きファイルを出力し、終了コードは1です。CLIは対話入力を要求しません。

UnifiedはUTF-8、BOMなし、LF改行だけが対象で、ファイル全体を1ハンクとして出力します。ヘッダーの名前は固定の`a/left` / `b/right`です。別の改行や文字コードのファイルにはJSONレポートを使ってください。JSONの行番号・範囲は0始まり、範囲の終点は含みません。

| 終了コード | 意味 |
|---|---|
| 0 | 完全一致、競合なしの保存完了、または待機なしGUIの起動成功 |
| 1 | 相違あり、または未解決競合 |
| 2 | I/Oエラー、未対応形式、比較未完了 |
| 64 | 引数の誤り |
| 130 | GUIマージを保存せず終了、または取消 |

`gui --wait`は画面を閉じるまで待ちます。マージを未保存で閉じると130、保存後に閉じると0です。比較画面は一致0 / 相違1です。`yymergew.exe`にも`gui`を除いた同じオプションを渡せます。

## フォルダー比較 {#folders}

CLIの`folders`はファイルの内容をチャンク単位でバイト比較します。更新日時やサイズだけで「一致」と判定しません。`--recursive`で子フォルダーも調べます。隠しファイルも含めます。読み取り不能はエラーです。シンボリックリンク、Windowsのジャンクション等のリパースポイントは追跡せず、比較未完了（2）を返します。1ツリー10万項目、深さ128階層が上限です。レポートは比較対象の外へ保存してください。走査中のツリー全体の整合性を固定するスナップショット機能はありません。

GUIフォルダー比較、3方向フォルダー比較、同期計画・実行、Git専用アダプター、ルール設定、表・構造化データ・画像・バイナリー比較、ZIP / SFTP / Office / PDFは未実装です。未対応コマンドは引数エラーとして扱います。
