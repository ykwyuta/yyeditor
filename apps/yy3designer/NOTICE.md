# Third-party components

YY3Designer is part of the yy series, GPL-3.0-or-later. See the repository's COPYING and COPYING.EXCEPTION.

The bundled UDEV Gothic font is under SIL Open Font License 1.1; see LICENSE-UDEVGothic.txt in the distribution. Help uses the existing yy-ui-win/yy-preview components, Microsoft Edge WebView2 when available, and their bundled assets and notices. The executable also contains the existing plain-text help fallback.

Rust dependencies are recorded in Cargo.lock (serde, serde_json, png, miniz_oxide, tempfile and the yy UI dependencies). Icon assets are generated locally from the yy series' icon generator; no external image or icon collection is included.
