# YY3Designer ヘルプ {#top}

YY3Designerは、ドット絵を編集して厚みを持たせ、最大6方向から立体を調整するWindowsアプリです。

## はじめに {#start}

1. 初期状態は幅32・高さ32・厚み8のオブジェクトです。左側で寸法を指定し「寸法変更」を押します。「画像も拡縮」は既存の各方向のドット絵も最近傍法で拡大縮小します。
2. 「鉛筆」を選び、上部のパレットから色を選んで左のキャンバスに描きます。背景の市松模様は透明です。
3. マウスを離すと右側に3Dが反映されます。3Dはドラッグで回転、ホイールでズームできます。プレビュー上部の「正面・背面・左面・右面・上面・下面・斜め」で決まった角度へ戻せます。どのボタンでもズームを標準に戻します。「斜め」は正面・右面・上面を同時に見る角度です。見出しには現在の方向を表示し、ドラッグ後は「自由回転」と表示します。
4. ファイル → 保存で`.yy3d`プロジェクトとして保存します。

左の設定欄は縦にスクロールできます。画面が狭いときはドット絵と3Dを上下に配置します。フォントはyyシリーズの共通設定と同梱UDEV Gothicを利用します。

## ドット絵の編集 {#pixels}

鉛筆・消しゴム・塗りつぶし・スポイト・直線・四角形・楕円・範囲選択を使えます。筆幅は1〜16。「図形を塗る」は四角形・楕円に適用します。消しゴムは透明に戻します。線や図形はドラッグ中に確認し、マウスを離して確定します。ひと筆を1回のUndoで取り消せます。

範囲選択後はその範囲だけを描画・塗りつぶし・消去・反転できます。コピーと貼り付けはYY3Designerの独自クリップボード形式で、透明度を保ち、別のオブジェクトや別プロセスにも貼り付けられます。選択範囲がなければ全体をコピーし、貼り付け先は左上になります。貼り付け先の画像からはみ出す部分は切り取ります。90度回転も範囲左上を基準とし、はみ出す部分は切り取ります。

キャンバスは中ボタンのドラッグで移動、ホイールでマウス位置を中心に拡大縮小します。表示 →「全体を表示」（F）で画面内に収めます。右クリックでスポイトとして色を取得できます。色欄は`RRGGBB`または`RRGGBBAA`（16進数）を入力して「適用」。カラーパレットからも変更できます。上部パレットを右クリックすると、その位置を現在の色に置き換えます。「色 ▶」で32色ずつページを切り替え、最大256色を選べます。

## 部分的に厚みを削る・戻す {#sculpt}

オブジェクト全体の厚みを変更する場合は左の「厚み」と「寸法変更」を使います。一部分だけを薄くする場合は、次のように操作します。

1. 左側で削る方向（正面・背面・左右・上下）を選びます。
2. ツールで「厚みを削る」を選ぶか、キャンバスにフォーカスしてTを押します。ドット絵の代わりに、残りの厚みを青色で表示します。濃い青は薄く、薄い青は厚い部分です。十分に拡大すると各ドットに厚みの数値も表示します。マウスを重ねると下部にも残りの厚みが出ます。
3. 左ボタンでなぞると、選択方向の手前側から1ボクセルずつ削ります。同じ場所をひと筆で何度通っても1段だけです。さらに削るときはマウスを離してもう一度なぞります。筆幅と範囲選択も使えます。0まで削ると、その方向の視線上は空になります。
4. 元へ戻す場合は「厚みを戻す」（U）でなぞります。その視線上で削った位置をすべて戻します。全体を元へ戻す場合はオブジェクト →「削った厚みをすべて戻す」を使います。

色やレイヤーの画素は変更しません。通常の鉛筆や消しゴムへ切り替えると元のドット絵に戻り、立体には削った状態が残ります。削る・戻す操作はひと筆単位でUndo／Redoでき、`.yy3d`に保存され、3DとOBJ出力にも反映します。3D表示はマウスを離すと更新されます。立体の手前にある実際のボクセルを削るため、背面からは反対側を削れます。削った位置はオブジェクト共通であり、編集レイヤーには依存しません。

「厚みを戻す」は削った位置を元へ戻す機能です。登録した方向画像の透明部分から新しい立体を盛り上げる機能ではありません。まだ使っていない方向を追加するときは、削る前の立体を基に方向画像を生成し、削った位置を別に保持します。

## レイヤーとオブジェクト {#layers}

オブジェクトメニューで追加・複製・削除します。オブジェクトごとに6方向の画像、寸法、丸み、アルファのしきい値を保存します。プレビューとエクスポートは現在のオブジェクトが対象です。

方向ごとに独立したレイヤーを持ちます。リストは上のレイヤーから表示します。レイヤーメニューで追加・複製・削除・上下移動・下との結合ができます。名前・不透明度（0〜255）・表示の変更は「適用」で確定します。描画は選択中のレイヤーが対象です。非表示のレイヤーは合成・立体生成に使いません。

## 写真・イラストから変換 {#import}

先に変換先の方向と寸法を決めます。設定欄下部で色数、最近傍、ディザリングを選び、ファイル →「写真・イラストをドット絵へ」を実行します。PNG・JPEG・BMP・GIF・TIFFなど、Windows Imaging Componentで読める画像の先頭フレームを読み込みます。

通常は面積平均で縮小し、透明色を考慮して輪郭の色にじみを抑えます。元がドット絵の場合は「最近傍」を選ぶとよいでしょう。減色は8〜256色または元の色を選択でき、ディザリングで中間色を表現できます。縦横比は指定した方向の寸法に合わせて変換します。変換結果は新しいレイヤーになるため、原画を残して比較・修正できます。背景の自動切り抜きや写真からの奥行き推定は行いません。

## 6方向と厚み {#views}

正面・背面・左面・右面・上面・下面の最大6枚を、1オブジェクトに登録できます。未使用の方向を選ぶと、現在の立体から投影したドット絵を生成します。生成した画像を編集するか、別の画像を取り込んで調整してください。「この方向を外す」でその方向の制約を除きます。少なくとも1方向は残します。

- 正面・背面は幅×高さ、左右は厚み×高さ、上下面は幅×厚みです。
- 各方向は外から見た向きで、背面は左右、左面は奥行き、下面は奥行きの見え方が反転します。
- 1枚だけなら、その画像の不透明なドットを対応する軸方向に押し出します。正面の場合、「厚み」の値が押し出し量です。
- 複数枚の場合、**登録したすべての方向で不透明になる場所の共通部分**を立体にします。透明なドットはその視線上を削り取ります。追加方向に何も描かなかったり、矛盾した輪郭を入れたりすると、立体が空になることがあります。
- アルファ値が「α」のしきい値以上のドットを使います（初期値128）。立体の色は登録方向のうち、そのボクセルに近い面の色を採用します。同距離の場合は正面・背面・左面・右面・上面・下面の順です。立体は不透明で、半透明の立体にはしません。

6枚の画像から一意の本物の形を復元する機能ではありません。輪郭の共通部分を使うため、方向画像から見えない凹みは表せません。

## 丸み {#roundness}

「丸み」に0〜100を入力して「丸み・αを適用」を押します。0は角のあるボクセル、値を大きくすると外側の角と辺が丸くなります。独立した1ドットは100で球に近い形です。元のドット絵は変えずに再調整できます。隣り合うドットの共有面には丸みを付けず、一つにつながった外表面として生成します。段差の内角や細い接続部分も分離しません。削ってできた表面にも同じルールを適用します。

「丸み付きドットをPNGへ」は1ドットを8×8画素に拡大し、外周の角を2Dの角丸として出力します。連続するドットの間に透明な溝は作りません。通常のPNG出力は元のドットと透明度を保ちます。

作例はリポジトリの`demo/yy3designer/examples.yy3d`（配布版では`examples/examples.yy3d`）を「開く」で読み込みます。オブジェクトの一覧から椅子・テーブル・子供・車・猫を選べます。それぞれ6方向の画像、厚みの削り情報、丸みを保存しているので、そのまま描画・厚みの調整ができます。`chair.yy3d`、`table.yy3d`、`child.yy3d`、`car.yy3d`、`cat.yy3d`は個別ファイルです。

## 保存と出力 {#files}

- `.yy3d`: マジック`YY3D`・バージョン1・展開後サイズと、zlib圧縮したUTF-8 JSONからなる独自バイナリです。全オブジェクト、各方向の全レイヤー・画素・名前・表示・不透明度、寸法、丸み、アルファしきい値、削った位置、パレット、選択中オブジェクト・レイヤーを保存します。オブジェクトの`carved`配列は削ったボクセルのインデックス`(z * 高さ + y) * 幅 + x`を昇順・重複なしで保持します。旧ファイルにこの配列がない場合は削っていない状態として読み込みます。画面のズームや範囲選択、Undo履歴は保存しません。読み込み時に版・寸法・配列長・削った位置を検証します。
- PNG: 現在の方向の表示レイヤーを合成して透過PNGとして出力します。
- OBJ + MTL: 現在のオブジェクトの三角形と色を出力します。OBJと同じフォルダーに生成する`yy3-*.mtl`も一緒に移動・配布してください。右手系、Y上、1ドット=1単位です。
- 3DプレビューPNG: 現在のカメラから1200×1000で描画します。

保存は同じフォルダーの一時ファイルへ書いてから置き換えます。編集中のプロジェクトを閉じる際には保存を確認します。

## 動作範囲 {#limits}

各辺1〜256、幅×高さ×厚みは最大2,097,152ボクセル、プロジェクトの全レイヤー合計4,194,304画素、64オブジェクト、各方向32レイヤーまでです。削った位置は全オブジェクト合計2,097,152件まで保持します。履歴は100操作か画素データ合計64MiBまで保持します。画像取り込みは4,000万画素・各辺16,384以下。3Dメッシュは最大200万三角形で、超える場合は寸法・厚みを減らすか丸みを下げます。プレビューは背景で生成し、カメラを動かすときは立体を再生成せず再描画します。

ヘルプは他のyyシリーズと共通のMarkdown表示を使います。WebView2が利用できない場合も、内蔵のテキスト表示でオフライン閲覧できます。
