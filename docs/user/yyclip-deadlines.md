# yyclipの期限・定期作業管理

yyclipの通知領域アイコンを右クリックし、「期限・定期作業を管理...」を開きます。
起動時にもこの画面を表示し、今日・明日期限の作業と期限超過の未完了作業を、期限順の一覧表で確認できます。
表示条件から「すべての未完了」「完了済み」に切り替えられます。

## 作業を登録する

「＋ 作業を追加」を押して登録フォームを開き、入力して「保存」を押します。
保存すると一覧画面へ戻ります。起動時は一覧を表示し、登録・編集フォームは操作時だけ開きます。

| 項目 | 設定 |
| --- | --- |
| タイトル | 必須。1～200文字 |
| 期限 | 必須。日付欄の▼からカレンダーを開いて選択し、「時」「分」のプルダウンで時刻を指定。24時間制、分は1分刻み。新規は当日18:00 |
| メモ | 任意。複数行、64 KiBまで |
| 通知間隔 | 任意。既定15分、最短5分。空欄も15分として保存 |
| 通知スタイル | 全ディスプレイの赤いアラート、Windows通知、両方。既定は両方 |
| 繰り返し | 単発、毎日、毎週、毎月 |
| 営業日補正 | 次の営業日へ（新規の既定）、前の営業日へ、補正しない。作業ごとに指定 |

一覧で作業を選び「編集」を押すか、ダブルクリックすると編集できます。変更後は「保存」を押します。
「← 一覧へ」で戻るとき、未保存の変更があれば確認を表示します。
「通知を試す」では入力中の設定で通知を表示し、作業の登録や通知済み時刻の変更は行いません。
初期サイズはディスプレイの作業領域とDPI・文字サイズに合わせます。
一覧の列幅はウィンドウ幅に合わせて調整し、狭い場合は繰り返し・通知間隔の列を省略します（編集画面で確認できます）。
編集フォームは広い画面では2列、狭い画面では縦に配置し、保存・一覧へ戻るボタンは画面下部に常に表示します。

## 休業日CSVと営業日補正

土日とCSV登録日を休業日、それ以外の平日を営業日として扱います。
期限が休業日と重なった場合、「前の営業日へ」は直前、「次の営業日へ」は直後の営業日へ自動で移します。時刻は変更しません。
補正後の日時はフォームの「保存後の期限」で確認でき、保存後の一覧と通知にはその日時を使います。
編集時のカレンダーには補正前の指定日を戻すため、CSVや補正方向を変えても二重に日付がずれません。
既存データで補正方向が未設定の作業は「補正しない」として読み込みます。

初期設定には[日本の祝日CSV（2026～2031年）](../../apps/yyclip/data/japan-holidays-2026-2031.csv)を使用します。
配布ZIPには`yyclip-data`フォルダーとして同梱します。振替休日と祝日に挟まれた休日も収録します。会社の年末年始休業・お盆休業などは自動では追加しません。
2026・2027年分は[内閣府](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html)の公式CSVと照合済みです。
2028～2031年分は現行法と[国立天文台の予測](https://www.nao.ac.jp/faq/a0301.html)による予定で、正式発表や法改正で変わる場合があります。正式発表後はCSVを更新してください。

「休業日CSV」から、UTF-8（BOMの有無どちらも可）またはCP932のCSVを読み込めます。
1列目は`YYYY-MM-DD`、`YYYY/MM/DD`、`YYYYMMDD`のいずれかの日付、2列目は任意の名称です。先頭の`日付,名称`などの見出しは省略できます。

```csv
日付,名称
2026-11-03,文化の日
2026-12-30,会社の年末休業
2026-12-31,会社の年末休業
```

上記は形式の抜粋です。実際に登録するファイルには、対象年の祝日・会社の休業日をすべて含めてください。
登録すると、現在のCSVを差し替え、営業日補正を指定した未完了作業の期限を補正前の日付から計算し直します。完了済み作業は変更しません。
エラー時にはCSV・作業のどちらも保存しません。登録したCSV自体を後から編集しても自動では読み直さないため、もう一度登録してください。
重複日はまとめ、土日はCSVに記載しなくても休業日とします。CSVは4 MiB、登録日は100,000日までです。
対象期間はCSVの最初の年～最後の年です。その範囲外は祝日の欠落を避けるため、営業日補正の保存・次回計算時にエラーにしてCSV更新を求めます。

定期作業では、補正前の曜日・日付と時刻を基準に次回を計算してから営業日へ補正します。
毎月末の作業が前営業日に移動しても翌月の基準日は月末のままです。複数回分が同じ営業日に重なる場合は、その回の完了後に同じ日時の通知を重ねず次の期限へ進みます。

## 通知と完了

期限当日の朝9:00から、完了まで指定間隔で通知します。9:00より早い期限は期限時刻から開始します。
期限を過ぎても通知を続けます。yyclipは約30秒ごとに確認するため、通知時刻には最大約30秒の差が生じます。
日時はWindowsのローカル時刻です。通知間隔の計測は実時間で行います。

- **赤いアラート**：現在接続中の全ディスプレイの作業領域右上に表示します。入力フォーカスを奪わず、
  コンパクトな表示で先頭の作業のタイトル・期限と件数を確認できます。
  「一覧・完了」で管理画面を開けます。「閉じる」で一時的に閉じても、次回の通知は止まりません。
- **Windows通知**：yyclipの通知領域アイコンからWindows標準通知を表示します。クリックすると管理画面を開きます。
  表示位置・履歴・通知音・集中モードでの抑制はWindowsの設定に従います。アプリからタスクバー左端などの位置は指定しません。

管理画面の一覧で対象を選び、「完了／再開」を押すと通知が止まります。
単発作業は「完了済み」に移ります。完了済みの作業を選び、同じボタンで未完了に戻すこともできます。
「削除」は作業を削除し、定期作業の場合は今後の通知も停止します。

yyclipの終了中やWindowsのスリープ中は通知しません。次回起動・復帰時に対象を確認します。
yyclipを再起動すると、前回の通知から指定間隔が経過していなくても、通知対象の未完了作業を直後に再表示します。
その後は設定した間隔で繰り返します。翌日期限など、まだ通知開始前の作業は一覧に表示するだけです。

## 定期作業

最初の期限を基準に、毎日は同じ時刻、毎週は同じ曜日・時刻、毎月は同じ日・時刻で繰り返します。
毎月29～31日を指定し、その日がない月は月末に補正します。次の月には元の日付に戻します。

定期作業は「完了／再開」を押すと、次回の期限へ進みます。期限超過中でも、完了するまで現在の作業の通知を続けます。
何回分も期限を過ぎていた場合、完了時点より後の最初の予定へ進め、過去の未実施回を大量に生成しません。
次回期限の当日の朝になったら、また通知を始めます。

## 保存先

作業・メモ・繰り返し設定・完了状態・通知済み時刻・休業日カレンダー・補正前の期限と方向は `%APPDATA%\yyclip\deadlines.json` に保存します。
保存に失敗した場合は編集を確定せずエラーを表示します。バックアップはyyclip終了後にこのファイルをコピーしてください。
形式が壊れている場合は、原文を上書きせず読み込みエラーを表示します。
