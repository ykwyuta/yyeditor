# バイナリテンプレート

バイナリの構造をC風のテンプレートで定義し、フィールドの名前・型・バイト位置・長さ・値を階層表示します。
「ファイル → バイナリとして開く」で対象を開き、「表示 → バイナリテンプレート...」を選びます。
通常のテキスト表示からも選べますが、文字コードの変換が必要な場合はバイト列のまま開き直します。

## 使い方

1. 左側（狭い画面では上側）にテンプレートを入力するか、「開く...」でUTF-8の`.yybt` / `.bt`を読み込みます。
2. 「解析する」を押します。現在の文書の未保存の編集も含めて解析します。ファイル自体は変更しません。
3. 結果の構造体・配列を展開して値を確認します。位置は0始まりの16進数、長さはバイト数です。
4. フィールドを選び「範囲を選択」を押すとダイアログを閉じ、16進数表示でその範囲を選択します。値の編集・Undo・保存は通常のバイナリ編集操作で行います。

テンプレートを変更した後は「解析する」で更新してください。エラー時は行番号と理由を表示し、古い結果からの移動を無効にします。
「保存...」でテンプレートを保存できます。最後に入力した内容はアプリ終了まで保持します。
「開く...」「サンプル」は入力欄を置き換えるため、必要な内容は先に保存してください。
「サンプル」を押すたびにBMP、WAV、単純なバイト列の定義へ切り替わります。

## テンプレートの例

```c
LittleEndian();
typedef struct {
    char signature[4];
    ushort count;
    uint entries[count];
} HEADER;
HEADER header;
if (header.count > 0) {
    uchar flags;
}
```

宣言順にバイトを読み進めます。構造体のアラインメントやパディングは自動挿入しません。
同じ位置を複数の型で読むには`union`または`FSeek`を使います。

| 機能 | 対応する構文 |
| --- | --- |
| 整数 | `char`, `uchar`, `byte`, `short`, `ushort`, `int`, `uint`, `long`, `ulong`, `int64`, `uint64`と`int8`～`uint64_t`の別名。`long`は4バイト |
| 符号指定 | `signed char/short/int/long`, `unsigned char/short/int/long` |
| 浮動小数点 | `float`（4バイト）, `double`（8バイト） |
| 配列 | `ushort values[10];`、既読の整数・配列要素・メンバーを使う長さの式 |
| 構造 | `struct NAME { ... }; NAME field;` / `typedef struct { ... } NAME;`、`union`、スカラーの`typedef` |
| 条件・繰り返し | `if/else`, `while`, `for(local int i=0; i<count; i++)`、`{ ... }` |
| ローカル整数 | `local int n = FTell();`、`=`, `+=`, `-=`, `++`, `--`による更新。ファイル上の変数への代入は不可 |
| 演算 | 整数の四則演算、剰余、比較、論理・ビット演算、括弧、10進・`0x`16進整数 |
| バイト順 | `LittleEndian();`（既定） / `BigEndian();`。宣言ごとにその時点のバイト順を使う |
| 位置 | `FSeek(offset);`, `FSkip(bytes);`, `FTell()`, `FileSize()`, `FEof()` |
| コメント | `// ...` / `/* ... */` |

`char`は1バイトの値として扱い、`char[]`にはUTF-8として解釈した文字列も表示します。不正なUTF-8は置換文字になります。
定義済みの整数は`header.count`や`values[0]`で参照できます。for/whileで同名フィールドを繰り返し宣言すると結果には各回が並び、整数参照は直近の値を指します。
local変数のスコープは構造体単位です。ブロックやforごとのC言語のスコープとは異なります。

## 制限

010 Editor Binary Templatesの基本的な書き方を参考にした機能です。010 Editorの`.bt`との完全互換ではありません。
列挙型、ビットフィールド、プリプロセッサ、文字列リテラル、ユーザー定義関数、属性、DLL呼び出しなどは未対応で、黙って読み飛ばさずエラーにします。
テンプレートから外部プログラムの起動やファイル書き込みは行いません。

テンプレートは1 MiB以下、結果はコンテナを含め20,000フィールドまでです。実行ステップと再帰・式の深さにも上限を設けています。
大きなデータ領域は1バイトずつ配列化する代わりに`FSkip(size);`で飛ばすと、ヘッダーだけを解析できます。
ファイル範囲外の読み取り、負の配列長、ゼロ除算などは解析エラーになります。

サンプル: [BMP](../../demo/binary-templates/bmp.yybt) / [WAV](../../demo/binary-templates/wav.yybt)。BMPはBITMAPINFOHEADER以降の主要ヘッダー、WAVはRIFFのチャンク位置とfmt基本項目を表示する例です。
