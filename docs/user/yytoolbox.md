# yytoolbox

正規表現・変換・テストデータ生成・日付と金額の計算・画面録画・簡易動画編集・画像処理をまとめたWindowsアプリです。
`yytoolbox.exe`を起動します。ネットワーク接続やWebView2は不要です。

## 使い方

1. 上部のツール一覧から機能を選び、条件と入力を指定します。
2. 「入力例」で試せる入力を読み込み、「実行」またはCtrl+Enterを押します。
3. 必要なら「結果をコピー」「結果を保存」で出力します。録画以外は「中止」またはEscで処理を中止できます。録画は小型バーの停止ボタンで保存します。

テキストの入力・結果は自動保存しません。録画・動画編集・画像処理は実行時に保存先を指定します。ツール切り替え・クリアでは入力と結果が消えます。
F1で[同梱ヘルプ](../../apps/yytoolbox/help/help.md)を開けます。対応構文・制限・計算条件・列定義の詳細は同梱ヘルプを参照してください。

右上の「−」「＋」またはCtrl＋/−で75〜200%の表示倍率を選べます。倍率ボタンまたはCtrl+0で100%に戻します。Ctrl+マウスホイールにも対応します。
小さい画面・拡大表示では条件と入出力が縦に並びます。画面右端のスクロールバーで全項目に移動でき、Tabで選んだ入力欄も自動で表示します。長い説明は折り返します。

| 分野 | 機能 |
| --- | --- |
| テキスト | 正規表現とキャプチャ、Base64標準／URL-safeエンコード・デコード |
| 検査 | MD5、SHA-1、SHA-224/256/384/512、BLAKE3、CRC32、JWTのヘッダー・ペイロード表示 |
| 整形 | JSON整形・圧縮、SQL整形、HTML・CSS・JavaScript整形 |
| 変換 | URLエンコード・デコード、XML／YAML／CSV／INIの相互変換 |
| QRコード | UTF-8テキストから生成、画面表示、SVG／PNG保存 |
| 録画・録音 | 全画面／矩形・時間指定MP4、音声のみのMP3保存、PC再生音とマイク、小型バーで途中保存、操作バーを録画から除外 |
| 動画編集 | 時間範囲を指定したカット・クリップ、複数範囲の連結、新規MP4保存 |
| 画像 | 複数画像のリサイズ、比率維持、指定色または透明背景による余白補完 |
| 生成 | 文字種の最低数と除外文字を指定するパスワード候補、YAML列定義によるダミーCSV |
| 計算 | 積立を含む複利、元利均等／元金均等の月次返済表 |
| 日付 | 和暦・西暦、満年齢と学年の対応、夏時間を反映する世界の時差一覧 |

JWTはデコード表示のみで署名を検証しません。パスワードはOSの暗号学的乱数、ダミーCSVはseedで再現するテスト用乱数を使います。
録画・画像処理はFFmpeg・ImageMagickに依存しません。録画はWindows標準のMedia FoundationとWASAPI、画像はRustの画像処理ライブラリを使用します。
相互変換の初期値は型・入れ子を保持する専用表現です。通常のXML・CSV・INIにしたい場合は「標準形式」を選びます。詳しい表現規則は同梱ヘルプを参照してください。
数値・キー順序を維持するJSON整形、金額の端数調整、改元日の境界、4月2日〜翌4月1日の学年区分を扱います。

## 音声だけを保存する

「画面録画・録音」の「保存する内容」を「音声のみ（MP3）」に変更し、PC再生音・マイク音のどちらか、または両方を「あり」にします。
「録音を開始」で保存先を指定すると、小型バーに切り替わります。指定時間（1〜3600秒）の経過または「停止して保存」で、その時点までをMP3へ保存します。Escでは停止しません。
画面範囲・fps・最大幅は無効になり、画面や映像トラックは保存しません。Pure Rustのエンコーダーで48kHz・ステレオ、VBR品質2のMP3へ逐次圧縮します。サイズは音の内容によって変わります。
保存先の指定は開始時の1回です。デバイスエラー時は既存ファイルを保持します。FFmpegなどの追加プログラムは不要です。

録音ゲインや音量の自動補正はありません。PC再生音は再生アプリの音量、マイクはWindowsの入力音量・ブースト設定が反映されます。
Windows全体の音量・ミュートの影響は機器に依存します。両方の音源を選ぶと各50%で混合します。

## ダミーCSVの定義を再利用する

「ダミーCSV」で分野を選び「入力例」を押すと、列ごとの名前・データ種・範囲・選択肢などのYAMLを読み込めます。
個人、企業、EC注文、医療、金融、物流、ITログ、IoTの8種類です。
[定義ファイルの作例](../../demo/yytoolbox/README.md)も「入力を開く」で使用できます。

`sequence`、`integer`、`decimal`、`date`、`datetime`、`choice`、`boolean`、`literal`、`uuid`、
氏名・企業名・メール・住所・部署・商品名・IPなどを組み合わせられます。`unique`で非空値の重複禁止、`null_percent`で空欄率を指定できます。
件数は画面上部の「行数（1〜100000）」で指定します。初期値は100件で、見出し行は数えません。
行数・seed・BOM・文字列の数式対策は画面の条件で指定し、「入力を保存」で列定義を `.yaml` に保存します。
同じアプリ版・定義・条件・seedなら同じ結果を生成します。ダミーの連絡先や番号は架空で、実在情報を取得しません。

## 計算の前提

複利・返済は一定の名目年率を期ごとの利率へ換算した試算です。税金、手数料、個別商品の条件を含みません。
年齢は誕生日を基準とし、2月29日生まれの非閏年の表示は3月1日で変わります。学年は標準進級の目安です。
和暦の年月日変換は1873年以降、時差は同梱IANA DBを使います。

計算・暦の参考資料: [Microsoft PMT](https://support.microsoft.com/en-us/excel/functions/pmt-function)、
[文部科学省・就学の取扱い](https://www.mext.go.jp/a_menu/shotou/shugaku/detail/1422233.htm)、
[国立天文台・暦の変更](https://www.nao.ac.jp/faq/a0307.html)。
