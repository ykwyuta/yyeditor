# アウトライン編集

yyeditor の「表示 → アウトライン編集」で、Workflowy のように項目を階層化して編集できます。
新規タブでこの表示を選び、「項目追加」で書き始め、Ctrl+S で `notes.yyoutline` などの名前で保存します。
保存したファイルを開いたときも「表示 → アウトライン編集」を選んでください。
[作例](../../demo/outline/example.yyoutline)も利用できます。

WebView2 が必要です。階層の深さに固定上限はありません。現在のライブ編集は、メタデータを含む文書全体で 1 MiB までです。

| 操作 | 方法 |
| --- | --- |
| 同じ階層に項目を追加 | Enter、または「項目追加」。選択した枝の後ろに追加 |
| 一段下の階層へ移動 | Tab、または「階層を下げる」。直前の兄弟項目の子になる |
| 一段上の階層へ移動 | Shift+Tab、または「階層を上げる」。親の枝の後ろへ移動 |
| 枝を上下に移動 | Alt+↑ / Alt+↓、または「上へ」「下へ」。子孫も一緒に移動 |
| 前後の表示項目を選択 | ↑ / ↓ |
| 子孫を折りたたむ・展開する | 項目左側の ▾ / ▸ |
| 特定の階層だけを表示 | ● をクリック。上部の経路や「全体」で戻る |
| ブックマークを登録・解除 | 項目を選択し「☆ ブックマーク」。左側の一覧からその階層を開く |
| 他の項目への参照を作成 | 「参照を追加」で参照先を選択。「↗ 項目名」で参照先へ移動 |
| 参照元を確認 | 選択中の項目を参照している項目を左側に表示 |
| 参照を解除 | 参照の横の ×。参照先の項目は残る |
| 枝を削除 | 「枝を削除」。子孫の件数を確認して削除 |
| 保存・元に戻す・やり直す | Ctrl+S / Ctrl+Z / Ctrl+Y。通常編集と同じ文書・履歴を使用 |

ズーム中の先頭項目で Enter を押すと、その階層の末尾に子項目を追加します。
項目の名前や位置を変更してもブックマークと参照先は維持されます。
参照先を削除すると「参照先なし」と表示します。Undo で項目を復元すると参照も再び利用できます。
参照は同じ文書内の項目へのリンクです。参照先の内容を複製したり、別ファイルと同期したりする機能はありません。

保存形式は `format: "yyoutline"`, `version: 1`, `nodes` を持つ JSON です。
`nodes` は表示順の平坦な配列で、各項目に安定した `id`、0 始まりの `depth`、
`text`、`bookmark`、`collapsed`、参照先 ID の配列 `refs` を保存します。
折りたたみ状態とブックマークも文書内に保存するため、ファイルの移動後も利用できます。
ズームと選択位置は表示中だけの状態です。

「通常編集に戻る」で JSON 原文を確認できます。普通のテキストや Markdown を自動変換する機能はありません。
形式や ID・階層が不正なファイルはエラーを表示し、原文を保持します。読み取り専用ファイルでは編集を無効にします。
