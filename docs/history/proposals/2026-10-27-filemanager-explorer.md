# yyfilemanager の拡張: エクスプローラーの代替・フラットビュー・一括リネーム・圧縮ファイル

2026-10-27。対象は yyfilemanager（[18 章](18-filemanager.md)の続き）。
現行の使い方は[同梱ヘルプ](../../../crates/yy-win/help/filemanager.md)。

## 1. 要求

| # | 要求 |
|---|------|
| F1 | エクスプローラーの完全な代替ができるように基本機能を揃える |
| F2 | フラットビュー: 選んだフォルダの下のすべてのサブフォルダのファイルを、階層を無視して 1 つの一覧に出す。深い場所のファイルを探し、まとめて移動・整理できる |
| F3 | 強力な一括リネームと検索: 正規表現・メタデータ（Exif・音楽のタグ・文書の属性）・連番・スクリプトを組み合わせる。変更後の名前をその場で確かめながら安全に処理する |
| F4 | 圧縮ファイルを展開せずに中を確かめる |

## 2. 現状（2026-10-27）

yyfilemanager は同期・検索・似たファイル・重複・削除の確認・記録の 6 つのタブを持つ作業用のアプリで、
フォルダを開いて見る画面がない。ツリー・アドレスバー・戻る/進む・アイコン・並べ替え・名前の変更・新しい
フォルダ・コピー/移動・ファイルのクリップボード・ドラッグ＆ドロップ・シェルの右クリック メニュー・
プロパティのいずれもない。メタデータの読み取り・一括リネーム・圧縮ファイルの一覧もない
（Office の文字列を読むための小さな ZIP 読み取りだけがある）。

## 3. 構成

- 新しいタブ「フォルダ」を先頭に置き、起動したときに開く。タブの中は自分の子ウィンドウ
  （`yy-win/src/fm/browse.rs`）で、ツリー・アドレスバー・一覧・状態を自分で並べる。既存のタブは変えない。
- OS に依らない部分は `yy-files` に置き、Linux の CI で試験する。
  - `yy_files::archive`: ZIP（ZIP64・UTF-8 の名前・CP932 の名前・暗号化の印）、tar（ustar・GNU の長い
    名前・pax）、tar.gz・tgz・gz、tar.xz・txz・xz、7z（目次。LZMA で縮めた目次も）の一覧と、1 項目の展開。
  - `yy_files::props`: メタデータ。JPEG/TIFF の Exif、画像の縦横（JPEG・PNG・GIF・BMP・WebP）、
    MP3 の ID3v2/ID3v1、FLAC・Ogg の Vorbis コメント、MP4/M4A のタグ、Office（docx・xlsx・pptx）の
    `docProps/core.xml`、PDF の `/Info`。
  - `yy_files::rename`: 一括リネームの規則・プレビュー・確かめ・実行・取り消しの記録。
- 長い処理（フラットビューの走査、メタデータの読み取り、圧縮ファイルの一覧）は作業スレッドで行い、
  一覧へ少しずつ足す。ほかのタブの処理（同期など）とは別に動かせる。

## 4. エクスプローラーの基本機能（F1）

| 分類 | 機能 |
|---|---|
| 移動 | アドレスバー（パスを打つ・貼る、Enter で移動、`%USERPROFILE%` などの環境変数）、戻る・進む・上へ（Alt+←・Alt+→・Alt+↑・Backspace）、最新の情報に更新（F5）、左のツリー（よく使うフォルダ・PC のドライブ・ネットワークの場所、子フォルダは開いたときに読む） |
| よく使うフォルダ | デスクトップ・ダウンロード・ドキュメント・ピクチャ・ミュージック・ビデオと、ピン留めしたフォルダ（右クリックで足す・外す。設定に保存） |
| 一覧 | 詳細（名前・フォルダ・大きさ・種類・更新日時・作成日時・属性）、システムのアイコン、列の見出しで並べ替え（フォルダが先、自然順）、表示形式（詳細・一覧・大きいアイコン）、隠しファイルの表示の切り替え、拡張子の表示 |
| 選ぶ | 複数選択、すべて選ぶ（Ctrl+A）、選び直す（反転）、名前の頭文字で移る |
| 絞り込み | 一覧の上の欄に入れた文字で絞り込む（検索の書き方は 6 章） |
| 開く | Enter・ダブルクリック（フォルダは中へ、圧縮ファイルは中へ、ほかは関連付け）、プログラムから開く、yyeditor で開く、ターミナル（yyterm）で開く、エクスプローラーで開く |
| 操作 | 名前の変更（F2・その場で）、新しいフォルダ（Ctrl+Shift+N）、削除（Del はごみ箱、Shift+Del は完全に）、切り取り・コピー・貼り付け（Ctrl+X・C・V。エクスプローラーとファイルをやり取りする `CF_HDROP` と「優先する動作」）、ドラッグ＆ドロップ（外へ出す・外から受ける。Shift で移動・Ctrl でコピー）、パスのコピー |
| コピー・移動 | Windows の `IFileOperation` を使う（エクスプローラーと同じ進み・衝突の確かめ・ごみ箱・取り消し） |
| シェル | 右クリックでシェルのメニュー（Shift でその拡張）を、yyfilemanager の項目と一緒に出す。プロパティ（Alt+Enter） |
| 状態 | 項目の数、選んだ数と大きさの合計、空き容量 |

サムネイル表示・プレビューの欄・タブで複数のフォルダを開くことは、この段階では作らない（14 章）。

## 5. フラットビュー（F2）

- ツールバーの「フラット」（Ctrl+Shift+F）を押すと、いま開いているフォルダの下のすべてのファイルを
  1 つの一覧に出す。「フォルダ」の列に開いているフォルダからの相対パスを出す。
- 走査は `yy_files::scan` で作業スレッドが行い、見つけた順に一覧へ足す（数十万件でも仮想リスト）。
  Esc で止められ、止めたところまでの結果を使える。隠しファイル・システム ファイルは表示の設定に従う。
- フォルダも出すか（既定では出さない）を切り替えられる。
- 並べ替え・絞り込み・開く・削除・コピー・切り取り・ドラッグ・一括リネームは通常の一覧と同じ。
- 「選んだものを移動...」「選んだものをコピー...」で、選んだファイルを 1 つのフォルダへまとめて送る
  （`IFileOperation`。同じ名前は Windows の確かめに従う）。
- 圧縮ファイルの中でも使える（中の全部の項目を 1 つの一覧に）。

## 6. 検索（F3 の検索）

一覧の上の絞り込み欄は、検索のタブ（18 章 8）と同じ書き方に、メタデータの条件を足して使う。

- 文字だけ: 名前に含む（大文字と小文字は区別しない。複数の語はすべてを含む）。`*`・`?` を使うと
  ワイルドカード、`re:` で正規表現（`re:^IMG_\d{4}\.jpe?g$`）。
- `ext:jpg,png`・`size:>1MB`・`modified:>=2026-01-01`・`created:<2025-01-01`・`type:folder`。
- メタデータ: `exif.model:EOS`・`exif.date:2024`・`id3.artist:"山田"`・`doc.author:佐藤`・
  `width:>=1920` など（`名前:値` は含む、`名前:>値` などで比べる）。メタデータの条件があると、その場で
  読み取る（作業スレッド。結果は覚えておく）。
- フラットビューと組み合わせると、深いフォルダ全体から探せる。

## 7. 一括リネーム（F3）

選んだ項目（フラットビューなら複数のフォルダにまたがってよい）に、上から順に次の処理を行う。

1. **置き換え**: 検索する文字（そのまま・正規表現）と置き換える文字。正規表現では `$1`・`${name}` で
   括弧の中を使う。対象（拡張子を除く名前・名前全体・拡張子）、大文字と小文字を区別するか、
   すべてか最初の 1 つか。
2. **ひな形**: 新しい名前を `{name}`（拡張子を除いた、置き換えの後の名前）・`{ext}`（`.jpg`）・`{n}`
   （連番）などで組み立てる。既定は `{name}{ext}`（変えない）。
   - 連番: `{n}`・`{n:3}`（3 桁で 0 を詰める）。始まり・増分、フォルダごとに振り直すか。
   - 元の情報: `{orig}`（元の名前）、`{parent}`（フォルダ名）、`{size}`、`{modified:%Y%m%d}`・
     `{created:%Y-%m-%d_%H%M%S}`（`strftime` 風の書式）。
   - メタデータ: `{exif.date:%Y%m%d}`・`{exif.model}`・`{exif.make}`・`{width}`・`{height}`・
     `{id3.artist}`・`{id3.album}`・`{id3.title}`・`{id3.track:2}`・`{id3.year}`・`{doc.title}`・
     `{doc.author}`・`{doc.created:%Y%m%d}` など。値がないときの代わり `{exif.model|不明}`。
   - 部分: `{name:1-8}`（1〜8 文字目）。
3. **大文字・小文字**: そのまま・すべて小文字・すべて大文字・語の頭だけ大文字・拡張子だけ小文字。
4. **スクリプト**（任意）: Rhai（3270 のマクロと同じ）。変数 `name`（ここまでの新しい名前）・`stem`・
   `ext`・`orig`・`n`・`index`・`folder`・`size`・`modified`・`meta`（メタデータの表）を読み、
   新しい名前を返す。ファイルの読み書き・外部のプログラムは使えない。1 項目あたりの演算の数に上限がある。

### 7.1 プレビューと確かめ

- 入力を変えるたびに（少し待ってから）全件の新しい名前を計算し、一覧に「元の名前・新しい名前・フォルダ・
  状態」を出す。変わる部分を強調する。メタデータは作業スレッドで読み、読めたものから反映する。
- 状態: 変わる・変わらない・**使えない名前**（`\ / : * ? " < > |`、制御文字、末尾の空白・`.`、`CON` など
  の予約名、長すぎる）・**重複**（この一括の中で同じ名前になる。大文字と小文字は区別しない）・
  **既にある**（一括に入っていない別のファイルと同じ名前）・スクリプトのエラー。
- 問題が 1 つでもあれば「実行」できない（問題のある項目を外して実行することは選べる）。

### 7.2 実行と取り消し

- 名前を入れ替える組（`a→b`・`b→a`）や連なり（`1→2`・`2→3`）でもぶつからないように、いったん全部を
  一時の名前（`.yyren-XXXX`）に変えてから新しい名前に変える 2 段で行う。
- 途中で失敗したら、そこまでの変更を元に戻す。
- 実行の記録（元のパス・新しいパス）を `logs\rename-日時.csv` に残し、「元に戻す」で記録から戻す。
  大文字と小文字だけを変えるときも Windows で正しく変わる（2 段なので）。
- 既定ではファイルとフォルダの両方を対象にできる。フォルダの名前を変えたときは、その中の項目の
  パスも更新する（フラットビューで同じ一括に入っている場合）。

## 8. 圧縮ファイル（F4）

- 一覧で圧縮ファイルを開く（Enter・ダブルクリック）と、フォルダと同じように中に入る。アドレスバーは
  `C:\work\資料.zip\図\` のように出す。展開はしない（目次だけを読む）。
- 列: 名前・フォルダ・大きさ・圧縮後・圧縮率・方式・更新日時・暗号化。
- 中のファイルを開くと、その 1 つだけを一時フォルダに展開して関連付けで開く（読み取り専用）。
  「展開してコピー...」で選んだ項目（フォルダはその中ごと）を選んだ場所へ展開する。
  ドラッグで外へ出すときも同じ（いったん一時フォルダに展開してから渡す）。
- 対応する形式と展開:

| 形式 | 一覧 | 展開 |
|---|---|---|
| ZIP（`.zip` など。ZIP64、UTF-8・CP932 の名前） | ○ | 無圧縮・Deflate。暗号化と他の方式（Deflate64・BZip2・LZMA など）は一覧だけ |
| tar・tar.gz・tgz・tar.xz・txz | ○ | ○ |
| gz・xz（1 ファイル） | ○（中の名前） | ○ |
| 7z | ○（LZMA で縮めた目次も） | 無圧縮・LZMA・LZMA2（フィルターなしのフォルダ）。ほかは一覧だけ |

- xz と 7z の LZMA2 は、使うライブラリ（`lzma-rs`）が展開した全体をメモリに持つため、展開後 1 GB までに限る
  （tar.xz の一覧も同じ）。
- 圧縮ファイルの中の圧縮ファイルは、一時フォルダに展開してから中に入る。
- 中への書き込み（足す・消す・名前を変える）はしない。
- 壊れた・悪意のある圧縮ファイルに備え、目次の項目数・名前の長さ・展開後の大きさに上限を持ち、
  展開先が展開先のフォルダの外に出る名前（`..`・絶対パス）は拒む。

## 9. 依存するクレート

- 追加: `lzma-rs`（xz・7z の LZMA/LZMA2。Rust だけで書かれている）、`rhai`（スクリプト。既に
  3270 のマクロで使っている版）、`encoding_rs`（CP932 の名前。既にワークスペースにある）。
- ZIP・tar・gzip・Exif・ID3・MP4・Office・PDF の読み取りは小さな自前の実装（既存の `miniz_oxide`）。

## 10. 設定（`[filemanager]` に足す）

| 項目 | 既定 | 意味 |
|---|---|---|
| `pinned` | `[]` | よく使うフォルダにピン留めしたフォルダ |
| `show_hidden` | `false` | 隠しファイル・システム ファイルを出す |
| `show_extensions` | `true` | 拡張子を出す |
| `view` | `"details"` | 表示形式 |
| `flat_folders` | `false` | フラットビューにフォルダも出す |
| `start_folder` | `""` | 起動したときに開くフォルダ（空なら前回の場所） |

## 11. 試験

- `yy_files::archive`: 作った ZIP（Deflate・無圧縮・ZIP64・CP932/UTF-8 の名前・暗号化の印・ディレクトリ）、
  tar（長い名前・pax・GNU）、gz・xz、7z（無圧縮・LZMA の目次）の一覧と展開、壊れたデータ・`..` の名前の拒否。
- `yy_files::props`: 作った JPEG（Exif の日時・機種・縦横）、PNG、ID3v2.3/2.4・ID3v1、FLAC、M4A、
  docx の core.xml、PDF の `/Info`（UTF-16・PDFDocEncoding）。
- `yy_files::rename`: ひな形・正規表現の置き換え・連番（フォルダごと）・日付の書式・メタデータ・
  大文字と小文字・スクリプト、使えない名前・重複・既にある名前の検出、入れ替え・連なりの実行、
  途中で失敗したときの巻き戻し、記録からの取り消し、大文字と小文字だけの変更。
- 検索の条件（メタデータの比べ方）。
- 画面は Windows の CI で型検査と起動の試験。

## 12. 実装の段階

1. この提案。
2. `yy-files` の `archive`・`props`・`rename` と試験。
3. 「フォルダ」のタブ: ツリー・アドレスバー・履歴・一覧（アイコン・並べ替え・絞り込み）・フラットビュー・
   圧縮ファイルの中・シェルの操作。
4. 一括リネームの画面（プレビュー）。
5. ヘルプ・利用者向けの文書・設定。

## 13. 決めたこと

- 依頼に「リリース後」とあるため、既存のタブ（同期など）の動きは変えず、追加だけで実現する。
- コピー・移動・削除は自前の処理ではなく `IFileOperation`（エクスプローラーと同じ確かめ・取り消し）を使う。
  同期のタブの自前のコピー（レジューム付き）はそのまま。

## 14. 今回はしないこと

- サムネイル表示・プレビューの欄・タブでの複数フォルダ・2 画面。
- 圧縮ファイルの作成・中への書き込み、RAR の一覧（形式の権利のため）。
- SSH 先のフォルダ（yysftp の役目のまま）。

## 15. 実装の状況（2026-10-28）

- 2〜5 章の段階をすべて実装した（`yy_files::archive`・`props`・`rename`・検索のメタデータの条件、
  `yy-win/src/fm/browse.rs`・`shell.rs`・`renamedlg.rs`、ヘルプ）。
- 10 章の設定は、利用者が編集する `config.toml` ではなく、画面の状態として `filemanager\folders.toml`
  （`yy_files::jobs::BrowseState`）に置いた。`start_folder` は作らず、前回の場所を開く。
- 試験: 中核は Linux で `cargo test -p yy-files`。zip・Python の zipfile（ZIP64）・GNU tar（gnu・pax）・gzip・
  xz（複数ブロック）で作った圧縮ファイルと、ffmpeg で作った MP3・FLAC・M4A・Ogg・Opus・PNG・JPEG・WebP・MP4 を
  読めることを確かめた（7z は試験の中で作ったもの。7-Zip で作ったものはこの環境では確かめていない）。
  画面は Windows の CI で型検査とアドレスの解釈の試験だけで、操作の試験はない。
