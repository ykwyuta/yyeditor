# SSH接続先GUI・SFTP/SCP検証（2026-10-25）

## 実施範囲

- Windows: yy-config全27件成功（設定保存・legacy優先順位・削除・12同時更新を含む）。
- Windows: yy-winの実ネイティブ設定ダイアログ巡回・設定保持2件、remote設定ポリシー3件成功。
- Windows: yy-ssh単体5件、実SSHソケットの模擬ゲートウェイ2件成功。
- Docker / Rust 1.99.0 / Debian bookworm: yy-config27件、yy-remote73件と結合2件、yy-ssh5件とgateway2件成功。
- LinuxのFileAccess検証は実 `scp` とOpenSSH `sftp-server` を使用。選択外の方式の呼び出しをassertで禁止し、2MiB全バイト値、日本語・引用符入りパス、元ファイル保持、競合・キャンセル、リンク拒否、一時ファイル回収を確認。
- 基本アクセス権の明示的復元を追加後、FileAccessのSCP/SFTP2件を再実施し成功（0640を保持）。
- Linux: yy-config / yy-remote / yy-sshのall-targets Clippy成功。
- Windows: ルート、yymerge、yydbmanager、YY3Designerのall-targets Clippy成功。独立ワークスペースのロックも更新。
- yyeditor / yyterm / yysftpのWindowsビルド成功。

## 結果の限界

模擬ゲートウェイでは、direct-tcpipと中継exec、サブシステム／SFTP起動、複数段keyboard-interactive、
PTYなしshell起動と開始前バナーの除去を検証した。NRI製品の独自実装を再現したものではない。
SecureCube Access Check／Essential実機との接続・転送は未検証。
現時点でWinSCPのSSH設定全項目と同等とはしていない。残件は[対応表](../proposals/2026-10-25-ssh-site-settings.md)を参照。
