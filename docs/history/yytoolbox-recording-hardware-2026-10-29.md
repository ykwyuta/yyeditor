# yytoolbox 実画面・実音声収録の検証（2026-10-29）

Windowsの対話デスクトップで `recording::hardware_tests` を明示実行した結果。FFmpeg・ImageMagickは使用していない。

| 対象 | 結果 | 根拠 |
| --- | --- | --- |
| メイン画面全体 | 成功 | 2秒、640×360のMP4を生成、30デコードフレーム、最終時刻1.933秒 |
| 指定矩形 | 成功 | 実デスクトップの640×360矩形を2秒収録、30フレームをデコード |
| PC再生音 | 成功 | 523.25Hzの確認音を実際の既定出力へ再生。WASAPIから49,920サンプル、RMS 1412。録画AACをPCMへデコードしRMS 1395、最終時刻1.984秒 |
| 自画面の除外・復元 | 成功 | 自スレッドの可視テストウィンドウをUiGuardで非表示、実GDIキャプチャの画素が変わり、終了後に可視状態を復元 |
| Esc中止 | 成功 | SendInputの実Esc入力からWM_HOTKEYを受信し録画中止。既存保存先の内容を保持 |
| マイク | 未完了（試験失敗） | 既定入力取得が0x80070490（要素が見つからない）。登録24入力エンドポイントはすべて無効・未接続・存在しない状態のいずれかで、有効な入力がない |

サンドボックス内ではグローバルEsc登録がアクセス拒否となった。通常デスクトップ権限で再実行したところ、除外・Esc試験は成功した。マイクは同じ権限で再実行しても取得できなかった。マイクを接続してWindowsの既定入力として認識させた環境で再検証が必要。

ログは `target/recording-hardware-test-unsandboxed.log`、動画は `target/recording-hardware/{fullscreen,rectangle,system-audio}.mp4`（Git管理外）。矩形選択のドラッグ操作、マイクとPC再生音の同時ミックス、長時間の同期、複数ディスプレイ・保護コンテンツまでは検証していない。

実行手順は[開発者向け説明](../developer/yytoolbox.md)を参照。これらは実デバイスを必要とする明示実行試験で、CIの合成映像・音声の回帰試験とは分けている。
