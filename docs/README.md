# 文書案内

| 読みたいこと | 入口 | 内容 |
| --- | --- | --- |
| アプリを使う | [利用者向け](user/README.md) | 起動、設定、操作、入出力、現在の制限、作例 |
| 実装・保守する | [開発者向け](developer/README.md) | ビルド、内部構成、保存形式の実装、共有ライブラリ、テスト、CI、素材生成 |
| 検討理由・作業結果を調べる | [検討経緯・作業記録](history/README.md) | 提案、未完了項目、レビュー、検証結果、測定値、CI障害分析 |

READMEは現在の用途と入口を示します。現在の操作仕様は利用者向けガイドと同梱ヘルプ、
現在の内部仕様は開発者向け文書とリンク先のソースを参照してください。
履歴の数値や完了状況は記録時点のもので、現在の対応状況の保証には使いません。

アプリ内ヘルプの原稿は実行ファイルへの埋め込み・配布のため、各アプリまたは`crates/yy-win/help/`に置きます。
デモのREADMEはデータや設定例と隣接させ、利用者向け索引から案内します。
COPYING、NOTICE、第三者ライセンスは頒布に必要な元の配置を保ちます。
