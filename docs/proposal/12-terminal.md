# 12. ターミナル（yyterm）

エディタとは別のアプリとして、同じクレートを使ったターミナル **yyterm** を作ります（2026-10-06 追加）。

## 1. 要求

| # | 要求 | 対応 |
|---|------|------|
| T1 | エディタと別のアプリ（`yyterm.exe`）。エディタのクレートをできるだけ使い回す | 3 |
| T2 | ワークスペース（エディタと同じ `*.yyworkspace`。手元とリモートのフォルダ） | 6 |
| T3 | 埋め込みフォントはエディタと同じ（UDEV Gothic） | 5 |
| T4 | OpenSSH に依存しない SSH（エディタと同じ組み込みの SSH） | 4.2 |
| T5 | ポートフォワーディング（失敗しても警告だけで接続は続ける。エディタ・ファイル転送は無視する） | 4.3 |

## 2. 全体構成

```
apps/yyterm ──► yy-win::run_terminal ──┬─ term/mod.rs     フレーム・タブ・入力・メニュー
                                       ├─ term/paint.rs   Direct2D / DirectWrite で格子に描く
                                       ├─ term/pty.rs     ConPTY（手元）と SSH の端末つきチャネル
                                       └─ term/sidebar.rs ワークスペースのツリー
                 ▲                           │
                 │                           ├─ yy-term    制御シーケンスの解釈・画面・スクロールバック（OS 非依存）
                 │                           ├─ yy-config  設定（[terminal]）・ワークスペース
                 │                           ├─ yy-remote  接続設定の解決・ホスト鍵・接続の記録・Transport::shell
 yy-ssh（russh）─┘                           └─ yy-win の部品（同梱フォント、ダイアログ、資格情報マネージャー、IME）
```

- 端末エミュレーションの中核は新しいクレート **`yy-term`**（OS 非依存。Linux の CI でテストする）。
- UI は `yy-win` の中の `term` モジュール。エディタの部品（同梱フォントの登録・フォールバックの解決、
  接続中の問い合わせのダイアログ、ホスト鍵の確認、パスワード保存、リモートのフォルダの選択、
  フォルダ・ワークスペースのファイルの選択、IME の位置合わせ、クリップボード）をそのまま使う。
- リモート接続の状態（接続設定、接続済みのセッション、問い合わせの受け手）は、エディタの `App` から
  切り離してスレッドごとの状態にした（`remote::install` で、どちらのアプリも同じ口で使う）。
- 設定ファイル（`config.toml`）、接続設定・`~/.ssh/config`・known_hosts、保存したパスワード、
  接続の記録（`logs\remote-ssh.log`）はエディタと共通。

## 3. 端末エミュレーション（`yy-term`）

- 構文は DEC VT500 系の状態遷移（Paul Williams の状態図）。UTF-8 のみ。C0、ESC、CSI（引数・サブ引数・
  private の印・中間文字）、OSC（タイトル 0・2）、DCS・SOS・PM・APC は読み飛ばす。CAN・SUB で中止。
- 画面: 行（セルの並びと「折り返して次の行へ続く」印）、全角（2 セル目は継続のセル）、結合文字は直前の
  セルに付ける、スクロール範囲、代替画面（`?47`・`?1047`・`?1049`。代替画面のスクロールは
  スクロールバックに入れない）、タブ位置、DEC の罫線文字（`ESC ( 0`）。
- SGR: 太字・薄字・斜体・下線（二重下線・`4:x`）・点滅・反転・非表示・取り消し線、16 色・256 色・
  24 ビット色（`38;2;r;g;b` と `38:2::r:g:b`）。消去はその時点の背景色で塗る。
- 応答: カーソル位置（`6n`）、状態（`5n`）、端末の種類（`c`・`>c`）。
- モード: カーソルキー（`?1`）、ブラケット ペースト（`?2004`）、マウス（`?9`・`?1000`・`?1002`・
  `?1003`、SGR 形式 `?1006`）、フォーカスの報告（`?1004`）、カーソルの表示と形（`?25`、`DECSCUSR`）、
  自動折り返し、origin、挿入、改行モード、画面の反転。
- スクロールバックは行数の上限まで（設定 `scrollback`）。行には通し番号（捨てた行の数＋位置）を振り、
  選択範囲とスクロール位置はこの番号で持つ（出力が続いても、さかのぼって見ている行がずれない）。
- 大きさの変更では折り返しをやり直さない。行を減らすときはカーソルより下の空行から消し、残りは
  上からスクロールバックへ。増やすときはスクロールバックから戻す。
- 選択範囲の文字列（折り返した行はつなぐ、行末の空白は除く）と、単語の範囲（ダブルクリック）。
- キー・貼り付け・マウスの送り方は xterm と同じ（`keys` モジュール）。ブラケット ペーストでは、
  貼り付ける文字列から ESC と終わりの印を取り除いて、貼り付けの外に出られないようにする。

## 4. シェル

### 4.1 手元（ConPTY）

- Windows 10 1809 以降の疑似コンソール（`CreatePseudoConsole`）。シェルは設定 `[terminal] shell`、
  空なら PowerShell 7（`pwsh.exe`）、なければ Windows PowerShell、なければコマンド プロンプト。
- 親の標準入出力を引き継がないよう `STARTF_USESTDHANDLES` に無効なハンドルを入れて起動する。
- シェルが終わっても疑似コンソールを閉じるまで出力のパイプは閉じないので、終了を待つスレッドが
  `ClosePseudoConsole` を呼んでから、読み取り用のスレッドが最後まで読む。

### 4.2 SSH

- `Transport::shell(term, (桁, 行), command)` を追加した（`yy-ssh` は `pty-req`・`shell`／`exec`、
  大きさの変更は `window-change`、タブを閉じたらチャネルを閉じる）。標準エラー出力もまとめて流す。
- 接続はエディタと同じ（接続設定・踏み台・プロキシ・ホスト鍵・認証・接続の記録・パスワードの保存）。
  シェルにはエージェントを使わない（`remote::transport`。Linux 以外の接続先にも使える）。
  エディタのセッション（エージェント）があれば、その接続にチャネルを足す。
- フォルダを指定して開くときは `cd '<フォルダ>' && exec "${SHELL:-/bin/sh}" -l` を端末つきで実行する。
- `TERM` は設定 `term`（既定は `xterm-256color`）。

### 4.3 ポートフォワーディング（2026-10-06 追加）

- OpenSSH と同じ 3 種類: `-L`（手元のポート → 接続先から転送先へ。`direct-tcpip`）、`-R`（接続先の
  ポート → 手元から転送先へ。`tcpip-forward` を求め、開かれた `forwarded-tcpip` チャネルをポートで
  振り分ける。0 なら接続先が選ぶ）、`-D`（手元のポートを SOCKS 4・4a・5 の CONNECT のプロキシにする）。
  待ち受けるアドレスの既定は手元が 127.0.0.1、接続先が localhost、`*` はすべて。IPv6 は `[…]`。
  UNIX ドメインソケットと、接続先での SOCKS（`-R ポート`）には対応しない。
- 指定は 3 か所から集める（同じものは 1 つ）: yyeditor の接続設定（`[remote.host.名前] forward =
  ["L 8080:localhost:80", "D 1080"]`）、`~/.ssh/config` の `LocalForward`・`RemoteForward`・
  `DynamicForward`（`ClearAllForwardings yes` で使わない）、「SSH で接続」の入力に続けた
  `-L 8080:localhost:80 -D1080` など。踏み台ではしない。
- 始めるのはターミナルだけ（`Transport::forward` を呼ぶのは `remote::start_forwards` だけ）。同じ接続
  （同じ接続先のタブは SSH の接続を共有する）では、試した指定を二度は始めない。接続が切れたら止める。
  エディタとファイル転送は、同じ接続設定を使っても呼ばないので無視される（接続の記録には
  「ターミナルだけが使う」と書く）。
- 始められなかったとき（手元のポートの使用中、接続先が断ったなど）は、タブの先頭に黄色の警告を
  表示し（OpenSSH が端末に出す警告と同じ扱い）、SSH の接続とシェルはそのまま使う。始めたものは
  水色の 1 行で表示する。転送の途中の出来事（転送先に接続できないなど）は、その接続先のタブに
  警告として表示する。結果は接続の記録（`remote-ssh.log`）にも残す。

## 5. 描画と入力

- Direct2D / DirectWrite。フォントは設定（空ならエディタと同じ。既定は同梱の UDEV Gothic）。
  1 桁の幅は "0" の送り幅、全角は 2 桁。同梱フォントは全角がちょうど 2 桁なので（テストで確かめる）、
  ASCII の続きは 1 回の DrawText でまとめ、それ以外は 1 文字ずつ桁の位置に置く。
- 背景は同じ色の続きをまとめて塗り、下線・取り消し線は線を描く。カーソルはブロック・下線・縦線、
  フォーカスがなければ枠だけ。色は Windows Terminal の Campbell に近い 16 色、太字は明るい色。
- 出力は読み取り用のスレッドからチャネルで受け取り、フレームに 1 回だけ知らせて（溜まっている分を
  まとめて）流し込む。1 回に流す量に上限を設けて UI の操作を止めない。入力はタブごとの書き込み用の
  スレッドが送る。
- キー: 文字は `WM_CHAR`（サロゲート ペアを組み立てる）、カーソルキー・ファンクション キーなどは
  `WM_KEYDOWN`、Alt との組み合わせは `WM_SYSCHAR` で ESC を前に付ける。IME は変換ウィンドウを
  カーソルの位置に合わせ、確定した文字列を送る。
- タブ: エディタと同じ閉じるボタン（`tabclose`。タブの「×」と中ボタン）。右クリックのメニュー
  （閉じる・ほかのタブをすべて・右側・左側を閉じる）もエディタと共通（`tabclose::menu`）。
- 操作: Ctrl+Shift+C/V（Ctrl+Insert/Shift+Insert）でコピー・貼り付け、右クリックは選択していれば
  コピー・していなければ貼り付け、ダブルクリックで単語、Shift+PageUp/PageDown とホイールで
  スクロールバック（代替画面ではホイールをカーソルキーで送る）。プログラムがマウスを使うときは報告し、
  Shift を押している間は選択できる（報告しているときにクリックすると、ステータスバーで Shift を案内する）。
- コピーは必ずできるようにする: 選択しているときの Ctrl+C はコピー（Ctrl+C がシェルへ送られて選択が解ける
  のを防ぐ。選択していなければ ^C）。すべて選択（Ctrl+Shift+A。スクロールバックの先頭から画面の最後まで）・
  表示している画面をコピー（さかのぼっていればその位置の画面）は、マウスで選択できないときの逃げ道。
  クリップボードは 0.5 秒ほど間を延ばしながら開き直し、書く処理ごと 3 回まで試す。書けなければステータス
  バーで知らせて選択を残し、右クリックでも貼り付けにはしない。コピーした文字数・行数をステータスバーに出す。
- ウィンドウ プロシージャの中で状態を借りている間に、子ウィンドウの大きさの変更・フォーカスの変更が
  同期的に届くことがあるので、それらは後でやり直す（`WM_APP_TERM_LAYOUT`・`WM_APP_TERM_FOCUS_CHANGED`）。

## 6. ワークスペース

- エディタと同じ `*.yyworkspace`。ターミナルが最後に使ったものは `terminal-last-workspace.txt`、
  記録がなければエディタが最後に使ったものを開く。名前を付けていなければ `terminal-untitled.yyworkspace`。
- フォルダをダブルクリック（Enter）すると、そこでターミナルを開く（リモートのフォルダは SSH）。
  ファイルはエディタ（`yyeditor.exe`）で開く。右クリックで「ここでターミナルを開く」「エディタで開く」
  「パスをコピー」「最新の情報に更新」「ワークスペースから外す」「フォルダを追加」「リモートのフォルダを追加」。
- エディタのワークスペースの「ターミナルで開く」は、`yyterm.exe` が同じフォルダにあれば yyterm で開く
  （リモートのフォルダも開ける）。

### 6.1 エージェントは任意（2026-10-06 追加）

- ワークスペースのリモートのフォルダの一覧（とフォルダの選択）に接続先のエージェントを使うかを選べる
  （設定 `use_agent`、ワークスペース メニューの「リモートのフォルダの一覧に接続先のエージェントを使う」。
  既定は使わない）。
- 使わなければ SFTP（`yy_remote::fs::SftpFs`。接続先の sftp-server）で一覧を読み、接続先に何も置かない。
  使えば、エディタと同じエージェント（11 章）で読む（sftp-server を止めている接続先でも一覧を出せる）。
- 一覧・フォルダの選択は、エージェントと SFTP の共通の口（`yy_remote::RemoteFs`）で書いてあり、エディタと
  同じ部品（`remote::fs`・`remote::list_dir`・`remotedlg`）を使う。エディタは常にエージェント。

### 6.2 フォルダを束ねる（2026-10-06 追加）

- VS Code の Compact Folders と同じく、中身がフォルダ 1 つだけのフォルダを `a/b/c` の 1 行にまとめる
  （エディタのワークスペースも同じ。共通の処理は `yy_config::workspace::compact`・`compact_local`）。
- 手元のフォルダは、フォルダの中身を並べるときに各フォルダの中を先に調べて束ねる（フォルダが
  `COMPACT_LIMIT`＝200 を超える分は調べない）。リモートのフォルダは、項目ごとの往復を避けるため、
  開いたときに中身がフォルダ 1 つだけなら束ねてその中を読む（`COMPACT_DEPTH`＝32 段まで）。
  起点のフォルダは束ねない。
- 束ねた行のパスはいちばん奥のフォルダ（操作の対象）で、先頭のフォルダも覚えておく。エディタでは、
  束ねた並びの途中のフォルダが変わったら（作成・移動・削除）親のフォルダから読み直して束ね直し、
  名前の変更ではいちばん奥のフォルダの名前を編集する。

## 7. 設定（`[terminal]`）

```toml
[terminal]
shell = []                 # 手元のシェルのコマンドと引数（例: ["cmd.exe"]、["wsl.exe"]）
font_family = ""           # 空ならエディタと同じ
font_size = 0.0            # 0 ならエディタと同じ
scrollback = 10000
ambiguous_wide = false     # ○ ※ などを全角とする（接続先の設定と合わせる）
term = "xterm-256color"    # SSH の接続先に知らせる TERM
copy_on_select = false
use_agent = false          # ワークスペースのリモートのフォルダの一覧に接続先のエージェントを使う
```

## 8. テスト

- `yy-term`: 文字の表示と折り返し、全角・結合文字、カーソル移動と消去、スクロール範囲、スクロールバック、
  色、代替画面、応答、モード、タイトル、罫線、タブ、大きさの変更、コピーの文字列、単語、origin、
  中止。キー・貼り付け・マウスの送り方。
- `yy-ssh`（`apps/yy-agent/tests/ssh.rs`）: 端末つきの対話シェルとコマンド、大きさの変更の通知。
  ポートフォワーディング: `-L` の中継、同じポートでの失敗（接続は続く）、転送先に接続できないときの
  知らせ、`-D`（SOCKS5 のホスト名・SOCKS4a）、`-R`（接続先が選んだポート、接続先が断ったとき）、
  止めたら待ち受けないこと。
- `yy-remote`: 指定の読み取り（`-L`・`-R`・`-D`、`~/.ssh/config`、IPv6、誤り）、表示、「SSH で接続」の
  入力の分け方、接続設定と `~/.ssh/config` の集め方（重複、`ClearAllForwardings`、踏み台）。
- Windows の CI: ConPTY でコマンドを動かして出力を最後まで読む、同梱フォントが格子に合う、
  ウィンドウを作ってシェルの出力（日本語を含む）が端末の画面に届き、Enter でタブとウィンドウが閉じる。
