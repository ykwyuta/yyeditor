# yyclip: 独立常駐アプリのクリップボード履歴

## 1. 目的と動作範囲

`yyclip.exe` を yyeditor・yyterm とは独立して動作する Windows 常駐アプリとして作る。実行中は、前面にあるアプリや他の yy アプリの起動状態に関係なく、同じ Windows ユーザーセッション内のクリップボード変更を監視する。ウィンドウは通常表示せず、通知領域のアイコンから履歴と終了を操作できる。

記録するのは `CF_UNICODETEXT` の本文だけ。画像、ファイル一覧、HTML のみのデータなど、文字列として取得できない形式は記録しない。本文を UTF-8 にしたとき **1 MiB (1,048,576 バイト)** を超えるもの、空文字は対象外。保存先はこのアプリ専用の `%APPDATA%\yyclip\history\` とし、1 件ずつ UTF-8 の `.txt` ファイルで保存する。

## 2. 常駐と操作

1. `yyclip.exe` を起動すると、非表示ウィンドウで `AddClipboardFormatListener` を登録し、Windows の `WM_CLIPBOARDUPDATE` を受ける。yyeditor を開いていなくても、任意のアプリのコピーを記録する。同一ユーザーセッションで二重起動しないようにする。
2. 左右どちらかの Control キーを「押して離す、500 ms 以内にもう一度押す」と、前面アプリに関係なくマウスポインターの近くにタブ付きの選択画面を表示する。途中で別のキーを押した場合やキーの自動反復は対象外。低レベルキーボードフックは専用スレッドで処理し、キーを抑止・変更しない。
3. 選択画面は「クリップボード」「定型文」のタブと一覧だけにする。履歴タブには新しい順に最新 100 件の冒頭、定型文タブには登録済みの最大 20 件を表示する。矢印キーと Enter、またはマウスのダブルクリックで選ぶと本文をクリップボードに戻す。Ctrl+Tab でタブを切り替え、Esc または画面外のクリックで閉じる。操作後は元のアプリにフォーカスを戻す。
4. 定型文の登録は通知領域アイコンの右クリックメニューの「定型文を登録...」から行う。別の入力画面に任意の文字列を直接入力でき、複数行に対応する。右クリックメニューのサブメニューから既存の定型文を編集・削除できる。空文字、1 MiB 超、同じ本文の重複登録は受け付けない。定型文は `%APPDATA%\yyclip\templates\01.txt` から `20.txt` までの UTF-8 ファイルに保持し、再起動後も利用できる。タブ、一覧、入力欄、ボタンには yy-win と同じ DPI 対応の Windows メッセージフォントを使い、フォント寸法と表示先モニターの DPI に合わせて全コントロールとウィンドウを再配置する。
5. 通知領域のアイコンを左クリックしても選択画面を開ける。右クリックメニューから常駐アプリを終了できる。履歴ファイルと定型文は終了しても残る。アイコンは他の yy アプリと同じ角丸・白い「YY」の構成で、紫の背景とクリップボードの図形を使う。

Windows のサインイン時に使いたい場合は、`yyclip.exe` のショートカットをユーザーのスタートアップフォルダへ置く。アプリ自身は起動設定を勝手に変更しない。

## 3. 保存と障害時の動作

- 既存の yy-win の `CF_UNICODETEXT` 読み書きと設定フォルダ処理を設計上の参考にし、独立アプリ内に必要な Win32 処理だけを持つ。yy-win や yy-config には依存しない。
- `GlobalSize` を見て読み取り量を制限し、UTF-8 変換後にも 1 MiB を確認する。ほかのプロセスがクリップボードを一時的に開いている場合は短時間再試行する。
- ファイル名には時刻と衝突回避番号を含める。一時ファイルに書き終えてから同じフォルダで名前を変更し、書きかけの履歴を表示しない。
- 復元した内容の通知は再記録しない。直前と同じ内容の連続通知も重複保存しない。保存失敗時も元のコピー操作を妨げない。
- 履歴の保存件数の上限と自動削除は設けない。選択画面には最新 100 件だけを表示し、ディスク上の履歴は利用者が管理できる。定型文は 20 件に制限する。

## 4. 実装と検証

| 場所 | 役割 |
|---|---|
| `apps/yyclip` | 独立した常駐 exe、通知領域、非表示ウィンドウ、グローバル入力監視 |
| `apps/yyclip/src/clipboard.rs` | 上限付きテキストの取得と復元 |
| `apps/yyclip/src/history.rs` | 専用保存先、ファイル履歴、Control キー判定 |
| `apps/yyclip/src/templates.rs` | 定型文の保存、20 件制限、削除 |

確認するケースは、yy シリーズを起動しない状態での他アプリのコピー、1 MiB ちょうどと超過、日本語、空文字、連続した同一内容、再起動後の履歴と定型文、任意文字列と複数行の入力・編集、定型文の 20 件上限と重複登録、定型文の削除、二重起動、左右 Control、キーの自動反復、途中の別キー、両タブでの矢印キー・マウス・Esc、復元後の元アプリへのフォーカス、通知領域からの終了とする。
