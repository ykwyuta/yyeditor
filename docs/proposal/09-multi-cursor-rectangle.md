# 09. 矩形選択とマルチカーソル（複数行同時編集）

## 1. 要求

- **矩形選択（ボックス選択）**: マウス（Alt+ドラッグ）またはキーボード（Alt+Shift+矢印）で矩形範囲を選択し、コピー・切り取り・削除・貼り付け・文字入力を行う。
- **マルチカーソル / 複数行同時編集**: 複数の位置にカーソル（選択範囲）を置き、入力・削除・貼り付け・IME 確定などを全カーソルに同時に適用する。
- 日本語（全角文字・タブ混在）でも表示上の桁が揃うこと。
- 巨大ファイル（数百万行にまたがる矩形）でも UI が固まらないこと。
- 区切り文字 / CSV モードではセル単位の矩形選択・同時編集ができること。
- 全カーソル分の編集が **1 回の Undo** で戻ること。

## 2. 選択モデル

### 2.1 データ構造（`yy-core::selection`）

```rust
pub struct Selection {
    pub anchor: Pos,             // 選択開始（固定端）
    pub head: Pos,               // カーソル位置（移動端）
    pub goal_x: Option<VCol>,    // 上下移動時に維持する表示桁（sticky column）
}

pub struct Pos {
    pub offset: u64,             // バッファ上のバイトオフセット（UTF-8、文字境界）
    pub virt: u32,               // 行末より右の仮想空白の桁数（フリーカーソル・矩形用、通常 0）
}

pub struct RectSelection {
    pub anchor_line: u64,        // 論理行（折り返し有効時は表示行、2.4 参照）
    pub head_line: u64,
    pub anchor_col: VCol,        // 表示桁（全角=2、タブ展開後）
    pub head_col: VCol,
}

pub enum SelectionSet {
    /// 通常選択・マルチカーソル。オフセット昇順、重なりなし（重なったら自動マージ）
    Multi { sels: Vec<Selection>, primary: usize },
    /// 矩形選択。行ごとの範囲は必要になった時点で計算する（遅延展開）
    Rect(RectSelection),
}
```

- 単一カーソルは `Multi` の要素数 1 の特殊ケース。すべての編集コマンドは `SelectionSet` を入力に取り、カーソル数に関係なく同じコードパスで処理する。
- 位置は **バイトオフセット** で保持し、表示桁（`VCol`）は描画・上下移動・矩形計算の時にのみ `yy-layout` で求める。
- 矩形は行ごとの範囲を持たない（**遅延展開**）。100 万行の矩形でもメモリは定数で、描画時は表示中の行だけ展開する。

### 2.2 表示桁（VCol）の定義

矩形の左右端は「バイト」や「文字数」ではなく **表示桁** で定義します。これにより全角・半角・タブが混在しても見た目どおりの矩形になります。

| 要素 | 桁幅 |
|------|------|
| ASCII・半角カナ | 1 |
| 全角文字（East Asian Width が W/F） | 2 |
| 曖昧幅（A: ①、○、ギリシャ文字等） | 設定（既定 2 = 日本語環境の慣習） |
| タブ | 次のタブ位置まで |
| 結合文字・異体字セレクタ・ZWJ | 0（直前の書記素クラスタに含める） |
| 絵文字 | 2 |

プロポーショナルフォント使用時は、桁の代わりにピクセル x 座標で矩形を定義する（`VCol` を `f32` の x 座標に切り替えるだけで、以降のロジックは共通）。

### 2.3 境界が文字の途中にかかる場合

矩形の端が全角文字の中央やタブの途中に来た場合の扱いを設定で選べるようにします。

| 設定 | 動作 |
|------|------|
| 含める（既定） | 端にかかった全角文字・タブを選択に含める |
| 含めない | 完全に内側の文字だけ選択 |
| 分割する（タブのみ） | 編集時に端にかかったタブを空白に展開してから操作（見た目の桁を厳密に維持） |

### 2.4 折り返し表示時

折り返し有効時の矩形は **表示行** を単位とします（見た目どおり）。各表示行はバッファ上の範囲に対応するので、行ごとの範囲への展開方法は同じです。折り返し位置が編集で変わると矩形の形も変わるため、編集後は矩形を「各行範囲のマルチカーソル」に変換します。

## 3. 矩形選択の操作

### 3.1 選択方法

| 操作 | 動作 |
|------|------|
| Alt + ドラッグ | 矩形選択 |
| Alt + Shift + ↑↓←→ | キーボードで矩形選択を拡張 |
| Alt + Shift + クリック | 現在のカーソルからクリック位置までを矩形選択 |
| 「矩形選択モード」切替（メニュー / ショートカット） | 通常の Shift+矢印・ドラッグを矩形選択として扱う（EmEditor・秀丸互換） |
| 行末より右へのドラッグ | 仮想空白として選択を拡張（フリーカーソル） |

### 3.2 編集操作

| 操作 | 動作 |
|------|------|
| 文字入力 / IME 確定 | 矩形の各行の **左端** の位置（選択範囲がある場合はそれを置き換え）に同じ文字列を挿入。行が短い場合は仮想空白を実際の空白で埋めてから挿入。入力後も幅 0 の矩形（縦一列のカーソル）が維持され、続けて入力できる |
| BackSpace / Delete | 各行で 1 文字（書記素クラスタ）を削除。選択範囲があればその範囲を削除 |
| コピー / 切り取り | 各行の選択部分を改行で連結したテキストをクリップボードへ。加えて矩形であることを示す形式（下記 3.3）も登録 |
| 貼り付け（矩形データ） | カーソル位置の桁から下方向へ 1 行ずつ矩形として挿入。行が足りなければ末尾に行を追加 |
| 貼り付け（通常テキスト・行数 = 矩形の行数） | 各行に 1 行ずつ分配して挿入（Excel の 1 列を貼り付ける用途） |
| 貼り付け（通常テキスト・それ以外） | 各行に同じテキストを挿入 |
| 空白で埋める / 文字で埋める | 矩形内を指定文字で置換 |
| 連番の挿入 | 各行に開始値・増分・桁数・書式（0 埋め、16 進）を指定して連番を挿入 |
| 大文字/小文字・全角/半角変換 | 矩形内のテキストに適用 |
| 矩形内の検索・置換 | 検索範囲を「矩形の各行範囲」に限定（05 章の `SearchScope::Selection` を複数範囲に拡張） |
| 矩形内の並べ替え | 矩形部分をキーに行を並べ替え |
| マルチカーソルに変換 | 矩形の各行範囲を個別の選択に変換（以後は 4 章の操作） |

### 3.3 クリップボード連携

- 通常テキスト（`CF_UNICODETEXT`）に加え、Visual Studio / EmEditor などとの互換のため登録クリップボード形式 `MSDEVColumnSelect` を同時に設定し、「矩形データである」ことを他のエディタと相互にやり取りできるようにする。
- 貼り付け時にこの形式が存在すれば矩形貼り付けとして処理する。
- マルチカーソルでのコピーは、各選択の内容を改行で連結し、独自形式 `yyeditor/multi-selection`（選択ごとの区切りを保持）も登録する。同じカーソル数で貼り付けた場合は 1 対 1 で分配する（VS Code と同様）。

## 4. マルチカーソル（複数位置同時編集）

### 4.1 カーソルの追加方法

| 操作 | 動作 |
|------|------|
| Ctrl + クリック / Ctrl + ドラッグ | クリック位置にカーソル・選択範囲を追加（同じ位置なら削除） |
| Ctrl + Alt + ↑ / ↓ | 上 / 下の行の同じ表示桁にカーソルを追加 |
| Ctrl + D | 選択中の文字列（未選択ならカーソル下の単語）の **次の出現箇所** を選択に追加 |
| Ctrl + K, Ctrl + D | 直前に追加した選択をスキップして次へ |
| Ctrl + Shift + L | 選択文字列・検索パターンの **すべての出現箇所** を選択（上限あり、下記 5） |
| 検索結果から | 検索バーの「すべて選択」で正規表現のマッチ全体をマルチ選択に |
| Alt + Shift + I | 複数行を選択中、各行の行末にカーソルを配置 |
| Esc | プライマリカーソル 1 つに戻す |

### 4.2 同時編集の動作

すべての編集コマンドは、カーソル数に関係なく次の手順で処理します。

```
1. SelectionSet を各カーソルの「編集要求」（削除範囲, 挿入文字列）の列に変換
   - 例: 文字入力 → 各選択範囲を入力文字で置換
        BackSpace → 各カーソル直前の書記素クラスタを削除
        改行 → 各カーソルに改行＋自動インデント（行ごとに異なるインデント）
2. 編集要求をオフセット昇順に並べ、重なりを解消（重なる削除範囲は結合）
3. 永続ピースツリーに一括適用（1 つのトランザクション = 1 つの新スナップショット）
   - オフセットの大きい方から適用すれば、先の編集で後の位置がずれない
4. 各カーソルの新しい位置を「累積シフト量」で一括補正（O(k)）
5. 重なった / 同じ位置になったカーソルをマージ
6. 1 つの HistoryEntry として Undo 履歴に登録（06 章。選択状態も前後とも保存）
```

- `k` 個のカーソルの編集コストは O(k log n)。1 万カーソルでも 1 打鍵あたり数 ms。
- カーソルごとに異なる内容になる操作（自動インデント、括弧の自動補完、連番、分配貼り付け）も、手順 1 で要求を個別に作るだけで同じ仕組みに乗る。
- カーソル移動（矢印キー、Home/End、単語移動、PageUp/Down）も全カーソルに適用。上下移動は各カーソルの `goal_x` を維持。

### 4.3 IME との連携

- 未確定文字列（変換中の文字列）は **プライマリカーソル位置にインライン表示** し、他のカーソル位置にも同じ未確定文字列を下線付きでプレビュー表示する（バッファは変更しない）。
- 確定時に、確定文字列を全カーソルに同時挿入（1 つの Undo 単位）。
- 候補ウィンドウはプライマリカーソルに追従。

### 4.4 表示

- プライマリカーソルは通常の太さ、セカンダリは少し細く・色を変えて表示。
- 表示範囲外にあるカーソル数をステータスバーに表示（例: `カーソル 1,532 個（画面外 1,480）`）。
- 選択範囲はすべてハイライト。描画は表示範囲に含まれるカーソルだけを二分探索で抽出するため、カーソル数が多くても描画コストは増えない。

## 5. 巨大ファイルでの扱い

| 状況 | 方式 |
|------|------|
| カーソル / 矩形行数が少ない（既定 10 万未満） | 4.2 の対話的一括編集（同期処理） |
| 巨大な矩形（例: 1,000 万行 × 桁 10〜20 の削除） | 1 打鍵ごとに 1,000 万箇所を木に適用すると重いため、**バッチジョブ** に切り替え。スナップショットを先頭から読み、各行の矩形部分を書き換えながら新しい一時ファイルへストリーミング出力し、完了時にツリーを差し替える（05 章の「すべて置換」と同じ仕組み）。Undo は O(1) |
| 「すべての出現箇所を選択」でマッチが多すぎる | 既定上限 10 万件で打ち切り、警告を表示。超える場合は「すべて置換」の利用を案内 |
| 矩形選択のまま連続入力（巨大矩形） | 入力をキーストロークごとに適用せず、入力バッファに溜めて表示上はプレビュー（表示範囲の行だけ仮反映）、確定操作またはアイドル時にバッチジョブで一括適用 |

矩形は遅延展開なので、**選択するだけ・スクロールするだけ** であれば行数に関係なくコストは表示範囲分のみです。

## 6. 区切り文字 / CSV モードでの矩形選択

区切り文字モード（04 章）では、矩形は **セル範囲**（レコード範囲 × フィールド範囲）として扱います。

```rust
pub struct CellRect {
    pub records: Range<u64>,
    pub fields: Range<u32>,
}
```

| 操作 | 動作 |
|------|------|
| Alt + ドラッグ / ヘッダーの Shift+クリック | セル範囲を選択（表示上の列幅に関係なくセル単位で吸着） |
| 文字入力 | 選択された全セルの内容を置換（またはセル内の同じ位置に挿入）。値に区切り文字・引用符・改行が含まれればセルごとに自動で引用符付け（RFC 4180） |
| コピー | TSV 形式（`CF_UNICODETEXT`）で出力。Excel にそのまま貼り付け可能 |
| 貼り付け | TSV / CSV のデータを選択セルの左上から展開。フィールド数が足りないレコードには空フィールドを補う |
| 削除 | セル内容を空にする（区切り文字は残す）。列ごと削除は 04 章の列操作 |
| 連番・一括値入力 | 選択セルに連番・同じ値を入力 |

セル範囲の各セルはバイト範囲に変換され、4.2 と同じ一括編集パスで処理されます。

## 7. 実装の置き場所

| 機能 | クレート |
|------|---------|
| `Selection` / `SelectionSet` / マージ・位置補正・一括編集 | `yy-core`（`selection.rs`, `edit.rs`） |
| 表示桁（VCol）計算、矩形の行範囲への展開、折り返し時の対応 | `yy-layout` |
| セル範囲 ↔ バイト範囲の変換 | `yy-delimited` |
| 巨大矩形・大量カーソルのバッチ適用 | `yy-core` の編集ジョブ（`yy-jobs` 上で実行） |
| マウス / キー操作、クリップボード形式、IME プレビュー描画 | `yy-win` |

## 8. テスト

- `proptest` でランダムなカーソル配置と編集操作を生成し、「各カーソルに逐次（後ろから）単独編集した結果」と「一括編集した結果」が一致することを検証。
- 全角・タブ・結合文字・絵文字を含む行での矩形の行範囲展開を、桁計算の素朴な実装と比較。
- 矩形の対話的一括編集とバッチジョブの結果が一致することを検証。
- 一括編集後の 1 回の Undo で内容と選択状態が完全に元に戻ること。
