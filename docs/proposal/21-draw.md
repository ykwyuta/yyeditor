# 21. 構成図エディタ（yydraw）

細かい方眼紙の上に基本図形やクラウドサービスのアイコンを配置し、線・矢印で接続して構成図を描く
Windows アプリ **yydraw** を追加する（2026-10-20 提案）。draw.io のような配置・接続の操作を目指し、
yy シリーズと同じフォント・設定の仕組みを利用する。編集用の原本は独自バイナリ形式で保存し、SVG・PNG を出力する。

本書は実装前の提案。拡張子、数値、構成要素名は以下を初期案とし、実装時の試作・測定で確定する。

## 1. 要求と範囲

| # | 要求 | 提案する対応 |
|---|------|--------------|
| D1 | yy シリーズの独立した作図アプリ | `yydraw.exe`、共通の設定・フォント・ヘルプ・異常終了記録を使用 |
| D2 | 細かい方眼紙の背景 | 細線・太線の格子、表示切替、間隔変更、格子への吸着、拡大縮小・パン |
| D3 | 基本図形を置いて構成図を作れる | 図形・ラベル・接続線、移動・サイズ変更・整列・グループ・重なり順 |
| D4 | クラウドサービスのアイコンを置ける | AWS・Azure・Google Cloud のパレット、検索、SVG・PNG の追加登録 |
| D5 | 他の yy シリーズと同じフォント | 既定は同梱の **UDEV Gothic**。共有フォント設定を引き継ぐ |
| D6 | 線・矢印の交差で片方がアーチ状に跨ぐ | 接続線の交点を検出し、一方だけにラインジャンプを生成。入切・優先側を指定可能 |
| D7 | 編集できる独自バイナリで保存 | `.yyd`。図形・接続関係・原文ラベル・使用素材を保存して再編集 |
| D8 | SVG・PNG へエクスポート | 同じ描画データから出力。範囲・余白・背景・倍率を指定可能 |

初版では D1〜D8 をすべて対象にする。

**draw.io・Visio 形式のインポート／エクスポートとファイル互換は、製品の要件から完全に除外する。**
将来対応も前提とせず、そのための互換層や保存形式の制約は設けない。draw.io は配置・接続の操作感の参考とする。
編集用原本は独自の `.yyd`、外部への出力は SVG・PNG とする。

共同編集、クラウドへの同期、AWS などのアカウントからの構成取得、自由曲線によるイラスト制作は初版の対象に含めない。
インターネット接続は作図・保存・出力の前提としない。

## 2. 画面と操作

### 2.1 画面構成

| 場所 | 内容 |
|------|------|
| 上部 | ファイル・編集・表示・配置・図形・ヘルプのメニュー、選択・接続・図形のツール |
| 左 | 基本図形、汎用ネットワーク、AWS、Azure、Google Cloud、利用者の素材。名称検索 |
| 中央 | 方眼紙のキャンバス。文書ごとのタブ、ページ境界、選択枠、接続先のハンドル |
| 右 | 選択対象の位置・大きさ・色・線種・文字・接続・ジャンプ設定 |
| 下部 | 拡大率、座標、吸着状態、保存・出力の進み |

- 素材をドラッグして配置する。図形のダブルクリックまたは F2 でラベルを編集し、日本語 IME を使える。
  ラベルは複数行・文字揃え・余白・文字サイズ・文字色を持つ。
- ドラッグで移動、ハンドルでサイズ変更、Shift で縦横比を保持。アイコンは原則として縦横比を維持する。
- Shift+クリックで追加選択、空白部分のドラッグで範囲選択。複数選択を整列・等間隔配置・グループ化できる。
  グループの移動では、内部の図形と接続点を一緒に移す。
  図形・アイコン・線を同じグループとして選択・移動・整列・複製できる。グループ化はCtrl+G、解除はCtrl+Shift+G。
  整列は左・左右中央・右・上・上下中央・下、縦横の均等配置、選択範囲／ページ基準の切替に対応する。
  線を含むグループ情報は保存版1.4のGRPSチャンクで保持し、旧版文書の読込を継続する。
- Ctrl+C／X／V、Delete、Ctrl+Z／Y、Ctrl+S を提供する。図形のコピーには専用のクリップボード形式を使い、
  利用者が選んだ場合は SVG・PNG としてもコピーする。貼り付け時は ID を振り直し、内部の接続を維持する。
- ホイールでスクロール、Ctrl+ホイールでカーソル位置を中心にズーム、Space+ドラッグまたは中ボタンでパン。
  全体表示・選択範囲表示・100% 表示を用意する。
- 未保存の変更をタブとタイトルに表示する。閉じるときは保存・破棄・取消を選べる。

### 2.2 方眼紙と座標

文書座標は DPI や拡大率から独立した DIP（96 DIP = 1 inch）とし、位置は有限の実数で保持する。
初期値は **8 DIP ごとの細線、5 マスごとの太線**。格子の表示と吸着は別々に切り替え、間隔・色を変更できる。
Alt を押している間は吸着を一時解除する。格子とは別に、他の図形の端・中央への整列ガイドを出す。

拡大率は初期案として 10〜800%。縮小時は細線を間引いて模様の潰れを防ぐが、文書の格子間隔と吸着位置は変えない。
キャンバスはパンで必要な範囲へ移動でき、原点の左・上にも配置できる。出力用にはページ寸法または図全体の範囲を使う。
背景格子は編集補助であり、SVG・PNG では既定で出力しない。出力時に含めることも選べる。

### 2.3 図形と接続

基本図形は矩形、角丸矩形、楕円、ひし形、三角形、円柱（データベース）、雲、テキスト、
領域を囲う枠を用意する。汎用ネットワークにはサーバー・クライアント・ルーターなどを用意する。
線幅・線色・塗り・破線・透明度を変更できる。領域の枠とグループは区別し、枠を置くだけで所属を変えない。

接続線は直線と直交折れ線、始点・終点それぞれの矢印、線上のラベルを持つ。
図形の接続ハンドルから別の図形へ引くと、接続先の **図形 ID と接続点** を保存する。
接続ハンドルは各辺5点、計20点とし、ホバー・選択時に表示する。選択ツールでもハンドルから線を引ける。
従来の中央4点への接続は維持し、追加した点を使用する文書だけ保存版1.2で保存する。
Shiftで上下左右へ方向を固定し、Shift+Tabで手動の折れ点を追加する。折れ点の後は逆向きを除く3方向へ
続けられ、Backspaceで直前の折れ点を取り消す。角の形（尖角／丸角）と半径は接続線のプロパティで編集し、
表示とSVG・PNGで共有する。丸角を使用する文書は保存版1.3のCRNRチャンクで半径を保持する。
図形の移動・サイズ変更でも接続を維持し、任意座標だけを持つ未接続の端点も許可する。
線上の交差だけでは接続したことにしない。接続する場合は明示的な接続点を置く。

直交線は図形の外周からの出入り方向と余白を守り、障害物を避ける経路を求める。
利用者は途中点を追加・移動でき、その指定を維持した区間ごとに経路を計算する。
経路が見つからないときは手動経路を保持するか単純な折れ線へ戻し、未解決を表示する。
編集中に無関係な接続線の経路まで変わらないよう、変更の影響範囲を限定する。

## 3. 交差する線のアーチ（ラインジャンプ）

### 3.1 表示上の規則

- 初期値は「交差でアーチを描く」。文書全体の入切に加え、線ごとに「自動・優先して跨ぐ・跨がない」を設定する。
- 自動では前面の線が跨ぐ。同じ順序の場合は保存された ID で決め、再表示・再読込・出力で勝手に入れ替わらない。
  両方が優先を指定した場合も同じ規則で一方だけを選ぶ。両方が「跨がない」場合は通常の交差とする。
- 跨ぐ側の線の交点付近を除き、接線方向へ滑らかにつながる半円状のパスに置き換える。
  背景色の白塗りで下の線を隠す方法にはせず、透明背景や色付き領域でも同じ形を保つ。
- 端点の共有、明示的な接続点、角への接触にはジャンプを作らない。矢印・ラベル・折れ曲がり点に近すぎる場合は、
  半径を縮小するか、その箇所だけジャンプを省略する。
- 同一直線上の区間の重なりはアーチでは区別できない。経路のずらし・途中点の編集で解消し、選択時に重複区間を示す。
  接続そのものは自動で変えない。
- 初期の半径は 5 DIP とし、文書で調整できる。密接する交点では各半径を制限してアーチ同士が重ならないようにする。
  3 本以上が同じ位置で交差する場合は順序で優先線を一つに決め、他の線同士にも重複したアーチを生成しない。

### 3.2 計算と再利用

1. 接続線の経路を線分に展開し、空間索引で交差候補を絞る。すべての線分の総当たりを毎フレーム行わない。
2. 端点・接触・同一直線上の重複を分け、許容誤差を文書座標で定義して交点を求める。
3. 跨ぐ線と向き、半径、線上の区間を決め、区間順に並べてジャンプを含む描画パスを生成する。
4. ジャンプを含むパスを画面・SVG・PNG で共有する。ズームだけでは経路やジャンプを再計算しない。

保存するのは接続関係・経路の指定・ジャンプの設定であり、交点キャッシュは保存の必須データにしない。
線の選択判定には元の線と表示上のアーチの両方を使い、跨いでいる線をクリックできるようにする。
アーチは障害物回避とは別の表示処理とし、Undo の新たな編集操作には数えない。

## 4. フォントとクラウドアイコン

### 4.1 共通フォント

既存の `crates/yy-win/src/font.rs` の **UDEV Gothic** 登録・DirectWrite コレクションを再利用する。
OS へのフォントのインストールは不要とする。新規文書のフォント名・サイズは共通の `editor.font_family`・
`editor.font_size` を初期値にし、文書内では図形ごとのサイズ変更を許可する。
フォント名・サイズを文書に記録し、設定変更だけで既存の図の折り返しが変わらないようにする。
日本語・英数字・記号の配置には DirectWrite の字形選択とフォールバックを使用する。

SVG は既定で文字をパスに変換し、出力先に同梱フォントがなくても見た目を保つ。
文字を選択・検索したい用途向けに `<text>` 出力も選べるようにし、その場合は閲覧側のフォントで見た目が変わり得ることを
出力画面に示す。独自形式では文字をパスに置き換えず、原文と書式を維持する。

### 4.2 素材の管理

クラウドアイコンは **AWS・Azure・Google Cloud** を対象に、ベンダー・カテゴリ・サービス名で選択する。
サービス名と検索用の別名を持ち、アイコンと別に編集できるラベルを添える。
公式アイコンは外形・色・縦横比を保ち、提供元の規則に合わせて回転・反転・変形の可否を素材ごとに制限する。

素材パックは `pack_id / version / icon_id`、名称、SVG または PNG、出典、利用条件の記録を持つ。
同じファイルを何度置いても実体は一つだけ保持する。パック更新は利用者が実行し、開いている図のアイコンを自動で差し替えない。
保存時は使用した素材の実体を文書へ格納し、相手に素材パックがなくても同じ図を開けるようにする。

公式の配布元は次のとおり（2026-10-20 確認）。配布ページの利用条件と、アプリへの同梱・素材を含む文書の配布条件は
素材パックを準備する段階で確認し、出典とともに記録する。図に使えることだけを根拠に、素材集の再配布まで可能とは判断しない。

| 対象 | 公式配布元 |
|------|------------|
| AWS | [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/) |
| Azure | [Azure Architecture Icons](https://learn.microsoft.com/en-us/azure/architecture/icons/) |
| Google Cloud | [Google Cloud Icon Library](https://cloud.google.com/icons) |

同梱できるパックはアプリと一緒に提供する。同梱条件が確定しない素材は公式パックのローカル取り込みで利用できるようにする。
取り込み済み素材はオフラインで使える。利用者独自の SVG・PNG も登録できる。
SVG はスクリプト・外部参照・イベント・`foreignObject` を実行しない許可要素への変換で扱い、
パス・塗り・線・グラデーションなどの静的な描画データにする。対応外の表現は黙って捨てず、取り込み時に示す。

## 5. 全体構成

```text
apps/yydraw ──► yy-win::run_draw
                  ├─ draw/mod.rs       フレーム・文書タブ・メニュー・保存確認
                  ├─ draw/canvas.rs    入力・選択・ドラッグ・ズーム・IME
                  ├─ draw/palette.rs   図形とアイコンの選択・検索
                  ├─ draw/property.rs  書式・位置・接続・出力の設定
                  └─ draw/paint.rs     Direct2D / DirectWrite、PNG 用オフスクリーン描画
                 │
                 ├─ yy-draw（新規、OS 非依存）
                 │    document   ページ・図形・接続線・グループ・素材参照
                 │    edit       編集コマンド・選択に伴う処理・Undo / Redo
                 │    geometry   吸着・整列・接続点・経路・交点・ジャンプ
                 │    scene      描画パス・クリップ・画像・文字配置を渡す共通の描画データ
                 │    format     .yyd の読込・保存・版の移行・検証
                 │    assets     素材パック・SVG の静的な図形への変換
                 │    svg        共通の描画データから SVG を生成
                 └─ 既存: yy-config / yy-jobs / yy-win の font・ime・crash・help
```

画面は既存のネイティブ実装を踏襲する。draw.io 本体や WebView2 上の編集アプリを組み込む構成にはしない。
図形の意味・接続関係を持つ文書モデルと、表示用の描画データを分ける。
DirectWrite が決めた文字の配置・字形の輪郭は Windows 側で共通の描画データに反映してから出力に渡す。
幾何計算とファイル形式は Linux の CI でも検証する。

文書モデルは安定した ID と明示的な重なり順を持つ。接続端点は図形への参照または絶対位置、途中点は文書座標で保持する。
描画パスだけを原本にせず、再読込後にも図形・ラベル・接続点を編集できることを優先する。
ドラッグ中の仮状態は表示に反映し、確定時に一回の Undo として記録する。
保存・出力は変更されない文書スナップショットから行い、UI の入力を止めない。

SVG の解析・描画には usvg／resvg を使用し、PNG も同じ OS 非依存の描画経路で符号化する。

## 6. 独自バイナリ形式（`.yyd`）

XML や JSON を単に拡張子変更する方式にはせず、版付きのヘッダーとチャンクを持つバイナリコンテナにする。
初版のマジックは `YYDRAW\0\0`（8 バイト）を案とし、整数のバイト順は little-endian とする。

| 部分 | 内容 |
|------|------|
| ヘッダー | マジック、メジャー／マイナー版、必須機能フラグ、目次の位置・長さ |
| 目次 | チャンク種別、ID、位置、格納長、展開長、圧縮方式、チェックサム |
| 文書 | 文書 ID、ページ、単位、格子・背景・ジャンプ設定、既定の書式 |
| オブジェクト | 図形・接続線・接続点・グループ、重なり順、位置・寸法・ラベル・書式 |
| 素材 | 使用した静的 SVG／PNG、素材の ID・版・出典・条件の記録 |
| 補助情報 | 任意のプレビュー画像、任意の拡張チャンク |

各チャンクの本文は `postcard` など既存のバイナリ直列化を利用する案とし、圧縮はチャンク単位で任意に行う。
モデルをそのまま直列化せず、版ごとの保存用構造体を定義する。ID の重複・不正参照・循環グループ・
非有限の座標・寸法・チャンク範囲・展開後の上限・チェックサムを読込時に検証する。
不正なファイルでメモリを使い切らないよう、素材寸法・チャンク数・展開量にも上限を設ける。

対応不能なメジャー版や必須機能は書き込み可能として開かない。同じメジャー版の未知の任意チャンクは
そのまま保持して再保存できる設計にする。破損・欠落がある場合は元ファイルを変更せず、対象を説明して読込を中止する。

保存は同じフォルダの一時ファイルへ全量を書き、書込完了・同期後に既存ファイルを原子的に置き換える。
ディスク不足・取消・途中失敗では元ファイルを残す。保存中に編集が進んだ場合は、保存したスナップショットの世代だけを
保存済みとし、後から加えた編集の未保存表示を消さない。出力した SVG・PNG を編集用原本の保存済みとは扱わない。

## 7. SVG・PNG エクスポート

| 設定 | 動作 |
|------|------|
| 対象 | 現在のページ、図全体、選択範囲。初版の各出力ファイルは一つの画像 |
| 余白 | 図形だけでなく線幅・矢印・アーチ・ラベルの外接範囲から計算 |
| 背景 | 透明または指定色。格子を含めるかは独立して選択 |
| SVG | `viewBox` と寸法、図形・ジャンプのベクターパス、素材の埋め込み、文字のパス／テキストの選択 |
| PNG | 倍率または画素寸法、透明度を保持。画面のスクリーンショットではなく専用の描画先から出力 |

SVG は外部の素材ファイル・JavaScript・アプリの実行環境を参照しない単独ファイルとする。
PNG の画像素材は埋め込み、SVG の素材は ID を衝突しない名前に変換して組み込む。
PNG は共通の描画データを resvg でオフスクリーン描画して符号化する。
透明背景では文字をグレースケールのアンチエイリアスで描き、ClearType の色の縁を持ち込まない。

出力前に幅・高さ・必要メモリを検査し、初期案として最大辺 32,768 px、総画素 64 MiPixels を上限とする。
上限超過は範囲・倍率の変更で対応し、不完全なファイルは成功として残さない。
画面上の選択枠・ハンドル・ガイドは出力に含めない。SVG・PNG とも進行中の取消と失敗時の一時ファイル削除に対応する。

## 8. 実装順序と受入条件

| 段階 | 実装 | その段階で確認すること |
|------|------|------------------------|
| 1 | 文書モデル・基本図形・ネイティブ画面・共通フォント・格子・選択 | 高 DPI、ズーム後も吸着位置が一致。日本語ラベルの IME 編集 |
| 2 | 接続線・直交経路・接続点・ラインジャンプ・配置・Undo | 図形移動後の接続維持。交差・接触・重複の区別、優先側の安定性 |
| 3 | 素材パックと AWS・Azure・Google Cloud の配置・検索 | 公式素材の扱いを確認。独自アイコンを含めオフラインで利用可能 |
| 4 | `.yyd` の保存・読込・SVG／PNG 出力 | 他の PC で素材パックなしに開ける。原文・接続関係・書式が保持される |
| 5 | 配布・関連付け・ヘルプ・CI・性能調整 | `.yyd` を指定して起動。D1〜D8 の一連の操作を検証 |

段階 1〜2 だけを完成扱いにはせず、独自形式・クラウドアイコン・両出力形式を含めて初版の完了とする。

試験は次を行う。

- **OS 非依存の試験**: 座標変換・吸着・図形境界への接続・直交経路・交点・ジャンプの端点と半径。
  水平／垂直／斜線、端点共有、同一直線上の重複、近接した交点、3 本以上の交差、極端な座標を含める。
- **文書・保存の試験**: 操作と Undo／Redo、接続先の削除、グループ、コピー時の ID 振り直し、保存→再読込の同値性。
  旧版の移行、未知チャンクの保持、途中で切れたファイル、不正な長さ、展開量超過、保存中の取消・失敗を確認する。
- **Windows の試験**: 同梱フォントの利用、日本語 IME、高 DPI（100／150／200%）、ドラッグと吸着、
  複数選択・タブの未保存確認、PNG 出力。既存の yy シリーズのフォント設定への副作用がないことを確認する。
- **出力の比較**: 日本語、アイコン、透明背景、直交線、交差アーチを含む基準図を使い、SVG を画像化した結果と PNG・
  画面の描画を許容差付きで比較する。見た目に加え、出力寸法・素材の内包・クリップの欠けも検査する。
- **性能の測定**: 初期の対象規模は図形 2,000 個・接続線 5,000 本。基準機を定め、パン・ズーム・選択が
  体感で引っ掛からず操作できることを測る。目標は操作の応答 100 ms 以内、通常のパン・ズームは 60 fps。
  出力・経路計算・保存はバックグラウンドで進みを表示し、測定結果に基づいて索引・キャッシュを調整する。

採用した方式:

- 画面は Win32 のネイティブ操作部品と Direct2D。文字・図形・素材は **usvg／resvg** の共通経路で描画し、
  同じ同梱フォントデータを読み込む。DirectWrite 専用の字形を SVG に変換する方式に代え、画面と出力の形を揃え、
  PNG の符号化も OS 非依存の経路にした。WebView2 は不要。
- 保存版 1.1 は 52 バイトのヘッダー（マジック・メジャー／マイナー版・本文長・BLAKE3）と、
  個数＋64 バイトずつの目次（種別・必須フラグ・ID・位置・長さ・BLAKE3）を持つ。
  文書 `DOCS` と素材 `ASTS` を別チャンクに保存し、未知の任意チャンクを保持する。
  未知の必須チャンク・版は拒否し、1.0 の旧ファイルは読み込んで移行する。圧縮は行わず、上限は 64 MiB。

検証: 中核の試験と Windows の編集・ページ・途中点・接続点・非同期保存・一覧描画・ドラッグ配置の操作試験、関連付けの
コマンド引用符の試験、Clippy を実行する。SVG／PNG の比較は日本語・アイコン・透明背景・太い線・
異なる表示範囲と倍率を含む。2,000 図形・5,000 接続線の経路計算は約 15 ms、
キャッシュ利用時のパン描画は約 14 ms。再現条件と測定の範囲は [性能の記録](../yydraw-performance.md)に記載する。
クラウドアイコン 200 個の描画比較では、画像ごとの描画範囲を絞ることで約 1,014 ms から約 17 ms に短縮。
移動中は背景と選択図形のビットマップを再利用し、原点・XY 軸は編集補助の重ね描きとして表示する。
実際の Windows 表示合成を含む 60 fps の保証や、全 DPI・IME の手動受入確認までは行っていない。

操作ガイドは [draw.md](../../crates/yy-win/help/draw.md)。サンプルは
`cargo run -p yy-draw --example sample -- target/yydraw-sample` で `.yyd`・SVG・PNG を生成できる。
