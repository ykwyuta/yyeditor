# 接続先からの性能分析SQLテンプレート（2026-10-21）

オブジェクトエクスプローラーの保存済み接続先、または配下のオブジェクトを右クリックし、「性能分析SQL（DB名）」から選択する。未接続でも、その接続設定に合うテンプレートを新しいSQLタブに表示できる。選択では接続・実行を行わず、既存の文書を保持する。

| DB | テンプレート数 |
|---|---:|
| SQLite | 5 |
| DuckDB | 3 |
| Oracle | 2 |
| SQL Server | 3 |
| PostgreSQL | 3 |
| MySQL | 3 |
| Db2 LUW | 3 |

## 検証結果

- 50件のテスト、clippy、フォーマット検査に成功。
- テンプレートのSQLは実接続で検証済みの`demo/yydbmanager/sql/performance`から組み込み、特定の業務テーブルを使うEXPLAINサンプルはメニューから除外。SQLite／DuckDBは空のDBでも実行できることを確認。
- Windows UIスモークテストで、全7DBのサブメニューと22個のテンプレートを作成。エディタ本文・対象接続先・必要権限のコメント、既存SQLの保持、未実行状態を確認。
- Windowsシェル試験で、実際の接続先右クリックメニューからSQLiteの項目を確認し、そのコマンドで新規SQLタブが作成され「未実行」と表示されることを確認。F5相当の明示操作で結果を1つ取得。
- テンプレート由来のSQLタブは接続先のDB種類と接続文字列を照合し、未接続・異なるDB種類・異なる接続先での実行を拒否することを確認。エラーやSQLコメントに接続文字列・パスワードは表示しない。
- 既存のSQL／ERタブ切り替え、列定義編集、実行計画ファイル、ヘルプ、接続設定の保存／再読み込みのWindows試験も成功。

必要な参照権限や統計収集の準備は、SQLコメントと「ヘルプ → DB別の性能分析ビュー…」に記載。メニューからの設定変更・権限付与・統計リセットは行わない。
