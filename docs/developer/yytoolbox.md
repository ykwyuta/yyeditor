# yytoolboxの構成と検証

ルートのCargoワークスペースにある独立したWindows GUIです。yy-win、WebView2、外部CLIを必要としません。
利用説明は[yytoolbox](../user/yytoolbox.md)と[同梱ヘルプ](../../apps/yytoolbox/help/help.md)を参照してください。

## 境界

- `lib.rs` がツールの項目・入力例・上限・処理を管理します。UIの結果は非同期ワーカーから受け取り、入力変更時に失効させます。
- `ui_appearance.rs` はネイティブ描画・フォント計測・配置を管理します。モニターDPIとアプリ倍率を掛け合わせ、条件はラベルを上に配置した1〜2列、入出力は幅に応じて縦横を切り替えます。説明・ステータスは実フォントで高さを測定し、画面全体のスクロール範囲とフォーカス追従を更新します。初期ウィンドウはモニターの作業領域に収めます。
- `webtools.rs` はQR、URL、HTML/CSS/JavaScript整形。QRはqrcode、整形はmarkup_fmt/Malva/Biome。JavaScriptはPure Rustのパーサーとフォーマッターを組み込み、C・アセンブラの補助ライブラリやNode.jsを必要としません。スクリプトは実行せず、文字列置換だけで整形しません。
- `formats.rs` は文字列キーの型付き共通ツリーを使います。「構造保持」ではXML/CSV/INIに専用のノード表現を出力し、YAMLとの全組合せで値を往復できます。標準形式で表現できない構造は拒否します。
- `images.rs` は明示的に渡されたファイルだけを読み、一時ファイルから `persist_noclobber` で保存します。名前の衝突は番号で解消し、元と既存出力を上書きしません。デコード・画素数・件数を制限します。
- `video.rs` はOS非依存の時間指定・編集タイムライン。秒/分:秒/時:分:秒を100ns単位で読み、最大100範囲を整列・統合し、残す区間の出力開始時刻を算出します。
- `video_edit.rs` は `recording` の子モジュールでSource Readerと録画用Encoderを共有します。ローカル動画の先頭映像・音声をRGB32/48kHz stereo PCMへデコードし、各サンプルを保持区間との交差で切り出し、出力時刻から除去区間を引いてH.264/AAC MP4へ書きます。音声はPCMフレーム境界に丸め、映像はフレーム境界をまたぐ指定では端のフレームの表示時間を調整します。元の有理数fpsを保持し、エンコーダーがフレームの表示間隔を正規化するため、映像の編集精度は元のfpsのフレーム単位です。1サンプル128MB・画像3200万画素を上限に逐次処理し、回転・非正方画素・奇数寸法・途中の形式変更は拒否します。Windowsのverbatim正規化パスはMFのURL解釈との互換のため同一のDOS/UNC表記へ変換します。
- 動画編集は新しいMP4のみ保存し、`persist_noclobber` で競合時も既存ファイルを維持します。中止・失敗では一時出力を破棄。録画の途中保存とは異なり、編集中のEscは取り消しです。結果は保存済みなので別の結果保存ボタンを出しません。
- `recording.rs` はWindows専用。GDIの矩形をRGB32へ取得し、Media FoundationのSink WriterでH.264/AAC MP4を生成します。キャプチャDIBは負の高さ（上の行から格納）、入力メディアは正のstrideに統一します。ffmpeg等の子プロセスは起動しません。
- 音声はWASAPI shared-modeで既定のPC再生音（loopback）とマイクを48 kHz/stereo/16-bit PCMとして取得します。キューは上限付き。選択した入力を平均してミックスし、無音部分を補い、デバイス取得・許可の失敗を通知します。
- 終了キーを選択した場合だけ、保存先の選択後、画面を隠す前にそのキーを`RegisterHotKey`で登録します。失敗時は開始せず設定欄で別のキーを選ぶよう案内します。成功した登録は録画終了まで保持し、確認と録画の間に他のアプリが取得する隙間を作りません。OSが検出できるグローバルキーの競合を検査するもので、他プロセスのキーボードフックによる入力の遮断までは予測できません。
- 録画時にはyytoolboxの可視トップレベル画面の状態を保存し、キャプチャ除外属性を設定して非表示にします。DWMの反映を待ってから録画し、小型バーの停止ボタンでその時点までを保存します。終了キーの初期値は「なし（ボタンのみ）」で、Escは登録せず録画中のEsc入力も無視します。矩形選択中のEsc取り消しは利用できます。終了・エラーでは画面と属性を戻し、ホットキー・COM・音声スレッド・GDI・MF資源を解放します。
- `recording_bar.rs`は約240×104論理pxの最前面操作バーです。開始前に`WDA_EXCLUDEFROMCAPTURE`を設定・確認してから表示し、タイマーで経過時間を更新します。「停止して保存」・バーを閉じる操作は既存のCANCELメッセージを送って途中保存し、保存中はボタンを無効化します。UiGuardがバーを破棄してから通常画面を復元します。録画結果は既にMP4へ保存済みなので、テキストの結果保存ボタンと二度目の保存ダイアログは提供しません。
- MP4は保存先フォルダの一時ファイルへ書き、指定時間・停止ボタン・任意の終了キーでの終了時にFinalizeと解放の後で置換します。早期終了時の音声は実際の経過時間までに制限し、指定時間まで無音で埋めません。開始前の取り消し・エラー時には既存ファイルを維持します。録画情報を表示するテキスト結果とMP4本体の保存先は区別します。

## 検証

```powershell
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test -p yytoolbox --locked
cargo build -p yytoolbox --locked
```

コア試験はOS非依存です。WindowsのUI試験は全23ツール、75/100/125/150/200%のアプリ倍率、480/640/1100論理px幅、96/120/144/192 DPIの組合せで、実GDIフォントと子コントロールを使用して配置を検査します。DPIはテスト専用の入力で再現するため、実際のモニター間移動の検証とは区別します。ラベル・初期値・全選択肢の文字幅、横方向の収まり、全要素のスクロール到達性、フォーカス追従を確認します。QR・YAML CSV・一括画像処理の非同期結果は期限付きで待ちます。
通常の録画試験は実デスクトップ・実マイクを収録せず、実際のキャプチャ用DIBにGDIで上下の色を描き分け、合成音声とともにH.264/AACへ符号化します。Media Foundation Source Readerでフレーム数・上下方向・長さ・音声の非無音を確認します。デコード時には出力メディアのstrideに従って上端・下端を判定します。
Source ReaderのRGB32変換には `MF_SOURCE_READER_ENABLE_VIDEO_PROCESSING` を使用します。
Windows Server CIでは必要ならServer-Media-Foundationを導入し、DLLと実コーデックの動作を試験します。必要なランタイムがない試験を成功扱いでスキップしません。
実機試験は明示的に実行します。実デスクトップを短時間収録し、PC再生音試験では小さい確認音を再生、マイク試験では既定の入力デバイスを収録します。システム音量・既定デバイス設定は変更しません。出力は `target/recording-hardware` に保存されます。実画面・実音声を含むため、必要に応じて確認後に削除してください。

```powershell
cargo test -p yytoolbox --bin yytoolbox --locked recording::hardware_tests -- --ignored --test-threads=1 --nocapture
```

全画面と指定矩形のMP4をデコードし、実WASAPIパケット、AACの音量、キャプチャからの自ウィンドウ消失・復元、停止ボタンによる録画途中の保存を確認します。マイクがない環境では試験は失敗し、成功としてスキップしません。矩形選択のマウス操作、保護されたコンテンツ、複数デバイスの組合せは追加確認が必要です。実行環境によってグローバルホットキーの権限も必要です。

参考: [Microsoft Source Reader](https://learn.microsoft.com/en-us/windows/win32/medfound/processing-media-data-with-the-source-reader)、[WASAPI loopback](https://learn.microsoft.com/en-us/windows/win32/coreaudio/loopback-recording)。

動画編集の通常試験は色分けした3シーンと440/880/1320Hz音声を実MFで符号化し、クリップ・カット・複数区間の結果をデコードします。シーン順序、上下方向、時刻の連続性、音声の周波数・長さ、無音声動画、既存ファイル保護、一時出力の片付けを検査します。実デスクトップや利用者の動画は収録しません。
