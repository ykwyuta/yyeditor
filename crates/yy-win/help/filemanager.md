# yyfilemanager ヘルプ

yyfilemanager は、エクスプローラーの代わりにフォルダを開いて整理する（フラットビュー・一括リネーム・
圧縮ファイルの中を見る）、手元のフォルダを共有フォルダへ同期する（途中で切れても続きから送る）、ファイルを
名前・属性・中身で探す、似た名前の版のうちどれが新しいかを判定する、中身が完全に同じファイルを見つける、
人が確かめてから古い版や写しをまとめて削除する、のためのアプリです。

## 画面の見かた {#screen}

- **タブ**（上）: フォルダ・同期・検索・似たファイル・重複・削除の確認・記録。Ctrl+1〜Ctrl+7 で切り替えます。
  起動すると「フォルダ」のタブを開きます（前回の場所）。
- 「フォルダ」のほかのタブでは、上に条件の欄とボタン、下に結果の一覧を出します。一覧は数十万行でも軽く動きます。
- 一覧の行を **ダブルクリック** すると既定のアプリで開きます（検索で中身が見つかった行は、yyeditor で
  その行を開きます）。**右クリック** で、場所を開く・yyeditor で開く・パスをコピー などを選べます。
- **ステータスバー**（下）: 進み（件数・大きさ・速さ）と結果。走査・比較・同期・削除などの長い処理は
  裏で 1 つずつ行い、その間も画面は動きます。**Esc** か「中止」で止められます。
- フォルダをウィンドウに **ドラッグ＆ドロップ** すると、今のタブの場所の欄に入ります（同期のタブは送り元）。

## フォルダ（エクスプローラーの代わり） {#folders}

「フォルダ」のタブで、エクスプローラーと同じようにフォルダを開いて、開く・コピー・移動・削除・名前の変更が
できます。コピー・移動・削除は Windows と同じ仕組みで行うので、進み・同じ名前の確かめ・ごみ箱・取り消し
（エクスプローラーの Ctrl+Z）もエクスプローラーと同じです。

- **アドレスバー**（上）: パスを打つか貼り付けて Enter（「移動」）。`%USERPROFILE%` などの環境変数、
  `PC`（ドライブの一覧）、圧縮ファイルの中（`C:\資料\a.zip\図`）も使えます。入力の途中で候補が出ます。
- **← → ↑ ⟳**: 戻る（Alt+←・Backspace は上へ）・進む（Alt+→）・上へ（Alt+↑）・最新の情報に更新（F5）。
  フォルダの中が変わると自動で読み直します。
- **左のツリー**: よく使うフォルダ（デスクトップ・ダウンロード・ドキュメント・ピクチャ・ミュージック・
  ビデオと、ピン留めしたフォルダ）と PC のドライブ。右クリックでピン留めする・外す。境界をドラッグして
  幅を変えられます。ネットワークの場所は `\\サーバー\共有` をアドレスバーに打ちます。
- **一覧**: 名前・更新日時・種類・サイズ・作成日時・属性（R 読み取り専用・H 隠し・S システム・A アーカイブ・
  C 圧縮・E 暗号化・L リンク）。列の見出しをクリックで並べ替え（フォルダが先、数字は数の順）。
  名前の頭の文字を打つとその行へ移ります。
- **表示 ▾**: 詳細・一覧・大きいアイコン、隠しファイルを表示、拡張子を表示、フラットビューにフォルダも出す。
- **開く**: ダブルクリック・Enter。フォルダは中へ、圧縮ファイルは[中へ](#archives)、ほかは関連付けで開きます。
- **右クリック**: 開く・プログラムから開く・yyeditor で開く・ターミナル（yyterm）で開く・ファイルのある場所を
  開く・切り取り・コピー・貼り付け・フォルダへコピー／移動・名前の変更・一括リネーム・削除・パスのコピー・
  プロパティ。「Windows のメニュー」にエクスプローラーの右クリックの項目（送る・圧縮・ほかのアプリの項目）が
  あります（Shift を押しながら右クリックで拡張の項目も）。何もないところの右クリックで新しいフォルダ・
  貼り付け・ピン留めなど。
- **クリップボード**: Ctrl+X・Ctrl+C・Ctrl+V はエクスプローラーとファイルをやり取りできます。
- **ドラッグ＆ドロップ**: 一覧から外（エクスプローラー・ほかのアプリ）へ、外から一覧へ。一覧のフォルダの上に
  落とすとそのフォルダへ。何も押さなければ同じドライブは移動・違うドライブはコピー、Shift で移動、Ctrl で
  コピーです。
- **名前の変更**: F2（拡張子を除いた部分を選んだ状態で始まります）。複数を選んで F2 は[一括リネーム](#rename)。
- **新しいフォルダ**: Ctrl+Shift+N。**削除**: Del（ごみ箱へ）・Shift+Del（完全に削除）。**プロパティ**: Alt+Enter。
- ステータスバーに、項目の数・選んだ数と大きさの合計・空き領域を出します。
- 開いている場所・表示の設定・ピン留めは設定のフォルダの `filemanager\folders.toml` に残ります。
- ほかのタブの一覧の右クリック「『フォルダ』のタブで場所を開く」で、そのファイルのある場所を開けます。

## フラットビュー {#flat}

**フラット**（Ctrl+Shift+F）を押すと、開いているフォルダの下の **すべてのサブフォルダのファイル** を、階層を
無視して 1 つの一覧に出します。「フォルダ」の列に、開いているフォルダからの場所を出します。

- 深い場所にあるファイルを探す: [絞り込み](#filter)と組み合わせます（例: `ext:pdf 見積`）。
- まとめて整理する: 選んで右クリックの「フォルダへ移動...」で 1 つのフォルダに集める、ドラッグで送る、
  削除する、[一括リネーム](#rename)する、など普通の一覧と同じことができます。
- 見つけた順に一覧に足していきます。数十万件でも動きます。読み込みの途中は Esc で止められます
  （止めたところまでの一覧を使えます）。
- 隠しフォルダの中のファイルは「隠しファイルを表示」のときだけ出します。リンク（ジャンクション）の先は
  たどりません。フォルダも出したいときは「表示 ▾」の「フラットビューにフォルダも出す」。
- 圧縮ファイルの中でも使えます（中の全部の項目）。

## 絞り込み {#filter}

一覧の上の欄（Ctrl+F・F3）に入れると、少し待ってから一覧を絞り込みます。Esc で消します。書き方は
[検索の書き方](#query)と同じで、メタデータの条件も使えます。

| 書き方 | 意味 |
|---|---|
| `見積 2024` | 名前に「見積」と「2024」を含む（全角・半角、大文字・小文字、ひらがな・カタカナの違いは無視） |
| `*.jpg`・`IMG_????.*` | ワイルドカード |
| `re:^IMG_\d{4}\.jpe?g$` | 正規表現 |
| `ext:jpg,png`・`size:>10MB`・`modified:2024`・`created:<2023-01-01` | 拡張子・大きさ・日時 |
| `exif.model:EOS`・`exif.date:2024-05`・`width:>=1920` | 写真の撮影情報・縦横 |
| `id3.artist:山田`・`id3.album:ベスト`・`id3.year:>=2000`・`duration:>300` | 音楽のタグ・長さ（秒） |
| `doc.author:佐藤`・`doc.title:報告`・`doc.pages:>10` | Office・PDF の文書の属性 |

メタデータの名前は `名前:値`（含む）・`名前:>値`・`名前:>=値`・`名前:<値`・`名前:<=値`・`名前:=値` で比べます。
メタデータの条件があると、対象のファイルを裏で読みます（ステータスバーに残りの数）。読めるメタデータは
[一括リネーム](#rename)の表を見てください。

## 一括リネーム {#rename}

選んだ項目（選んでいなければ一覧のすべて。フラットビューなら複数のフォルダにまたがってよい）の名前を、
規則でまとめて変えます。**一括リネーム...**（Ctrl+Shift+R・複数を選んで F2・右クリック）で開きます。
規則を変えるたびに、下のプレビューに **新しい名前** をすぐに出します（変わる名前は青、問題は赤）。

規則は上から順に使います。

1. **検索・置換**: 検索する文字と置き換える文字。「正規表現」なら `$1`・`${name}` で括弧の中を使えます
   （例: 検索 `IMG_(\d+)` 置換 `photo-$1`）。対象は 名前（拡張子を除く）・名前全体・拡張子。
   「すべて」を外すと最初の 1 つだけ。
2. **ひな形**: 新しい名前の形。既定の `{name}{ext}` は「変えない」です。「挿入 ▾」から選べます。

   | 書き方 | 意味 |
   |---|---|
   | `{name}`・`{ext}` | 名前（拡張子を除く。置換の後）・拡張子（`.jpg`） |
   | `{n}`・`{n:3}` | 連番（`{n:3}` は 3 桁にそろえる）。始まり・増分を下で決め、「フォルダごとに振り直す」もできます |
   | `{orig}`・`{origname}`・`{parent}`・`{size}` | 元の名前・元の名前（拡張子を除く）・フォルダの名前・大きさ（バイト） |
   | `{modified:%Y%m%d}`・`{created:%Y-%m-%d_%H%M%S}`・`{today:%Y%m%d}` | 日時（`%Y` 年 `%m` 月 `%d` 日 `%H` 時 `%M` 分 `%S` 秒 `%y` 年の下 2 桁 `%j` 年の何日目 `%a` 曜日（英） `%A` 曜日 `%b` 月（英）） |
   | `{name:1-8}`・`{name:3-}` | 名前の 1〜8 文字目・3 文字目から |
   | `{exif.date:%Y%m%d_%H%M%S}`・`{exif.make}`・`{exif.model}`・`{exif.lens}`・`{exif.iso}`・`{exif.fnumber}`・`{exif.exposure}`・`{exif.focal}`・`{width}`・`{height}` | 写真（JPEG・TIFF・RAW・PNG・GIF・BMP・WebP、MP4 などの動画の縦横） |
   | `{id3.title}`・`{id3.artist}`・`{id3.album}`・`{id3.albumartist}`・`{id3.track:2}`・`{id3.disc}`・`{id3.year}`・`{id3.genre}`・`{duration}` | 音楽（MP3・FLAC・Ogg・Opus・M4A） |
   | `{doc.title}`・`{doc.author}`・`{doc.subject}`・`{doc.keywords}`・`{doc.lastmodifiedby}`・`{doc.company}`・`{doc.pages}`・`{doc.created:%Y%m%d}`・`{doc.modified:%Y%m%d}` | 文書（docx・xlsx・pptx・PDF） |
   | `{exif.model\|不明}` | `\|` の後は値がないときの文字 |
   | `{{`・`}}` | `{`・`}` という文字 |

3. **大文字・小文字**: そのまま・すべて小文字・すべて大文字・語の頭だけ大文字・拡張子だけ小文字。
4. **スクリプト**（任意）: [Rhai](https://rhai.rs) で書いた式が返した文字列を新しい名前にします（何も返さなければ
   そのまま）。使える変数は `name`（ここまでの新しい名前）・`stem`・`ext`・`orig`・`n`（連番）・`index`（0 から）・
   `folder`・`path`・`size`・`modified`（秒）・`is_dir`・`meta`（メタデータの表。`meta["exif.model"]`）。関数は
   `pad(数, 桁)`・`fmt_time(秒, "%Y%m%d")`・`re_replace(文字, 正規表現, 置換)`・`re_match(文字, 正規表現)`・
   `re_capture(文字, 正規表現, 番号)` と Rhai の文字列の関数（`to_lower()`・`replace()` など）。ファイルの読み書き・
   ほかのプログラムの実行はできません。終わらないスクリプトは止めてエラーにします。

   ```
   // 「Track 3 - Song.mp3」→「003_song.mp3」。テキストは変えない
   if ext == ".txt" { return; }
   pad(n, 3) + "_" + re_capture(stem, "Track \\d+ - (.*)", 1).to_lower() + ext
   ```

**状態**（プレビューの右の列）: 変わる・変わらない・**使えない名前**（`\ / : * ? " < > |`、終わりの空白・`.`、
`CON` などの予約された名前、255 文字を超える）・**重複**（この一括の中で同じ名前になる。大文字と小文字は
区別しない）・**既にある**（一括に入っていない別のファイルと同じ名前）・**エラー**（スクリプト）。問題が
1 つでもあると「実行」は押せません。「問題を除いて実行」で問題のない項目だけを変えられます。

**実行** すると、入れ替え（`a→b`・`b→a`）や連なり（`1→2`・`2→3`）、大文字と小文字だけの変更でもぶつからない
ように、いったん一時の名前に変えてから新しい名前にします。フォルダとその中を一緒に変えるときは中から変えます。
途中で失敗したら、それまでに変えたものをすべて元に戻します。実行の記録は設定のフォルダの
`filemanager\renames\rename-日時.csv` に残り、**元に戻す...** で記録を選ぶと元の名前に戻せます。

## 圧縮ファイルの中 {#archives}

一覧の圧縮ファイルを開く（ダブルクリック・Enter）と、**展開せずに** フォルダと同じように中に入ります
（目次だけを読みます）。アドレスバーは `C:\資料\a.zip\図` のようになります。上へ（↑・Backspace）で外へ戻ります。

- 列: 名前・サイズ・圧縮後・圧縮率・方式・更新日時・暗号化（🔒）。フラットビュー・並べ替え・絞り込みも使えます。
- 中のファイルを開くと、その 1 つだけを一時フォルダに展開して関連付けで開きます（読み取り専用の写しです。
  直しても圧縮ファイルには戻りません）。中の圧縮ファイルは、展開してからその中に入ります。
- **展開してコピー...**（右クリック）: 選んだ項目（フォルダはその中ごと）を選んだフォルダへ展開します。
  **Ctrl+C** とドラッグで外へ出すこともできます（いったん一時フォルダに展開します。512 MB まで）。
- 中を書き換える（足す・消す・名前を変える）ことはできません。

| 形式 | 中を見る | 展開 |
|---|---|---|
| ZIP（ZIP64、日本語の名前は UTF-8 と Shift_JIS） | ○ | 無圧縮・Deflate。暗号化されたもの・ほかの方式（Deflate64・BZip2・LZMA など）は中を見るだけ |
| tar・tar.gz・tgz・tar.xz・txz | ○ | ○ |
| gz・xz（1 つのファイル） | ○ | ○ |
| 7z | ○（目次が圧縮されていても） | 無圧縮・LZMA・LZMA2 の 1 段のもの。BCJ などのフィルター・暗号化されたものは中を見るだけ |

xz と 7z の LZMA2 は、展開した全体をメモリに置くため 1 GB までです。壊れたものは CRC の不一致などで止め、
展開先の外に出る名前（`..`）は展開しません。RAR には対応していません。

## 同期 {#sync}

手元のフォルダ（送り元）の中身を共有フォルダ（送り先）へ送ります。向きは **送り元 → 送り先の一方向** です
（逆向きは [共有フォルダから手元へ](#download)）。

1. 送り元・送り先を入力します（「参照...」で選べます）。送り先がなければ作ります。
2. **やり方** を選びます。
   - **更新**: 新しいファイルと変わったファイルを送ります。送り先にだけあるファイルは残します。
   - **ミラー**: 送り先を送り元と同じにします。送り元にないファイルは送り先から **消します**（一覧の
     「削除」の行）。消すファイルは隔離フォルダへ移し、その場所は実行のたびに尋ねます
     （[隔離フォルダの場所](#trashwhere)）。
3. **比べ方** を選びます。
   - **大きさと日時**（既定）: 大きさか更新日時が違えば変わったとみなします。日時の誤差は 2 秒まで許します
     （共有フォルダは日時の精度が粗いことがあるため）。
   - **中身で比べる**: 大きさが同じで日時だけが違うときは、両方の中身（BLAKE3）を比べます。遅くなりますが
     確実です。
4. **比べる** を押すと、送るものの一覧（計画）が出ます。種類は 新規・更新・日時だけ（中身は同じで日時を
   合わせる）・削除・衝突 です。
5. 確かめてから **実行** を押します。

- **衝突**: 前回の同期のあとで送り先のファイルも変わっていたものです。上書きで消してしまわないよう、
  既定では送りません。行を右クリックして「上書きする」「両方残す（送り先の名前に日時を付けて残す）」
  「送らない」を選べます。
- 送り方: 送り先には一時的な名前（`.yypart`）で書き、書き終えて大きさを確かめてから本来の名前に置き換えます。
  途中で止まっても、送り先の元のファイルが壊れることはありません。
- **同期ジョブ**: 送り元・送り先・やり方・比べ方に名前を付けて保存できます（「保存」。組み合わせボックスで
  選ぶと読み込みます）。

## 同期の続き（レジューム） {#resume}

同期は、ファイルの途中まで送った位置と、どのファイルまで済んだかを記録しながら進めます。

- ネットワークが切れたときは、少し待ってから自動で続けます（2 秒・5 秒・10 秒…最長 60 秒と間隔を延ばして、
  進みがないまま 10 回続いたら中断）。
- 中止した・アプリを閉じた・PC が止まった ときは、次にアプリを起動すると「前回の同期が終わっていません」と
  出ます。同期のタブの **続ける** を押すと、送りかけのファイルは **途中から** 、済んだファイルは飛ばして
  続けます。
- 送りかけのファイルは、送り元が変わっていたら最初から送り直します。

## 大きなファイルの差分の送り方 {#delta}

大きなファイル（既定 64 MB 以上。設定の `delta_min_mb`）は、送ったときに中身を 1 MB ずつに分けたハッシュを
覚えておきます。次の同期で、送り先のファイルが前回送ったときのまま（大きさ・日時が同じ）なら:

1. 送り先のファイルを、同じ共有フォルダの中で `.yypart` に写します（サーバー側のコピー。回線をほとんど
   使いません）。
2. 送り元を手元で読んでハッシュを比べ、**違う 1 MB だけ** を書き込みます。
3. 大きさを確かめてから本来の名前に置き換えます（ふつうの送り方と同じ）。

- 中の一部だけが書き換わる大きなファイル（データベース・仮想ディスク・追記されるログなど）で、送る量が
  大きく減ります。ブロックは位置で比べるので、先頭に挿入したファイルではほとんど減りません。
- 送り先がほかで変わっていた・覚えたハッシュがない・サーバー側のコピーができない ときは、ファイル全体を
  送ります。記録に「差分の送り方: ○ ブロック中 ○ ブロックを書きました」と出ます。
- 途中で止まったときは、次は差分の送り方をやり直します（サーバー側のコピーからなので速い）。
- `delta_min_mb = 0` で使わなくなります。

## 共有フォルダから手元へ {#download}

送り先の欄の右の **⇅ 入れ替え** を押すと、送り元と送り先が入れ替わります。送り元に共有フォルダ、送り先に
手元のフォルダを入れれば、共有フォルダの中身を手元へ同期できます（やり方・比べ方・衝突・レジュームは同じ）。

- 両方向の同期（両側の変更を混ぜる）はしません。同じフォルダを両方向に使うと、相手側の変更は衝突として
  扱われます。
- 送り元が共有フォルダのときは、差分の送り方は使いません（送り元を読むのに回線を使うため、減らないため）。
- 同期ジョブとして保存すれば、定期実行もできます。

## 定期実行（タスク スケジューラー） {#schedule}

保存した同期ジョブは、画面を出さずに実行できます。

```
yyfilemanager.exe --sync 案件A
```

Windows のタスク スケジューラーに登録すると、毎晩などに同期できます。衝突は送らずに記録に残します。
結果は記録のファイル（[記録](#log)）に書きます。終了コードは 0（済んだ）・1（失敗があった）・2（ジョブがない）
です。

## 検索 {#search}

1. **場所** にフォルダを入れます（`;` で区切って複数。「追加...」で足せます）。共有フォルダも指定できます。
2. **検索** の欄に条件を書いて Enter（または「検索」）。書き方は [検索の書き方](#query)。
3. 中身の条件（`content:`）があれば、名前・種類・大きさ・日時で絞ったあとのファイルの中身を読みます。
   文字コード（UTF-8・Shift_JIS・EUC-JP・UTF-16 など）はファイルごとに判別します。
   「Office・PDF の中も」にチェックがあれば、`docx`・`xlsx`・`pptx` と PDF の中の文字列も探します。
   PDF は文字が埋め込まれているもの（ワープロなどから作ったもの）だけで、スキャンした画像の PDF・暗号化された
   PDF は探せません。

- **中身を読むのは、設定の `content_patterns` で名指ししたファイル名のパターン（拡張子）に合うファイルだけ**
  です（既定は `*.txt`・`*.csv`・`*.log`・`*.md`・`*.json`・`*.xml`・`*.html`・`*.sql`・`*.cbl`・`*.cpy`・
  `*.jcl`・`*.docx`・`*.xlsx`・`*.pptx`・`*.pdf` など）。合わないファイルは中身を探さず、中身の索引にも
  入れません。ほかの種類も探したいときは、設定に足してください（例: `"*.java"`）。
- バイナリのファイルと、大きすぎるファイル（既定 1 GB 超）は中身を読みません。
- Office 文書は圧縮前のファイルサイズとは別に、展開した XML 全体・抽出したテキスト・項目数にも上限を設けています。
  展開・抽出の上限はそれぞれ通常 8 MiB で、背景メモリの設定が小さい場合はさらに下がります。
  上限を超える文書や壊れた文書は内容検索・全文索引の対象から外します。
- **中身の索引**: 中身を読んだファイルは、隣り合う 2 文字の組を索引に残します。次からは、探す文字列の組を
  すべて含むファイルだけを読むので、同じ場所を何度も探すときに速くなります（記録に「○ 個を読まずに済み
  ました」と出ます）。候補は実際に読んで確かめるので、結果は索引を使わないときと同じです。変わったファイル・
  新しいファイルは、その検索のときに読んで索引に足します。1 文字だけの検索と正規表現では索引を使いません。
  使わないときは設定の `fulltext_index = false`。
- **CPU とメモリの上限**: 中身の索引の作成・中身の検索・索引のバキュームは、設定で許した上限をなるべく守って
  裏で動かします。
  - CPU: `background_cpu_percent`（既定 25%）の分のスレッドだけを使い、Windows ではスレッドをバックグラウンド
    モードにして CPU・ディスク・メモリの優先度を下げます（ほかの作業を邪魔しにくくします）。
  - メモリ: `background_memory_mb`（既定 512 MB）の半分を、同時に読むファイルの見積もりの合計の上限にします。
    これより大きなファイルは、ほかに読んでいるものがないときに 1 つだけ読みます（このときは上限を超えます）。
    残りの半分を中身の索引に使い、超えるファイルは索引に足さずに探すだけにします（記録に出ます）。索引は
    場所ごとに 1 つずつ読み込み、探し終えたら保存して手放します。
- **中身の索引のバキューム**: 「整理」メニューの **中身の索引のバキューム...** で、パターンに合わなくなった
  ファイル・消えたファイル・変わったファイルの記録を除いて索引を詰め直します。場所（フォルダ）がなくなった
  索引は消します。ファイルがあるかを確かめるので、共有フォルダでは時間がかかることがあります。届かない共有の
  記録は消さずに残します。
- 中止（Esc）しても、そこまでに見つかったものは残します。
- 結果は右クリックの「一覧を CSV に書き出す」で CSV にできます（yysheet で開けます）。
- 結果の 1 行を右クリックして **このファイルの別の版を探す** を選ぶと、検索した場所の中から似た名前の版を
  集めて、どれが新しいかを判定します（結果は「似たファイル」のタブ）。**同じ中身のファイルを探す** は、
  大きさが同じファイルだけを読んで、中身が完全に同じものを探します（結果は「重複」のタブ）。そこから
  削除の確認へ送れます。
- 結果の行を右クリックして **削除の確認に加える** を選ぶと、選んだファイルを削除の確認の一覧に 1 件ずつ加えます
  （チェックは付けません。確かめてからチェックしてください）。**このフォルダを同期の送り元にする** は、
  そのファイルのフォルダを同期のタブの送り元に入れます。
- 名前・属性だけの検索では、前回の目録が古いときは、走査し直す前に前回の目録で見つかったものを先に出します。
  前回の目録がない場所は、走査しながら見つかった順に結果を足していきます。どちらも走査し終えると最新の結果に
  置き換わります。

## 検索の書き方 {#query}

条件は空白で区切って並べます（すべてを満たすものを探します）。空白を含む値は `"…"` で囲みます。

| 書き方 | 意味 |
|---|---|
| `見積` | 名前に「見積」を含む（全角・半角、大文字・小文字、ひらがな・カタカナの違いは無視） |
| `見積*.xlsx` | ワイルドカード（`*` は何文字でも、`?` は 1 文字） |
| `/^\d{8}_.*\.pdf$/` | 名前の正規表現 |
| `ext:xlsx;xls;csv` | 拡張子 |
| `kind:文書` | 種類（文書・表計算・画像・動画・音声・圧縮・テキスト） |
| `size:>100MB`・`size:1KB..10KB`・`size:空` | 大きさ |
| `modified:2026-09-01..2026-09-30` | 更新日時の範囲。`>=2026-09-01`・`<=…` も |
| `modified:今日`・`昨日`・`今週`・`今月` | 決まった範囲 |
| `modified:30日以内`・`modified:30日より前` | 今からの日数 |
| `created:…` | 作成日時（書き方は modified と同じ） |
| `path:案件A\見積` | パスにそのフォルダを含む |
| `-path:old` | パスにそのフォルダを含まない |
| `attr:readonly`・`attr:hidden` | 読み取り専用・隠し |
| `content:"税込"` | 中身にその文字列を含む |
| `case:on` | 名前の大文字・小文字などを区別する |
| `dupe:yes`・`dupe:no`（`has:重複`） | 中身が同じファイルが探した場所のほかにある・ない（重複を探すのと同じように中身を読みます） |
| `version:old` | 似たファイルの判定で古い版とされたもの（新しい版がほかにある） |
| `version:newest`・`version:any` | 判定で最新とされたもの・版のグループに入るもの |

例: `見積 ext:xlsx size:>1MB modified:>=2026-09-01 content:"税込"`

## 保存した検索・目録 {#saved}

- **保存した検索**: 検索の欄・場所・「Office・PDF の中も」に名前を付けて保存できます（「保存した検索」の欄に
  名前を入れて「保存」）。組み合わせボックスで選ぶと、すぐにその検索を行います。設定のフォルダの
  `filemanager\searches.toml` に保存します。
- **目録**: 走査した結果（ファイルの一覧と大きさ・日時）を場所ごとに保存し、設定の時間（既定 60 分。
  `index_max_age_min`）より新しければ、検索と似たファイルでは走査し直さずに使います（記録に「○ 分前の目録を
  使います」と出ます）。最新の状態で探したいときは「走査し直す」にチェックを付けてください。重複は中身を
  読むので、毎回走査し直します。

## 似たファイル（新しい版の判定） {#similar}

`見積_v2.xlsx`・`見積_最終.xlsx`・`見積 - コピー (2).xlsx` のように、同じ文書の別の版と思われるファイルを
グループにまとめ、どれが一番新しいかを提案します。

- 名前から版の手がかり（`v3`・`第2版`・`rev.B`・`_20260901`・`最終`・`修正`・`コピー`・`(2)` など）を
  取り除いて比べ、似ている度合いが一定以上（既定 0.85）のものをまとめます。種類の違うもの（`xlsx` と `docx`
  など）はまとめません（`xls` と `xlsx` のような同じ仲間はまとめます）。
- 順位は **名前の手がかりを日時より優先** します（版の番号・名前の日付・「最終」→ 更新日時 → 大きさ）。
  1 位を「最新（提案）」とし、理由と **自信**（高・中・低）を出します。
- 「古い版を削除の確認へ」で、グループ全部を [削除の確認](#review) に送ります（自信が高いグループの古い版
  だけにチェックが付きます）。行を右クリックすると、そのグループだけを送れます。

- **対象の絞り込み**: 「拡張子」に `xlsx;docx`（`*.xlsx`・`.csv` の書き方も可。`;`・`,`・空白で区切る）、
  「名前の正規表現」に `^見積_` のような正規表現（ファイル名だけに当てます。大文字・小文字は区別しません）を
  入れると、それに合うファイルだけで探します。どちらも空なら全部が対象です。
- **除く条件**: 「除くフォルダ名」に `^(old|バックアップ|_旧)$` のような正規表現を入れると、途中のどの階層の
  フォルダの名前に合っても、その下のファイルを除きます（探す場所そのものの名前には当てません）。「除くファイル名」
  に `^~\$|\.bak$` のような正規表現を入れると、名前が合うファイルを除きます。どちらも大文字・小文字は区別せず、
  部分一致です（全体に合わせるときは `^…$`）。

判定は名前と日時・大きさからの推測です。必ず [削除の確認](#review) で確かめてください。

## 重複（完全に同じファイル） {#dupes}

中身が 1 バイトも違わないファイルを探します。

1. 大きさが同じものだけを候補にします（0 バイトのファイルは除きます）。
2. 先頭と末尾（各 64 KB）のハッシュで絞ります。
3. 全体のハッシュ（BLAKE3）で確かめます。

ハッシュは置き場所（設定のフォルダの `filemanager\index`）に残すので、2 回目からは変わったファイルだけを
読みます。「写しを削除の確認へ」で、各グループの 1 つ（作成日時がいちばん古いもの）を残し、ほかの写しにチェックを
付けて [削除の確認](#review) に送ります。

- **対象の絞り込み**: 「拡張子」に `xlsx;docx`（`*.xlsx`・`.csv` の書き方も可。`;`・`,`・空白で区切る）、
  「名前の正規表現」に `^見積_` のような正規表現（ファイル名だけに当てます。大文字・小文字は区別しません）を
  入れると、それに合うファイルだけで探します。どちらも空なら全部が対象です。
- **除く条件**: 「除くフォルダ名」に `^(old|バックアップ|_旧)$` のような正規表現を入れると、途中のどの階層の
  フォルダの名前に合っても、その下のファイルを除きます（探す場所そのものの名前には当てません）。「除くファイル名」
  に `^~\$|\.bak$` のような正規表現を入れると、名前が合うファイルを除きます。どちらも大文字・小文字は区別せず、
  部分一致です（全体に合わせるときは `^…$`）。
  絞り込んだときも、対象外のファイルのハッシュの覚え書きは残します。

## 削除の確認と削除 {#review}

似たファイル・重複・検索から送ったファイルを、人が確かめてから消す一覧です（閉じても残ります）。

- チェックの付いたものが消す対象です（行の左のチェック、Space、右クリックの「チェックする」）。
  「残す」の行（最新・残す写し）にはチェックを付けられません。
- **削除...** を押すと、消す前に次を確かめます。合わないものは消さずに飛ばします。
  - 一覧に出したあとで大きさ・日時が変わっていないか。
  - 重複の写しは、残すファイルがまだあり、中身が同じか。
  - グループの全部にチェックが付いていないか（最後の 1 つは必ず残す）。検索から加えたものは 1 件ずつで、
    この決まりは使いません。
  - 設定の守るフォルダ（`protect`）の中でないか。
- 消し方:
  - 手元のドライブのファイルは **ごみ箱** へ送ります。
  - 共有フォルダのファイルは **隔離フォルダ**（`.yyfm-trash`）へ移します（共有フォルダにはごみ箱がないため）。
    隔離フォルダを作る場所は、削除するたびに尋ねます（[隔離フォルダの場所](#trashwhere)）。設定の日数（既定 30 日）が過ぎたものは「整理」メニューで消せます
    （[隔離フォルダの整理](#trash)）。
  - 隔離フォルダを作れない共有では、**確認を 2 回** したうえで、すぐに（元に戻せない形で）消します。
- 消したものは記録（設定のフォルダの `filemanager\purges\日時.csv`）に残します。

## 隔離フォルダの場所 {#trashwhere}

共有フォルダのファイルを削除するとき・ミラーの同期で送り先のファイルを消すときは、すぐには消さずに隔離フォルダ
（`.yyfm-trash`）へ移します。**作る場所は作業ごとに尋ねます**。

- **はい**: 既定の場所に作ります。削除ではそれぞれのファイルのある共有（同期・検索したフォルダ）の下に
  `.yyfm-trash\日時\元の相対パス`、ミラーでは送り先の下に作ります。同じ共有の中なので名前の変更で移し、
  大きなファイルでもすぐ終わります。
- **いいえ**: 場所（フォルダ）を選びます。`選んだ場所\.yyfm-trash\日時\元の場所の名前\元の相対パス` に移します
  （いくつかの共有のファイルが混ざらないよう、元の場所ごとのフォルダに分けます）。選んだ場所が別のドライブ・
  共有のときは、写して大きさを確かめ、日時を合わせてから元を消します（回線を使うので時間がかかります）。
- **キャンセル**: 削除・同期をやめます。
- 同期ジョブをミラーで保存するときにも尋ね、ジョブに覚えます（定期実行ではその場所を使います）。
- 移した先は削除の記録・同期の記録に残ります。「記録から元に戻す」は、別の場所から戻すときも写してから戻します。

## 削除を元に戻す {#undo}

「記録から元に戻す...」で削除の記録（CSV）を選ぶと、隔離フォルダへ移したファイルを元の場所に戻します。
元の場所に同じ名前のファイルがあれば戻しません。ごみ箱へ送ったものは、エクスプローラーのごみ箱から戻して
ください。すぐに消したものは戻せません。

## 隔離フォルダの整理 {#trash}

「整理」メニューの **隔離フォルダの古いものを消す...** で隔離フォルダを作った場所（`.yyfm-trash` のある
フォルダ）を選ぶと、その `.yyfm-trash` の中で設定の日数（`trash_days`。既定 30 日）より前の日時の
フォルダを一覧にし、確かめてから消します。消したものは元に戻せません。ミラーの同期で消したファイルも
同じ隔離フォルダに入ります。

## 記録 {#log}

記録のタブには、行った操作・失敗・結果を出します。同じものを設定のフォルダの `logs\filemanager.log` にも
書きます（ヘルプ メニューの「記録のフォルダを開く」）。画面なしの同期（`--sync`）の結果もここに書きます。

## 設定 {#settings}

設定ファイル（ファイル メニューの「設定ファイルを開く」）の `[filemanager]` で変えられます。

| キー | 既定 | 意味 |
|---|---|---|
| `scan_threads` | 16 | 走査の並列数 |
| `copy_threads` | 4 | 同期で同時に送るファイルの数 |
| `time_tolerance_sec` | 2.0 | 更新日時の誤差の許し幅（秒） |
| `delta_min_mb` | 64 | この大きさ以上のファイルは差分の送り方にする（MB。0 で使わない） |
| `verify` | `"size"` | 送ったあとの確かめ。`"hash"` なら中身も比べる |
| `copy_acl` | `false` | 同期で送ったファイルにアクセス権も写す（Windows は明示的なアクセス権と継承の止め方。所有者・監査は写さない。写せなかったときは記録に残し、送ったことは済みにする） |
| `similar_threshold` | 0.85 | 似たファイルの似ている度合いのしきい値 |
| `trash_days` | 30 | 隔離フォルダに残す日数の目安 |
| `search_threads` | 8 | 中身の検索・ハッシュの並列数 |
| `search_max_mb` | 1024 | これより大きなファイルの中身は探さない（MB） |
| `content_patterns` | `["*.txt", "*.csv", …, "*.pdf"]` | 中身を探す・中身の索引を作るファイルの名前のパターン。合わないファイルの中身は読まない（空なら既定の一覧） |
| `background_cpu_percent` | 25 | 裏の処理（中身の索引の作成・中身の検索・バキューム）が使ってよい CPU の割合（%） |
| `background_memory_mb` | 512 | 裏の処理が使ってよいメモリ（MB。0 で上限なし） |
| `fulltext_index` | `true` | 中身の検索で中身の索引を使う（設定のフォルダの `filemanager\fulltext\` に置く） |
| `index_max_age_min` | 60 | 検索・似たファイルで、これより新しい目録は走査し直さずに使う（分） |
| `exclude` | `[]` | 走査で除くファイルの名前のパターン（`Thumbs.db`・`~$*` などの既定に足す） |
| `protect` | `[]` | 削除の対象にしないフォルダ |

同期ジョブ・保存した検索・同期の途中の記録・前回の同期の状態（ブロックのハッシュを含む）・目録・ハッシュの
索引・削除の確認の一覧・削除の記録は、設定のフォルダの
`filemanager\` に置きます。

## 困ったときは {#trouble}

- **共有フォルダに書けない**: エクスプローラーでその共有にファイルを作れるか確かめてください。資格情報は
  Windows の資格情報マネージャーのものを使います。
- **同期のたびに全部が「更新」になる**: 共有フォルダ（NAS）の日時の精度が粗いことがあります。設定の
  `time_tolerance_sec` を大きくするか、比べ方を「中身で比べる」にしてください。
- **衝突が多い**: 送り先をほかの人も変えています。一方向の同期なので、送り先で変わったものは上書きしません。
  内容を確かめてから右クリックで扱いを選んでください。
- **似たファイルの判定がおかしい**: 判定は推測です。自信が「中」「低」のグループにはチェックを付けません。
  削除の確認で 1 件ずつ確かめてください。
- **異常終了した**: ヘルプ メニューの「異常終了の記録のフォルダを開く」に記録があります。
