# yybrowser ヘルプ

yybrowser は、**OS（インターネット オプション）とは別のプロキシを指定できる** タブブラウザです。表示には
Microsoft Edge と同じ WebView2 を使います。社内のプロキシを通さずにつなぎたい・検証用のプロキシ（Fiddler・
mitmproxy など）だけを通したい・yyterm の SSH のポート転送（`-D`）で作った SOCKS を通したい、といったときに、
OS の設定を変えずに、このブラウザだけ別の経路でつなぎます。

## 画面の見かた {#screen}

- **タブ**（上）: ページのタイトルを出します（読み込み中は ⟳）。右端の × か中クリックで閉じます。右クリックで
  「ほかのタブを閉じる」などを選べます。
- **ツールバー**: 戻る・進む・再読み込み（読み込み中は中止）・ホーム、アドレスバー、**プロキシのボタン**
  （今のプロファイルの名前。押すとプロファイルを切り替えるメニュー）。アドレスバーの右の **🛡 件数** は、
  今のページで [広告ブロック](#adblock) が止めた数です（切なら「🛡 切」、止めないサイトなら「🛡 除外」）。
- **アドレスバーの左の表示**: 開いているページが [ホストの転送](#hosts) の対象なら `転送 → 127.0.0.1:8443`、
  さらに開発者用証明書で受け入れたページなら **🔒 開発者用証明書を利用中** と出します。押すと詳しく出します。
- **状態表示**（下）: 今のプロキシ（例: `検証用（127.0.0.1:8888）`）と、読み込めなかったときの理由。
- ウィンドウのタイトルにも、今のプロファイルの名前を `[名前]` で出します（どの経路でつないでいるかを
  取り違えないように）。

## プロキシ {#proxy}

「プロキシ」メニューの **プロキシの設定...** の **ふだんの経路** で、プロファイルごとに **やり方** を選びます。

| やり方 | 内容 |
|---|---|
| OS と同じ | インターネット オプションの設定（自動検出・PAC・手動）に従います |
| 使わない（直接） | OS にプロキシがあっても、直接つなぎます |
| 指定 | 指定したプロキシを使います |
| 自動構成（PAC） | PAC ファイルの URL（`http://…`・`https://…`・`file:///…`）に従います |

「指定」のときは、**プロキシ** の行で種類を選び、ホスト（名前か IP アドレス）とポートを入れます。ポートを
空にすると、よく使う番号（HTTP 8080・HTTPS 443・SOCKS 1080）になります。

| 種類 | 内容 |
|---|---|
| HTTP | ふつうのプロキシ（https のページも CONNECT でこれを通ります） |
| HTTPS | HTTPS でつなぐプロキシ |
| SOCKS5 | SOCKS5（ホスト名もプロキシ側で解決します） |
| SOCKS4 | SOCKS4 |
| 詳しい指定 | 前の版で保存した「スキームごとの指定」（`http=…;https=…`）などのときだけ出ます |

- **ドットのない名前（社内のサーバーなど）は直接** にチェックすると、`intranet` のような名前はプロキシを通しません。
- **直接にする** の欄に、ほかにプロキシを通さないホストを `;` 区切りで書けます（`*.example.co.jp; 192.168.0.0/16`）。

yyterm で `ssh -D 1080 踏み台` に相当するポート転送を開いておき、種類を SOCKS5、ホストを `127.0.0.1`、ポートを
`1080` にすれば、踏み台の先のネットワークのサイトを開けます。

## プロキシのプロファイル {#profiles}

- **プロキシの設定...** の上の段で、プロファイル（名前を付けたプロキシの設定）を選び、**新規**・**複製**・**削除**
  できます。下の **起動するときにこのプロファイルを使う** にチェックしたものが、次に起動したときの既定です。
  **広告ブロックを使う** で、そのプロファイルの [広告ブロック](#adblock) を入・切できます。
- 「プロキシ」メニューやプロキシのボタンでプロファイルを選ぶと、このウィンドウのプロキシを切り替えます。
  ブラウザ（WebView2）を起動し直し、開いていたタブは同じ URL で開き直します（入力中のフォームの内容は
  失われます）。
- プロファイルは設定のフォルダの `browser.toml` に保存します。
- **Cookie・キャッシュ・ログインの状態はプロファイルごとに分かれます**（`%LOCALAPPDATA%\yyeditor\yybrowser\`
  の下に、プロファイルごとのフォルダ）。検証用の経路でのログインが、普段の経路に混ざりません。

## ドメインごとのプロキシ {#rules}

プロキシの設定の **ドメインごとのプロキシ** の一覧で、ドメインごとに別の経路を使えます。上から順に調べ、
最初に当てはまったものを使います（↑↓ で順番を変えられます）。どれにも当てはまらなければ、ふだんの経路
（「使わない（直接）」なら直接、「指定」なら指定のプロキシ）に従います。

**追加...**（か **編集...**・ダブルクリック）の画面で選びます。

| 欄 | 選ぶもの |
|---|---|
| 対象 | このドメインとサブドメイン ／ サブドメインだけ ／ IP アドレスの範囲 ／ `*` を使う型 |
| ドメイン | `corp.example.jp`（範囲なら `10.20.0.0/16`） |
| 経路 | 直接 ／ HTTP ／ HTTPS ／ SOCKS5 ／ SOCKS4 |
| プロキシ | 経路がプロキシのとき、ホストとポート |

例: 「corp.example.jp とサブドメイン → HTTP 10.0.0.1:8080」（社内のシステムだけ社内のプロキシ）、
「10.20.0.0/16 → SOCKS5 127.0.0.1:1080」（踏み台の先だけ SOCKS）、「example.org とサブドメイン → 直接」。

- ドメインごとのプロキシは、やり方が「使わない（直接）」か「指定」のときに使えます（「OS と同じ」「自動構成」では
  一覧を使えません）。
- 内部では、これらを自動構成のスクリプト（PAC）にしてブラウザに渡します。OS の設定は変えません。

## ホストの転送と開発者用証明書 {#hosts}

プロキシの設定の **ホストの転送** の一覧に足すと、そのホストへの接続だけを、決めた IP アドレスとポートに
向けます（hosts ファイルを書き換えたのと同じことを、このブラウザのこのプロファイルだけで行います。ポートも
替えられます）。**追加...** の画面:

| 欄 | 入れるもの |
|---|---|
| ホスト | `www.example.com`（`*.dev.example.com` のようにまとめても可） |
| 対象のポート | すべて ／ 443（https） ／ 80（http） ／ ほかのポート |
| 転送先 | IP アドレス（`127.0.0.1` が入っています）と、ポート（空なら元のまま） |
| 開発者用証明書 | 使わない ／ 登録済みのものを使う ／ 新しく作る（自己署名） ／ 証明書ファイルから登録... |

例: ホスト `www.example.com`、対象のポート「すべて」、転送先 `127.0.0.1` : `8443` にすると、
`https://www.example.com/` が手元のサーバー 127.0.0.1:8443 につながります。

- アドレスバーの URL は `https://www.example.com/` のままで、サーバーには `Host: www.example.com` と、TLS の
  SNI `www.example.com` が届きます。
- 転送するホストは、プロキシを通さずに直接つなぎます（プロキシを通すと、プロキシの側で名前を解決してしまう
  ため）。ただし「OS と同じ」「自動構成（PAC）」のときは、そのプロキシの設定で、転送するホストが直接に
  なっているか確かめてください。

### 開発者用証明書

転送先のサーバーは、ふつう `www.example.com` の正式な証明書を持っていないので、https のページは証明書の
エラーになります。そこで、**開発者用証明書** を使います。

1. 転送の画面の **開発者用証明書** で **新しく作る（自己署名）** を選んで OK を押します。そのホスト名の証明書と
   秘密鍵を作り、設定のフォルダの `browser-devcerts` に `www.example.com.crt`・`www.example.com.key` として
   保存します（保存した場所を表示します）。
2. 転送先のサーバー（127.0.0.1:8443）に、その証明書と秘密鍵を設定します。
3. 保存して `https://www.example.com/` を開くと、サーバーが出した証明書の指紋が登録したものと一致したときだけ、
   証明書のエラーを許してページを開きます。アドレスバーの左に **🔒 開発者用証明書を利用中** と出ます。

- 既にサーバーで使っている証明書があるときは、**証明書ファイルから登録...** でそのファイル（PEM・DER）を
  選びます。
- 一覧では、開発者用証明書を登録した転送に「🔒 開発者用証明書」と出ます。
- 指紋が一致しないとき（サーバーの証明書を入れ替えた・別のサーバーにつながった）は、ふつうの証明書のエラーの
  画面になり、状態表示に理由を出します。
- 受け入れるのは、そのプロファイルで転送しているホストの、その指紋の証明書だけです。OS の証明書ストアには
  入れないので、ほかのブラウザやアプリには影響しません。受け入れはウィンドウ（ブラウザ）を開いている間だけ
  覚えます。

## 広告ブロック {#adblock}

広く使われているフィルタリストを使って、広告・追跡の要求を止め、残った広告の枠を隠します。拡張機能は
要りません。このブラウザの中だけで効きます。

- 既定で有効なリスト: **EasyList**（広告）・**EasyPrivacy**（追跡）・**AdGuard 日本語フィルタ**（日本のサイトの広告）。
  ほかに **uBlock filters**・**EasyList Cookie List**（Cookie の同意のバナー）を選べます。
- リストは yybrowser が自分でダウンロードし（同梱はしていません）、リストに書かれた間隔（多くは 4〜5 日）で
  自動で更新します。初めて起動したときは、ダウンロードが終わるまで（数秒）止めません。
- ダウンロードは、今のプロファイルの経路で行います（ドメインごとのプロキシ・「指定」のプロキシ。「OS と同じ」
  「自動構成」なら OS の設定）。SOCKS5 のプロキシではダウンロードできないので、OS の設定で行います。
- キャッシュは `%LOCALAPPDATA%\yyeditor\yybrowser\filters\` にあります。

**🛡 ボタン**（アドレスバーの右）か、メニューの **広告ブロック** で:

| 項目 | 内容 |
|---|---|
| 広告ブロック（プロファイル「…」） | このプロファイルで入・切（検証用のプロファイルでは切にする、など） |
| このサイトでは止めない（ホスト名） | 今のサイト（とサブドメイン）では止めない。もう一度選ぶと元に戻す |
| フィルタを今すぐ更新 | 期限に関係なく、すべてのリストを取り直す |
| フィルタリスト... | リストの入・切（ダブルクリック）・追加・削除・既定に戻す。規則の数・更新した時刻・失敗も出す |

- **フィルタリスト** の **追加...** では、名前と URL（`https://…`）か、ローカルのファイルのパス
  （`C:\filters\my.txt`）を入れます。ローカルのファイルは、社内のミラーをファイル共有に置いたときや、自分で書いた
  規則（`@@||intra.example.jp^` で止めない、`||ads.example.com^` で止める、`example.jp##.banner` で隠す）に使えます。
- 止められないもの: 動画の本編と同じ通信で流れる広告、広告ブロックを検知して表示を拒むサイト。uBlock Origin
  独自のスクリプトの差し込み（`##+js(...)`）は使えません。
- ページが崩れたり、ボタンが押せなくなったりしたときは、**このサイトでは止めない** を選んでください。

## 別のプロキシのウィンドウを同時に開く {#windows}

1 つのウィンドウのタブは、すべて同じプロキシを使います（WebView2 の仕組みのため）。違うプロキシで同時に
開きたいときは、「プロキシ」メニューの **別のプロキシで新しいウィンドウ** からプロファイルを選びます。別の
ウィンドウ（別のプロセス）として開きます。Ctrl+N は今のプロファイルで新しいウィンドウを開きます。

## プロキシの認証 {#auth}

- 社内のプロキシの多くは Windows の統合認証で、サインイン中の利用者の資格情報で自動的に認証します。
- Basic 認証を求められたときは、ユーザー名とパスワードを尋ねます（保存はしません）。プロキシの認証で
  尋ねられるかは WebView2 のランタイムの版によります。

## ブラウザの機能 {#features}

- **アドレスバー**: URL を入力して Enter。`example.com` のように入れれば `https://` を補い、`localhost:8080`・
  `192.168.0.10` のような手元のホストは `http://` で開きます。`C:\…` のパスはファイルとして開きます。URL らしく
  ないもの（空白を含むなど）は検索語として、[検索エンジン](#search)（既定は Bing）で開きます。Esc で入力を取り消します。
- **新しいウィンドウを開くリンク**（`target="_blank"`・`window.open`）は新しいタブで開きます。
- **ページ内検索**（Ctrl+F）: 下に検索の欄が出ます。Enter で次、Shift+Enter で前、Esc で閉じます。WebView2 の
  ランタイムが古いと使えません。
- **拡大・縮小**（Ctrl++・Ctrl+−・Ctrl+0）、**印刷**（Ctrl+P）、**全画面**（F11。動画の全画面にも合わせます）、
  **開発者ツール**（F12）。
- **ダウンロード**: [ダウンロード](#downloads) を見てください。
- **閉じたタブを開き直す**（Ctrl+Shift+T）。最後のタブを閉じるとウィンドウも閉じます。
- 証明書のエラーなどは WebView2 の既定のエラーの画面になります。

拡張機能は持ちません（[ブックマーク](#bookmarks)・[閲覧履歴](#history) はあります）。

## ブックマーク {#bookmarks}

- アドレスバーの右の **☆** か **Ctrl+D** で、今のページをブックマークに足します（名前・URL・フォルダを
  確かめて「保存」）。登録済みのページでは **★** になり、押すと名前・フォルダの変更や削除ができます。
- フォルダは、一覧から選ぶか、新しい名前を入れます。`仕事 / 社内` のように `/` で区切ると入れ子になります。
- メニューの **ブックマーク** に一覧が出ます（フォルダはサブメニュー）。選ぶと今のタブで開きます。
- **ブックマークの管理...**（**Ctrl+Shift+O**）で、開く・新しいタブで開く・編集・削除・並べ替え（↑↓）ができます。
  一覧の行をダブルクリックしても開きます。
- **読み込み...** で、Edge・Chrome・Firefox が書き出したブックマークの HTML を読み込みます（同じ URL のものは
  足しません。フォルダもそのまま）。**書き出し...** で、それらのブラウザが読み込める HTML に書き出します。
- ブックマークはプロファイルに関係なく共通で、設定のフォルダの `bookmarks.toml` に保存します。ほかの
  ウィンドウで足したものも、メニューを開くと出ます。

## ダウンロード {#downloads}

- リンクなどからファイルをダウンロードすると、**保存先**（既定は Windows の「ダウンロード」フォルダ）に保存
  します。同じ名前のファイルがあれば「名前 (1).zip」のように番号を付けます（上書きしません）。
- **同じファイルを何度もダウンロードしたとき**: ダウンロードが終わったら、保存したフォルダ（サブフォルダは
  見ません）に **同じ内容のファイル**（SHA-256 が同じ）があるかを調べます。あれば、新しくダウンロードしたものは
  破棄し（上書きも別名での保存もしません）、「同じ内容のファイル「…」が既にあるので破棄しました」と出します。
  一覧には ♻ で出て、**開く** で前からあるファイルを開きます。
- 進み具合は下の状態表示に出ます（「ダウンロード中: a.zip 45%（3.2 MB / 7.0 MB）」）。
- メニューの **履歴 > ダウンロード...**（**Ctrl+J**）で一覧を開きます。進行中のものが上、終わったもの（履歴）が
  下に出ます。
  - **開く**（ダブルクリック）・**フォルダを開く**（エクスプローラーでそのファイルを選んだ状態）
  - **一時停止・再開**・**中止**（進行中のもの）
  - **履歴から消す**・**履歴をすべて消す**（ダウンロードしたファイルは消しません）
  - **保存先** の **変更...** で保存先のフォルダを変えられます。**ダウンロードのたびに保存先を確かめる** に
    チェックすると、毎回「名前を付けて保存」の画面を出します。
- ダウンロード履歴はプロファイルごとです（プロファイルのデータのフォルダの `yybrowser-downloads.tsv`）。

## 閲覧履歴と閲覧データの消去 {#history}

- 開いたページを閲覧履歴に残します（プロファイルごと。`about:` などのページは残しません）。
- メニューの **履歴 > 閲覧履歴...**（**Ctrl+H**）で一覧を開きます。新しい順で、上の欄に語を入れると題名・URL で
  絞り込めます。**開く**（ダブルクリック）・**新しいタブで開く**・**選んだものを消す**（Ctrl・Shift で複数選べます）。
- **履歴 > 閲覧データの消去...**（**Ctrl+Shift+Del**）で、期間（過去 1 時間〜すべての期間）を選んで消去します。

| 消すもの | 内容 |
|---|---|
| 閲覧履歴 | yybrowser の閲覧履歴と、ブラウザの内部の履歴 |
| ダウンロード履歴 | ダウンロードの一覧の履歴（ファイルは消しません） |
| キャッシュされた画像とファイル | ページを速く出すために残しているもの |
| Cookie とサイトのデータ | ログインの状態なども消えます |
| 自動入力のデータとパスワード | フォームに自動で入る値・保存したパスワード |

- 消去するのは今のプロファイルのデータだけです（ほかのプロファイルのものは残ります）。

## 検索エンジン {#search}

アドレスバーに URL でないものを入れたときに使う検索エンジンを、メニューの **ファイル > 検索エンジン** から
選びます: Bing（既定）・Google・Yahoo! JAPAN・DuckDuckGo・Brave Search・Startpage。**その他** では、検索語の
場所に `%s` を書いた URL（例: `https://example.com/search?q=%s`）を入れられます。選んだものは `browser.toml` に
保存し、すべてのプロファイルで使います。

## コマンドライン {#cmdline}

```
yybrowser.exe [--profile 名前] [--proxy プロキシ] [URL ...]
```

- `--profile 名前`: そのプロファイルで開きます。
- `--proxy`: その場限りのプロキシ（`127.0.0.1:8888`・`socks5://127.0.0.1:1080`・`http://…/proxy.pac`・`direct`・
  `system`）。プロファイルとして保存はしません。
- URL を並べると、それぞれをタブで開きます。

## 設定 {#settings}

設定ファイル（ファイル メニューの「設定ファイルを開く」）の `[browser]` で変えられます。

| キー | 既定 | 意味 |
|---|---|---|
| `home` | `"about:blank"` | ホーム・新しいタブで開くページ |
| `search_url` | `"https://www.bing.com/search?q=%s"` | 検索の URL（`%s` を検索語に置き換えます）。メニューの ファイル > 検索エンジン で選んだものがあれば、そちらを使います |
| `devtools` | `true` | F12 の開発者ツールを使えるようにする |

## 困ったときは {#trouble}

- **ページが開けない**: 状態表示の理由と、今のプロキシを確かめてください。「つなげません」ならプロキシの
  ホスト・ポートが違うか、プロキシが動いていません。
- **ブラウザを起動できない**: WebView2 ランタイムが入っているか確かめてください。同じプロファイルの
  yybrowser を開いたままプロファイルを書き換えたときは、ほかのウィンドウを閉じてからやり直してください
  （同じデータのフォルダを、違うプロキシの設定で同時に使えないため）。
- **転送したのに本物のサイトが開く**: 「OS と同じ」「自動構成」のプロファイルで、そのホストがプロキシを
  通っていないか確かめてください（プロキシの側で名前を解決するため、転送が効きません）。
- **開発者用証明書なのに証明書のエラーになる**: 状態表示に出るサーバーの証明書の指紋と、行の `cert=` が同じか
  確かめてください。サーバーの証明書を作り直したときは、行の指紋も登録し直します。
- **広告ブロックのリストが更新されない**: 「フィルタリスト...」の状態の欄に失敗の理由が出ます。社内のプロキシで
  外に出られないときは、プロファイルの経路を確かめるか、リストをファイル共有に置いてパスで追加してください。
- **プロキシを通っているか確かめたい**: 検証用のプロキシ（Fiddler など）のプロファイルで開き、プロキシの側に
  要求が届いているかを見てください。
