yydraw 操作ガイド

左の一覧には図形・アイコンの画像と名前を表示します。
初期表示は基本図形です。クラウドアイコンはカテゴリを選択して表示します。
全カテゴリを一括で並べる表示はありません。検索も選択中のカテゴリ内で行います。
一覧から方眼紙へアイコンをドラッグすると、半透明の画像がマウスに追従し、離した位置に配置します。
項目を選んで方眼紙をクリックして配置することもできます。
基本図形は60種類です。「基本図形」で全種類を表示し、図形・演算子・かっこ・ブロック矢印・
吹き出し・フローチャートの分類でも絞り込めます。＋－×÷＝≠、星、ハート、ドーナツ、
四角・角丸・楕円・雲・思考の吹き出し、方向矢印、書類・開始終了などを選べます。
演算子は +、-、*、/、=、!= や英語名でも検索できます。
基本図形は画像素材ではなく、塗り・線色・線幅・サイズと本文を編集できます。
新しい図形の接続点は輪郭に沿い、吹き出しの本文は尻尾を避けて表示します。
SVG・PNG 素材を追加し、クラウドの公式アイコンも配置できます。
素材フォルダの追加では下位フォルダも読み込みます。

公式カタログは AWS 859 個、Azure 714 個、Google Cloud 261 個の計 1,834 個です。
AWS の同じアイコンのサイズ違いはまとめ、Google Cloud の旧版は Legacy カテゴリに分けています。
カタログは同梱しているため、作図中のインターネット接続は不要です。
使用したアイコンだけを文書に取り込みます。

「業務・IT」には独自アイコンを376種類、38カテゴリに収録しています。
コンピューティング、ネットワーク、データ・連携、セキュリティ、開発・運用、組織・拠点、
業務プロセス、プロジェクト、戦略・ビジネス、分析・報告をカテゴリから選択できます。
日本語名に加え、server、VPN、ETL、KPI、SWOT、roadmap などの英語・略語でも検索できます。
モバイル、開発言語、データベース製品、AIサービス、キュー、バックアップ、暗号化、クラスタも収録。
公式クラウド素材と合わせて2,210種類です。すべてオフラインで配置・保存・出力できます。

原点は XY 軸と (0, 0) の印で示します。右が X の正方向、下が Y の正方向です。
原点が画面外のときは、キャンバス左上から見た原点の位置を画素数で表示します。
軸と原点の印は編集補助であり、SVG・PNG 出力には含みません。

図形をドラッグすると移動、右下をドラッグするとサイズを変更します。
移動中は描画済みの図形がマウスに追従し、離したときに全体の描画を確定します。
移動中は他の図形の端・中心に整列ガイドが表示され、吸着します。
Shift+クリックで複数選択、空白をドラッグで範囲選択します。
Ctrl+G または「配置 → グループ化」で選択した図形・アイコン・線をまとめます。
両端の図形を選ぶと、その間の接続線もグループに含めます。
グループの構成要素をクリックすると全体を選択し、一緒に移動・複製・整列できます。
Shift+クリックでグループ単位の選択を追加・解除し、Ctrl+クリックでは構成要素だけを選べます。
Ctrl+Shift+G でグループを解除します。既存グループをまとめ直すと一つのグループになります。
グループにロックされた図形がある場合は、グループ全体の移動・整列を行いません。

「配置」メニュー、またはキャンバスの右クリックから以下を使えます。
左揃え／左右中央揃え／右揃え、上揃え／上下中央揃え／下揃え、左右／上下の均等配置。
「選択したオブジェクトを基準に整列」では選択全体の外枠を基準にします。
「ページを基準に整列」では用紙の端・中央を基準にし、一つのグループをページ中央にも置けます。
均等配置は図形・グループ間の隙間を等しくします。選択基準では3単位以上、ページ基準では2単位以上が必要です。
グループ内の位置関係は保ち、接続された線は図形に追従します。自由な線は個別に整列できます。
整列・グループ化はUndo／Redoに対応し、グループ情報は保存・コピー・別ウィンドウへの貼り付けでも維持します。

右の欄でラベル・位置・大きさ・文字サイズ・色を編集して「適用」を押します。
塗り・線の「色」ボタンからカラーパレットを開き、基本色・RGB 値・作成した色を選べます。
色の選択は選択中の図形・接続線へ適用され、Undo できます。選んだ色は新しく作る図形・線にも使います。
図形を選んでいないときは、新しく作る図形・線の色を設定します。
ラベルは日本語 IME と複数行に対応しています。F2 でも編集欄へ移れます。

直線または直交線を選び、図形から図形へドラッグして接続します。
図形・アイコンにマウスを重ねると、各辺5点、計20点の接続ハンドルを表示します。
選択ツールでもハンドルからドラッグして直交線を引けます。接続先の点は青く強調されます。
接続した線は図形の移動・サイズ変更に追従し、保存・再読込後も同じ点につながります。
点付近から図形を移動したい場合は Alt+ドラッグしてください。
線を引いている間に Shift を押すと、現在の線分が上下左右の4方向に固定されます。
Shift を押したまま Tab を押すと、その位置に折れ点を確定して続きを引けます。
折れ点の後は、来た方向へ逆戻りしない3方向を選べます。Tab で折れ点を続けて追加できます。
Backspace で直前の折れ点を戻し、マウスボタンを離して確定、Esc で取り消します。
Shift を離すと方向固定を解除します。方向固定中の接続点への吸着も水平・垂直を保つ点に限ります。
右側の「角の形」で尖角・丸角を選び、「角の半径 (DIP)」で丸みを調整して「適用」を押します。
選択した接続線を変更でき、選んだ設定は新しく引く線にも使われます。図形未選択でも設定できます。
丸みは描画中・確定後・SVG・PNGで共通です。短い線分では角が重ならない大きさに自動で抑えます。
ShiftやTabで指定した経路は手動経路として保存され、自動の迂回経路へ置き換わりません。
直交線は図形を避けて経路を探索します。経路が見つからない線は赤色で示します。
線をダブルクリックすると途中点を追加し、選択後のハンドルで移動できます。
Alt+ダブルクリックで近くの途中点を削除します。
「接続点」を線の上に配置すると線を分割して接続します。交差の上に置くと双方が接続します。
交差する線は一方がアーチになります。線ごとのジャンプ欄は
0=自動、1=優先して跨ぐ、2=跨がないです。
表示・接続メニューで矢印・破線・格子・吸着・アーチを変更できます。

中ボタンドラッグまたは Space+ドラッグ: パン
Ctrl+ホイール: ズーム / ホイール: 縦移動 / Shift+ホイール: 横移動
拡大縮小はマウス位置を中心に滑らかに補間し、途中でマウスを動かすと中心も追従します。
操作が止まってから鮮明な表示へ更新します。
Alt+ドラッグ: 一時的に吸着解除
Ctrl+N: 新規 / Ctrl+O: 開く / Ctrl+S: 保存 / Ctrl+W: タブを閉じる
Ctrl+Z: 戻す / Ctrl+Y: やり直す / Ctrl+D: 複製
Ctrl+C/X/V: 図形のコピー・切り取り・貼り付け（別の yydraw ウィンドウにも対応）
Ctrl+A: 全選択 / Delete: 削除 / Esc: 選択ツール
矢印キー: 格子単位で移動 / Shift+矢印: 1 DIP 移動

独自形式 .yyd は素材と接続関係を保存します。
追加の基本図形を含む文書は保存版1.5で保存し、既存の1.0～1.4も読み込めます。
右上の一覧でページを切り替えます。「ページ」メニューで追加・削除・複製・改名・寸法変更ができます。
灰色の枠が現在のページの大きさです。枠の外にも図形を配置できます。

「出力・共有」で現在のページ／図全体（現在のページ上の全要素）／選択範囲を選び、
背景色・透明背景・方眼紙・余白を設定します。PNG 倍率はファイルメニューから指定します。
出力の背景色もカラーパレットで選べます。
SVG の文字は既定でパス化し、「文字をテキストで保持」を有効にすると編集可能な文字を残します。
PNG／SVG としてコピーすると、他のアプリへ画像や SVG を貼り付けられます。
出力には選択枠・ハンドル・整列ガイド・ページ枠を含めません。

保存・読込・画像出力・素材の追加はバックグラウンドで進み、タイトルに状況を表示します。
「処理を取消」で中止できます。保存の置換が始まった後は確定完了を待ちます。
保存中の追加編集は未保存のまま残り、保存前の内容を誤って保存済みにはしません。

「素材・設定」で TOML の素材パックを追加し、有効な版を選択・削除できます。
配置済みのアイコンは文書に内包され、パックの切替・削除では変わりません。
素材ライブラリは yy シリーズの設定フォルダ内の yydraw/library.yyd に保存されます。
同じパック ID・版で内容を変えることはできないため、変更時は版を更新します。
「.yyd の関連付けを登録」で現在のユーザーの「プログラムから開く」に追加できます。
既存の既定アプリは上書きしません。
draw.io・Visio 形式の入出力は扱いません。
