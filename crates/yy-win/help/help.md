# yyeditor ヘルプ

yyeditor は、数 GB のファイルもすぐに開ける Windows 向けの軽量テキストエディタです。
日本語の文字コード（CP932・EUC-JP・JIS X 0213・EBCDIC など）、区切り文字（CSV・TSV）の
表示と編集、Markdown・HTML のプレビューに対応しています。

## アウトライン編集 {#outline}

新規タブで「表示 → アウトライン編集」を選ぶと、項目を階層化して編集できます。
Enter で項目追加、Tab / Shift+Tab で階層変更、Alt+↑↓ で子孫ごと移動します。
▾ / ▸ で折りたたみ、● でその階層だけを表示し、上部の経路で戻ります。
「☆ ブックマーク」で登録・解除し、左側の一覧からその階層を開けます。
「参照を追加」で同じ文書内の項目を選ぶとリンクを作成します。参照元も左側に表示します。
名前や階層を変更しても参照を維持し、参照先を削除すると「参照先なし」と表示します。

Ctrl+S で `notes.yyoutline` などの名前で JSON として保存します。
再度開いたときも「表示 → アウトライン編集」を選びます。Ctrl+Z / Ctrl+Y は通常編集と同じ Undo / Redo です。
階層の深さに固定上限はありませんが、文書全体は現在 1 MiB までです。WebView2 が必要です。
Markdown の自動変換や別文書への参照には対応していません。

## エクスプローラーの右クリックから開く {#explorer}

yyeditor・yytermのそれぞれで「ヘルプ → エクスプローラーの右クリックに登録」を選ぶと、
現在ログインしているWindowsユーザーのメニューへ、その実行ファイルを登録します。管理者権限は不要です。

- **yyeditor で開く**: ファイルを編集します。フォルダー・ドライブ・フォルダー内の空白部分では、対象フォルダーをワークスペースへ追加して開きます。
- **yyterm で開く**: フォルダー・ドライブ・フォルダー内の空白部分から、その場所を作業ディレクトリとするローカル端末を開きます。
- 各項目にはアプリのアイコンを表示します。Windows 11では「その他のオプションを確認」（Shift+F10）の中に表示されます。複数選択時は表示しません。
- 解除は各アプリの「ヘルプ → エクスプローラーの右クリックから解除」です。既定のファイル関連付けや他のアプリのメニューは変更しません。
- 実行ファイルを移動した場合は、移動先で再登録してください。削除する前に解除してください。

PowerShellからも登録・解除できます（各プロセスの終了コードは成功0、失敗1）。

```powershell
Start-Process -FilePath .\yyeditor.exe -ArgumentList '--register-context-menu' -Wait
Start-Process -FilePath .\yyterm.exe -ArgumentList '--register-context-menu' -Wait
# 解除
Start-Process -FilePath .\yyeditor.exe -ArgumentList '--unregister-context-menu' -Wait
Start-Process -FilePath .\yyterm.exe -ArgumentList '--unregister-context-menu' -Wait
```

登録先は `HKEY_CURRENT_USER\Software\Classes` 配下の `*\shell\yyeditor.Open`、
`Directory\shell\{yyeditor,yyterm}.Open`、`Directory\Background\shell\{yyeditor,yyterm}.Open`、
`Drive\shell\{yyeditor,yyterm}.Open` です。解除は該当アプリのこれらのキーだけを削除します。

## ファイルを開く・保存する {#files}

- **開く**（Ctrl+O）: 文字コードは自動で判別します。開くダイアログで文字コードを指定することもできます。
  ファイルはウィンドウにドラッグ＆ドロップしても開けます。
- 大きなファイルもすぐに表示します。行数は裏で数えるので、数え終わるまでは行番号が推定値
  （灰色）になります。UTF-8 以外のファイルは裏で変換し、その間は先頭部分を読み取り専用で表示します。
- **共有中のファイルを読み取り専用で開く**: 他のアプリが書き込み中のファイル（出力中のログなど）を、
  開いた時点の内容で表示します。
- **文字コードを指定して開き直す**: 文字化けしたときに、正しい文字コードで読み直します。
- **バイナリとして開く**: ファイルをバイト列のまま [16 進数表示](#hex) で開きます。
- **上書き保存**（Ctrl+S）・**名前を付けて保存**（Ctrl+Shift+S）: 名前を付けて保存では、文字コード・
  BOM・改行コード（CRLF / LF）を選べます。
  - 保存は裏で行い、進み具合をステータスバーに表示します（Esc で中止）。保存中も編集できます。
  - 保存先の文字コードで表せない文字があると、似た文字（① → (1)、ｶﾞ → ガ など）や「?」・
    数値文字参照に置き換えるかを尋ねます。置き換えは「元に戻す」で取り消せます。
  - 保存後も「元に戻す」で保存前の内容に戻せます。
- タイトルとタブの `*` は、保存していない変更があることを示します。閉じるときに保存するか尋ねます。
- **最近開いたファイル**（Ctrl+E、ファイル メニュー）: 開いたファイル（名前を付けて保存したファイルを含む）を
  新しい順に最大 1,000 件まで覚えています。
  - 一覧の上の「絞り込み」に入力すると、パスにその語（空白で区切るとすべての語）を含むファイルだけを表示します。
  - Enter かダブルクリックで開きます。Ctrl / Shift を押しながらクリックすると、複数選んでまとめて開けます。
  - 「一覧から削除」で履歴から外します。「ブックマークに追加」で、選んだファイルをブックマークに加えます。
- **ブックマーク**（Ctrl+B、ファイル メニュー）: よく開くファイルを最大 100 件まで登録できます。
  - 開いているファイルは **このファイルをブックマーク**（Ctrl+Shift+B）で登録・解除できます。
    登録済みならメニューにチェックが付きます。
  - 一覧での絞り込み・開き方は履歴と同じです。「上へ」「下へ」で並べ替え、「一覧から削除」で外せます。
  - 100 件に達しているときは、不要なものを外してから登録してください。
- 履歴は `%APPDATA%\yyeditor\history.txt`、ブックマークは `bookmarks.txt` に 1 行 1 パスで保存します
  （yyeditor を複数起動していても、互いの記録を消しません）。

## リモート（SSH）のファイル {#remote}

SSH で接続できる Linux（x86_64）のファイルを、手元のファイルと同じように開いて編集・保存できます。
SSH は yyeditor に組み込んであるので、Windows の OpenSSH（ssh.exe）は使いません。

- **リモートのファイルを開く**（Ctrl+Shift+O、ファイル メニュー）: 接続先（`ユーザー@ホスト:ポート`、
  または `~/.ssh/config` の Host の名前）を入力して「接続」を押し、一覧からファイルを選びます。
  - フォルダの欄にパス（`~/` も可）を入力して Enter で移動します。ダブルクリックでフォルダを開きます。
  - 文字コードは自動で判別します。文字コードの欄で指定することもできます。
  - 最近開いたファイル（Ctrl+E）とブックマークには `ssh://ホスト/パス` の形で残り、そこからも開けます。
- 初めて接続するホストでは、ホスト鍵の指紋を確かめるよう尋ねます。接続先の管理者から知らされた指紋
  （`ssh-keygen -lf` で表示されるもの）と一致する場合だけ「はい」を選んでください。承認した鍵は
  `%APPDATA%\yyeditor\known_hosts` に記録します。記録と違う鍵のホストには接続しません。
- 認証は、秘密鍵（`~/.ssh/id_ed25519` など、または設定の `identity_file`）、ワンタイムパスワードなどの
  対話式の認証、パスワードの順に試します。
- **パスワードの保存**: パスワードの入力欄で「このパスワードを保存する（Windows の資格情報マネージャー）」に
  チェックを入れると、認証に成功したパスワードを保存し、次からは尋ねずに使います（プロキシのパスワードも同じ）。
  - 保存はこのパソコンのこのユーザーだけのもので、Windows が暗号化して持ちます。yyeditor の設定ファイルには書きません。
  - 保存したパスワードが受け付けられなかったら（接続先でパスワードを変えた場合など）、保存を消して尋ね直します。
  - **ヘルプ メニューの「保存したリモート接続のパスワードを削除」** でまとめて削除できます。コントロール パネルの
    「資格情報マネージャー」→「Windows 資格情報」の `yyeditor/ssh/…`・`yyeditor/proxy/…`・`yyeditor/key/…` からも確認・削除できます。
  - 秘密鍵のパスフレーズも、入力欄で「このパスフレーズを保存する」を選んだ場合だけ保存します（鍵を開けたものだけ）。
    ただし、鍵ファイルとパスフレーズが同じパソコンに揃うため、パソコンの中身を持ち出されると鍵がそのまま使えます
    （パスフレーズは本来、鍵ファイルが盗まれたときの守りです）。共用のパソコンや、多くのサーバーに登録している鍵では
    保存しないことを勧めます。保存したパスフレーズで開けなくなったら（パスフレーズを変えた場合など）、保存を消して尋ね直します。
  - 保存させたくない場合は設定で `remember_passwords = false` にします（パスワードもパスフレーズも保存せず、チェックボックスも出なくなります）。
  - ワンタイムパスワードなど、対話式の認証の答えは保存しません。
- **踏み台・プロキシ**: `~/.ssh/config` の `ProxyJump`（`踏み台1,踏み台2` の多段も可）か、設定の
  `proxy_jump` で踏み台を経由して接続します。踏み台ごとにホスト鍵の確認と認証を行います。
  HTTP（CONNECT）・SOCKS5・SOCKS4 のプロキシは設定の `proxy` で指定します（踏み台を使う場合は最初の踏み台への接続に使います）。
  - `~/.ssh/config` の `ProxyCommand` は、yyeditor が外部のプログラムを起動しないため、次の形だけを読み替えます:
    `ssh -W %h:%p 踏み台`（踏み台と同じ）、`nc -X 5|4|connect -x プロキシ %h %p`、`ncat --proxy プロキシ %h %p`、
    `connect -S|-H プロキシ %h %p`。それ以外の `ProxyCommand` が当てはまる接続先には接続できないので、
    yyeditor の設定で `proxy_jump` か `proxy`（`"none"` で直接接続）を指定してください。
- **接続できないとき**: 接続の各段階（設定の解決、TCP 接続、プロキシ・踏み台、ホスト鍵の照合、試した認証方式と
  サーバーが受け付ける方式、エージェントの配置と起動）を記録しています。接続に失敗したときのメッセージに記録の
  最後の部分を表示します。全体は **ヘルプ メニューの「リモート接続の記録を開く」**
  （`%APPDATA%\yyeditor\logs\remote-ssh.log`）で見られます。パスワード・パスフレーズは記録しません。
- 従来の既定動作では、接続先の `~/.yyeditor/agent` に小さなプログラムを置き、一覧・読み出し・保存を行います。
  [接続先管理](#ssh-sites)でSFTP／SCPを指定すると、エージェントを配置せずその方式で編集します。
- **上書き保存**（Ctrl+S）は接続先のファイルを置き換えます。エージェント方式では権限・所有者・シンボリックリンクを保ちます。
  エージェントなしの保存条件・属性の制限は[接続先管理](#ssh-sites)を参照してください。
  開いたあとでほかの人やプログラムがファイルを変更していた場合は、上書きするか尋ねます。
- **名前を付けて保存**（Ctrl+Shift+S）: リモートのファイルはリモートに保存します。
  **リモートに名前を付けて保存**・**このパソコンに名前を付けて保存** で保存先を選べます。
- 今のところ、リモートのファイルは全体を取り寄せてから開きます（256 MB を超えるときは確かめます）。
  Grep（ファイルから検索）は手元のフォルダだけが対象です。

## ワークスペース {#workspace}

VS Code のワークスペースのように、作業に使う **起点のフォルダを複数まとめて** 登録し、左側の
**サイドバー**（エクスプローラー）にフォルダの中身をツリーで表示します。

- **サイドバー（エクスプローラー）**（Ctrl+Shift+E、ワークスペース メニュー）で表示を切り替えます。
  境界をドラッグすると幅を変えられます。
- **フォルダをワークスペースに追加**（ワークスペース メニュー、サイドバーの右クリック）で起点のフォルダを
  加えます。フォルダをウィンドウにドラッグ＆ドロップしても加わります。起点はいくつでも登録できます。
- フォルダは開いたときに中身を読みます（フォルダが先、名前順。`.git` などは表示しません）。
  ファイルはダブルクリックか Enter で開きます。項目にマウスを置くとフルパスを表示します。
- **フォルダを束ねる**（VS Code と同じ）: 中身がフォルダ 1 つだけのフォルダは、`src/main/java` のように
  1 行にまとめて表示します。手元のフォルダは並べるときに、リモートのフォルダは開いたときに束ねます
  （起点のフォルダは束ねません）。束ねた行の操作（新しいファイル・名前の変更・削除・貼り付けなど）は、
  いちばん奥のフォルダ（`java`）が対象です。途中のフォルダに項目が増えれば、束ね方は自動で変わります。
- **右クリックのメニュー**:
  - **ターミナルで開く**: そのフォルダ（ファイルならそのファイルのあるフォルダ）を作業フォルダにして
    ターミナルを開きます。yyeditor と同じフォルダに [yyterm](#terminal) があればそれを（リモートのフォルダも
    SSH で開けます）、なければ Windows Terminal、それもなければコマンド プロンプトを使います
    （設定の `[workspace]` の `terminal` で変えられます）。
  - **エクスプローラーで開く**: フォルダを開きます（ファイルならそのフォルダを開いてファイルを選びます）。
  - **フォルダ内を検索 (Grep)**: そのフォルダを指定して [ファイルから検索](#search) を開きます。
  - **パスをコピー**・**相対パスをコピー**（起点のフォルダからのパス）
  - **最新の情報に更新**: フォルダの中身を読み直します（ワークスペース メニューの「最新の情報に更新」は全体）。
  - **ワークスペースから削除**（起点のフォルダのみ）: 登録を外します（フォルダ自体は消しません）。
- **ワークスペースの保存**: 変更はすぐに保存し、次に起動したときも同じワークスペースを開きます。
  **ワークスペースに名前を付けて保存** で `*.yyworkspace` ファイルに保存でき、**ワークスペースを開く** で
  切り替えられます（タイトルにワークスペースの名前を表示します）。**新しいワークスペース** で空にします。
- ワークスペースのファイルは TOML で、`folders = ["C:\\src\\app", "docs"]` のように起点のフォルダを並べます
  （相対パスはファイルのあるフォルダから）。
- **ファイル・フォルダの操作**（手元のフォルダでも、リモートのフォルダでも同じように使えます）:
  - **新しいファイル**・**新しいフォルダ**（フォルダの右クリック）: 名前を尋ねて、そのフォルダの中に作ります
    （新しいファイルは作ったあとで開きます）。
  - **名前の変更**（F2、右クリック）: ツリーの上で名前を書き換えて Enter。
  - **削除**（Delete、右クリック）: 手元のファイル・フォルダは **ごみ箱** に移します。リモートのものはごみ箱がないため、
    確かめたうえで完全に削除します（元に戻せません）。開いているタブは閉じます（保存していない変更があれば削除しません）。
  - **移動**: 項目をドラッグして、移動先のフォルダ（またはその中のファイル）の上で離します。または **切り取り**
    （Ctrl+X、右クリック）してから、移動先のフォルダで **貼り付け**（Ctrl+V、右クリック）します。
    移動は同じ場所（このパソコンの中、または同じ接続先の中）でだけできます（別の場所へはコピーします）。
    移動先に同じ名前があれば移動しません。
  - **コピー**: **コピー**（Ctrl+C、右クリック）してから、コピー先のフォルダで **貼り付け**（Ctrl+V、右クリック）します。
    **このパソコンとリモートの間、別の接続先の間でもコピーできます**（フォルダは中身ごと）。ドラッグ＆ドロップでは、
    別の場所へ落とすとコピー、同じ場所の中で Ctrl を押しながら落としてもコピーになります。
    - コピーする量（フォルダは中身の合計）が **10 MB 以上** のときは、始める前に確かめます。
    - このパソコンとリモートの間（別の接続先の間を含む）では、**50 MB 以上** はコピーできません
      （コピー中に 50 MB を超えたときも中止し、作りかけのコピーを消します）。同じ場所の中のコピーには制限はありません。
    - 同じ名前があるときは上書きせず、「名前 - コピー」「名前 - コピー (2)」… の名前にします。
    - 進み具合はステータスバーに表示します。Esc で中止すると、作りかけのコピーは消します。
    - 同じ接続先の中のコピーは接続先で行うので、転送はしません。別の接続先の間は、このパソコンを経由します。
    - リモートから手元へコピーするとき、パスの区切り・親フォルダへの移動・Windows の予約名などを含む名前は受け付けません。
    - フォルダを指すシンボリックリンクはたどらずに飛ばします（ファイルを指すリンクは中身をコピーします）。
      このパソコンからリモートへコピーしたファイルの権限は、接続先の既定（umask）になります。
  - 名前を変えた・移動したファイルを開いていれば、タブはそのまま新しい場所を指します（編集中の内容もそのまま）。
  - 起点のフォルダ自体の名前の変更・削除・移動はできません（「ワークスペースから削除」で登録を外します）。
- **リモートのフォルダをワークスペースに追加**（ワークスペース メニュー、サイドバーの右クリック）:
  SSH 接続先のフォルダも起点として登録できます（[リモート（SSH）のファイル](#remote)）。接続先を入力して
  「接続」を押し、フォルダを辿って「このフォルダを追加」を押します。
  - サイドバーには `フォルダ名 [接続先]` と表示します。フォルダを開いたときに接続し（パスワードなどを
    尋ねることがあります）、中身を読みます。ファイルを開くと、リモートのファイルとして開きます。
  - ワークスペースのファイルには `ssh://接続先/パス` の形で書きます。
  - **ダウンロード フォルダにコピー**（リモートの項目の右クリック）: リモートのファイル・フォルダ（中身ごと）を、
    このパソコンのダウンロード フォルダ（Windows の「ダウンロード」。場所を変えていればその場所）にコピーします。
    同じ名前があれば `名前 (2).拡張子` にします（上書きしません）。10 MB 以上なら始める前に確かめます
    （大きさの上限はありません。ワークスペースのコピー・貼り付けの 50 MB の上限もかかりません）。進み具合は
    ステータスバーに出し、Esc で中止すると作りかけを消します。ターミナル（yyterm）のワークスペースでも同じです
    （yyterm は、エージェントを使う設定でなければ SFTP で読み、接続先に何も置きません）。
  - **zip にしてダウンロード**（リモートのフォルダの右クリック）: 接続先（Linux）のエージェントにフォルダを
    zip にさせ、1 つのファイルとして受け取ります。zip ができたら保存先を毎回尋ねます（既定はダウンロード
    フォルダの `フォルダ名.zip`）。圧縮中・受け取り中の進み具合はステータスバーに出し、Esc で中止できます
    （接続先の一時ファイル・作りかけのファイルは消します）。シンボリックリンクと読めないファイルは入れません。
    **zip が 100 MB を超えるときはダウンロードしません**。代わりに保存先のフォルダを尋ね、yysftp を起動して
    その転送の一覧にフォルダのダウンロードとして入れます（中断しても続きから再開できます）。この機能は
    エージェントを使います（yyterm でエージェントを使わない設定でも、このときはエージェントを置きます）。
  - リモートの項目では、ターミナル・エクスプローラーで開く、フォルダ内を検索（Grep）は使えません。
    「パスをコピー」は接続先のパス（`/home/...`）をコピーします。

## ソース管理（Git） {#git}

VS Code のソース管理と同じように、ワークスペースの中の Git のリポジトリの変更を見て、ステージ・コミット・
プル・プッシュができます。**ソース管理（Git）**（Ctrl+Shift+G、ワークスペース メニュー）で、サイドバーを
エクスプローラーと切り替えます（Ctrl+Shift+E でエクスプローラーに戻ります）。

- **Git**: 入っている `git` コマンド（[Git for Windows](https://gitforwindows.org/) など）を使います。PATH に
  `git.exe` のフォルダを入れてください。資格情報（資格情報マネージャー）・フック・`.gitconfig` の設定は、
  コマンド プロンプトの git と同じです。
- **リポジトリを選ぶ**: ワークスペースのフォルダの下（深さ 8 まで。`node_modules` などは見ません）にある
  `.git` を探して、上の一覧に並べます。ワークスペースのフォルダがリポジトリの中のフォルダなら、そのリポジトリも
  入ります（「（フォルダ名 を含む）」）。サブモジュール・`git worktree` で作った作業ツリーも入ります（「（リンク）」）。
  **どれを表示するかを一覧から 1 つ選びます**（1 つだけなら自動で選びます）。選んだものは覚えて、次も同じものを
  表示します。フォルダを足したときは探し直します（「…」> リポジトリを探し直す でも）。
- **ブランチ**（⎇ のボタン）: 今のブランチと、上流との差（↑ プッシュしていないコミットの数・↓ プルしていない
  コミットの数）を表示します。押すとブランチの一覧が出て、切り替えられます。**新しいブランチを作成して
  切り替え** もここから。リモートのブランチ（`origin/feat`）を選ぶと、同じ名前の手元のブランチを作って追跡します。
- **コミット**: メッセージを上の欄に書いて **✓ コミット**（欄で Ctrl+Enter）。ステージした変更がなければ、
  すべての変更をステージしてコミットするかを尋ねます。「…」> **直前のコミットを修正** で amend します
  （メッセージが空なら直前のメッセージのまま）。
- **変更の一覧**: **マージの競合**・**ステージ済みの変更**・**変更**（追跡されていないファイルを含む）に分けて、
  状態の文字（M 変更・A 追加・D 削除・R 名前の変更・U 追跡されていない・! 競合）・ファイル名・フォルダを
  並べます。
  - ダブルクリック（Enter）で **差分** を比較のウィンドウに出します（ステージ済みは HEAD ⇔ ステージした版、
    変更はステージした版〔なければ HEAD〕⇔ 作業ツリー）。
  - 右クリック: **ファイルを開く**・**ステージ**・**ステージを解除**・**変更を破棄**（確かめてから。追跡されて
    いないファイルは削除します）・**パスをコピー**。見出し（「変更」など）の右クリックで、まとめてステージ・解除・
    破棄。競合のファイルは、直してから **解決済みにする（ステージ）**。
- **「…」のメニュー**: **プル**・**プッシュ**（上流がなければ `origin` の同じ名前のブランチへ、上流として設定）・
  **同期**（プルしてプッシュ）・**フェッチ**・すべてステージ・すべてのステージを解除・すべての変更を破棄・
  直前のコミットを修正・リポジトリを探し直す・**Git の出力を表示**（最近の git の出力。失敗したときの理由も）。
- **資格情報**（プル・プッシュ・同期・フェッチ）: パスワードなどが要って通らなかったときは、失敗にせずに
  **尋ねます**。
  - HTTPS のリモート（`https://github.com/...` など）: ユーザー名と、パスワード（またはアクセス トークン）。
  - SSH のリモート（`git@github.com:...`）: 秘密鍵のパスフレーズか SSH のパスワード。
  - **保存する** を選ぶと、通ったときに Windows の資格情報マネージャーに保存し（名前は
    `yyeditor/git/https://github.com` など。リモートのホストごと）、次からは尋ねずに使います。保存していた
    資格情報が受け付けられなくなったら（パスワードの変更・トークンの期限切れ）、保存を消してもう一度尋ねます。
  - 資格情報は、その git の起動にだけ渡します（askpass。コマンドの引数には出しません。リモートのフォルダの
    リポジトリでは SSH の標準入力で渡し、接続先に作る一時的な askpass は終わったら消します）。渡すときは、
    設定済みの資格情報ヘルパーは使いません。
  - 設定で `[remote] remember_passwords = false` にすると保存しません（毎回尋ねます）。保存した資格情報は
    ヘルプ > 保存したリモート接続のパスワードを削除 でも消せます。
- git は裏で動かすので、プッシュなどの間も編集できます（ブランチのボタンに「… 実行しています」と出ます）。
  変更の一覧は、↻ のボタン、ファイルを保存したとき、ほかのアプリから yyeditor に戻ったときに読み直します。
- **リモート（SSH）のフォルダ**: ワークスペースに登録したリモートのフォルダ（[リモート（SSH）のファイル](#remote)）の
  下のリポジトリも、同じように一覧に入り（「名前 [接続先]」）、同じ操作ができます。git は **接続先の git** を
  SSH で動かします（接続先に git が要ります。エージェントは使いません）。
  - リポジトリを探すとき（ソース管理を開いたとき）に、まだ接続していない接続先には接続します（パスワードなどを
    尋ねることがあります）。接続できなかった接続先のフォルダは探しません（「…」> Git の出力を表示 に記録）。
  - 接続が切れていれば、操作・↻ のときに接続し直してから行います（ファイルの保存・ウィンドウに戻ったときの
    自動の読み直しでは、接続し直しません）。
  - 差分は接続先から版と作業ツリーのファイルを読みます。「ファイルを開く」はリモートのファイルとして開き、
    「パスをコピー」は接続先のパス（`/home/...`）をコピーします。
  - プッシュ・プルの資格情報は、まず接続先の git の設定（SSH の鍵・credential helper）を使い、それで通らなければ
    下の「資格情報」と同じく尋ねます。

## ターミナル（yyterm） {#terminal}

yyterm は、yyeditor と同じ部品で作ったターミナルです（`yyterm.exe`。yyeditor と同じフォルダに置きます）。
フォント（同梱の UDEV Gothic）、設定ファイル、SSH の接続設定・ホスト鍵・保存したパスワード、ワークスペースを
yyeditor と共通に使います。

- **手元のシェル**: 既定は PowerShell 7、なければ Windows PowerShell、なければコマンド プロンプトです
  （設定の `[terminal]` の `shell` で変えられます。例: `["cmd.exe"]`、`["wsl.exe"]`）。
- **SSH で接続**（Ctrl+Shift+O）: 接続先（`ユーザー@ホスト:ポート` または `~/.ssh/config` の Host の名前）を
  入力します。yyeditor と同じ組み込みの SSH を使い、OpenSSH（ssh.exe）は使いません。踏み台・プロキシ・
  パスワードの保存・接続の記録も [リモート（SSH）のファイル](#remote) と同じです。ターミナルだけの接続では
  エージェントを使わないので、Linux 以外の接続先にも接続できます。
- **ポートフォワーディング**: 「SSH で接続」の入力で、接続先に続けて `-L 8080:localhost:80`（手元の
  8080 番 → 接続先から localhost:80）、`-R 9000:localhost:3000`（接続先の 9000 番 → 手元の 3000 番）、
  `-D 1080`（手元の 1080 番を SOCKS のプロキシに）を書けます。接続設定の `forward` と `~/.ssh/config` の
  `LocalForward`・`RemoteForward`・`DynamicForward` も使います。始めたものと、始められなかったもの
  （ポートの使用中など）はタブの先頭に表示します。始められなくても SSH の接続はそのまま使えます。
  yyeditor と yysftp はポートフォワーディングの指定を無視します。
- **エージェント**: ワークスペースのリモートのフォルダの一覧に、接続先のエージェントを使うかを選べます
  （ワークスペース メニュー、設定の `[terminal]` の `use_agent`。既定は使わない＝SFTP で読み、接続先に
  何も置きません）。シェルにはどちらでもエージェントを使いません。
- **ワークスペース**（Ctrl+Shift+E）: 中身がフォルダ 1 つだけのフォルダは、エディタと同じく `a/b/c` のように
  束ねて表示します（ダブルクリックでは、いちばん奥のフォルダでターミナルを開きます）。
  フォルダをダブルクリック（Enter）すると、そこでターミナルを開きます
  （リモートのフォルダは SSH で接続して、そのフォルダで始めます）。ファイルは yyeditor で開きます。
  ワークスペースのメニューで、新しいワークスペース・開く・名前を付けて保存・フォルダの追加ができます。
  リモートのファイル・フォルダは、右クリックの **ダウンロード フォルダにコピー** でこのパソコンのダウンロード
  フォルダにコピーでき、リモートのフォルダは **zip にしてダウンロード** で zip として受け取れます
  （[ワークスペース](#workspace) と同じ）。
- **タブ**: 新しいタブ（Ctrl+Shift+T。選んでいるタブと同じ場所で開きます）、閉じる（Ctrl+Shift+W、
  タブの「×」、中ボタンのクリック）、切り替え（Ctrl+Tab・Ctrl+Shift+Tab）。シェルが終わったタブは
  Enter で閉じます。タブの右クリックで「閉じる」「ほかのタブをすべて閉じる」「右側のタブを閉じる」
  「左側のタブを閉じる」（まとめて閉じるとき、シェルが動いているタブがあれば確かめます）。
- **タブごとのテキストログ**: **既定は無効**です。ログを取りたいタブを右クリックし、
  **テキストログをファイルに出力** を選んで保存先を指定します。有効なタブには `[ログ]` と表示します。
  同じ項目をもう一度選ぶと停止します。選択中でないタブも、そのタブの右クリックから操作できます。
  - 開始以降に改行で確定した表示行を UTF-8 のテキスト（LF 改行）で保存します。色・カーソル制御などの
    エスケープシーケンスは書かず、進捗表示の `CR` による上書きは改行時の最終状態を記録します。
    画面幅による折り返しは結合します。スクロールバックの過去の内容を開始時にまとめて書くことはありません。
  - ローカル・SSH の端末で共通です。閲覧のスクロール・タブ切り替え・再描画で同じ行を追記することはありません。
    同じ文字列でも、実際に別の出力行として受信した場合はそれぞれ記録します。
  - 停止・プロセス終了・タブを閉じる・アプリ終了時には、最後の未改行の行も保存してファイルを閉じます。
    新しいタブや、セッションに再接続したタブでは自動で有効になりません。同じファイルへ複数タブから同時に
    出力することはできません。保存先に既存ファイルを選んだ場合は、保存ダイアログで確認して上書きします。
  - vim などの全画面表示を画面単位で保存する方式ではありません。3270 のタブでは、画面更新時の変更行を記録します。
- **リンク**: 画面の **URL**（`https://…` など）と **ファイルのパス**（`/etc/hosts`・`~/notes.txt`・`./run.sh`・
  `src/main.rs:12:5`・`C:\work\a.cpp(34,7)`・`README.md` など）にマウスを置くと下線を引き、**Ctrl+クリック** で開きます
  （右クリックのメニューからも）。
  - URL は既定のブラウザで開きます。
  - ファイルはエディタ（yyeditor。yyterm と同じフォルダに置きます）で開き、`:12`・`:12:5`・`(12,5)` があれば
    その行へ移動します。SSH のタブでは、接続先のファイルをリモートのファイルとして開きます（接続先で、あるかを
    確かめてから）。フォルダは、手元ならエクスプローラー、接続先なら yysftp で開きます。
  - 相対パス・`~` は **作業フォルダ** から探します。作業フォルダは、シェルが知らせたもの（OSC 7・OSC 9;9。
    設定しているシェルだけ）、なければ上の **プロンプトの行**（`user@host:~/src$`・`PS C:\work>`・
    `C:\work>`）、なければタブを開いたフォルダ（接続先ならホーム）です。見つからなければステータスバーで知らせます。
- **右クリックのメニュー**: リンクの上なら「ブラウザで開く」「エディタで開く」「リンクのアドレス（パス）を
  コピー」、ほかにコピー・貼り付け・すべて選択・表示している画面をコピー。**SSH のタブでは「カレント
  ディレクトリを yysftp で開く」**（作業フォルダを、上と同じ方法で決めて yysftp〔同じフォルダに置きます〕で
  開きます）、手元のタブでは「カレントディレクトリをエクスプローラーで開く」。設定の `right_click_menu = false`
  で、前と同じ「選択していればコピー、していなければ貼り付け」にできます。プログラムがマウスを使っているときは
  Shift を押しながら右クリックします。
- **コピー・貼り付け**: ドラッグで選択、ダブルクリックで単語を選択します。Ctrl+Shift+C（Ctrl+Insert）で
  コピー、Ctrl+Shift+V（Shift+Insert）で貼り付け。**選択しているときの Ctrl+C もコピー**です（選択して
  いなければ、いつもどおりシェルへ送ります〔中断〕）。右クリックは、選択していればコピー、していなければ
  貼り付けです。コピーできたか（文字数・行数）はステータスバーに出ます。
  - vim や tmux などがマウスを使っているときは、Shift を押しながら選択します（クリックするとステータスバーで
    案内します）。
  - **すべて選択**（Ctrl+Shift+A。スクロールバックも）と、**表示している画面をコピー**（編集 メニュー）でも
    コピーできます。選択できないプログラムでも、画面の文字はこれでコピーできます。
  - クリップボードをほかのアプリが使っていて書けなかったときは、少し待って何度か試し、それでも書けなければ
    ステータスバーで知らせて選択を残します（もう一度コピーできます。右クリックで貼り付けにはなりません）。
- **スクロールバック**: Shift+PageUp・PageDown・↑・↓、マウスのホイール、スクロールバー
  （less・vim などの全画面のプログラムでは、ホイールはカーソルキーとして送ります）。
- **文字の大きさ**: Ctrl++・Ctrl+-・Ctrl+0、Ctrl+ホイール。
- **起動の引数**: `yyterm.exe [フォルダ | ssh://接続先/パス | ユーザー@ホスト]`。

### tmux / screen とタブを結び付ける

接続先に tmux または GNU Screen がある場合、ホスト別に永続セッションを使えます。
ヘルプ > 設定ファイルを開く で、接続先の名前（SSH の Host 別名を使うならその別名）に設定を登録し、yyterm を再起動します。

```toml
[remote.host.build]
terminal_multiplexer = "tmux"       # "none"（既定）/ "tmux" / "screen" のいずれか 1 つ
terminal_session_prefix = "yyterm-" # 有効にする場合は必須
```

- **タブ名は必須**: このホストへ接続するときに名前を入力します。セッション名は **プレフィクス＋タブ名** です。
  例: プレフィクス `yyterm-`、タブ名 `build` → `yyterm-build`。区切りの記号は自動では追加しません。
  文字・数字・`-`・`_` が使え、合計は UTF-8 で 64 バイト以内です。日本語の名前も使えます。
- **再接続**: 同名のセッションがあれば接続し、なければ作成します。タブの表示名は入力した名前で固定します。
  同じ yyterm ウィンドウでは、接続中の同一セッションを別のタブで重ねて開けません。
- **セッションメニュー**: メニューバーの **セッション > 接続先ホスト** にカーソルを合わせると、そのホストの
  tmux / screen のセッション一覧を取得します。接続中・デタッチ中を表示し、セッションを選ぶと対応するタブを
  開きます。タブ名は登録プレフィクスを除いた名前です。すでに開いているタブはそのタブへ切り替えます。
  プレフィクスやタブ名の条件に一致しないセッションは対象外と表示します。ホストを開き直すと一覧を再取得します。
  **新規セッションを作成** からは、タブ名を入力して新しいセッションを作成できます。
- **フォルダから開く**: yyeditor・yysftp の「ターミナルで開く」、yyterm のワークスペースからリモートのフォルダを
  開く場合も、同じホスト設定を使ってタブ名を入力します。この経路では **新規セッションを作成** し、指定フォルダで
  シェルを始めます。同名のセッションがある場合は再利用せず、別のタブ名を指定するよう知らせます。
  セッションメニューで選んだ既存セッションは、その中の作業フォルダ・処理を維持して再接続します。
- **閉じる**: タブを閉じる・複数タブをまとめて閉じる・yyterm を終了する操作は、クライアントをデタッチします。
  接続先のセッションと、その中の処理は残ります。同じホスト・プレフィクス・タブ名で再開できます。
  セッション内で `exit` するなど、利用者がシェル自体を終了した場合はセッションも終了します。
- **ホストごとに排他選択**: `terminal_multiplexer` に tmux と screen を同時には指定できません。
  指定したプログラムが接続先の PATH にない場合や、プレフィクスが未登録の場合はエラーを表示します。
  設定は SSH ターミナルのタブだけに適用します。
- デタッチ時に処理が残るよう、tmux の対象セッションの `destroy-unattached` とサーバーの `exit-unattached` を
  `off` にし、screen の対象セッションの `autodetach` を `on` にします。既存のほかのクライアントを追い出しません。
  screen に完全に同じ名前のセッションが複数ある場合は、接続先で重複を解消してから再接続してください。

## ファイル転送（yysftp） {#transfer}

`yysftp.exe` は、yyeditor と同じ部品で作った SFTP・SCP のファイル転送のアプリです。接続（組み込みの SSH、
踏み台・プロキシ・ホスト鍵・保存したパスワード・接続の記録）と設定ファイルは yyeditor と共通です。
転送には、SFTP は接続先の sftp-server、SCP は接続先の scp を使います。

- **エージェントを使うか**（転送メニュー「接続先にエージェントを置いて使う」、設定の `use_agent`。既定は
  使わない）: 使わなければ接続先に何も置かず、SFTPモードでは一覧もSFTPで読みます。SCPモードではPOSIXシェルとGNUコマンドで一覧を読み、SFTPサブシステムを要求しません。
  使うと、yyeditor と同じエージェントを接続先に置いて、一覧・ファイル操作をエージェントで行い
  （sftp-server を止めている接続先でも一覧を表示できます）、送り終えた内容をファイル全体の SHA-256 で
  照合します（一致しなければ途中のファイルを捨てて 1 回送り直します）。エージェントは Linux の接続先で
  動きます。

- **接続**（Ctrl+N）: 接続先（`ユーザー@ホスト:ポート`、`~/.ssh/config` の Host の名前。`:/パス` も付けられます）を
  入力するか、左のツリーの接続先を開きます。アドレスバー（Ctrl+L）に `ユーザー@ホスト:/パス` や `/パス` を
  入力して Enter でも移動できます。戻る（Alt+←）・進む（Alt+→）・上へ（Alt+↑、Backspace）。
- **一覧**: 名前・更新日時・種類・サイズ・属性。列の見出しのクリックで並べ替えます。フォルダはダブルクリック
  （Enter）で開きます。名前の変更（F2）、削除（Del。フォルダは中身ごと）、新しいフォルダ（Ctrl+Shift+N）、
  すべて選択（Ctrl+A）、パスをコピー、隠しファイルの表示（表示メニュー）。右クリックのメニューもあります。
- **アップロード**: エクスプローラーからファイル・フォルダをドラッグ＆ドロップするか、Ctrl+U（ファイル）・
  転送メニューの「フォルダをアップロード」。表示しているフォルダに送ります。
- **ダウンロード**: 項目を選んで Ctrl+D（ファイルはダブルクリックでも）。保存先は設定の `download_dir`、
  なければ「ダウンロード」フォルダです。「保存先を選んでダウンロード」もあります。
- 送り先に同じ名前のファイルがあるときは、置き換える（はい）・飛ばす（いいえ）・やめる（キャンセル）を尋ねます。
- **転送の一覧**（下の「転送」タブ）: 進み・速度・状態を表示します。右クリックで一時停止・再開・取り消し
  （途中まで送ったファイルも消します）・手元のフォルダを開く・すべて再開・完了したものを消す。
- **レジューム**: 転送中に接続が切れたら、間を空けて（2・5・10・20・30・60 秒）自動で接続し直し、続きから
  送ります。送り終えた位置はジャーナル（`%APPDATA%\yyeditor\transfers`）に書くので、一時停止したときや
  アプリを閉じたときも、後で（次に起動したときも）続きから送れます。送っている途中のファイルは
  `<名前>.yypart` で、送り終えて大きさを確かめてから本来の名前にします。
  **yysftp が落ちたとき**（強制終了・Windows の停止・停電でも）も、次に起動したときに再開するか尋ねます。
  ジャーナルと途中のファイルはディスクに書き出しながら進めるので、確かに送り終えた位置から続けます。
  送り終えて名前を変えた直後に落ちた転送は、送り直さずに完了とします。yysftp を 2 つ起動したときは、
  先に起動した方だけがジャーナルから再開します。
- **記録**（下の「記録」タブ、ヘルプ メニューの「転送の記録を開く」）: 転送の様子（接続、続ける位置の決め方、
  10 秒ごとの進みと速さ、切断と再接続、確認、名前の変更、完了・失敗）を
  `%APPDATA%\yyeditor\logs\transfer.log` に残します。
- **SFTP と SCP**: 転送メニューで切り替えます（既定は設定の `protocol`）。SFTP が使えない接続先では SCP に
  します。SCP のアップロードは区切り（`scp_chunk_mb`）ごとに送ってつなげるので、切断で失うのは多くても 1 区切りです。
- ファイルはエディタ（yyeditor）、フォルダはターミナル（yyterm）で開けます（ファイル メニュー・右クリック）。
- **起動の引数**: `yysftp.exe [ssh://接続先/パス | ユーザー@ホスト:/パス | ユーザー@ホスト]`。
  `yysftp.exe --download ssh://接続先/フォルダ --to 保存先のフォルダ` は、起動したらそのフォルダのダウンロードを
  転送の一覧に入れます（エディタ・ターミナルの「zip にしてダウンロード」で zip が 100 MB を超えたときに使います）。

### SSH接続先をGUIで管理する {#ssh-sites}

yyeditor・yyterm・yysheetは「ヘルプ → SSH接続先を管理…」、yysftpは「ファイル → SSH接続先を管理…」から
共通の接続先一覧を開きます。新規・編集・複製・削除ができ、画面上部で設定カテゴリを切り替えます。
保存した接続名は、リモートファイル選択、端末のSSH接続、yysftpの接続先、yysheetのファイル読み書き、yymergeのSSH入力として指定できます。
ホスト・ユーザー・鍵・接続経路・SSH認証設定と、ホスト別のSFTP／SCP選択を共通に使います。
yysheetの保存、ワークスペースのコピー／ダウンロードもホスト別指定に従います。
方式が指定されている場合は、各アプリの従来のエージェント切り替えより優先します。
設定は `%APPDATA%\yyeditor\connections.toml` に保存し、エディタ設定や `.ssh/config` は書き換えません。

| カテゴリ | 主な設定 |
| --- | --- |
| 基本 | 接続名、ホスト、ポート、ユーザー、SFTP／SCP、開始フォルダー |
| 秘密鍵・接続経路 | 秘密鍵、ProxyJump、中継コマンド、HTTP／SOCKSプロキシ、エージェント |
| SFTP・SCP／一覧・ポート転送 | SFTP起動方法、独自の一覧コマンド、L／R／D転送 |
| 端末・セッション | none／tmux／screenの排他選択、セッション名プレフィクス |
| SSH認証・接続維持 | タイムアウト、死活確認、公開鍵・対話認証・パスワード認証の有効化 |
| SSH暗号・互換性 | 暗号・鍵交換・ホスト鍵・MACの優先順、圧縮、PTYなしshellでのコマンド起動 |

転送方式を指定すると、そのホストのファイル編集・一覧・転送には専用エージェントを使いません。
SCP指定ではSFTPサブシステムも要求しません。方式が空欄の場合は従来の設定を引き継ぎます。
yysftpの転送メニューで接続中ホストの方式を変えた場合も、そのホストへ保存します。
接続前の切り替えは今回の未設定ホスト用の既定値です。自動的なSFTP／SCP切り替えは行いません。

ProxyJumpは `gateway` や `user@gateway:2222`、多段の場合は `gateway1,gateway2` と指定します。
各踏み台の接続名もGUIで登録できます。ポート転送は `L 8080:localhost:80; R 9000:localhost:3000; D 1080`
のようにセミコロンで区切ります。Lはローカル、Rはリモート、DはローカルSOCKSプロキシです。
転送はyytermの接続時だけ開始します。tmux／screenにはプレフィクスが必須で、接続時にタブ名を入力します。
タブを閉じてもセッションは残ります。

優先順位は接続引数の明示的なユーザー／ポート → `connections.toml` の同名接続 →
`config.toml` の接続（GUI側に同名接続がない場合）→ `.ssh/config` → 既定値です。
接続名は大文字小文字を区別せず、GUI側の同名接続はホスト定義全体を置き換えます。
ファイルロックと一時ファイルの置換で保存します。保存したアプリは新しい接続から反映し、
接続中の端末は維持します。ほかの起動中アプリは再起動してください。

パスワードや鍵のパスフレーズ、MFAの回答は接続時に入力します。保存を選んだ資格情報は
Windows資格情報マネージャーを使い、接続設定ファイルには書きません。
プロキシURLもパスワードを含めず、ユーザー名まで指定してください。
暗号等のリストはSSHの正式名をカンマで区切ります。空欄は組み込みライブラリの既定値です。
WinSCPの短縮名や `WARN` トークンをそのまま貼り付ける形式ではありません。

```toml
version = 1
[hosts.essential]
hostname = "gateway.example.com"
user = "環境の手順に記載された転送用ログイン名"
port = 22
protocol = "scp"
remote_directory = "/work"
terminal_multiplexer = "tmux"
terminal_session_prefix = "work-"
forward = ["L 8080:localhost:80", "D 1080"]
[hosts.essential.ssh]
connect_timeout_secs = 30
keepalive_secs = 15
keyboard_interactive_auth = true
exec_via_shell = true
```

`exec_via_shell = true` は、PTYなしのSSH shell要求から `sh -c` で各コマンドを開始します。
開始前のバナーは境界マーカーまで読み飛ばし、その後はバイナリを変更せず渡します。
PTY必須の対話メニューへの自動回答や、製品固有の接続先選択プロトコルは実装していません。
通常のexec要求が使えるホストはfalseのままにします。

エージェントなしの編集保存は同じフォルダーへ一時ファイルを送り、変更競合を検査して置き換えます。
SFTPで既存ファイルを置き換えるには `posix-rename@openssh.com` 拡張が必要です。
SFTP／SCPの変更検出はサイズ・更新日時等に依存し、同じ値に戻された変更や置換直前の競合を完全には検出できません。
アクセス権の基本モードは保持しますが、所有者・ACL等は作り直したファイルのものになります。

**現在の範囲**: WinSCPのSSH関連全設定との完全互換には未達です。GSSAPI／SSPI、Pageant／ssh-agent、
PuTTY形式鍵・証明書認証、Telnet／任意ローカルコマンドのプロキシ、SFTP v4～6、
ファイル名文字コード・時差補正、サーバー不具合の個別回避、リモートごみ箱等は未対応です。
任意のWinSCP raw設定を保存しただけで適用される仕組みにはしていません。

### SSH診断情報を記録する {#ssh-diagnostics}

yyeditor・yyterm・yysftp・yysheetの「ヘルプ → SSH診断の記録を開始」を選び、接続し直して問題を再現します。「記録を停止」の後、「SSH診断情報を書き出す…」でUTF-8テキストを保存してください。既存接続の認証履歴は遡って収集できません。記録は既定で無効で、アプリごとに有効にします。

接続経路、認証方式・MFAの段階、チャネル要求、PTYなしshellの開始、SFTPの起動、SCP転送、独自一覧コマンドの形式と失敗段階を記録します。ユーザー名は`@`の個数だけ記録します。接続先名・ユーザー名の値・パス・コマンド本文・パスワード・鍵本文・認証プロンプト・ファイル／端末本文は記録しません。既存の接続ログや設定ファイルは同梱しません。原因の候補は推定であり、管理者によるサーバー側の監査ログとの照合が必要です。

元の記録は開始時に表示する `%APPDATA%\yyeditor\logs\ssh-diagnostic-*.log` に保存し、終了後も残ります。上限8192イベントまたは4 MiBで記録を停止します。書き出しは現在のアプリで最後に開始した記録のスナップショットです。再起動前の記録はログフォルダーのファイルを参照してください。ネットワークへの送信は行いません。

### SSHゲートウェイを経由したファイル転送 {#sftp-gateway}

SecureCube Access Checkで複合ユーザー名を使う場合は、接続先管理のホスト名にゲートウェイ、ユーザー名に `Access Checkのユーザー@接続先ユーザー@接続先ホスト` を入力します。ユーザー名の`@`は分割せずそのまま認証に渡します。転送方式はSCP、一覧コマンドは環境で指定された `ls -la`、一覧形式は`ls`を選択してください。ロケールを指定できる場合は `LC_ALL=C ls -la` を推奨します。コマンドの許可範囲は管理者に確認してください。実機のSecureCubeによる検証は行っていません。


SSHGW／特権アクセス管理製品には、SSHトンネルを通す方式と、ゲートウェイ自身がSFTPを中継する方式があります。製品名だけでは接続方式を決められません。管理者が許可した経路を[SSH接続先管理](#ssh-sites)のGUIから設定してください。SFTPで利用する場合は`[transfer]`の`use_agent = false`（既定）で接続先エージェントを使わず、`protocol = "sftp"`を指定します。SCPで利用する場合は後述の条件を確認してください。WinSCPの「接続→トンネル」は`proxy_jump`、「環境→SFTP→SFTPサーバー」は`sftp_server`に相当します。

**SecureCube Access Check／Access Check Essential**: 製品がSSHを終端して接続先へ中継する構成では、まず製品の転送用接続口へ直接接続します。通常のOpenSSH踏み台と同じ`proxy_jump`、`jump_command`や、ゲートウェイ自身の`/usr/lib/openssh/sftp-server`を実行する構成だとは仮定しないでください。ゲートウェイのOSがRHELであっても、中継先のOSや利用できるコマンドは別です。接続先選択を含むログイン名・ポート・認証手順は、その環境の利用者向け手順で確認します。公開資料だけから製品固有のログイン名の書式を決めることはできません。

標準版の[公式カタログ](https://www.nri-secure.co.jp/hubfs/NRIS/PDF/ac_pamphlet_jp.pdf)はSFTP・SCPを掲載しています。一方、[Essentialの公式FAQ](https://www.nri-secure.co.jp/service/solution/access-check-essential)の中継プロトコルはSSH・RDP・SCPで、SFTPは掲載されていません。SCPで利用する環境では、ホスト別の転送方式にSCPを指定してください。専用エージェントとSFTPは要求しません。転送メニューからSCPを選ぶこともできます。SCP選択時は既存の一覧用接続を作り直します。

SCPの一覧・ファイル操作には、中継先でPTYなしのexec要求、または上述のPTYなしshell要求を受け付けるPOSIXシェルとGNU `find`、`stat`、`realpath`、`mkdir`、`mv`、`rm`、`rmdir`、転送には従来の`scp`、`wc`、`cat`、`tail`等が必要です。SFTPとエージェントは使いません。名前・メタデータはNUL区切りで取得し、空白や日本語を含む名前を扱います。これは[WinSCPのSCPが一覧等にUnixシェルを必要とする方式](https://winscp.net/eng/docs/requirements#scp_requirements)を参考にした実装です。SCPコマンドだけを許可し、一覧用コマンドやPTYなしexec／shellの両方を禁止する製品ポリシーでは、一覧付き画面を利用できません。SFTPへの自動切替やポリシーの迂回はしません。製品実機での互換性は未検証です。

**SSHトンネル方式**では、接続先とゲートウェイのホスト鍵・認証をそれぞれ確認します。内部ホスト名はゲートウェイ側で解決します。

```toml
[remote.host.gateway]
hostname = "gateway.example.com"
user = "gateway-user"
port = 22

[remote.host.internal]
hostname = "internal.example.local"
user = "server-user"
proxy_jump = "gateway"
```

yysftpで`internal`へ接続します。ゲートウェイが`direct-tcpip`を許可せず、代わりに**リモート中継コマンド**を提供する場合だけ、`[remote.host.gateway]`へ`jump_command = "nc -- %h %p"`等を追加します。実際のコマンドは管理者に確認してください。ゲートウェイ上でPTYなしのexecを行い、標準入出力で次のSSH接続を中継します。ローカルの外部プログラムは起動しません。`%h`は次ホスト（POSIXシェルの1引数として自動引用）、`%p`はポート、`%%`は`%`です。`%h`をさらに引用符で囲まないでください。多段接続では各踏み台に個別指定できます。未指定なら従来どおり`direct-tcpip`を使い、失敗時に別方式へ自動切替はしません。

**SFTPプロキシ方式**では、ゲートウェイのアドレスへ直接接続し、製品指定のユーザー名を設定します。`@`を含む複合ユーザー名もそのまま送信します。以下のユーザー名の構造は例であり、製品共通の文法ではありません。

```toml
[remote.host.sftp-via-gateway]
hostname = "gateway.example.com"
user = "operator@server-user@internal.example.local"
# 通常は以下の指定は不要。製品が別のサブシステム名を指定する場合だけ変更
# sftp_subsystem = "vendor-sftp"
```

標準の`sftp`サブシステムが使えず、接続先でSFTPサーバーのバイナリをexecする方式が必要なら、対象の`[remote.host.名前]`へ`sftp_server = "/usr/lib/openssh/sftp-server"`等を指定します。これは接続先で実行するコマンド全体です。パスはOS・製品に合わせて変更してください。PTYは要求せず、標準出力をSFTPのバイナリ通信専用にします。`sftp_server`と`sftp_subsystem`は同時指定できません。未指定なら`sftp`サブシステムです。これらの設定はフォルダー一覧と転送キューのアップロード・ダウンロードで共通に使います。SCPへは適用されません。

認証時のパスワード・ワンタイムパスワード・接続先選択がkeyboard-interactiveの質問として届く場合、表示される質問に順番に答えてください。秘密値を`config.toml`や起動コマンドへ書く必要はありません。SFTP起動要求を拒否された場合は、許可・起動設定を確認するエラーを表示します。起動要求へのSSH応答は20秒で時間切れになります。

接続できないときは[接続の記録]で、SSH認証の失敗か、踏み台の中継の拒否か、SFTP起動の拒否かを確認します。ゲートウェイが対話シェルのメニューだけを提供し、SFTP・exec中継・ポート転送をすべて禁止している場合、この設定だけでは転送できません。管理者にSFTP用の許可された接続方式を確認してください。任意のシェルメニューを自動操作する機能や製品固有プロトコルには対応していません。

参照した公式仕様: [WinSCPのSSHトンネル](https://winscp.net/eng/docs/ui_login_tunnel)、[SFTPサーバーの起動設定](https://winscp.net/eng/docs/ui_login_sftp)、[プロキシ](https://winscp.net/eng/docs/ui_login_proxy)。WinSCPの設定ファイルを直接読み込む機能ではありません。

### 接続先ごとのディレクトリ一覧コマンド {#sftp-list-command}

一覧に使うコマンドを変更する場合、ヘルプ → 設定ファイルを開くで、対象の接続先に次の項目を追加し、yysftpを再起動します。

```toml
[remote.host.internal]
hostname = "internal.example.local"
user = "server-user"
list_command = "ls -1A"
list_format = "lines"
```

`list_command`には任意のコマンドやスクリプトを指定できます。表示対象のディレクトリへ移動してから、接続先のPOSIXシェルでPTYなしのSSH execとして実行します。環境変数`YY_LIST_DIRECTORY`にも対象ディレクトリの絶対パスを渡します。プレースホルダーの置換は行わず、`%`やシェルの引用符はそのまま使えます。接続先がexecを許可している必要があります。

- `list_format = "lines"`（省略時）: 標準出力に直下のファイル名だけを1行ずつ出します。LF・CRLFに対応し、名前の前後の空白は保持します。`ls -la`のような属性付き一覧やフルパスは使えません。
- `list_format = "ls"`: `ls -la`のUnix長形式を解析します。推奨例は `list_command = "LC_ALL=C ls -la"`。空白・日本語の名前、リンクの` -> `表記、通常・ISO日時を扱います。改行を含む名前や引用・エスケープされた名前、複数の矢印を含むリンク表示は扱えません。
- `list_format = "nul"`: 各ファイル名の末尾にNULを出します。改行や末尾のCRを含む名前にも対応します。GNU findの例は、TOMLのリテラル文字列を使って `list_command = 'find . -mindepth 1 -maxdepth 1 -printf "%f\0"'` とします。
- 空のディレクトリでは何も出力しません。`.`と`..`は無視します。空行・重複・`/`を含む名前はエラーです。説明や診断は標準エラーへ出し、失敗時は非ゼロで終了させてください。失敗時に標準の一覧方式へ自動で戻ることはありません。

指定した接続先名でのyysftp・yyeditor・yyterm・yysheetのリモート一覧に適用します。SFTP・SCP・エージェントのいずれでも使えますが、別の接続先名や踏み台の設定からは継承しません。未指定の接続先は従来の一覧処理を使います。属性取得とファイル操作・転送は選択した方式を引き続き使うため、それらも接続先で動作する必要があります（SCPの属性取得はGNU stat等が必要です）。属性は各項目について取得するため、大量の項目では通常の一覧より時間がかかる場合があります。

## スプレッドシート（yysheet） {#yysheet}

`yysheet.exe` は、yyeditor と同じ部品で作った、大量のデータ（50 億セル程度）を扱えるスプレッドシートです
（開発中。今は値の表示・入力・CSV と独自形式の読み書き・絞り込み・並べ替え・書式・数式まで）。

- **開く**（Ctrl+O、ドラッグ＆ドロップ）: 独自形式（`.yys`）と CSV（`.csv`・`.tsv`・`.txt`）。CSV は文字コード
  （UTF-8・Shift_JIS・EUC-JP・UTF-16 など）・区切り文字・見出し行・列の型（数値・日付・真偽値・文字列）を
  推定して、全コアで並列に取り込みます（進みをステータスバーに出します。Esc で中止）。`00123` のように
  数値にすると元に戻らない値は文字列のままにします。
- **保存**（Ctrl+S）: `.yys` は、開いたファイルなら変わった部分だけを書き足すので、大きなファイルでもすぐ
  終わります（使われなくなった部分が増えたら書き直します）。CSV から開いたものは、CSV のまま保存するか
  `.yys` で保存するかを尋ねます。「CSV に書き出し」は、開いたときの区切り文字・文字コードで、表示形式を
  当てた値（日付は日付の形）を書きます。
- **操作**: 矢印・Ctrl+矢印（データの端へ）・Shift で範囲選択・PageUp/PageDown・Ctrl+Home/End、
  F2（編集）・文字の入力で編集を始める（IME も使えます）・Enter／Tab で確定して移動・Esc で取り消し、
  Delete（消す）、Ctrl+Z／Y、Ctrl+C／X／V（Excel との間でタブ区切りの文字列）、Ctrl++／Ctrl+-
  （行の挿入・削除）、Ctrl+ホイール（拡大・縮小）。列見出しの境目をドラッグして列幅を変えます。
  先頭に `'` を付けると文字列として入力します。
- **表示**: 数値は Excel と同じ表示形式（`#,##0`・`yyyy/m/d`・`ggge年m月d日` など）で、標準の数値は列幅に
  合わせて丸め・指数表記にします（入らなければ `#`）。数値は右、文字列は左、真偽値・エラー値は中央。
- **数式**: `=` で始めて入力します（Excel と同じ文法。参照 `A1`・`$A$1`・`A1:C10`・`A:A`・`1:1`・
  `Sheet2!A1`・`'売上 2026'!B:B`、配列定数 `{1,2;3,4}`、演算子 `+ - * / ^ % &` と比較）。使える関数は
  `SUMIFS`・`COUNTIFS`（条件 `"東京"`・`">=100"`・`"<>"`・`"東*"` など）・`XLOOKUP`（一致モード・検索
  モード・見つからない場合）・`SUM`・`COUNT`・`AVERAGE`・`MAX`・`MIN`・`MEDIAN`・`PERCENTILE`（`.INC`・`.EXC`）・`ROUND`・`ROUNDUP`・`ROUNDDOWN`・`IF`・`MOD`・`PI`・`TRUE`・`FALSE`・`PRODUCT`・`ABS`・`CONCAT`（`CONCATENATE`）・`TEXTJOIN`・`TEXTSPLIT`・
  `IFERROR`・`CBL.LOW-VALUE`・`CBL.HIGH-VALUE`（固定長の項目のすべてのバイトを X'00'・X'FF' に）・`CBL.MOVE`（範囲を COBOL の MOVE で送る。`CBL.` は COBOL のための関数） です
  （ほかの関数は `#NAME?`）。複数の値を返す式（`TEXTSPLIT`、範囲どうしの演算、複数列の `XLOOKUP`）は
  右・下のセルにあふれ（スピル）、あふれる先に値があれば `#SPILL!` になります。値を直すと、そのセルを参照する式
  （とそれに依存する式）だけを依存の順に、バックグラウンドで計算し直します（時間がかかるときは
  ステータスバーに「再計算中…」と出し、その間の入力は受け付けません。循環する式は `#CALC!`）。
  `XLOOKUP` の完全一致は列の索引を作って引き、条件の値だけが違う多数の `SUMIFS`・`COUNTIFS` は範囲を
  1 回読んでまとめて計算します。
- **式の入力の補助**: 式の入力中に、演算子・`(`・`,`・`=` の直後でセルをクリックすると参照（`C3`）が、
  ドラッグすると範囲（`C3:E10`）が、列見出し・行番号をクリックすると列全体（`C:C`）・行全体（`3:3`）が
  式に入ります。Shift+クリックで範囲を広げ、続けてクリックすると入れた参照を差し替えます（文字を入力すると
  確定します）。文字の入力で始めた編集では矢印キー（Shift+矢印で範囲）でも選べます。F4 で参照の `$` を
  切り替えます（`A1` → `$A$1` → `A$1` → `$A1`）。参照を入れられる位置でシートのタブをクリックすると、
  入力を続けたままそのシートに切り替わり、セルをクリックすると `Sheet2!B3` のような参照が入ります
  （Enter で元のシートのセルに確定し、元のシートに戻ります。Esc で取り消し）。関数名を途中まで入力すると候補と説明が出ます（↑↓で選び、
  Tab・Enter・クリックで入れる。Esc で閉じる）。関数のかっこの中では、引数の書き方（例:
  `SUMIFS(合計範囲, 条件範囲1, 条件1, …)`）を出し、いま入力している引数を太字にします。式の中の参照には
  色の付いた枠が出ます。セルの編集の内容は数式バーにも出ます。
- **検索・置換**（編集 メニュー）: 「検索」（Ctrl+F）で表から文字列を探し、「次を検索」（F3）で続きを
  探します（大文字・小文字は区別しません。末尾まで行ったら先頭に戻ります）。「置換」（Ctrl+H）は、
  選んだ列（または表のすべての列）の文字列を置き換えます。正規表現（置換後の文字列で `$1` などの組を
  使えます）、大文字と小文字の区別、セル全体の一致を選べます。
- **重複の削除・列の型**（データ メニュー）: 「重複の削除」は、選んだ列の値の組が前の行と同じ行を消します
  （大文字・小文字は区別しません）。「列を数値に変換」は数値・日付に読める文字列を数値に、「列を文字列に
  変換」は数値を文字列にします。どれも Ctrl+Z で戻せます。
- **フィルハンドル**: 選択範囲の右下の小さな四角（ポインターが ＋ になります）を上下左右にドラッグすると、
  その方向へ値を広げます。`1, 2` → `3, 4, …`（数値が 2 つ以上なら同じ増え方で）、日付は 1 日ずつ、
  `項目1` → `項目2`、`月` → `火`、`1月` → `2月` のように続け、それ以外はコピーします（数値 1 つは
  コピー。離すときに Ctrl を押していると、連続データとコピーが入れ替わります）。日付が `1/31, 2/28` のように
  月ずつ並んでいれば月単位で続けます（`3/31, 4/30`）。フィルのあと右下に出るボタン（▼）で、セルのコピー・
  連続データ・書式のみコピー・書式なしコピー、日付なら日・週日（土日を飛ばす）・月・年の単位を選んで
  入れ直せます。右ボタンでドラッグすると、離したときに同じメニューが出ます。式は相対参照をずらして
  コピーし、書式も写します。範囲の中へ戻すと外れたセルを消します。フィルハンドルをダブルクリックすると、
  左（なければ右）の列の値が続く行まで下へ広げます（表の全行に式を入れるときに便利です）。
- **下へコピー**（Ctrl+D）: 選択範囲の 1 行目を下の行へコピーします。式は行ごとに相対参照をずらし、
  16 行以上なら「共有式」として 1 つの式で持つので、表の全行（数百万行）に `=A2*2+B2` や
  `=XLOOKUP(D2,Sheet2!A:A,Sheet2!B:B)` を入れてもすぐに計算できます。共有式の範囲の中のセルに値や
  別の式を入れると、そこで分かれます。行・列の挿入と削除では、式の参照を付け替えます
  （消えた範囲を指す参照は `#REF!`）。数式バーと編集では式を、セルには結果を表示します。式は `.yys` に
  保存し、開いたときに計算し直します。
- **書式**（書式 メニュー）: 「セルの書式設定」（Ctrl+1）で、表示形式（候補から選ぶか書式記号を入力。
  例を見ながら）、太字・斜体、横の配置、塗りつぶしの色、文字の色、罫線（なし・格子・外枠・上・下・左・
  右。線の種類は細線・中線・太線・点線・破線・二重線、線の色）をまとめて付けます。太字（Ctrl+B）・
  斜体（Ctrl+I）・塗りつぶしの色・文字の色・罫線・表示形式はメニューからも直接付けられます。
  「書式のクリア」で既定に戻します。列見出し・行番号をクリックして（または Ctrl+A で）列全体・行全体を
  選んで付けた書式は、あとから増えた行・列にも効きます。書式は `.yys` に保存し、CSV に書き出すときは
  表示形式を当てた値を書きます。表示形式の色（`[赤]` など）は文字の色より優先します。
- **絞り込み**: 表の列見出しの ▼（またはデータ メニューの「列の絞り込み」、Ctrl+Shift+L）で、値の一覧
  （件数付き。検索して選ぶ。ほかの列の条件で残った行の値だけを出します）か、条件（等しい・含む・で始まる・
  ワイルドカード・より大きい・範囲・上位／下位 N 件・N %・平均より上／下・空・空でない。2 つまで「かつ」・
  「または」）を付けます。条件はいくつの列にも付けられ、すべてを満たす行を表示します。付けた順に「段階」と
  して数え、「絞り込みの段階」で段階ごとの残りの行数を見て、段階を外す・順を変えられます。絞り込み中の
  行番号は元の行番号（青）で出し、ステータスバーに残りの行数を出します。
- **並べ替え**: ▼ のダイアログか、データ メニューの「昇順／降順に並べ替え」（アクティブなセルの列）・
  「並べ替え」（キーを複数。上のキーが優先）。値の順は Excel と同じ（数値 < 文字列 < 真偽値 < エラー、
  空のセルは昇順・降順とも最後、英字の大文字・小文字は区別しない）で、同じ値の行は元の順のままです。
- 絞り込み・並べ替えはデータを動かさず、表示する行の並びだけを変えます（見えている行への入力・貼り付けは
  元の行に入ります）。条件はファイル（`.yys`）に保存し、開いたときに当て直します。値を直したあとは
  「再適用」（Ctrl+Alt+L）で計算し直します。表示中は行の挿入・削除はできません（「解除」するか、
  「並べ替えを確定」で表を並べた順に作り直してから）。CSV に書き出すときは、見えている行を表示の順に
  書くか、すべての行を元の順に書くかを選べます。どの操作も Ctrl+Z で戻せます。
- **固定長ファイル**: IBM COBOL のコピーブック互換のレイアウト定義で、固定長のファイルを読み書きします
  （マルチレイアウトは対象外）。
  - **開く**: ファイル > **固定長ファイルを開く**（`.dat`・`.bin` は「開く」・ドラッグ＆ドロップでも）で
    データのファイルを選ぶと、レイアウトのダイアログが出ます。コピーブックを貼り付けるか「ファイルから
    読み込む」で読み込み、文字コード（MS932、EBCDIC の IBM-930・939・1390・1399・290・1027・037・500・
    1047）、レコードの区切り（自動・なし・CR LF・LF・NL）、2 進数の並び（ビッグ／リトルエンディアン）を
    選びます。下の欄に、レコード長・項目の一覧（位置・長さ・名前・型）・レコードの数・1 件目の値が出るので、
    確かめてから OK で取り込みます。
  - 基本項目 1 つが 1 列になります（見出しは項目の名前。`OCCURS` は `名前(1)`、同じ名前は `名前 OF 親`）。
    使える型は `PIC X`・`A`・`N`・`G`・`NATIONAL`・`9`（ゾーン 10 進数。`SIGN LEADING`・`SEPARATE` も）・
    `COMP-3`・`COMP`/`BINARY`・`COMP-5`・`COMP-1`・`COMP-2`・数字編集（`ZZ,ZZ9.99-` など）です。`REDEFINES`
    する項目は使わず、元の定義で読み書きします。15 桁を超える数値は桁を落とさないよう文字列で表示します。
    数値として読めない項目（壊れたパック 10 進数など）は `X'404040'` のように表示し、そのまま書き戻します。
  - **作成**: 新しいシートで データ > **固定長のレイアウト** を選び、コピーブックを設定すると、項目の列
    （見出し）ができます。2 行目から入力してください。表のあるシートでは、名前の同じ列を項目に結び付けます。
  - **型**: 列見出しに項目の型、ステータスバーの右にレコード長と列の項目が出ます。セルの書式設定（Ctrl+1）の
    「COBOL の型」で型を選び直せます。型に合わない値（数値の項目に文字、桁の超えなど）は入力できません。
    式の結果が型に合わなければ、セルに `#VALUE!`（型が違う）・`#NUM!`（桁・範囲の外）を出します。
    値は COBOL と同じく項目の長さまで埋めます（英数字は空白、数値は表示を 0 で）。
  - **マルチレイアウト**: データ > マルチレイアウトの設定 で、最初に 1 行のデータ長（必須）を入れ、レイアウトを名前を付けて登録し、A 列に行ごとの
    レイアウトの名前を入れます（未確定の行は背景が赤く、A 列に `#レイアウト未確定`）。ファイル >
    固定長ファイルを開く（マルチレイアウト）で読み込めます。
    詳しくは yysheet の ヘルプ > yysheet ヘルプ（F1）を見てください（COBOL の型と関数の一覧があります）。
  - **保存**: ファイル > **固定長ファイルに書き出し**（固定長ファイルを開いたときは上書き保存でも）で、
    文字コード・区切り・2 進数の並びを選んで書きます。開いたときと別の文字コード（MS932 ⇔ EBCDIC）にも
    できます。桁あふれ・長すぎる文字列・文字コードにない文字があれば、数と最初の場所を知らせます。空のセルは
    英数字・ゾーン 10 進数なら空白、パック 10 進数・2 進数なら 0 で書きます。数値の小数部が項目の桁より
    多いときは、COBOL の MOVE と同じく切り捨てます（例: `PIC 9V99` に 1.239 → 1.23）。列を並べ替えたり削除したりしても、
    レイアウトの項目の順に書きます。`.yys` で保存すると、レイアウトも保存されます。
- **メモリ**: アプリが使うメモリは既定で 8 GB まで（設定 `[sheet] memory_limit_gb`）。データはファイルに
  置いたまま必要な部分だけを読み、新しく作ったデータは作業ファイル（`work_dir`、既定は一時フォルダ）に
  書きます。使用状況はヘルプ メニューの「メモリの使用状況」で見られます。
- 設定（`config.toml`）:

```toml
[sheet]
memory_limit_gb = 8.0   # アプリが使うメモリの上限
work_dir = ""           # 作業ファイルのフォルダ（空なら一時フォルダ）
font_family = ""        # 格子のフォント（空なら Yu Gothic UI）
font_size = 11.0
column_width = 8.43     # 既定の列幅（半角の文字数）
layout_catalog = ""     # 固定長のレイアウトカタログのルート（空なら %APPDATA%\yyeditor\layouts）
use_agent = false       # 接続先のファイルの読み書きにエージェントを使う（false なら SFTP）
```

## ターミナルのマクロ・文法・変数 {#terminal-macros}

yyterm（yyterminal）のマクロは、人が編集できる**UTF-8のRhaiテキストファイル（`.rhai`）**です。接続中のSSHタブと3270端末タブで使用できます。ローカルシェルと3287プリンターのタブは対象外です。

- **実行**: 対象タブを表示し、[マクロ] → [マクロを実行]（Ctrl+Shift+F5）でファイルを選びます。開始したタブに結び付くため、実行中に別タブへ切り替えても送信先は変わりません。同時に実行できるのは1つです。
- **停止**: [マクロを止める]、または対象タブでCtrl+Break／Pause。文字待ち・待機・繰り返しも停止できます。実行中は対象タブへの利用者の入力を送りません。
- **記録とテキスト出力**: [操作の記録を開始・終了]（Ctrl+Shift+F6）で記録を開始し、もう一度選ぶと保存先を選べます。UTF-8の`.rhai`として保存し、yyeditorで開きます。他のエディターでも編集できます。手書きのマクロも同じ形式で実行します。
- マクロの既定フォルダーは`%APPDATA%\yyeditor\macros`です。[マクロのフォルダを開く]から開けます。SSHと3270で共通の`[tn3270.macro]`設定（`folder`、`output`、`timeout`）を使用します。出力の既定先はドキュメントの`yyterm\macros-out`、文字待ちの既定上限は30秒です。

SSHの記録は、実際に送ったUTF-8文字・改行・制御シーケンスを`type("…")`として保存します。ESC等は`\x1b`、改行は`\r` / `\n`のように読める形へ変換します。入力の間隔やホストのプロンプトは推定しないため、記録後に必要な`wait_text`を追加してください。SSHのパスワード欄は3270の非表示フィールドのようには識別できず、**記録中の手入力はパスワードも含めて保存されます**。秘密値は記録せず、編集時に`password("名前")`へ置き換えてください。3270では従来どおり非表示フィールドの値を記録せず、`password`に置き換えます。

### 変数と基本文法

変数は`let 名前 = 値;`、定数は`const 名前 = 値;`です。文字列・整数・真偽値、配列`[値, …]`、マップ`#{名前: 値, …}`を使えます。変数は`=`で再代入でき、`+=`なども使えます。文末は`;`、処理のまとまりは`{ … }`です。コメントは`// …`または`/* … */`。文字列には`\"`、`\\`、`\n`、`\r`、`\t`、`\x1b`等のエスケープを使えます。

```rhai
// SSHの例。変数はローカルのマクロ内の値で、シェル変数ではありません。
const prompt = "$ ";                 // 接続先のプロンプトに合わせて変更
let directory = ask("調べるディレクトリー（スペースを含まないもの）");
if directory == () { throw "取り消しました"; }
wait_text(prompt, 30);
send_line("ls -ld -- " + directory); // 送信文字列はそのまま。シェルの引用は必要に応じて記述
wait_text(prompt, 30);
let report = text_open("ssh-screen.txt");
for line in screen_lines() {
    report.write_line(line);
}
report.close();
```

シェル側の応答が来る前から同じプロンプトが画面に残っている場合、`wait_text`はその既存表示にも一致します。コマンドごとに異なる完了マーカーを出してそれを待つと、前の表示と区別できます。

```rhai
let marker = "YY_MACRO_FINISHED_01";
// コマンド文字列にマーカー全文を含めず、入力エコーとの誤一致を避ける
send_line("pwd; printf '%s%s\\n' YY_MACRO_ FINISHED_01");
wait_text(marker, 30);
```

| 文法 | 例 |
| --- | --- |
| 条件分岐 | `if count > 0 { log(count); } else { log("なし"); }` |
| 比較・論理演算 | `==`、`!=`、`<`、`<=`、`>`、`>=`、`&&`、`||`、`!` |
| 四則演算・文字列結合 | `n + 1`、`n - 1`、`n * 2`、`n / 2`、`"cd " + path` |
| 回数の繰り返し | `for n in 0..3 { log(n); }`（0、1、2） |
| 配列の繰り返し | `for value in ["one", "two"] { send_line("echo " + value); }` |
| 条件付き・無限ループ | `while count < 3 { count += 1; }`、`loop { … }` |
| ループ制御 | `break;`、`continue;` |
| 関数 | `fn command(value) { return "echo " + value; }` |
| 配列・マップの参照 | `items[0]`、`position.row`、`position["col"]` |
| エラー | `throw "説明";`、`try { … } catch (error) { log(error); }` |
| 空値と取消 | `()`。`ask`の取消結果も`()` |

`screen_text()`等で得た文字列や`ask`の結果を変数に入れ、加工して送信できます。`${名前}`のような独自の自動置換は行いません。文字列の結合等で送信内容を組み立てます。スクリプトはホストのシェルへ文字を送るもので、Rhaiから直接OSプログラムを起動したり任意のネットワーク接続を作ったりはできません。モジュールの`import`は提供しません。

### 共通命令（SSH／3270）

行・桁は1始まりで、長さは端末の表示セル数です。全角文字の継続セルは重複して返しません。SSHでは最新の可視画面が対象で、利用者がスクロールバックを動かしても取得対象は変わりません。端末の非表示属性の文字は空白になります。

| 命令 | 動作 |
| --- | --- |
| `type(text)` / `input(text)` / `send(text)` | 改行を加えず文字列を送る。SSHではUTF-8をそのまま送信し、ブラケット付き貼り付けにはしない |
| `send_line(text)` | 文字列を送ってEnterキーを送る。シェルの引用・変数展開は接続先の規則に従う |
| `key(name)` | 指定のキーを送る。下表参照。キーを送っただけではホストの応答を待たない |
| `tab()` / `home()` | Tab / Homeキーを送る |
| `wait_text(text[, seconds])` | 画面内の行に文字列が現れるまで待つ |
| `wait_text_at(row, col, text[, seconds])` | 指定セル位置の文字列を待つ |
| `wait_unlocked([seconds])` | 3270のロック解除を待つ。SSHはロック状態を持たず即時復帰するので、応答待ちには`wait_text`を使う |
| `wait_change(seconds)` | 画面・状態の世代が変わるまで待ち、変われば`true`、上限まで変わらなければ`false` |
| `text_at(row, col, length)` / `row(row)` | セル範囲／1行の文字列を取得。画面外は空 |
| `screen_lines()` / `screen_text()` | 行の配列／改行で連結した画面文字列を取得 |
| `rows()` / `cols()` | 画面の行数／桁数 |
| `cursor()` | `#{row, col}`を返す |
| `locked()` | 3270のキーボードロック状態。SSHは`false` |
| `password(name)` | 資格情報から秘密値を直接送信。値を変数に返さず、診断ログに残さない。なければ入力を尋ねる |
| `ask(question)` | 文字列を尋ねて返す。取消は`()` |
| `message(value)` | メッセージを表示 |
| `log(value)` / `print(value)` / `debug(value)` | 実行の記録へ出力。SSHの`log`はステータスにも表示 |
| `sleep(milliseconds)` | ミリ秒単位で待つ。停止可能 |
| `text.trim()` | 前後の空白を除去し、変更した文字列も返す。`text_at(1, 1, 20).trim()`等で使用 |

`wait_text` / `wait_text_at` / `wait_unlocked`の秒指定を省略すると設定の`timeout`を使います。0以下なら現在の画面を調べて真偽値を返します。正の時間での上限超過、切断、停止、使用できない操作は行番号付きのエラーとなり、通常はそこで終了します。

| キー | SSH | 3270 |
| --- | --- | --- |
| `Enter`、`Tab`、`BackTab`、`Home`、`Up`、`Down`、`Left`、`Right`、`Backspace`、`Delete`、`Insert` | 対応 | 対応 |
| `Escape`（`Esc`）、`End`、`PageUp`（`PgUp`）、`PageDown`（`PgDn`）、`Space`、1文字 | 対応 | 文字は`type`で入力 |
| `F1`〜`F12`、`PF1`〜`PF12` | 対応 | `PF1`〜`PF12`を使用 |
| `Ctrl+C`、`Ctrl+Space`、`Alt+a`、`Shift+Tab`等 | `Ctrl` / `Control`、`Alt`、`Shift`を`+`で組み合わせる | この文字列表記は非対応 |
| `PF13`〜`PF24`、`PA1`〜`PA3`、`Clear`、`SysReq`、`Attn`、`Reset`、`EraseEOF`、`EraseInput`、`Dup`、`FieldMark` | 非対応 | 対応 |
| `NewLine` | Enterとして送信 | 3270の改行キー |

SSHのカーソルキーは、その時点の端末のアプリケーションカーソルモード等に従って符号化します。秘密値の資格情報キーはSSHが`ssh-macro/名前`、3270が既存の`tn3270/名前`です。診断ログは共通の`%APPDATA%\yyeditor\logs\tn3270-macro.log`に残します。SSHの送信本文は診断ログへ記録せず、明示的な操作記録は別扱いです。

### ファイルへの出力（既存命令）

| 命令 | 動作 |
| --- | --- |
| `csv_open(relative_path)` | CSV用ファイルを開き、UTF-8 BOMを付ける。既存ファイルは置換 |
| `text_open(relative_path)` | テキストファイルを開く。UTF-8、BOMなし。既存ファイルは置換 |
| `file.write_row([values…])` | CSVの引用・引用符の二重化を行い、CRLFで1行書く |
| `file.write_line(text)` | 文字列とCRLFを書き込む |
| `file.close()` | 出力を閉じる |
| `file.path` | 実際の出力パス |

出力先は設定されたマクロ出力フォルダー配下の相対パスです。`csv_open` / `text_open`はマクロの実行結果の出力で、操作の記録を`.rhai`へ保存する機能とは別です。

### 3270専用の既存命令

- `move_to(row, col)`: 3270カーソルを移動。SSHではローカル表示のカーソル位置を変更せず、使用不可のエラーを返します。
- `fields()`: フィールド情報の配列。`field_at(row, col)`: そのセルのフィールド情報または`()`. フィールドの情報は`row`、`col`、`len`、`protected`、`numeric`、`hidden`、`text`です。非表示フィールドの本文は渡しません。SSHでは`fields()`は空配列、`field_at`は`()`。
- `transfer_get(host_file, local_file[, options])` / `transfer_put(local_file, host_file[, options])`: IND$FILE転送。`#{ok, message}`を返します。`host`は`tso`（既定）/ `cms` / `cics`、`mode`は`text`（既定）/ `ascii` / `binary`、`recfm`は`F` / `V` / `U`、数値指定は`lrecl` / `space`、追記は`append: true`です。SSHでSFTP転送を行う命令ではなく、使用不可のエラーになります。
- `print_screen()`: 3270の画面を設定したプリンター出力先へ送ります。SSHでは使用不可です。SSH画面を保存する場合は`screen_lines()`と`text_open`を使用してください。
- `on_connect`: 3270ホストの既存設定です。SSHマクロは上記メニューから明示的に実行します。

## 3270（メインフレーム） {#tn3270}

yyterm のタブで、IBM メインフレーム（z/OS など）に 3270 端末として接続できます（TN3270・TN3270E）。

- **接続**（ファイル メニューの「3270 で接続」、Ctrl+Shift+M）: `ホスト[:ポート]`（既定のポートは 23）、
  `tn3270://LU名@ホスト:ポート`、`tn3270s://ホスト`（TLS。既定のポートは 992）、または設定の
  `[tn3270.host.名前]` の名前を入力します。設定に `ssh` を書くと、その SSH の接続（踏み台・プロキシも
  使えます）を経由します（手元のポートは開きません）。
- **TLS**: 設定の `tls = "tls"`（暗黙の TLS）か `tls = "starttls"`（Telnet の STARTTLS。ふつうのポートで
  接続してから TLS に切り替えるホスト）で暗号化します。サーバーの証明書は Windows の信頼する認証局と設定の
  `ca_file` で検証します。検証できない証明書（社内の自己署名など）は、SSH のホスト鍵と同じく初めて接続する
  ときに主体・発行者・有効期間・SHA-256 の指紋を表示して確かめ、受け入れたら
  `%APPDATA%\yyeditor\known_certs` に記録します。次からは記録と同じなら黙って接続し、違えば接続しません
  （証明書を正しく更新したと分かったら、その行を消してください）。クライアント証明書を求めるホストには、
  `client_cert`（PEM。秘密鍵も入っていてよい）と `client_key` を設定します（秘密鍵は暗号化していないもの）。
  TLS で接続したタブは OIA に `TLS` と出し、版・暗号・証明書を `tn3270.log` に記録します。
- **日本語**: 既定の文字コードは CCSID 930（カタカナ＋漢字）。939・1390・1399・037・1047 も選べます
  （設定の `ccsid`）。漢字は IME で入力でき、半角と全角の切り替え（SO/SI）は自動で入れます。
- **画面の下の 1 行（OIA）**: 接続の種類（TN3270・TN3270E）、LU 名、キーボードの状態（`X SYSTEM` は
  ホストの応答待ち、`X 保護` などは操作の誤りで Reset で解除）、挿入モード（INS）、カーソルの位置、文字コード。
- **キー**:

| 機能 | キー |
|------|------|
| Enter / New Line | Enter / Shift+Enter |
| PF1〜PF12 / PF13〜PF24 | F1〜F12 / Shift+F1〜F12 |
| PF7 / PF8（上下） | PageUp / PageDown |
| PA1 / PA2 / PA3 | Alt+1 / Alt+2 / Alt+3 |
| Clear | Esc |
| Reset | Ctrl+R |
| Erase EOF / Erase Input | End / Shift+End |
| 挿入モード | Insert |
| Tab / Back Tab | Tab / Shift+Tab |
| Dup / Field Mark | Ctrl+D / Ctrl+M |
| Attn / SysReq | Ctrl+Pause / Alt+PrintScreen |

- **キーパッド**: 画面の右に、PF1〜PF24・PA1〜PA3・Clear・Reset・Attn・SysReq・Erase EOF・Erase Input・
  Field Mark・Dup・Enter のボタンを出します（設定の `keypad = false` で消せます）。
- マウスのクリックでカーソルを移し、ドラッグで選択してコピーします（非表示のフィールドはコピーしません）。
  貼り付けは非保護のフィールドにだけ入れます（Tab で次のフィールド、改行で New Line）。
- 接続の記録（交渉・LU・切断・ファイル転送）は `%APPDATA%\yyeditor\logs\tn3270.log` に残します。
- **ファイル転送（IND$FILE）**（ファイル メニューの「3270 のファイル転送」、Ctrl+Shift+I）: TSO の `READY`、
  CMS の `Ready` の後で使います。向き（ホストから受け取る GET・ホストへ送る PUT）、ホストの種類（TSO・CMS・CICS）、
  ホストのファイル（TSO は `'USER.DATA(MEM)'`、CMS は `PROFILE EXEC A`）、手元のファイル、データの扱いを選ぶと、
  カーソルの位置に `IND$FILE ...` のコマンドを入力して Enter を押し、ホストとの転送（DFT）を行います。
  - **テキスト（端末で変換）**: 日本語の既定。バイナリで転送し、端末でタブの CCSID（930 など）と UTF-8 を
    変換します（ホストの ASCII 変換は日本語を扱えないことが多いため）。受け取ったテキストは UTF-8・CRLF で、
    行末の空白（固定長の詰め物）を除きます。
    - **固定長**（送るときは RECFM F と LRECL、受け取るときは LRECL を指定）: `CRLF` を使わず、行を LRECL まで空白で
      詰めて送り、受け取ったものを LRECL ごとに分けます。どのホストでも確実なので、固定長のデータセットでは
      LRECL を指定してください。
    - **それ以外**（可変長など）: `CRLF` オプションでホストにレコードを区切ってもらいます。ホストによっては
      区切らないことがあります（MVS 3.8j の IND$FILE 2.0.5 は区切りません）。受け取ったものに区切りがなく、
      大きさが 80 の倍数なら 80 バイトずつ分けます。
    送るときは手元のファイルの文字コードを自動判別し、CCSID にない文字があれば行番号を示して止めます。
  - **テキスト（ホストの ASCII 変換）**: `ASCII CRLF`。ファイルはそのまま（末尾の EOF 文字 0x1A は除きます）。
  - **バイナリ**: 変換しません。
  - 送るときは、新しく作るファイルの RECFM・LRECL・トラック数（TSO）と、追加（APPEND）を指定できます。
  - 送るとき、テキストの行が LRECL を超えれば行番号を示して止めます（切り詰めません）。
  - 転送の開始・終了・エラーは `%APPDATA%\yyeditor\logs\tn3270-transfer.log` に残します。IND$FILE は途中から
    再開できないので、切断されたら最初からやり直してください。
  - 受け取ったファイルは yyeditor で開けます。進み具合は画面の下の行とステータスバーに出し、
    「3270 のファイル転送を取り消す」で取り消せます（ホストは取り消しのメッセージを返して終わります）。
- **通信の記録（トレース）**（ファイル メニューの「3270 の通信の記録を開始・終了」）: 表示している 3270 のタブの
  送受信を `%APPDATA%\yyeditor\logs\tn3270-trace-<日付>-<時刻>-<名前>.log` に書きます。記録中は画面の下の行に
  `TRACE` と出ます。終えると記録を yyeditor で開きます。接続（交渉）から記録するには設定の `trace = true` にします。
  - Telnet の命令・サブネゴシエーション（端末の種類・LU・関数）と、3270 のレコードごとに、16 進と解釈
    （コマンド・WCC・オーダー・フィールドの属性・文字・構造化フィールド・IND$FILE の要求・AID とカーソル）を書きます。
    `<` はホストから、`>` はホストへ送ったものです。
  - 非表示のフィールド（パスワード）に入れた文字は、16 進では `**`、解釈では `"******"` に置き換えます。
  - 障害の調査のときは、この記録をそのまま送ってください（受け取ったものから同じ画面を作り直せます）。
    IND$FILE の転送の中身も 16 進で残るので、大きなファイルを転送するときは記録を止めておくと小さく済みます。
- **プリンター（3287）**（ファイル メニューの「3270 のプリンターを接続」）: 3270 の端末のタブで選ぶと、
  ホストの印刷を受け取るプリンターのタブを開きます。設定の `printer_lu` があればその LU、なければ端末に
  割り当てられた LU に対応するプリンター（TN3270E の ASSOCIATE）につなぎます。設定で `printer = "auto"` に
  すると、端末に LU が割り当てられたときに自動で開きます。
  - LU1 の SCS（改行・改ページ・タブ・用紙の桁数と行数・位置・日本語の SO/SI）と、LU3 の 3270 データストリーム
    （WCC の行の長さ、または NL・EM・FF で区切る形）に対応します。ジョブの終わりは TN3270E の PRINT-EOJ、
    なければ `eoj_timeout` 秒データが来なかったときです。
  - タブには受け取った印刷を古い順に並べ（新しいものが下）、ページの中身を表示します。
  - 出力先は設定の `output`: `printer`（Windows のプリンター。`printer_name` が空なら既定のプリンター）、
    `pdf`・`text`（`folder` に保存。空ならドキュメントの `yyterm-print`）、`ask`（一覧に置くだけ）。
  - 一覧の印刷は、ファイル メニューの「受け取った印刷を印刷」「PDF で保存」「テキストで保存」で番号（#）を選んで
    出せます。PDF は Windows の「Microsoft Print to PDF」で作ります。テキストは UTF-8 で、改ページは FF です。
  - 印刷は用紙に合わせて文字の大きさを決め（桁数はジョブの最大の桁数、行数は 60 行以上）、
    全角は 2 桁に置きます（MS ゴシック）。受け取りと出力は `logs\tn3270-transfer.log` に残します。
- **マクロ**（マクロ メニュー）: 3270 の操作を Rhai のスクリプトで自動化します。マクロは
  `%APPDATA%\yyeditor\macros\*.rhai`（設定の `folder` で変えられます）に置き、「マクロを実行」
  （Ctrl+Shift+F5）で表示している 3270 のタブで動かします。実行中は利用者のキー入力を止め、画面の
  下の行に「マクロ実行中」と出します。Ctrl+Break か「マクロを止める」で止めます。接続先の設定の
  `on_connect = "logon.rhai"` で、接続したときに実行することもできます。
  - 使える操作（行・桁は 1 から。全角は 2 桁）:

    | 操作 | 説明 |
    |------|------|
    | `wait_unlocked(秒)` | キーボードのロックが解けるまで待つ（ホストの応答を待つ基本） |
    | `wait_text("文字", 秒)`・`wait_text_at(行, 桁, "文字", 秒)` | 画面（その位置）に文字が出るまで待つ。秒が 0 なら今あるかを返す |
    | `text_at(行, 桁, 長さ)`・`row(行)`・`screen_lines()`・`cursor()`・`fields()`・`field_at(行, 桁)` | 画面を読む |
    | `move_to(行, 桁)`・`tab()`・`home()`・`type("文字")`・`key("PF8")` | 入力する（`key` の後は自動では待たない） |
    | `password("名前")` | 資格情報マネージャーの `tn3270/名前` のパスワードを入れる（なければ尋ねる。スクリプトには渡さない） |

## タブと比較 {#tabs}

- ファイルはタブで開きます。タブの「×」または中ボタンのクリックで閉じます。
- タブの右クリックで「閉じる」「ほかのタブをすべて閉じる」「右側のタブを閉じる」「左側のタブを閉じる」。
  変更を保存していないファイルは 1 つずつ保存するか尋ね、キャンセルするとそこでやめます。
- Ctrl+Tab / Ctrl+Shift+Tab でタブを切り替えます。
- **開いているファイルを比較**（表示メニュー）: 2つのタブの現在の内容をyymergeの別ウィンドウで比較します。
  未保存の編集やSSH上の文書も含みます。元の文字コードにかかわらず、エディタが読み取ったUTF-8の内容で比較します。

  Windowsの一時フォルダーに`yyeditor-compare-*`が残る場合があります。内容には編集中の文書が含まれます。

## 編集 {#editing}

- **元に戻す**（Ctrl+Z）・**やり直し**（Ctrl+Y / Ctrl+Shift+Z）: 続けて入力した文字は 1 回で戻ります。
- **上書きモード**: Insert キーで挿入・上書きを切り替えます（ステータスバーに表示）。
- **コメント化 / 解除**（Ctrl+/）: 選択した行を、ファイルの種類に合ったコメントにします。
- **対応する括弧へ移動**（Ctrl+]）。カーソルの位置の括弧と対応する括弧は色を付けて表示します。
- **タグジャンプ**（F12）: カーソル行の「パス(行番号)」（Grep の結果など）のファイルを開いて、その行へ移動します。
- Shift+Delete / Ctrl+Insert / Shift+Insert でも切り取り・コピー・貼り付けができます。
- **変換**（編集メニュー）: 選択した文字列（選択がなければカーソル位置の単語）を変換します。複数の選択はまとめて変換し、1 回の Undo で戻ります。
  - **大文字に**（Ctrl+Shift+U）・**小文字に**（Ctrl+U）: 英字（全角英字・アクセント付きのラテン文字を含む）だけを変換します。
  - **全角カタカナに**・**半角カタカナに**: 濁点・半濁点（ｶﾞ ⇔ ガ）と長音符・中黒も変換します。句読点とかぎ括弧はそのままです。
  - **キャメルケースに**・**スネークケースに**・**ケバブケースに**: `userName` ⇔ `user_name` ⇔ `user-name` のように、英数字の識別子の区切り方を変えます。
- **重複行を削除**（編集メニュー）: 選択した行（選択がなければ文書全体）で、前に同じ内容の行があれば削除します（最初の行を残し、順番は変えません。改行コードの違いは無視します）。大きな文書はバックグラウンドで処理します。
- 文字列を選択すると、ステータスバーに先頭 10 文字のコード値を表示します（Unicode の文書では `コード値 (U+) 3042` のように符号位置、それ以外ではその文字コードでのバイト値）。

## Markdown ライブ編集 {#markdown-live}

**表示 > Markdown ライブ編集** で、現在のタブを段落単位のライブ編集に切り替えます。
既定は通常編集です。タブごとの切り替えなので、ほかのファイルの入力方法は変わりません。
未保存の文書でも利用でき、拡張子の変更は必要ありません。

- 編集する段落をクリックすると、その段落の Markdown 原文を表示します。別の段落へ移ると、
  見出し・太字・斜体・取消線・引用・リスト・コード・表・画像などの表示に戻ります。
  見出しの入力中は文字を大きく表示します。リンクは編集対象として選択します。
- 上部の書式ボタン、**Ctrl+B**（太字）・**Ctrl+I**（斜体）で Markdown 記号を挿入できます。
  リストの途中で Enter を押すと、次の項目を作ります。空の項目で Enter を押すとリストを終了します。
  通常の Enter は空行で区切った次の段落、Shift+Enter は段落内の改行を作ります。Tab は空白 4 個です。
  折り返しを含む段落の最初・最後の表示行から上下キーで隣の段落に移れます。
  コード枠・複数行の数式の中では Enter も通常の改行になります。
- **表の行・列**: 表示された表のセルをクリックすると、そのセルの原文位置へ移動し、上部の表操作が有効になります。
  **左に列追加／右に列追加／列削除**、**上に行追加／下に行追加／行削除** で選んだセルを基準に操作します。
  表の原文の中でカーソルを移しても対象を選べます。列操作は見出し・配置指定・本文全行へ反映し、追加列の配置は
  選択列を引き継ぎます。各操作は一回の Undo で元に戻せます。見出し行と最後の一列は削除できません。
  見出しを選んだ場合は下に本文行を追加できます。引用・リストなどに入れ子になった表は原文で編集してください。
- **全体の原文** で文書全体を一つの入力欄にできます。複数段落をまたぐ貼り付けや選択に利用してください。
  **通常編集に戻る**、表示メニューの同じ項目、または Esc で元のエディタに戻ります。
- Ctrl+S で既存の保存、Ctrl+Z／Ctrl+Y で既存の Undo／Redo を利用します。
  日本語 IME の変換中は画面を作り直さず、確定した文字を文書に反映します。
  保存・終了・タブ切り替えの前には入力を反映します。読み取り専用の文書は編集しません。
- 保存するのは Markdown の原文です。HTML から文書全体を再生成しないため、編集していない部分の
  記法・改行・未知の構文を保持します。画像の相対パスは手元・SSH とも文書のフォルダを基準にします。
- 通常編集と **プレビュー（Ctrl+Shift+V）** は引き続き利用でき、ライブ編集と右側プレビューを同時に表示できます。
  ライブ編集でも Mermaid、LaTeX（`$...$`、`$$...$$`、`math`・`latex`・`tex` コード枠）、
  `d3` コード枠を描画し、編集中は原文の下に描画結果を表示します。d3 の引数・戻り値は右側プレビューと同じです。
  図の **d3 コードを編集** ボタンで原文を開けます。文書フォルダの CSV・JSON なども読み込めます。
  d3 は編集本文から分離したフレームで実行します。文書内の HTML は文字として表示します。
  d3 のライブ描画には新しい WebView2 ランタイムを利用してください。
- 検索・置換・行へ移動・矩形選択・バイナリ表示など、通常エディタ専用の操作を選ぶと原文の通常編集に戻ります。
- WebView2 ランタイムと、読み込み済みの 1 MiB 以下のテキスト文書が必要です。
  16 進数・固定長・コード値・区切り文字表示では、通常のテキスト表示に戻してから有効にしてください。

- プレビューには Microsoft Edge WebView2 ランタイムを使います（Windows 10 / 11 には通常インストール済み）。

## 16 進数（バイナリ）編集 {#hex}

- **16 進数表示**（Ctrl+Shift+X）で、オフセット・16 進・文字の欄で表示します。
- Tab で 16 進の欄と文字の欄を切り替えます。Insert で挿入・上書きを切り替えます（既定は上書き）。
- Ctrl+G でオフセット（`0x1F00` や 10 進）へ移動します。
- UTF-8 以外で開いた文書は、バイト列のまま開き直してから 16 進数表示にします。
- **文字の欄の文字コード**（表示メニューの「16 進数表示の文字の欄の文字コード」）: 右側の文字の欄を
  ASCII・UTF-8・UTF-16・CP932・EUC-JP・EBCDIC など、どの文字コードで表示するかを選べます。
  テキストとして開いていた文書は、その文字コードで表示します。ステータスバーに現在の文字コードを表示します。
  - 多バイト文字は先頭のバイトの位置に表示し、残りのバイトの位置は空白になります。
  - 不正なバイトは赤い `.`、制御文字（改行など）は `.` で表示します。
  - 文字の欄での入力・貼り付け・コピーも、選んだ文字コードで行います。

## 固定長表示 {#record}

- **固定長表示**（Ctrl+Shift+R、表示メニュー）で、ファイルを固定長のレコードに分けて表示します。
  レコード長を尋ねます（文字コードが `IBM-930/fixed:80` のような固定長レコードなら、その長さが初期値）。
- 1 行目は先頭からのバイト位置（1 始まり）の目盛りです（99 バイト目までは全バイト、それより先は 5 バイトごと）。
- 各レコードを 3 行で表示し、各バイトの桁をそろえます。左端はレコード番号です。
  - **コード値**: 文字コードでの文字の値（`C1`、漢字は `4541` のように 2 バイト分、シフトは `SO` `SI`）
  - **16 進数**: 各バイトの値
  - **文字**: その文字（制御文字は `.`、不正なバイトは赤い `.`）
- 文字はレコードごとに読みます（EBCDIC のシフト状態はレコードの先頭で 1 バイト部に戻ります）。文字の欄の文字コードは
  16 進数表示と同じく表示メニューで変えられます。
- 編集は上書きだけです（レコードの長さを変えないため、挿入・削除はできません）。16 進数の行では 0〜9・A〜F で 1 桁ずつ、
  文字の行では文字のバイト列を入力します。Tab で 16 進数の行と文字の行を切り替えます。上下キーで前後のレコードの同じ位置へ移動します。
- UTF-8 以外で開いた文書は、16 進数表示と同じくバイト列のまま開き直してから表示します。もう一度 Ctrl+Shift+R で元の表示に戻ります。

## コード値の編集 {#code}

- **コード値表示**（Ctrl+Shift+K、表示メニュー）で、16 進数表示と同じ形で、1 行 8 文字ずつ、左に各文字の
  Unicode のコード値（`3042` など）、右に文字を表示します。左端は行番号です（長い行は 8 文字ごとに折り返します）。
- Tab でコード値の欄と文字の欄を切り替えます。Insert で挿入・上書きを切り替えます（既定は上書き）。
- コード値の欄で 16 進数を入力し、Space か Enter で確定すると、その文字になります（上書きではカーソルの文字を
  置き換え、挿入ではカーソルの前に入れます）。6 桁入力するか、カーソルを動かしても確定します。
  入力中は BackSpace で 1 桁消し、Esc で取り消します。
- 文字の欄では文字をそのまま入力できます（日本語入力も使えます）。
- コピーはコード値の欄では `3042 3044` の形、文字の欄では文字列として。コード値の欄への貼り付けは
  `3042 U+3044 0x41 \u{1F600}` のようなコード値の並びとして読みます（読めなければ文字列として貼り付けます）。
- 改行（`000D` `000A`）・タブ（`0009`）も 1 文字として表示・編集できます。読み込み時の不正なバイトは赤い `\x82` です。
- ファイルの文字コードが Shift_JIS などでも、コード値は Unicode です（文字コードでの値は、文字列を選ぶと
  ステータスバーに表示します）。

## 文字コード {#encodings}

- UTF-8 / UTF-16 / UTF-32（BOM あり・なし）、CP932（Shift_JIS の Windows 拡張）、Shift_JIS、
  Shift_JIS-2004・EUC-JIS-2004（JIS X 0213）、EUC-JP、ISO-2022-JP、EBCDIC（IBM-930 / 939 / 1390 /
  1399 / 290 / 1027 / 037 / 500 / 1047）、Windows-1252・ISO-8859 系・GBK・Big5・EUC-KR など。
- 読み込み時に不正だったバイトは `\xNN` と表示し、同じ文字コードで保存すると元のバイトに戻ります。
- EBCDIC を選ぶと、レコードの区切り方（改行 NL・LF、固定長）を尋ねます。
- 独自の対応表（ベンダー漢字・外字）を追加できます（[設定](#settings) の `mappings` フォルダ）。

## EBCDIC のパック 10 進数・バイナリ項目 {#ebcdic-data}

COBOL の `COMP-3`（パック 10 進数）・`COMP` / `BINARY`（2 進数）の項目は文字ではないので、
テキストとして開くと、各バイトを **その文字コードの 1 バイト文字として** 表示します。
項目ごとの数値としての表示（`+12345` など）はしません。

**表示の例**（IBM-037、`PIC S9(5) COMP-3` の `+12345` = `12 34 5C`、`PIC S9(8) COMP` の `300` = `00 00 01 2C`）:

| 項目 | バイト | 本文での表示 |
|------|--------|--------------|
| パック 10 進数 +12345 | `12 34 5C` | `␒<94>*` |
| パック 10 進数 -12345 | `12 34 5D` | `␒<94>)` |
| 2 進数 300 | `00 00 01 2C` | `␀␀␁<8C>` |
| ゾーン 10 進数 +123 | `F1 F2 C3` | `12C`（符号は最後の桁の文字になる） |

- バイトは次のように見えます（詳しくは [制御文字の表示](#controls)）。
  - `00`〜`3F` の多くは `␀` `␒` のような制御文字の記号です。
  - 字形のない C1 制御文字（`34` → U+0094 など）は、灰色の `<94>` のように Unicode の値で表示します
    （1 文字なので、カーソルは 1 回の移動で飛び越えます）。表示の幅が 4 桁になるので、
    パック 10 進数の項目は本来の桁数より長く見え、後ろの項目の桁がずれることがあります。
  - `4A` `5C` `C1` など文字に当たるバイトは、その文字（`¢` `*` `A`）で表示します。
  - 文字コードの表にないバイトは赤い `\x9C` のように表示し、ステータスバーの「不正バイト」に数えます。
- **漢字を含む EBCDIC（IBM-930 / 939 / 1390 / 1399）の注意**: パック 10 進数・2 進数の中に `0E`（SO）が
  あると、そこから 2 バイト文字として読みます。2 バイト文字として読めないバイトは `\x12` のような
  表示になり、読めてしまったバイトの組は漢字に見えます。2 バイト文字として読む範囲は次のとおりです。
  - 改行 NL / LF 区切りでは、次の `0F`（SI）までです（改行も越えます）。
  - 固定長レコードでは、そのレコードの終わりまでです。
- 数値を確かめるには:
  - 項目を選択すると、ステータスバーに元のバイト（`コード値 (IBM-930) 12 34 5C`）を表示します（10 文字まで）。
  - **16 進数表示**（Ctrl+Shift+X）では全バイトを 16 進で表示します。文字の欄の文字コードは
    開いていた EBCDIC になります。
  - **コード値表示**（Ctrl+Shift+K）では、1 文字ずつ `.` とコード値（`0094`）で表示します。
- **保存**: 編集していない部分のバイトはそのまま保存されます（不正なバイト・制御文字・
  対応しない SO / SI も元に戻ります）。漢字を含む EBCDIC でファイルが 2 バイト文字の途中で
  終わっている（最後の SO に SI が続かない）場合も、最後に SI を加えずにそのまま保存します。
- **編集**: パック 10 進数・2 進数の項目を本文で書き換えると、別のバイトになったり、固定長の
  レコードの長さが変わったりします。数値の項目は 16 進数表示で書き換えてください。

## 制御文字の表示 {#controls}

本文では、そのままでは見えない文字を記号で表示します。表示メニューの **制御文字を表示** を
外すと、`␀` `<94>` などの記号と `␤` `¶` は空白で表示します。

| 文字 | 本文での表示 |
|------|--------------|
| C0 制御文字 U+0000〜U+001F（タブ・改行を除く） | `␀` `␁` … `␟`（U+2400〜U+241F の記号。例: U+000D は `␍`、U+001B は `␛`） |
| DEL U+007F | `␡` |
| NEL U+0085・行区切り U+2028 | `␤` |
| 段落区切り U+2029 | `¶` |
| そのほかの C1 制御文字 U+0080〜U+009F | 灰色の `<80>` 〜 `<9F>`（Unicode の値の下 2 桁） |
| 読み込み時に不正だったバイト | 赤い `\xNN` |
| タブ | タブの幅の空白（**空白・タブ・改行を表示** で `→`） |
| 半角スペース | 空白（**空白・タブ・改行を表示** で `·`） |
| 改行 CRLF / LF | 行の終わり（**空白・タブ・改行を表示** で `↵` / `↓`） |

16 進数表示の文字の欄とコード値表示の文字の欄では、制御文字は `.`、不正なバイトは赤い `.` です。

**EBCDIC の制御文字**（IBM-037 / 500 / 1047 / 290 / 1027 / 930 / 939 / 1390 / 1399 で共通）:

| EBCDIC | Unicode | 本文での表示 |

## 設定 {#settings}

設定は `%APPDATA%\yyeditor\config.toml` に書きます（ヘルプメニューの「設定ファイルを開く」で開けます）。
**変更は次に起動したときから反映されます。** よく使う項目:

```toml
[editor]
font_family = "UDEV Gothic"   # フォント
font_size = 11.0              # 文字の大きさ（ポイント）
tab_width = 4                 # タブの幅
ambiguous_wide = true         # ①・○ などを全角（2 桁）として数える
detect_ebcdic = false         # 文字コードの自動判別に EBCDIC を含める

[view]
line_numbers = true           # 行番号
show_whitespace = true        # 空白・タブ・改行を記号で表示
wheel_lines = 3               # ホイール 1 目盛りでスクロールする行数

[workspace]
# 「ターミナルで開く」のコマンド（{dir} はフォルダ）。空なら yyterm → Windows Terminal → コマンド プロンプト
terminal = ["pwsh.exe", "-NoExit", "-WorkingDirectory", "{dir}"]

[colors]
background = "#FFFFFF"
foreground = "#1E1E1E"
whitespace = "#A8B4C8"        # 空白・タブ・改行の記号

[colors.syntax]               # コードの色（keyword・string・comment など）
keyword = "#0000FF"
```

リモート（SSH）のファイルの設定（[リモート（SSH）のファイル](#remote)）:

```toml
[remote]
read_ssh_config = true        # %USERPROFILE%\.ssh\config を読む（読むだけ）
read_ssh_known_hosts = true   # %USERPROFILE%\.ssh\known_hosts を読む（読むだけ）
keepalive_secs = 15           # 接続の死活確認の間隔（秒）
agent_dir = ""                # エージェントを置くフォルダ（空なら ~/.yyeditor/agent）
proxy = ""                    # すべての接続先に使うプロキシ（例: "http://proxy:8080"、"socks5://user@socks:1080"）
remember_passwords = true     # パスワード・パスフレーズを資格情報マネージャーに保存できるようにする

[terminal]                    # ターミナル（yyterm）
shell = []                    # 手元のシェルのコマンドと引数（空なら pwsh → powershell → cmd）
font_family = ""              # 空なら [editor] と同じ
font_size = 0.0               # 0 なら [editor] と同じ
scrollback = 10000            # スクロールバックの行数
ambiguous_wide = false        # ○ ※ などを全角とする（接続先の設定と合わせる）
term = "xterm-256color"       # SSH の接続先に知らせる端末の種類
copy_on_select = false        # 選択したら自動でコピーする
right_click_menu = true       # 右クリックでメニュー（false なら、選択していればコピー・していなければ貼り付け）
use_agent = false             # リモートのフォルダの一覧に接続先のエージェントを使う（使わなければ SFTP）

[transfer]                    # ファイル転送（yysftp）
protocol = "sftp"             # 転送の方式（"sftp" か "scp"）
retries = 10                  # 進みがないまま再接続してよい回数
scp_chunk_mb = 32             # SCP のアップロードで 1 回に送る量（MiB）
show_hidden = false           # 名前が . で始まるファイルも表示する
download_dir = ""             # ダウンロードの既定の保存先（空なら「ダウンロード」フォルダ）
use_agent = false             # 接続先にエージェントを置いて使う（一覧と SHA-256 の照合）

[remote.host.build]           # 接続先の名前ごとの設定（書いていない項目は ~/.ssh/config）
hostname = "build01.example.co.jp"
user = "yamada"
port = 22
identity_file = "~/.ssh/id_build"
proxy_jump = "bastion"        # 踏み台（"a,admin@b:2022" の多段も可。"none" で ~/.ssh/config の指定も使わない）
proxy = "none"                # この接続先のプロキシ（"none" で共通のプロキシも使わない）
agent_dir = "/work/yamada/.yyeditor"   # ホームが noexec の場合など
# list_command = "ls -1A"     # yysftpの一覧だけを任意コマンドに変更（直下の名前だけ出力）
# list_format = "lines"       # "lines"（既定）/ "nul" / "ls"。詳細はディレクトリ一覧コマンドの節
forward = ["L 5432:localhost:5432", "D 1080"]   # ポートフォワーディング（yyterm だけが使う）
terminal_multiplexer = "none"  # "none" / "tmux" / "screen"（yyterm の永続セッション）
terminal_session_prefix = ""  # tmux / screen を使う場合は登録必須。タブ名と連結してセッション名にする
```

- `proxy_jump`・`proxy` のどちらかを書いた接続先では、`~/.ssh/config` の `ProxyJump`・`ProxyCommand` は使いません。
- プロキシのパスワード認証（HTTP の Basic 認証、SOCKS5 のユーザー名・パスワード認証）に対応しています。
  `http://ユーザー@ホスト:ポート` のようにユーザー名だけを書くと接続のときにパスワードを尋ね、何も書かなければ
  プロキシに認証を求められたときにユーザー名とパスワードを尋ねます。間違えたら尋ね直します。入力したパスワードは、選んだ場合だけ資格情報マネージャーに保存します
  （`http://ユーザー:パスワード@…` と設定に書くこともできますが、勧めません）。

- `%APPDATA%\yyeditor\syntax\<名前>.toml`: シンタックスハイライトの定義を追加・置き換え。
- `%APPDATA%\yyeditor\mappings\<名前>.map`: 独自の文字コードの対応表。

## 困ったときは {#trouble}

- **文字化けする**: ファイルメニューの「文字コードを指定して開き直す」で正しい文字コードを選びます。
- **ファイルを開けない（使用中）**: 他のアプリが書き込み中です。「共有中のファイルを読み取り専用で開く」を使います。
- **保存できない文字があると言われる**: 表示された選択肢で置き換えるか、「キャンセル」で最初の文字へ移動して直します。
  別の文字コード（UTF-8 など）で「名前を付けて保存」する方法もあります。
- **プレビューが表示されない**: Microsoft Edge WebView2 ランタイムをインストールしてください。
- **矩形選択の桁がずれる**: 全角が半角のちょうど 2 倍の幅のフォント（既定の UDEV Gothic、MS ゴシックなど）を使います。
- **リモートのファイルを開けない**: 接続先が Linux（x86_64）であることを確かめます。ホームフォルダで
  プログラムを実行できない（noexec）場合は、設定の `agent_dir` で実行できる場所を指定します。
  「ホスト鍵が記録と違う」と表示された場合は、接続先の管理者に鍵が変わったことを確かめてから、
  `known_hosts` の該当する行を削除します。
- **設定を変えたのに反映されない**: yyeditor を起動し直します。設定ファイルに誤りがあると、起動時にその内容を表示します。
- **異常終了した**: yyeditor・yyterm・yysftp・yysheet は、異常終了するときに `%LOCALAPPDATA%\yyeditor\logs` へ
  `crash-アプリ-日時-プロセス番号.log`（版・日時・異常の内容・バックトレース）を残し、その場所を表示します。
  不具合の報告にはこのファイルを添えてください。記録は新しいものから 30 個まで残します。
