# yyeditor ヘルプ

yyeditor は、数 GB のファイルもすぐに開ける Windows 向けの軽量テキストエディタです。
日本語の文字コード（CP932・EUC-JP・JIS X 0213・EBCDIC など）、区切り文字（CSV・TSV）の
表示と編集、Markdown・HTML のプレビューに対応しています。

## ファイルを開く・保存する {#files}

- **開く**（Ctrl+O）: 文字コードは自動で判別します。開くダイアログで文字コードを指定することもできます。
  ファイルはウィンドウにドラッグ＆ドロップしても開けます。
- 大きなファイルもすぐに表示します。行数は裏で数えるので、数え終わるまでは行番号が推定値
  （灰色）になります。UTF-8 以外のファイルは裏で変換し、その間は先頭部分を読み取り専用で表示します。
- **共有中のファイルを読み取り専用で開く**: 他のアプリが書き込み中のファイル（出力中のログなど）を、
  開いた時点の内容で表示します。
- **文字コードを指定して開き直す**: 文字化けしたときに、正しい文字コードで読み直します。
- **バイナリとして開く**: ファイルをバイト列のまま [16 進数表示](#hex) で開きます。
- **上書き保存**（Ctrl+S）・**名前を付けて保存**（Ctrl+Shift+S）: 名前を付けて保存では、文字コード・
  BOM・改行コード（CRLF / LF）を選べます。
  - 保存は裏で行い、進み具合をステータスバーに表示します（Esc で中止）。保存中も編集できます。
  - 保存先の文字コードで表せない文字があると、似た文字（① → (1)、ｶﾞ → ガ など）や「?」・
    数値文字参照に置き換えるかを尋ねます。置き換えは「元に戻す」で取り消せます。
  - 保存後も「元に戻す」で保存前の内容に戻せます。
- タイトルとタブの `*` は、保存していない変更があることを示します。閉じるときに保存するか尋ねます。
- **最近開いたファイル**（Ctrl+E、ファイル メニュー）: 開いたファイル（名前を付けて保存したファイルを含む）を
  新しい順に最大 1,000 件まで覚えています。
  - 一覧の上の「絞り込み」に入力すると、パスにその語（空白で区切るとすべての語）を含むファイルだけを表示します。
  - Enter かダブルクリックで開きます。Ctrl / Shift を押しながらクリックすると、複数選んでまとめて開けます。
  - 「一覧から削除」で履歴から外します。「ブックマークに追加」で、選んだファイルをブックマークに加えます。
- **ブックマーク**（Ctrl+B、ファイル メニュー）: よく開くファイルを最大 100 件まで登録できます。
  - 開いているファイルは **このファイルをブックマーク**（Ctrl+Shift+B）で登録・解除できます。
    登録済みならメニューにチェックが付きます。
  - 一覧での絞り込み・開き方は履歴と同じです。「上へ」「下へ」で並べ替え、「一覧から削除」で外せます。
  - 100 件に達しているときは、不要なものを外してから登録してください。
- 履歴は `%APPDATA%\yyeditor\history.txt`、ブックマークは `bookmarks.txt` に 1 行 1 パスで保存します
  （yyeditor を複数起動していても、互いの記録を消しません）。

## リモート（SSH）のファイル {#remote}

SSH で接続できる Linux（x86_64）のファイルを、手元のファイルと同じように開いて編集・保存できます。
SSH は yyeditor に組み込んであるので、Windows の OpenSSH（ssh.exe）は使いません。

- **リモートのファイルを開く**（Ctrl+Shift+O、ファイル メニュー）: 接続先（`ユーザー@ホスト:ポート`、
  または `~/.ssh/config` の Host の名前）を入力して「接続」を押し、一覧からファイルを選びます。
  - フォルダの欄にパス（`~/` も可）を入力して Enter で移動します。ダブルクリックでフォルダを開きます。
  - 文字コードは自動で判別します。文字コードの欄で指定することもできます。
  - 最近開いたファイル（Ctrl+E）とブックマークには `ssh://ホスト/パス` の形で残り、そこからも開けます。
- 初めて接続するホストでは、ホスト鍵の指紋を確かめるよう尋ねます。接続先の管理者から知らされた指紋
  （`ssh-keygen -lf` で表示されるもの）と一致する場合だけ「はい」を選んでください。承認した鍵は
  `%APPDATA%\yyeditor\known_hosts` に記録します。記録と違う鍵のホストには接続しません。
- 認証は、秘密鍵（`~/.ssh/id_ed25519` など、または設定の `identity_file`）、ワンタイムパスワードなどの
  対話式の認証、パスワードの順に試します。
- **パスワードの保存**: パスワードの入力欄で「このパスワードを保存する（Windows の資格情報マネージャー）」に
  チェックを入れると、認証に成功したパスワードを保存し、次からは尋ねずに使います（プロキシのパスワードも同じ）。
  - 保存はこのパソコンのこのユーザーだけのもので、Windows が暗号化して持ちます。yyeditor の設定ファイルには書きません。
  - 保存したパスワードが受け付けられなかったら（接続先でパスワードを変えた場合など）、保存を消して尋ね直します。
  - **ヘルプ メニューの「保存したリモート接続のパスワードを削除」** でまとめて削除できます。コントロール パネルの
    「資格情報マネージャー」→「Windows 資格情報」の `yyeditor/ssh/…`・`yyeditor/proxy/…`・`yyeditor/key/…` からも確認・削除できます。
  - 秘密鍵のパスフレーズも、入力欄で「このパスフレーズを保存する」を選んだ場合だけ保存します（鍵を開けたものだけ）。
    ただし、鍵ファイルとパスフレーズが同じパソコンに揃うため、パソコンの中身を持ち出されると鍵がそのまま使えます
    （パスフレーズは本来、鍵ファイルが盗まれたときの守りです）。共用のパソコンや、多くのサーバーに登録している鍵では
    保存しないことを勧めます。保存したパスフレーズで開けなくなったら（パスフレーズを変えた場合など）、保存を消して尋ね直します。
  - 保存させたくない場合は設定で `remember_passwords = false` にします（パスワードもパスフレーズも保存せず、チェックボックスも出なくなります）。
  - ワンタイムパスワードなど、対話式の認証の答えは保存しません。
- **踏み台・プロキシ**: `~/.ssh/config` の `ProxyJump`（`踏み台1,踏み台2` の多段も可）か、設定の
  `proxy_jump` で踏み台を経由して接続します。踏み台ごとにホスト鍵の確認と認証を行います。
  HTTP（CONNECT）・SOCKS5・SOCKS4 のプロキシは設定の `proxy` で指定します（踏み台を使う場合は最初の踏み台への接続に使います）。
  - `~/.ssh/config` の `ProxyCommand` は、yyeditor が外部のプログラムを起動しないため、次の形だけを読み替えます:
    `ssh -W %h:%p 踏み台`（踏み台と同じ）、`nc -X 5|4|connect -x プロキシ %h %p`、`ncat --proxy プロキシ %h %p`、
    `connect -S|-H プロキシ %h %p`。それ以外の `ProxyCommand` が当てはまる接続先には接続できないので、
    yyeditor の設定で `proxy_jump` か `proxy`（`"none"` で直接接続）を指定してください。
- **接続できないとき**: 接続の各段階（設定の解決、TCP 接続、プロキシ・踏み台、ホスト鍵の照合、試した認証方式と
  サーバーが受け付ける方式、エージェントの配置と起動）を記録しています。接続に失敗したときのメッセージに記録の
  最後の部分を表示します。全体は **ヘルプ メニューの「リモート接続の記録を開く」**
  （`%APPDATA%\yyeditor\logs\remote-ssh.log`）で見られます。パスワード・パスフレーズは記録しません。
- 最初に接続したとき、接続先のホームの `~/.yyeditor/agent` に小さなプログラム（エージェント）を置きます。
  ファイルの一覧・読み出し・保存はエージェントが行います。インターネットへの接続は必要ありません。
- **上書き保存**（Ctrl+S）は接続先のファイルを置き換えます（権限・所有者・シンボリックリンクは保ちます）。
  開いたあとでほかの人やプログラムがファイルを変更していた場合は、上書きするか尋ねます。
- **名前を付けて保存**（Ctrl+Shift+S）: リモートのファイルはリモートに保存します。
  **リモートに名前を付けて保存**・**このパソコンに名前を付けて保存** で保存先を選べます。
- 今のところ、リモートのファイルは全体を取り寄せてから開きます（256 MB を超えるときは確かめます）。
  Grep（ファイルから検索）は手元のフォルダだけが対象です。

## ワークスペース {#workspace}

VS Code のワークスペースのように、作業に使う **起点のフォルダを複数まとめて** 登録し、左側の
**サイドバー**（エクスプローラー）にフォルダの中身をツリーで表示します。

- **サイドバー（エクスプローラー）**（Ctrl+Shift+E、ワークスペース メニュー）で表示を切り替えます。
  境界をドラッグすると幅を変えられます。
- **フォルダをワークスペースに追加**（ワークスペース メニュー、サイドバーの右クリック）で起点のフォルダを
  加えます。フォルダをウィンドウにドラッグ＆ドロップしても加わります。起点はいくつでも登録できます。
- フォルダは開いたときに中身を読みます（フォルダが先、名前順。`.git` などは表示しません）。
  ファイルはダブルクリックか Enter で開きます。項目にマウスを置くとフルパスを表示します。
- **フォルダを束ねる**（VS Code と同じ）: 中身がフォルダ 1 つだけのフォルダは、`src/main/java` のように
  1 行にまとめて表示します。手元のフォルダは並べるときに、リモートのフォルダは開いたときに束ねます
  （起点のフォルダは束ねません）。束ねた行の操作（新しいファイル・名前の変更・削除・貼り付けなど）は、
  いちばん奥のフォルダ（`java`）が対象です。途中のフォルダに項目が増えれば、束ね方は自動で変わります。
- **右クリックのメニュー**:
  - **ターミナルで開く**: そのフォルダ（ファイルならそのファイルのあるフォルダ）を作業フォルダにして
    ターミナルを開きます。yyeditor と同じフォルダに [yyterm](#terminal) があればそれを（リモートのフォルダも
    SSH で開けます）、なければ Windows Terminal、それもなければコマンド プロンプトを使います
    （設定の `[workspace]` の `terminal` で変えられます）。
  - **エクスプローラーで開く**: フォルダを開きます（ファイルならそのフォルダを開いてファイルを選びます）。
  - **フォルダ内を検索 (Grep)**: そのフォルダを指定して [ファイルから検索](#search) を開きます。
  - **パスをコピー**・**相対パスをコピー**（起点のフォルダからのパス）
  - **最新の情報に更新**: フォルダの中身を読み直します（ワークスペース メニューの「最新の情報に更新」は全体）。
  - **ワークスペースから削除**（起点のフォルダのみ）: 登録を外します（フォルダ自体は消しません）。
- **ワークスペースの保存**: 変更はすぐに保存し、次に起動したときも同じワークスペースを開きます。
  **ワークスペースに名前を付けて保存** で `*.yyworkspace` ファイルに保存でき、**ワークスペースを開く** で
  切り替えられます（タイトルにワークスペースの名前を表示します）。**新しいワークスペース** で空にします。
- ワークスペースのファイルは TOML で、`folders = ["C:\\src\\app", "docs"]` のように起点のフォルダを並べます
  （相対パスはファイルのあるフォルダから）。
- **ファイル・フォルダの操作**（手元のフォルダでも、リモートのフォルダでも同じように使えます）:
  - **新しいファイル**・**新しいフォルダ**（フォルダの右クリック）: 名前を尋ねて、そのフォルダの中に作ります
    （新しいファイルは作ったあとで開きます）。
  - **名前の変更**（F2、右クリック）: ツリーの上で名前を書き換えて Enter。
  - **削除**（Delete、右クリック）: 手元のファイル・フォルダは **ごみ箱** に移します。リモートのものはごみ箱がないため、
    確かめたうえで完全に削除します（元に戻せません）。開いているタブは閉じます（保存していない変更があれば削除しません）。
  - **移動**: 項目をドラッグして、移動先のフォルダ（またはその中のファイル）の上で離します。または **切り取り**
    （Ctrl+X、右クリック）してから、移動先のフォルダで **貼り付け**（Ctrl+V、右クリック）します。
    移動は同じ場所（このパソコンの中、または同じ接続先の中）でだけできます（別の場所へはコピーします）。
    移動先に同じ名前があれば移動しません。
  - **コピー**: **コピー**（Ctrl+C、右クリック）してから、コピー先のフォルダで **貼り付け**（Ctrl+V、右クリック）します。
    **このパソコンとリモートの間、別の接続先の間でもコピーできます**（フォルダは中身ごと）。ドラッグ＆ドロップでは、
    別の場所へ落とすとコピー、同じ場所の中で Ctrl を押しながら落としてもコピーになります。
    - コピーする量（フォルダは中身の合計）が **10 MB 以上** のときは、始める前に確かめます。
    - このパソコンとリモートの間（別の接続先の間を含む）では、**50 MB 以上** はコピーできません
      （コピー中に 50 MB を超えたときも中止し、作りかけのコピーを消します）。同じ場所の中のコピーには制限はありません。
    - 同じ名前があるときは上書きせず、「名前 - コピー」「名前 - コピー (2)」… の名前にします。
    - 進み具合はステータスバーに表示します。Esc で中止すると、作りかけのコピーは消します。
    - 同じ接続先の中のコピーは接続先で行うので、転送はしません。別の接続先の間は、このパソコンを経由します。
    - フォルダを指すシンボリックリンクはたどらずに飛ばします（ファイルを指すリンクは中身をコピーします）。
      このパソコンからリモートへコピーしたファイルの権限は、接続先の既定（umask）になります。
  - 名前を変えた・移動したファイルを開いていれば、タブはそのまま新しい場所を指します（編集中の内容もそのまま）。
  - 起点のフォルダ自体の名前の変更・削除・移動はできません（「ワークスペースから削除」で登録を外します）。
- **リモートのフォルダをワークスペースに追加**（ワークスペース メニュー、サイドバーの右クリック）:
  SSH 接続先のフォルダも起点として登録できます（[リモート（SSH）のファイル](#remote)）。接続先を入力して
  「接続」を押し、フォルダを辿って「このフォルダを追加」を押します。
  - サイドバーには `フォルダ名 [接続先]` と表示します。フォルダを開いたときに接続し（パスワードなどを
    尋ねることがあります）、中身を読みます。ファイルを開くと、リモートのファイルとして開きます。
  - ワークスペースのファイルには `ssh://接続先/パス` の形で書きます。
  - リモートの項目では、ターミナル・エクスプローラーで開く、フォルダ内を検索（Grep）は使えません。
    「パスをコピー」は接続先のパス（`/home/...`）をコピーします。

## ターミナル（yyterm） {#terminal}

yyterm は、yyeditor と同じ部品で作ったターミナルです（`yyterm.exe`。yyeditor と同じフォルダに置きます）。
フォント（同梱の UDEV Gothic）、設定ファイル、SSH の接続設定・ホスト鍵・保存したパスワード、ワークスペースを
yyeditor と共通に使います。

- **手元のシェル**: 既定は PowerShell 7、なければ Windows PowerShell、なければコマンド プロンプトです
  （設定の `[terminal]` の `shell` で変えられます。例: `["cmd.exe"]`、`["wsl.exe"]`）。
- **SSH で接続**（Ctrl+Shift+O）: 接続先（`ユーザー@ホスト:ポート` または `~/.ssh/config` の Host の名前）を
  入力します。yyeditor と同じ組み込みの SSH を使い、OpenSSH（ssh.exe）は使いません。踏み台・プロキシ・
  パスワードの保存・接続の記録も [リモート（SSH）のファイル](#remote) と同じです。ターミナルだけの接続では
  エージェントを使わないので、Linux 以外の接続先にも接続できます。
- **ポートフォワーディング**: 「SSH で接続」の入力で、接続先に続けて `-L 8080:localhost:80`（手元の
  8080 番 → 接続先から localhost:80）、`-R 9000:localhost:3000`（接続先の 9000 番 → 手元の 3000 番）、
  `-D 1080`（手元の 1080 番を SOCKS のプロキシに）を書けます。接続設定の `forward` と `~/.ssh/config` の
  `LocalForward`・`RemoteForward`・`DynamicForward` も使います。始めたものと、始められなかったもの
  （ポートの使用中など）はタブの先頭に表示します。始められなくても SSH の接続はそのまま使えます。
  yyeditor と yysftp はポートフォワーディングの指定を無視します。
- **エージェント**: ワークスペースのリモートのフォルダの一覧に、接続先のエージェントを使うかを選べます
  （ワークスペース メニュー、設定の `[terminal]` の `use_agent`。既定は使わない＝SFTP で読み、接続先に
  何も置きません）。シェルにはどちらでもエージェントを使いません。
- **ワークスペース**（Ctrl+Shift+E）: 中身がフォルダ 1 つだけのフォルダは、エディタと同じく `a/b/c` のように
  束ねて表示します（ダブルクリックでは、いちばん奥のフォルダでターミナルを開きます）。
  フォルダをダブルクリック（Enter）すると、そこでターミナルを開きます
  （リモートのフォルダは SSH で接続して、そのフォルダで始めます）。ファイルは yyeditor で開きます。
  ワークスペースのメニューで、新しいワークスペース・開く・名前を付けて保存・フォルダの追加ができます。
- **タブ**: 新しいタブ（Ctrl+Shift+T。選んでいるタブと同じ場所で開きます）、閉じる（Ctrl+Shift+W、
  タブの「×」、中ボタンのクリック）、切り替え（Ctrl+Tab・Ctrl+Shift+Tab）。シェルが終わったタブは
  Enter で閉じます。タブの右クリックで「閉じる」「ほかのタブをすべて閉じる」「右側のタブを閉じる」
  「左側のタブを閉じる」（まとめて閉じるとき、シェルが動いているタブがあれば確かめます）。
- **コピー・貼り付け**: ドラッグで選択、ダブルクリックで単語を選択します。Ctrl+Shift+C（Ctrl+Insert）で
  コピー、Ctrl+Shift+V（Shift+Insert）で貼り付け。右クリックは、選択していればコピー、していなければ
  貼り付けです。vim や tmux などがマウスを使っているときは、Shift を押しながら選択します。
- **スクロールバック**: Shift+PageUp・PageDown・↑・↓、マウスのホイール、スクロールバー
  （less・vim などの全画面のプログラムでは、ホイールはカーソルキーとして送ります）。
- **文字の大きさ**: Ctrl++・Ctrl+-・Ctrl+0、Ctrl+ホイール。
- **起動の引数**: `yyterm.exe [フォルダ | ssh://接続先/パス | ユーザー@ホスト]`。

## ファイル転送（yysftp） {#transfer}

`yysftp.exe` は、yyeditor と同じ部品で作った SFTP・SCP のファイル転送のアプリです。接続（組み込みの SSH、
踏み台・プロキシ・ホスト鍵・保存したパスワード・接続の記録）と設定ファイルは yyeditor と共通です。
転送には、SFTP は接続先の sftp-server、SCP は接続先の scp を使います。

- **エージェントを使うか**（転送メニュー「接続先にエージェントを置いて使う」、設定の `use_agent`。既定は
  使わない）: 使わなければ接続先に何も置かず、一覧も SFTP で読みます（どの OS の接続先でも使えます）。
  使うと、yyeditor と同じエージェントを接続先に置いて、一覧・ファイル操作をエージェントで行い
  （sftp-server を止めている接続先でも一覧を表示できます）、送り終えた内容をファイル全体の SHA-256 で
  照合します（一致しなければ途中のファイルを捨てて 1 回送り直します）。エージェントは Linux の接続先で
  動きます。

- **接続**（Ctrl+N）: 接続先（`ユーザー@ホスト:ポート`、`~/.ssh/config` の Host の名前。`:/パス` も付けられます）を
  入力するか、左のツリーの接続先を開きます。アドレスバー（Ctrl+L）に `ユーザー@ホスト:/パス` や `/パス` を
  入力して Enter でも移動できます。戻る（Alt+←）・進む（Alt+→）・上へ（Alt+↑、Backspace）。
- **一覧**: 名前・更新日時・種類・サイズ・属性。列の見出しのクリックで並べ替えます。フォルダはダブルクリック
  （Enter）で開きます。名前の変更（F2）、削除（Del。フォルダは中身ごと）、新しいフォルダ（Ctrl+Shift+N）、
  すべて選択（Ctrl+A）、パスをコピー、隠しファイルの表示（表示メニュー）。右クリックのメニューもあります。
- **アップロード**: エクスプローラーからファイル・フォルダをドラッグ＆ドロップするか、Ctrl+U（ファイル）・
  転送メニューの「フォルダをアップロード」。表示しているフォルダに送ります。
- **ダウンロード**: 項目を選んで Ctrl+D（ファイルはダブルクリックでも）。保存先は設定の `download_dir`、
  なければ「ダウンロード」フォルダです。「保存先を選んでダウンロード」もあります。
- 送り先に同じ名前のファイルがあるときは、置き換える（はい）・飛ばす（いいえ）・やめる（キャンセル）を尋ねます。
- **転送の一覧**（下の「転送」タブ）: 進み・速度・状態を表示します。右クリックで一時停止・再開・取り消し
  （途中まで送ったファイルも消します）・手元のフォルダを開く・すべて再開・完了したものを消す。
- **レジューム**: 転送中に接続が切れたら、間を空けて（2・5・10・20・30・60 秒）自動で接続し直し、続きから
  送ります。送り終えた位置はジャーナル（`%APPDATA%\yyeditor\transfers`）に書くので、一時停止したときや
  アプリを閉じたときも、後で（次に起動したときも）続きから送れます。送っている途中のファイルは
  `<名前>.yypart` で、送り終えて大きさを確かめてから本来の名前にします。
  **yysftp が落ちたとき**（強制終了・Windows の停止・停電でも）も、次に起動したときに再開するか尋ねます。
  ジャーナルと途中のファイルはディスクに書き出しながら進めるので、確かに送り終えた位置から続けます。
  送り終えて名前を変えた直後に落ちた転送は、送り直さずに完了とします。yysftp を 2 つ起動したときは、
  先に起動した方だけがジャーナルから再開します。
- **記録**（下の「記録」タブ、ヘルプ メニューの「転送の記録を開く」）: 転送の様子（接続、続ける位置の決め方、
  10 秒ごとの進みと速さ、切断と再接続、確認、名前の変更、完了・失敗）を
  `%APPDATA%\yyeditor\logs\transfer.log` に残します。
- **SFTP と SCP**: 転送メニューで切り替えます（既定は設定の `protocol`）。SFTP が使えない接続先では SCP に
  します。SCP のアップロードは区切り（`scp_chunk_mb`）ごとに送ってつなげるので、切断で失うのは多くても 1 区切りです。
- ファイルはエディタ（yyeditor）、フォルダはターミナル（yyterm）で開けます（ファイル メニュー・右クリック）。
- **起動の引数**: `yysftp.exe [ssh://接続先/パス | ユーザー@ホスト:/パス | ユーザー@ホスト]`。

## 3270（メインフレーム） {#tn3270}

yyterm のタブで、IBM メインフレーム（z/OS など）に 3270 端末として接続できます（TN3270・TN3270E）。

- **接続**（ファイル メニューの「3270 で接続」、Ctrl+Shift+M）: `ホスト[:ポート]`（既定のポートは 23）、
  `tn3270://LU名@ホスト:ポート`、または設定の `[tn3270.host.名前]` の名前を入力します。設定に `ssh` を
  書くと、その SSH の接続（踏み台・プロキシも使えます）を経由します（手元のポートは開きません）。
- **日本語**: 既定の文字コードは CCSID 930（カタカナ＋漢字）。939・1390・1399・037・1047 も選べます
  （設定の `ccsid`）。漢字は IME で入力でき、半角と全角の切り替え（SO/SI）は自動で入れます。
- **画面の下の 1 行（OIA）**: 接続の種類（TN3270・TN3270E）、LU 名、キーボードの状態（`X SYSTEM` は
  ホストの応答待ち、`X 保護` などは操作の誤りで Reset で解除）、挿入モード（INS）、カーソルの位置、文字コード。
- **キー**:

| 機能 | キー |
|------|------|
| Enter / New Line | Enter / Shift+Enter |
| PF1〜PF12 / PF13〜PF24 | F1〜F12 / Shift+F1〜F12 |
| PF7 / PF8（上下） | PageUp / PageDown |
| PA1 / PA2 / PA3 | Alt+1 / Alt+2 / Alt+3 |
| Clear | Esc |
| Reset | Ctrl+R |
| Erase EOF / Erase Input | End / Shift+End |
| 挿入モード | Insert |
| Tab / Back Tab | Tab / Shift+Tab |
| Dup / Field Mark | Ctrl+D / Ctrl+M |
| Attn / SysReq | Ctrl+Pause / Alt+PrintScreen |

- **キーパッド**: 画面の右に、PF1〜PF24・PA1〜PA3・Clear・Reset・Attn・SysReq・Erase EOF・Erase Input・
  Field Mark・Dup・Enter のボタンを出します（設定の `keypad = false` で消せます）。
- マウスのクリックでカーソルを移し、ドラッグで選択してコピーします（非表示のフィールドはコピーしません）。
  貼り付けは非保護のフィールドにだけ入れます（Tab で次のフィールド、改行で New Line）。
- 接続の記録（交渉・LU・切断・ファイル転送）は `%APPDATA%\yyeditor\logs\tn3270.log` に残します。
- **ファイル転送（IND$FILE）**（ファイル メニューの「3270 のファイル転送」、Ctrl+Shift+I）: TSO の `READY`、
  CMS の `Ready` の後で使います。向き（ホストから受け取る GET・ホストへ送る PUT）、ホストの種類（TSO・CMS・CICS）、
  ホストのファイル（TSO は `'USER.DATA(MEM)'`、CMS は `PROFILE EXEC A`）、手元のファイル、データの扱いを選ぶと、
  カーソルの位置に `IND$FILE ...` のコマンドを入力して Enter を押し、ホストとの転送（DFT）を行います。
  - **テキスト（端末で変換）**: 日本語の既定。バイナリで転送し、端末でタブの CCSID（930 など）と UTF-8 を
    変換します（ホストの ASCII 変換は日本語を扱えないことが多いため）。レコードの区切りは `CRLF` オプションで
    ホストに入れてもらいます。受け取ったテキストは UTF-8・CRLF で、行末の空白（固定長の詰め物）を除きます。
    送るときは手元のファイルの文字コードを自動判別し、CCSID にない文字があれば行番号を示して止めます。
  - **テキスト（ホストの ASCII 変換）**: `ASCII CRLF`。ファイルはそのまま（末尾の EOF 文字 0x1A は除きます）。
  - **バイナリ**: 変換しません。
  - 送るときは、新しく作るファイルの RECFM・LRECL・トラック数（TSO）と、追加（APPEND）を指定できます。
  - 送るとき、テキストの行が LRECL を超えれば行番号を示して止めます（切り詰めません）。
  - 転送の開始・終了・エラーは `%APPDATA%\yyeditor\logs\tn3270-transfer.log` に残します。IND$FILE は途中から
    再開できないので、切断されたら最初からやり直してください。
  - 受け取ったファイルは yyeditor で開けます。進み具合は画面の下の行とステータスバーに出し、
    「3270 のファイル転送を取り消す」で取り消せます（ホストは取り消しのメッセージを返して終わります）。
- 設定（`config.toml`）:

```toml
[tn3270]
model = 2            # 2（24×80）・3（32×80）・4（43×80）・5（27×132）
ccsid = 930
terminal_type = ""   # 空なら IBM-3278-<model>-E
tn3270e = true
keypad = true

[tn3270.host.prod]
host = "mvs01.example.co.jp"
port = 23
lu = "TCP00042"      # TN3270E で求める LU 名
ccsid = 939
ssh = "bastion"      # この SSH の接続を経由する
```

## Markdown・HTML のプレビュー {#preview}

**プレビュー**（Ctrl+Shift+V、表示メニュー）で、エディタの右側にプレビューを表示します。
境界はドラッグで動かせます。入力すると 0.25 秒ほどで反映され、エディタのスクロールに合わせて
プレビューもスクロールします。

Markdown で使える記法:

| 記法 | 書き方の例 |
|------|-----------|
| 表 | `\| 列 \| 列 \|` と `\|---\|---\|` |
| タスクリスト | `- [x] 完了` |
| 取り消し線・上付き・下付き | `~~取消~~`・`x ^2^`・`H ~2~ O` |
| 脚注 | `本文[^1]` と `[^1]: 脚注` |
| 定義リスト | `用語` の次の行に `: 説明` |
| アラート | `> [!NOTE]`・`[!TIP]`・`[!IMPORTANT]`・`[!WARNING]`・`[!CAUTION]` |
| 数式（KaTeX） | `$E = mc^2$`・`$$ \int_0^1 x\,dx $$`・```` ```math ```` |
| 図（Mermaid） | ```` ```mermaid ```` のコードブロック |
| グラフ（d3） | ```` ```d3 ```` のコードブロック（JavaScript。下記） |
| 見出しの ID | `## 見出し {#id}` |

- 画像などの相対パスは文書のフォルダから読みます。リンクは、同じフォルダの Markdown・HTML なら
  エディタで、それ以外は既定のブラウザで開きます。
- [リモート（SSH）のファイル](#remote) の文書も同じようにプレビューできます。画像・CSS・スクリプトなどの
  相対パスは、接続先の文書のフォルダから取り寄せて表示します（1 ファイル 32 MB まで。接続が切れている
  間は表示されません）。同じフォルダの Markdown・HTML へのリンクは、リモートのファイルとしてエディタで開きます。
- HTML 文書はそのまま表示します。
- **d3**: ```` ```d3 ```` のコードブロックは [d3.js](https://d3js.org/)（v7）を使う JavaScript として実行し、
  その場所にグラフを描きます。スクリプトでは `d3`、描く場所の要素 `el`、その幅 `width` を使えます。
  要素や d3 の選択（`d3.create("svg")` など）を `return` すると `el` に加わります。`await` も使えます
  （`await d3.csv("data.csv")` で文書のフォルダのファイルを読めます）。誤りがあればその場所に赤く表示します。

  ```` 
  ```d3
  const data = [3, 8, 5];
  const svg = d3.create("svg").attr("width", width).attr("height", 80);
  svg.selectAll("rect").data(data).join("rect")
    .attr("x", (d, i) => i * 40).attr("y", d => 80 - d * 8)
    .attr("width", 30).attr("height", d => d * 8).attr("fill", "steelblue");
  return svg;
  ```
  ````

  文書の中のスクリプトを実行するので、信頼できる文書だけをプレビューしてください（HTML 文書も同じです）。
  HTML 文書からは `<script src="https://yy-preview.local/assets/d3.min.js"></script>` で同梱の d3 を読み込めます。
- プレビューには Microsoft Edge WebView2 ランタイムを使います（Windows 10 / 11 には通常インストール済み）。

## 16 進数（バイナリ）編集 {#hex}

- **16 進数表示**（Ctrl+Shift+X）で、オフセット・16 進・文字の欄で表示します。
- Tab で 16 進の欄と文字の欄を切り替えます。Insert で挿入・上書きを切り替えます（既定は上書き）。
- Ctrl+G でオフセット（`0x1F00` や 10 進）へ移動します。
- UTF-8 以外で開いた文書は、バイト列のまま開き直してから 16 進数表示にします。
- **文字の欄の文字コード**（表示メニューの「16 進数表示の文字の欄の文字コード」）: 右側の文字の欄を
  ASCII・UTF-8・UTF-16・CP932・EUC-JP・EBCDIC など、どの文字コードで表示するかを選べます。
  テキストとして開いていた文書は、その文字コードで表示します。ステータスバーに現在の文字コードを表示します。
  - 多バイト文字は先頭のバイトの位置に表示し、残りのバイトの位置は空白になります。
  - 不正なバイトは赤い `.`、制御文字（改行など）は `.` で表示します。
  - 文字の欄での入力・貼り付け・コピーも、選んだ文字コードで行います。

## 固定長表示 {#record}

- **固定長表示**（Ctrl+Shift+R、表示メニュー）で、ファイルを固定長のレコードに分けて表示します。
  レコード長を尋ねます（文字コードが `IBM-930/fixed:80` のような固定長レコードなら、その長さが初期値）。
- 1 行目は先頭からのバイト位置（1 始まり）の目盛りです（99 バイト目までは全バイト、それより先は 5 バイトごと）。
- 各レコードを 3 行で表示し、各バイトの桁をそろえます。左端はレコード番号です。
  - **コード値**: 文字コードでの文字の値（`C1`、漢字は `4541` のように 2 バイト分、シフトは `SO` `SI`）
  - **16 進数**: 各バイトの値
  - **文字**: その文字（制御文字は `.`、不正なバイトは赤い `.`）
- 文字はレコードごとに読みます（EBCDIC のシフト状態はレコードの先頭で 1 バイト部に戻ります）。文字の欄の文字コードは
  16 進数表示と同じく表示メニューで変えられます。
- 編集は上書きだけです（レコードの長さを変えないため、挿入・削除はできません）。16 進数の行では 0〜9・A〜F で 1 桁ずつ、
  文字の行では文字のバイト列を入力します。Tab で 16 進数の行と文字の行を切り替えます。上下キーで前後のレコードの同じ位置へ移動します。
- UTF-8 以外で開いた文書は、16 進数表示と同じくバイト列のまま開き直してから表示します。もう一度 Ctrl+Shift+R で元の表示に戻ります。

## コード値の編集 {#code}

- **コード値表示**（Ctrl+Shift+K、表示メニュー）で、16 進数表示と同じ形で、1 行 8 文字ずつ、左に各文字の
  Unicode のコード値（`3042` など）、右に文字を表示します。左端は行番号です（長い行は 8 文字ごとに折り返します）。
- Tab でコード値の欄と文字の欄を切り替えます。Insert で挿入・上書きを切り替えます（既定は上書き）。
- コード値の欄で 16 進数を入力し、Space か Enter で確定すると、その文字になります（上書きではカーソルの文字を
  置き換え、挿入ではカーソルの前に入れます）。6 桁入力するか、カーソルを動かしても確定します。
  入力中は BackSpace で 1 桁消し、Esc で取り消します。
- 文字の欄では文字をそのまま入力できます（日本語入力も使えます）。
- コピーはコード値の欄では `3042 3044` の形、文字の欄では文字列として。コード値の欄への貼り付けは
  `3042 U+3044 0x41 \u{1F600}` のようなコード値の並びとして読みます（読めなければ文字列として貼り付けます）。
- 改行（`000D` `000A`）・タブ（`0009`）も 1 文字として表示・編集できます。読み込み時の不正なバイトは赤い `\x82` です。
- ファイルの文字コードが Shift_JIS などでも、コード値は Unicode です（文字コードでの値は、文字列を選ぶと
  ステータスバーに表示します）。

## 文字コード {#encodings}

- UTF-8 / UTF-16 / UTF-32（BOM あり・なし）、CP932（Shift_JIS の Windows 拡張）、Shift_JIS、
  Shift_JIS-2004・EUC-JIS-2004（JIS X 0213）、EUC-JP、ISO-2022-JP、EBCDIC（IBM-930 / 939 / 1390 /
  1399 / 290 / 1027 / 037 / 500 / 1047）、Windows-1252・ISO-8859 系・GBK・Big5・EUC-KR など。
- 読み込み時に不正だったバイトは `\xNN` と表示し、同じ文字コードで保存すると元のバイトに戻ります。
- EBCDIC を選ぶと、レコードの区切り方（改行 NL・LF、固定長）を尋ねます。
- 独自の対応表（ベンダー漢字・外字）を追加できます（[設定](#settings) の `mappings` フォルダ）。

## EBCDIC のパック 10 進数・バイナリ項目 {#ebcdic-data}

COBOL の `COMP-3`（パック 10 進数）・`COMP` / `BINARY`（2 進数）の項目は文字ではないので、
テキストとして開くと、各バイトを **その文字コードの 1 バイト文字として** 表示します。
項目ごとの数値としての表示（`+12345` など）はしません。

**表示の例**（IBM-037、`PIC S9(5) COMP-3` の `+12345` = `12 34 5C`、`PIC S9(8) COMP` の `300` = `00 00 01 2C`）:

| 項目 | バイト | 本文での表示 |
|------|--------|--------------|
| パック 10 進数 +12345 | `12 34 5C` | `␒<94>*` |
| パック 10 進数 -12345 | `12 34 5D` | `␒<94>)` |
| 2 進数 300 | `00 00 01 2C` | `␀␀␁<8C>` |
| ゾーン 10 進数 +123 | `F1 F2 C3` | `12C`（符号は最後の桁の文字になる） |

- バイトは次のように見えます（詳しくは [制御文字の表示](#controls)）。
  - `00`〜`3F` の多くは `␀` `␒` のような制御文字の記号です。
  - 字形のない C1 制御文字（`34` → U+0094 など）は、灰色の `<94>` のように Unicode の値で表示します
    （1 文字なので、カーソルは 1 回の移動で飛び越えます）。表示の幅が 4 桁になるので、
    パック 10 進数の項目は本来の桁数より長く見え、後ろの項目の桁がずれることがあります。
  - `4A` `5C` `C1` など文字に当たるバイトは、その文字（`¢` `*` `A`）で表示します。
  - 文字コードの表にないバイトは赤い `\x9C` のように表示し、ステータスバーの「不正バイト」に数えます。
- **漢字を含む EBCDIC（IBM-930 / 939 / 1390 / 1399）の注意**: パック 10 進数・2 進数の中に `0E`（SO）が
  あると、そこから 2 バイト文字として読みます。2 バイト文字として読めないバイトは `\x12` のような
  表示になり、読めてしまったバイトの組は漢字に見えます。2 バイト文字として読む範囲は次のとおりです。
  - 改行 NL / LF 区切りでは、次の `0F`（SI）までです（改行も越えます）。
  - 固定長レコードでは、そのレコードの終わりまでです。
- 数値を確かめるには:
  - 項目を選択すると、ステータスバーに元のバイト（`コード値 (IBM-930) 12 34 5C`）を表示します（10 文字まで）。
  - **16 進数表示**（Ctrl+Shift+X）では全バイトを 16 進で表示します。文字の欄の文字コードは
    開いていた EBCDIC になります。
  - **コード値表示**（Ctrl+Shift+K）では、1 文字ずつ `.` とコード値（`0094`）で表示します。
- **保存**: 編集していない部分のバイトはそのまま保存されます（不正なバイト・制御文字・
  対応しない SO / SI も元に戻ります）。漢字を含む EBCDIC でファイルが 2 バイト文字の途中で
  終わっている（最後の SO に SI が続かない）場合も、最後に SI を加えずにそのまま保存します。
- **編集**: パック 10 進数・2 進数の項目を本文で書き換えると、別のバイトになったり、固定長の
  レコードの長さが変わったりします。数値の項目は 16 進数表示で書き換えてください。

## 制御文字の表示 {#controls}

本文では、そのままでは見えない文字を記号で表示します。表示メニューの **制御文字を表示** を
外すと、`␀` `<94>` などの記号と `␤` `¶` は空白で表示します。

## 設定 {#settings}

設定は `%APPDATA%\yyeditor\config.toml` に書きます（ヘルプメニューの「設定ファイルを開く」で開けます）。
**変更は次に起動したときから反映されます。** よく使う項目:

```toml
[editor]
font_family = "UDEV Gothic"   # フォント
font_size = 11.0              # 文字の大きさ（ポイント）
tab_width = 4                 # タブの幅
ambiguous_wide = true         # ①・○ などを全角（2 桁）として数える
detect_ebcdic = false         # 文字コードの自動判別に EBCDIC を含める

[view]
line_numbers = true           # 行番号
show_whitespace = true        # 空白・タブ・改行を記号で表示
wheel_lines = 3               # ホイール 1 目盛りでスクロールする行数

[workspace]
# 「ターミナルで開く」のコマンド（{dir} はフォルダ）。空なら yyterm → Windows Terminal → コマンド プロンプト
terminal = ["pwsh.exe", "-NoExit", "-WorkingDirectory", "{dir}"]

[colors]
background = "#FFFFFF"
foreground = "#1E1E1E"
whitespace = "#A8B4C8"        # 空白・タブ・改行の記号

[colors.syntax]               # コードの色（keyword・string・comment など）
keyword = "#0000FF"
```

リモート（SSH）のファイルの設定（[リモート（SSH）のファイル](#remote)）:

```toml
[remote]
read_ssh_config = true        # %USERPROFILE%\.ssh\config を読む（読むだけ）
read_ssh_known_hosts = true   # %USERPROFILE%\.ssh\known_hosts を読む（読むだけ）
keepalive_secs = 15           # 接続の死活確認の間隔（秒）
agent_dir = ""                # エージェントを置くフォルダ（空なら ~/.yyeditor/agent）
proxy = ""                    # すべての接続先に使うプロキシ（例: "http://proxy:8080"、"socks5://user@socks:1080"）
remember_passwords = true     # パスワード・パスフレーズを資格情報マネージャーに保存できるようにする

[terminal]                    # ターミナル（yyterm）
shell = []                    # 手元のシェルのコマンドと引数（空なら pwsh → powershell → cmd）
font_family = ""              # 空なら [editor] と同じ
font_size = 0.0               # 0 なら [editor] と同じ
scrollback = 10000            # スクロールバックの行数
ambiguous_wide = false        # ○ ※ などを全角とする（接続先の設定と合わせる）
term = "xterm-256color"       # SSH の接続先に知らせる端末の種類
copy_on_select = false        # 選択したら自動でコピーする
use_agent = false             # リモートのフォルダの一覧に接続先のエージェントを使う（使わなければ SFTP）

[transfer]                    # ファイル転送（yysftp）
protocol = "sftp"             # 転送の方式（"sftp" か "scp"）
retries = 10                  # 進みがないまま再接続してよい回数
scp_chunk_mb = 32             # SCP のアップロードで 1 回に送る量（MiB）
show_hidden = false           # 名前が . で始まるファイルも表示する
download_dir = ""             # ダウンロードの既定の保存先（空なら「ダウンロード」フォルダ）
use_agent = false             # 接続先にエージェントを置いて使う（一覧と SHA-256 の照合）

[remote.host.build]           # 接続先の名前ごとの設定（書いていない項目は ~/.ssh/config）
hostname = "build01.example.co.jp"
user = "yamada"
port = 22
identity_file = "~/.ssh/id_build"
proxy_jump = "bastion"        # 踏み台（"a,admin@b:2022" の多段も可。"none" で ~/.ssh/config の指定も使わない）
proxy = "none"                # この接続先のプロキシ（"none" で共通のプロキシも使わない）
agent_dir = "/work/yamada/.yyeditor"   # ホームが noexec の場合など
forward = ["L 5432:localhost:5432", "D 1080"]   # ポートフォワーディング（yyterm だけが使う）
```

- `proxy_jump`・`proxy` のどちらかを書いた接続先では、`~/.ssh/config` の `ProxyJump`・`ProxyCommand` は使いません。
- プロキシのパスワード認証（HTTP の Basic 認証、SOCKS5 のユーザー名・パスワード認証）に対応しています。
  `http://ユーザー@ホスト:ポート` のようにユーザー名だけを書くと接続のときにパスワードを尋ね、何も書かなければ
  プロキシに認証を求められたときにユーザー名とパスワードを尋ねます。間違えたら尋ね直します。入力したパスワードは、選んだ場合だけ資格情報マネージャーに保存します
  （`http://ユーザー:パスワード@…` と設定に書くこともできますが、勧めません）。

- `%APPDATA%\yyeditor\syntax\<名前>.toml`: シンタックスハイライトの定義を追加・置き換え。
- `%APPDATA%\yyeditor\mappings\<名前>.map`: 独自の文字コードの対応表。

## 困ったときは {#trouble}

- **文字化けする**: ファイルメニューの「文字コードを指定して開き直す」で正しい文字コードを選びます。
- **ファイルを開けない（使用中）**: 他のアプリが書き込み中です。「共有中のファイルを読み取り専用で開く」を使います。
- **保存できない文字があると言われる**: 表示された選択肢で置き換えるか、「キャンセル」で最初の文字へ移動して直します。
  別の文字コード（UTF-8 など）で「名前を付けて保存」する方法もあります。
- **プレビューが表示されない**: Microsoft Edge WebView2 ランタイムをインストールしてください。
- **矩形選択の桁がずれる**: 全角が半角のちょうど 2 倍の幅のフォント（既定の UDEV Gothic、MS ゴシックなど）を使います。
- **リモートのファイルを開けない**: 接続先が Linux（x86_64）であることを確かめます。ホームフォルダで
  プログラムを実行できない（noexec）場合は、設定の `agent_dir` で実行できる場所を指定します。
  「ホスト鍵が記録と違う」と表示された場合は、接続先の管理者に鍵が変わったことを確かめてから、
  `known_hosts` の該当する行を削除します。
- **設定を変えたのに反映されない**: yyeditor を起動し直します。設定ファイルに誤りがあると、起動時にその内容を表示します。
