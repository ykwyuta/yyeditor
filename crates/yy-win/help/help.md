# yyeditor ヘルプ

yyeditor は、数 GB のファイルもすぐに開ける Windows 向けの軽量テキストエディタです。
日本語の文字コード（CP932・EUC-JP・JIS X 0213・EBCDIC など）、区切り文字（CSV・TSV）の
表示と編集、Markdown・HTML のプレビューに対応しています。

## ファイルを開く・保存する {#files}

- **開く**（Ctrl+O）: 文字コードは自動で判別します。開くダイアログで文字コードを指定することもできます。
  ファイルはウィンドウにドラッグ＆ドロップしても開けます。
- 大きなファイルもすぐに表示します。行数は裏で数えるので、数え終わるまでは行番号が推定値
  （灰色）になります。UTF-8 以外のファイルは裏で変換し、その間は先頭部分を読み取り専用で表示します。
- **共有中のファイルを読み取り専用で開く**: 他のアプリが書き込み中のファイル（出力中のログなど）を、
  開いた時点の内容で表示します。
- **文字コードを指定して開き直す**: 文字化けしたときに、正しい文字コードで読み直します。
- **バイナリとして開く**: ファイルをバイト列のまま [16 進数表示](#hex) で開きます。
- **上書き保存**（Ctrl+S）・**名前を付けて保存**（Ctrl+Shift+S）: 名前を付けて保存では、文字コード・
  BOM・改行コード（CRLF / LF）を選べます。
  - 保存は裏で行い、進み具合をステータスバーに表示します（Esc で中止）。保存中も編集できます。
  - 保存先の文字コードで表せない文字があると、似た文字（① → (1)、ｶﾞ → ガ など）や「?」・
    数値文字参照に置き換えるかを尋ねます。置き換えは「元に戻す」で取り消せます。
  - 保存後も「元に戻す」で保存前の内容に戻せます。
- タイトルとタブの `*` は、保存していない変更があることを示します。閉じるときに保存するか尋ねます。

## タブと比較 {#tabs}

- ファイルはタブで開きます。タブの「×」または中ボタンのクリックで閉じます。
- Ctrl+Tab / Ctrl+Shift+Tab でタブを切り替えます。
- **開いているファイルを比較**（表示メニュー）: 2 つのタブの内容の差分を別のウィンドウに表示します。

## 編集 {#editing}

- **元に戻す**（Ctrl+Z）・**やり直し**（Ctrl+Y / Ctrl+Shift+Z）: 続けて入力した文字は 1 回で戻ります。
- **上書きモード**: Insert キーで挿入・上書きを切り替えます（ステータスバーに表示）。
- **コメント化 / 解除**（Ctrl+/）: 選択した行を、ファイルの種類に合ったコメントにします。
- **対応する括弧へ移動**（Ctrl+]）。カーソルの位置の括弧と対応する括弧は色を付けて表示します。
- **タグジャンプ**（F12）: カーソル行の「パス(行番号)」（Grep の結果など）のファイルを開いて、その行へ移動します。
- Shift+Delete / Ctrl+Insert / Shift+Insert でも切り取り・コピー・貼り付けができます。
- **変換**（編集メニュー）: 選択した文字列（選択がなければカーソル位置の単語）を変換します。複数の選択はまとめて変換し、1 回の Undo で戻ります。
  - **大文字に**（Ctrl+Shift+U）・**小文字に**（Ctrl+U）: 英字（全角英字・アクセント付きのラテン文字を含む）だけを変換します。
  - **全角カタカナに**・**半角カタカナに**: 濁点・半濁点（ｶﾞ ⇔ ガ）と長音符・中黒も変換します。句読点とかぎ括弧はそのままです。
  - **キャメルケースに**・**スネークケースに**・**ケバブケースに**: `userName` ⇔ `user_name` ⇔ `user-name` のように、英数字の識別子の区切り方を変えます。
- **重複行を削除**（編集メニュー）: 選択した行（選択がなければ文書全体）で、前に同じ内容の行があれば削除します（最初の行を残し、順番は変えません。改行コードの違いは無視します）。大きな文書はバックグラウンドで処理します。
- 文字列を選択すると、ステータスバーに先頭 10 文字のコード値を表示します（Unicode の文書では `コード値 (U+) 3042` のように符号位置、それ以外ではその文字コードでのバイト値）。

## 複数のカーソルと矩形選択 {#multi}

- **次の出現箇所を選択に追加**（Ctrl+D）: 選択している文字列の次の出現箇所にもカーソルを置きます。
- **すべての出現箇所を選択**（Ctrl+Shift+L）。
- **検索条件に一致する箇所をすべて選択**（Ctrl+Shift+M、検索バーの「一致箇所をすべて選択」）。
- **選択した各行の行末にカーソル**（Alt+Shift+I）。
- **上下の行にカーソルを追加**（Ctrl+Alt+↑ / ↓）。
- 複数のカーソルで入力すると、すべての位置に同時に入力されます。Esc で 1 つに戻ります。
- **矩形選択**: Alt を押しながらドラッグ、または Alt+Shift+矢印キー。編集メニューの「矩形選択モード」
  をオンにすると、Alt なしのドラッグで矩形になります。矩形の中で入力・削除・貼り付けができます。
  「矩形選択をカーソルに変換」で各行のカーソルにできます。

## 検索・置換 {#search}

- **検索**（Ctrl+F）で検索バーを開きます。入力するとすぐに一致箇所へ移動し、すべての一致に色を付けます。
  Enter で次、Shift+Enter で前を検索します（F3 / Shift+F3 でも）。Esc で閉じます。
- 「大/小文字」「単語」「正規表現」で条件を変えます。正規表現では置換文字列に `$1` などを使えます。
- **置換**（Ctrl+H）、または検索欄の下の「置換を表示」で置換の行を開きます。「選択範囲のみ置換」もできます。
  すべて置換は 1 回の「元に戻す」で戻せます。
- 検索欄の下のボタン:
  - **置換を表示 / 置換を隠す**
  - **一致箇所をすべて選択**: 選んだあとそのまま入力すると、一致箇所がまとめて書き換わります
  - **フォルダ内を検索 (Grep)**: 検索欄の条件で、フォルダ内のファイルを検索します
- **ファイルから検索 (Grep)**（Ctrl+Shift+F）: 結果は新しいタブに「パス(行番号): 内容」の形で表示します。
  行にカーソルを置いて F12 でそのファイルを開きます。

## 表示 {#view}

- **拡大・縮小**: Ctrl++ / Ctrl+- / Ctrl+0、または Ctrl+マウスホイール。
- **行へ移動**（Ctrl+G）。
- **行番号**・**空白・タブ・改行を表示**・**制御文字を表示** を表示メニューで切り替えます。
  空白は「·」、タブは「→」、改行は CRLF が「↵」、LF が「↓」で表示します
  （全角スペースはフォントの字形で見えます）。
- Shift+マウスホイールで横にスクロールします。
- 長い行は折り返さずに 1 行のまま表示します（非常に長い行は複数の表示行に分けます）。
- 既定のフォントは同梱の UDEV Gothic です（全角が半角のちょうど 2 倍の幅なので矩形選択がずれません）。

## 区切り文字モード（CSV・TSV） {#csv}

- `.csv`・`.tsv` などを開くと、列をそろえて表示します（CSV メニューで区切り文字の種類を選べます）。
- 本文の上に、Excel と同じ規則の列名（A、B、…、Z、AA、AB、…）を表示します。カーソルのある列の列名は色を変えて示します。
- Tab / Shift+Tab で次・前のセルへ移動します。
- **列を挿入**・**列を削除**・**カンマ区切り ⇔ タブ区切りの変換**（1 回の「元に戻す」で戻せます）。
- 区切り文字や改行を含む文字列を入力すると、自動的に `"` で囲みます。
- ステータスバーにカーソルのある行・列の番号を表示します。

## シンタックスハイライト {#syntax}

- ファイルの種類（拡張子・ファイル名・先頭行など）から自動で色を付けます。
  表示メニューの「ハイライト」で種類を選び直せます（「なし」で色を付けません）。
- C / C++ / C# / Java / JavaScript / TypeScript / Python / Rust / Go / HTML / CSS / SQL / Markdown /
  COBOL / JCL など 37 種類に対応しています。
- 独自の定義を追加できます（[設定](#settings) の `syntax` フォルダ）。

## Markdown・HTML のプレビュー {#preview}

**プレビュー**（Ctrl+Shift+V、表示メニュー）で、エディタの右側にプレビューを表示します。
境界はドラッグで動かせます。入力すると 0.25 秒ほどで反映され、エディタのスクロールに合わせて
プレビューもスクロールします。

Markdown で使える記法:

| 記法 | 書き方の例 |
|------|-----------|
| 表 | `\| 列 \| 列 \|` と `\|---\|---\|` |
| タスクリスト | `- [x] 完了` |
| 取り消し線・上付き・下付き | `~~取消~~`・`x ^2^`・`H ~2~ O` |
| 脚注 | `本文[^1]` と `[^1]: 脚注` |
| 定義リスト | `用語` の次の行に `: 説明` |
| アラート | `> [!NOTE]`・`[!TIP]`・`[!IMPORTANT]`・`[!WARNING]`・`[!CAUTION]` |
| 数式（KaTeX） | `$E = mc^2$`・`$$ \int_0^1 x\,dx $$`・```` ```math ```` |
| 図（Mermaid） | ```` ```mermaid ```` のコードブロック |
| 見出しの ID | `## 見出し {#id}` |

- 画像などの相対パスは文書のフォルダから読みます。リンクは、同じフォルダの Markdown・HTML なら
  エディタで、それ以外は既定のブラウザで開きます。
- HTML 文書はそのまま表示します。
- プレビューには Microsoft Edge WebView2 ランタイムを使います（Windows 10 / 11 には通常インストール済み）。

## 16 進数（バイナリ）編集 {#hex}

- **16 進数表示**（Ctrl+Shift+X）で、オフセット・16 進・文字の欄で表示します。
- Tab で 16 進の欄と文字の欄を切り替えます。Insert で挿入・上書きを切り替えます（既定は上書き）。
- Ctrl+G でオフセット（`0x1F00` や 10 進）へ移動します。
- UTF-8 以外で開いた文書は、バイト列のまま開き直してから 16 進数表示にします。
- **文字の欄の文字コード**（表示メニューの「16 進数表示の文字の欄の文字コード」）: 右側の文字の欄を
  ASCII・UTF-8・UTF-16・CP932・EUC-JP・EBCDIC など、どの文字コードで表示するかを選べます。
  テキストとして開いていた文書は、その文字コードで表示します。ステータスバーに現在の文字コードを表示します。
  - 多バイト文字は先頭のバイトの位置に表示し、残りのバイトの位置は空白になります。
  - 不正なバイトは赤い `.`、制御文字（改行など）は `.` で表示します。
  - 文字の欄での入力・貼り付け・コピーも、選んだ文字コードで行います。

## コード値の編集 {#code}

- **コード値表示**（Ctrl+Shift+K、表示メニュー）で、16 進数表示と同じ形で、1 行 8 文字ずつ、左に各文字の
  Unicode のコード値（`3042` など）、右に文字を表示します。左端は行番号です（長い行は 8 文字ごとに折り返します）。
- Tab でコード値の欄と文字の欄を切り替えます。Insert で挿入・上書きを切り替えます（既定は上書き）。
- コード値の欄で 16 進数を入力し、Space か Enter で確定すると、その文字になります（上書きではカーソルの文字を
  置き換え、挿入ではカーソルの前に入れます）。6 桁入力するか、カーソルを動かしても確定します。
  入力中は BackSpace で 1 桁消し、Esc で取り消します。
- 文字の欄では文字をそのまま入力できます（日本語入力も使えます）。
- コピーはコード値の欄では `3042 3044` の形、文字の欄では文字列として。コード値の欄への貼り付けは
  `3042 U+3044 0x41 \u{1F600}` のようなコード値の並びとして読みます（読めなければ文字列として貼り付けます）。
- 改行（`000D` `000A`）・タブ（`0009`）も 1 文字として表示・編集できます。読み込み時の不正なバイトは赤い `\x82` です。
- ファイルの文字コードが Shift_JIS などでも、コード値は Unicode です（文字コードでの値は、文字列を選ぶと
  ステータスバーに表示します）。

## 文字コード {#encodings}

- UTF-8 / UTF-16 / UTF-32（BOM あり・なし）、CP932（Shift_JIS の Windows 拡張）、Shift_JIS、
  Shift_JIS-2004・EUC-JIS-2004（JIS X 0213）、EUC-JP、ISO-2022-JP、EBCDIC（IBM-930 / 939 / 1390 /
  1399 / 290 / 1027 / 037 / 500 / 1047）、Windows-1252・ISO-8859 系・GBK・Big5・EUC-KR など。
- 読み込み時に不正だったバイトは `\xNN` と表示し、同じ文字コードで保存すると元のバイトに戻ります。
- EBCDIC を選ぶと、レコードの区切り方（改行 NL・LF、固定長）を尋ねます。
- 独自の対応表（ベンダー漢字・外字）を追加できます（[設定](#settings) の `mappings` フォルダ）。

## 設定 {#settings}

設定は `%APPDATA%\yyeditor\config.toml` に書きます（ヘルプメニューの「設定ファイルを開く」で開けます）。
**変更は次に起動したときから反映されます。** よく使う項目:

```toml
[editor]
font_family = "UDEV Gothic"   # フォント
font_size = 11.0              # 文字の大きさ（ポイント）
tab_width = 4                 # タブの幅
ambiguous_wide = true         # ①・○ などを全角（2 桁）として数える
detect_ebcdic = false         # 文字コードの自動判別に EBCDIC を含める

[view]
line_numbers = true           # 行番号
show_whitespace = true        # 空白・タブ・改行を記号で表示
wheel_lines = 3               # ホイール 1 目盛りでスクロールする行数

[colors]
background = "#FFFFFF"
foreground = "#1E1E1E"
whitespace = "#A8B4C8"        # 空白・タブ・改行の記号

[colors.syntax]               # コードの色（keyword・string・comment など）
keyword = "#0000FF"
```

- `%APPDATA%\yyeditor\syntax\<名前>.toml`: シンタックスハイライトの定義を追加・置き換え。
- `%APPDATA%\yyeditor\mappings\<名前>.map`: 独自の文字コードの対応表。

## 困ったときは {#trouble}

- **文字化けする**: ファイルメニューの「文字コードを指定して開き直す」で正しい文字コードを選びます。
- **ファイルを開けない（使用中）**: 他のアプリが書き込み中です。「共有中のファイルを読み取り専用で開く」を使います。
- **保存できない文字があると言われる**: 表示された選択肢で置き換えるか、「キャンセル」で最初の文字へ移動して直します。
  別の文字コード（UTF-8 など）で「名前を付けて保存」する方法もあります。
- **プレビューが表示されない**: Microsoft Edge WebView2 ランタイムをインストールしてください。
- **矩形選択の桁がずれる**: 全角が半角のちょうど 2 倍の幅のフォント（既定の UDEV Gothic、MS ゴシックなど）を使います。
- **設定を変えたのに反映されない**: yyeditor を起動し直します。設定ファイルに誤りがあると、起動時にその内容を表示します。
