# yysheet ヘルプ

yysheet は、yyeditor と同じ部品で作った、大量のデータ（50 億セル程度）を扱えるスプレッドシートです。
CSV と独自形式（`.yys`）のほか、IBM COBOL のコピーブックのレイアウトで固定長ファイル（MS932・EBCDIC）を
読み書きできます。

## 画面の見かた {#screen}

- **名前ボックス・数式バー**（上）: アクティブなセルの位置（`B3`。範囲なら `3R × 2C`）と、セルの値（式なら式）。
  数式バーをクリックすると、そこで入力できます。
- **格子**: 列見出し（`A`・`B`…）と行番号。表（CSV など）の 1 行目は列の名前（見出し行）で、色を変えて表示します。
  固定長のシートでは、列見出しに列の名前と並べて **COBOL の型**（`S9(7)V99 COMP-3` など）を青で出します。
- **シートのタブ**（下）: クリックでシートを切り替えます。挿入・削除 > シートを追加 で増やせます。
- **ステータスバー**: 左はメッセージと、範囲を選んだときの集計（データの個数・合計・平均）。固定長のシートでは、
  右に **文字コードとレコード長**（`固定長 IBM-930・レコード長 83 バイト`）と、アクティブなセルの列の項目
  （名前・型・何バイト目から何バイト目か）を出します。

## ファイルを開く・保存する {#files}

- **開く**（Ctrl+O、ドラッグ＆ドロップ）: 独自形式（`.yys`）と CSV・TSV（`.csv`・`.tsv`・`.txt`）。CSV は文字コード
  （UTF-8・Shift_JIS・EUC-JP・UTF-16 など）・区切り文字（カンマ・タブ・セミコロン・パイプ・US）・レコードの
  終わり（改行。LF がなければ RS・GS・FS・CR も）・見出し行・列の型（数値・日付・真偽値・文字列）を
  推定して、全コアで並列に取り込みます（進みをステータスバーに出します。Esc で中止）。`00123` のように
  数値にすると元に戻らない値は文字列のままにします。`.dat`・`.bin` などは固定長ファイルとして開きます
  （[固定長ファイル](#fixed)）。
- **保存**（Ctrl+S）: `.yys` は、開いたファイルなら変わった部分だけを書き足すので、大きなファイルでもすぐ
  終わります。CSV から開いたものは、CSV のまま保存するか `.yys` で保存するかを尋ねます。固定長ファイルから
  開いたものは、固定長のまま保存するかを尋ねます。
- **区切りを指定して開く**（ファイル メニュー・ワークスペースの右クリック）: 文字コード・区切り文字・
  レコードの終わり・引用符・見出しを指定して開きます。区切り文字とレコードの終わりは候補から選ぶか、書いて
  指定します（下の表）。レコードの終わりを改行以外にすると、値の中の改行（CR・LF）はただの文字になります。
  区切り文字は 4 バイトまで、レコードの終わりは 8 バイトまでで、改行以外で終わるときは区切り文字に LF も
  使えます。

  | 書き方 | 意味 |
  |---|---|
  | `,` `;` `~~` | その文字（続けて書けば複数の文字） |
  | `<TAB>` `<CR>` `<LF>` `<US>` `<RS>` `<GS>` `<FS>` `<NUL>` など | 制御コード（0x00〜0x1F の名前、`<SP>`・`<DEL>`） |
  | `<0x1F>` | 16 進数で書いた 1 バイト |
  | `\t` `\r` `\n` `\0` `\x1F` `\\` | エスケープ |

- **書き出し**: ファイル > CSV・TSV に書き出し（開いたときの区切り文字・レコードの終わり・文字コードで、
  表示形式を当てた値。別の名前の `.csv`・`.tsv` に書くときは拡張子に合わせてカンマ・タブ）、
  ファイル > 区切りを指定して書き出し（文字コード・BOM・区切り文字・レコードの終わり・引用符を指定。
  区切り文字・引用符・改行・レコードの終わりを含む値は引用符で囲みます）、ファイル > 固定長ファイルに書き出し。
  開いたファイルに書けば、次の上書き保存も同じ区切りで書きます。
- **新規**（Ctrl+N）・**名前を付けて保存**（Ctrl+Shift+S）。
- データはファイルに置いたまま必要な部分だけを読み、新しく作ったデータは作業ファイルに書きます。アプリが
  使うメモリは既定で 8 GB まで（[設定](#settings)）。使用状況は ヘルプ > メモリの使用状況 で見られます。
- **リモートのファイルを開く**（ファイル メニュー）: SSH の接続先のファイルを選んで開きます
  （[ワークスペースとリモートのファイル](#workspace)）。

## ワークスペースとリモートのファイル {#workspace}

エディタ（yyeditor）・ターミナル（yyterm）と同じく、よく使うフォルダを左のサイドバー（**ワークスペース**）に
並べて、そこからファイルを開けます。SSH の接続先のフォルダも並べられ、接続先のファイルを直接開いて保存できます。

- **表示**: 表示 > ワークスペース（Ctrl+Shift+E）で出し入れします。
- **フォルダを加える**: ワークスペース > フォルダを追加、またはフォルダをウィンドウにドラッグ＆ドロップ。
  接続先のフォルダは ワークスペース > リモートのフォルダを追加（接続先を選んで、フォルダを選びます）。
  外すときは、右クリック > ワークスペースから外す（または Delete）。
- **ファイルを開く**: ダブルクリック（Enter）。`.yys`・CSV はそのまま、それ以外は固定長ファイルとして開きます。
  右クリックで「固定長ファイル（マルチレイアウト）として開く」「固定長ファイルをシートとして追加」も選べます。
  中身が 1 つのフォルダだけのフォルダは `a/b` のように束ねて表示します（VS Code と同じ）。
- **ワークスペースのファイル**: 並べたフォルダは `*.yyworkspace` に保存します（エディタ・ターミナルと同じ形式）。
  ワークスペース > 名前を付けて保存・ワークスペースを開く で切り替えられます。名前を付けていなければ、
  yysheet 用のもの（設定フォルダの `sheet-untitled.yyworkspace`）を使います。
- **接続先のファイル**: 開くと、手元の一時フォルダに取り寄せてから開きます（タイトルに `[接続先]` が付きます）。
  上書き保存（Ctrl+S）すると、手元に書いてから接続先に送り返します。
  - 接続先では、同じフォルダに一時の名前で書いてから置き換えます。途中で切れても元のファイルは残り、
    権限（パーミッション）も引き継ぎます。
  - 開いたあとで接続先のファイルがほかで変更・削除されていたら、置き換えてよいかを尋ねます。
  - 送れなかったときは、手元の写しには保存したまま「未保存」の印（`*`）を残します。もう一度上書き保存すると、
    送り直します。
  - 名前を付けて保存は手元のファイルとして保存します。
  - 取り寄せた写しは、別の文書を開いたときと終わるときに消します。
- **エージェントか SFTP か**: 接続先のフォルダの一覧とファイルの読み書きは、既定では SFTP を使います
  （接続先に何も置きません）。ワークスペース > リモートの読み書きに接続先のエージェントを使う、または設定の
  `[sheet] use_agent` で、エディタと同じエージェントに切り替えられます。
- 右クリックの「ダウンロード フォルダにコピー」で、接続先のファイル・フォルダをこのパソコンのダウンロード
  フォルダにコピーできます。パスワードの入力・ホスト鍵の確認・`~/.ssh/config` はエディタ・ターミナルと共通です。

## セルの操作と入力 {#editing}

- **移動**: 矢印・Ctrl+矢印（データの端へ）・PageUp/PageDown・Home・Ctrl+Home/End。Shift を押しながらで
  範囲を選びます。列見出し・行番号のクリックで列全体・行全体、Ctrl+A ですべてを選びます。
- **入力**: 文字を入力すると編集が始まります（IME も使えます）。F2 で今の値を編集します。Enter・Tab で確定して
  下・右へ（Shift で上・左へ）、Esc で取り消します。文字の入力で始めた編集では、矢印キーでも確定して移動します。
  先頭に `'` を付けると文字列として入力します（`'00123`）。
- 数値（`1,234`・`50%`・`¥1,000`）・日付（`2026/10/7`）・時刻・真偽値（`TRUE`）・エラー値（`#N/A`）は
  その型の値になり、それ以外は文字列になります。
- **消す・元に戻す**: Delete（内容を消す）、Ctrl+Z／Ctrl+Y。
- **コピー・貼り付け**: Ctrl+C／Ctrl+X／Ctrl+V（タブ区切りの文字列。Excel との間でも使えます）。
- **行・列**: Ctrl++／Ctrl+-（行の挿入・削除）、挿入・削除 メニュー（列の挿入・削除）。式の参照は付け替えます。
- **列幅・拡大**: 列見出しの境目をドラッグ、Ctrl+ホイール・Ctrl+0（100%）。

## 式（数式） {#formulas}

- `=` で始めて入力します（Excel と同じ文法）。参照 `A1`・`$A$1`・`A1:C10`・`A:A`・`1:1`・`Sheet2!A1`・
  `'売上 2026'!B:B`、配列定数 `{1,2;3,4}`、演算子 `+ - * / ^ % &` と比較 `= <> < > <= >=` が使えます。
- 使える関数は [関数の一覧](#functions) のとおりです（ほかの関数は `#NAME?`）。
- 複数の値を返す式（`TEXTSPLIT`、範囲どうしの演算、複数列の `XLOOKUP`）は右・下のセルにあふれ（スピル）、
  あふれる先に値があれば `#SPILL!` になります。
- 値を直すと、そのセルを参照する式だけを依存の順に、バックグラウンドで計算し直します（時間がかかるときは
  「再計算中…」と出し、その間の入力は受け付けません。循環する式は `#CALC!`）。
- 式に誤りがあると「式に誤りがあります」と知らせ、入力した式を残したまま編集を続けます（直して Enter）。
- 数式バーと編集では式を、セルには結果を表示します。式は `.yys` に保存し、開いたときに計算し直します。

## 関数の一覧 {#functions}

| 関数 | 書き方 | 説明 |
|---|---|---|
| `ABS` | `ABS(数値)` | 数値の絶対値を返します。 |
| `AND` | `AND(論理式1, [論理式2], …)` | すべての論理式が真なら `TRUE`、1 つでも偽なら `FALSE` を返します（`=AND(B2>=60,C2>=60)`）。数値は 0 以外が真、直接書いた文字列は `TRUE`・`FALSE` だけ（ほかは `#VALUE!`）。範囲・配列の中の文字列と空は無視し、見る値が 1 つもなければ `#VALUE!`。エラーはそのまま返します。 |
| `AVERAGE` | `AVERAGE(数値1, [数値2], …)` | 数値の平均値を返します（範囲の中の文字列・真偽値・空は無視します。数値がなければ `#DIV/0!`）。 |
| `CBL.HIGH-VALUE` | `CBL.HIGH-VALUE()` | COBOL の HIGH-VALUE。固定長の項目の列で、項目のすべてのバイトを X'FF' にします（セルには `HIGH-VALUE` と出ます）。COBOL の型のない列では `#VALUE!`。`CBL.HIGH-VALUES()` も同じです。 |
| `CBL.LOW-VALUE` | `CBL.LOW-VALUE()` | COBOL の LOW-VALUE。固定長の項目の列で、項目のすべてのバイトを X'00' にします（セルには `LOW-VALUE` と出ます）。COBOL の型のない列では `#VALUE!`。`CBL.LOW-VALUES()` も同じです。 |
| `CBL.MOVE` | `CBL.MOVE(送り出し範囲, 受け取り範囲)` | COBOL の MOVE。送り出し範囲の値を、受け取り範囲の列の COBOL の型で送ります（[CBL.MOVE](#cbl-move)）。式は固定長の範囲の外の列などに入力し、値は受け取り範囲に置かれます。 |
| `CONCAT` | `CONCAT(文字列1, [文字列2], …)` | 文字列をつなげます（範囲はセルの順に）。`CONCATENATE` も同じです。 |
| `COUNT` | `COUNT(値1, [値2], …)` | 数値のセルの数を返します（範囲の中の文字列・空・真偽値・エラーは数えません）。 |
| `COUNTIFS` | `COUNTIFS(条件範囲1, 条件1, [条件範囲2, 条件2], …)` | すべての条件に合うセルの数を返します。 |
| `FALSE` | `FALSE()` | 論理値 `FALSE`（偽）を返します。`FALSE` とだけ書いても同じです。 |
| `IF` | `IF(条件, 真の場合, [偽の場合])` | 条件が真なら「真の場合」、偽なら「偽の場合」の値を返します（`=IF(B2>=80,"合格","不合格")`）。選んだ方だけを計算します。偽の場合を省くと `FALSE`、空の引数（`IF(A1,,1)`）は 0。条件は数値なら 0 以外が真、空は偽、文字列は `TRUE`・`FALSE` だけ（ほかは `#VALUE!`）。入れ子にもできます。 |
| `IFERROR` | `IFERROR(値, エラーの場合の値)` | 値がエラー（`#DIV/0!`・`#N/A`・`#VALUE!` など）なら「エラーの場合の値」を、そうでなければ値をそのまま返します（`=IFERROR(B2/C2,0)`、`=IFERROR(XLOOKUP(…),"なし")`）。値がエラーでなければ 2 つ目は計算しません。配列なら要素ごと。 |
| `IFS` | `IFS(条件1, 値1, [条件2, 値2], …)` | 最初に真になった条件の値を返します（`=IFS(B2>=80,"A",B2>=60,"B",TRUE,"C")`。最後の条件を `TRUE` にすると「それ以外」）。後ろの条件・値は計算しません。どれも真でなければ `#N/A`、条件と値が組になっていなければ `#VALUE!`。条件が配列なら要素ごとに選びます。 |
| `MAX` | `MAX(数値1, [数値2], …)` | 数値の最大値を返します（範囲の中の文字列・真偽値・空は無視します。数値がなければ 0）。 |
| `MEDIAN` | `MEDIAN(数値1, [数値2], …)` | 数値の中央値を返します（数が偶数なら中央の 2 つの平均。数値がなければ `#NUM!`）。 |
| `MIN` | `MIN(数値1, [数値2], …)` | 数値の最小値を返します（範囲の中の文字列・真偽値・空は無視します。数値がなければ 0）。 |
| `MOD` | `MOD(数値, 除数)` | 数値を除数で割った余り（剰余）を返します。符号は除数と同じです（`MOD(10,3)` = 1、`MOD(-3,2)` = 1、`MOD(3,-2)` = -1）。除数が 0 なら `#DIV/0!`。 |
| `OR` | `OR(論理式1, [論理式2], …)` | 論理式が 1 つでも真なら `TRUE`、すべて偽なら `FALSE` を返します（`=OR(B2="東京",B2="大阪")`）。値の扱いは `AND` と同じです。 |
| `PERCENTILE` | `PERCENTILE(範囲, 率)` | 範囲の数値のパーセンタイル（百分位数。率は 0〜1、0.9 なら 90 パーセンタイル）を返します。間の値は前後の値から比例で求めます。`PERCENTILE.INC` と同じです。 |
| `PERCENTILE.EXC` | `PERCENTILE.EXC(範囲, 率)` | パーセンタイルを返します（率は 0 と 1 を含みません。順位は 率×(個数+1) で、1〜個数の外なら `#NUM!`）。 |
| `PERCENTILE.INC` | `PERCENTILE.INC(範囲, 率)` | パーセンタイルを返します（率は 0〜1。位置は 率×(個数−1)。率が範囲の外なら `#NUM!`）。 |
| `PI` | `PI()` | 円周率 π（3.14159265358979）を返します（`=PI()*B2^2` で円の面積）。 |
| `PRODUCT` | `PRODUCT(数値1, [数値2], …)` | 数値の積を返します。 |
| `ROUND` | `ROUND(数値, 桁数)` | 数値を指定の桁で四捨五入します（5 は 0 から遠い方へ。`ROUND(2.15,1)` = 2.2、`ROUND(-2.5,0)` = -3）。桁数が負なら整数部で四捨五入（`ROUND(626.3,-3)` = 1000）。 |
| `ROUNDDOWN` | `ROUNDDOWN(数値, 桁数)` | 数値を指定の桁で切り捨てます（0 に近い方へ）。桁数は小数点以下の桁で、0 なら整数に、負なら整数部の桁（`ROUNDDOWN(31415.9,-2)` = 31400）。 |
| `ROUNDUP` | `ROUNDUP(数値, 桁数)` | 数値を指定の桁で切り上げます（0 から遠い方へ。`ROUNDUP(-3.14,1)` = -3.2）。桁数は `ROUNDDOWN` と同じです。 |
| `ROW` | `ROW([参照])` | 参照の行番号（1 始まり）を返します（`=ROW(C5)` = 5）。省略すれば式のあるセルの行（`=ROW()`。連番や `=MOD(ROW(),2)` での 1 行おきに使えます）。複数の行の範囲なら行番号を縦に並べます（スピル。`=ROW(A1:A3)` = 1・2・3）。列全体（`A:A`）は使っている行まで。 |
| `SUM` | `SUM(数値1, [数値2], …)` | 数値の合計を返します（範囲の中の文字列・真偽値・空は無視します）。 |
| `SUMIFS` | `SUMIFS(合計範囲, 条件範囲1, 条件1, [条件範囲2, 条件2], …)` | すべての条件に合う行の、合計範囲の数値の合計を返します。 |
| `TEXTJOIN` | `TEXTJOIN(区切り文字, 空のセルを無視, 文字列1, [文字列2], …)` | 区切り文字をはさんで文字列をつなげます。 |
| `TEXTSPLIT` | `TEXTSPLIT(文字列, 列の区切り, [行の区切り], [空を無視], [一致モード], [埋める値])` | 文字列を区切り文字で分け、行・列に並べます。 |
| `TRUE` | `TRUE()` | 論理値 `TRUE`（真）を返します。`TRUE` とだけ書いても同じです。 |
| `XLOOKUP` | `XLOOKUP(検索値, 検索範囲, 戻り範囲, [見つからない場合], [一致モード], [検索モード])` | 検索範囲から検索値を探し、戻り範囲の同じ位置の値を返します。 |

- `[ ]` の引数は省略できます。`…` は同じ形の引数を続けられることを表します。
- `MAX`・`MIN`・`AVERAGE`・`MEDIAN`・`PERCENTILE` は `SUM` と同じく、直接書いた値は数値に変え（`"3"`・`TRUE` も）、
  範囲の中は数値のセルだけを使います。範囲の中にエラー値があれば、そのエラーを返します。
- `ROUND`・`ROUNDUP`・`ROUNDDOWN` は、計算の誤差で 1 つずれないよう、有効数字 15 けたにしてから四捨五入・切り上げ・
  切り捨てをします（`ROUND(2.675,2)` = 2.68、`ROUNDUP(0.1*3,1)` = 0.3）。
- `IF` の条件に範囲・配列を書くと、要素ごとに選んだ配列になります（`=SUM(IF(A2:A10>0,B2:B10,0))`）。
- `CBL.` で始まる関数は COBOL のための関数です（`CBL.` まで入力すると候補が出ます）。`CBL.LOW-VALUE()`・`CBL.HIGH-VALUE()` は、COBOL の `MOVE LOW-VALUE TO 項目` と同じく、項目の型（数値・パック 10 進数・
  2 進数・2 バイト文字も）にかかわらず、項目のすべてのバイトを 0x00・0xFF にして書き出します（文字コードにも
  よりません）。`=A2=CBL.LOW-VALUE()` のように比べることもできます（COBOL の `IF A = LOW-VALUE`）。
- `SUMIFS`・`COUNTIFS` の条件: `"東京"`（等しい）・`">=100"`・`"<>"`（空でない）・`"東*"`（ワイルドカード
  `*`・`?`）。条件の値だけが違う多数の式は、範囲を 1 回読んでまとめて計算します。
- `XLOOKUP` の一致モード: 0 = 完全一致（既定）・-1 = 完全一致か次に小さい値・1 = 完全一致か次に大きい値・
  2 = ワイルドカード。検索モード: 1 = 先頭から（既定）・-1 = 末尾から・2 / -2 = 二分探索。完全一致は列の索引を
  作って引きます。

## 式の入力の補助 {#formula-assist}

- 式の入力中に、演算子・`(`・`,`・`=` の直後でセルをクリックすると参照（`C3`）が、ドラッグすると範囲
  （`C3:E10`）が、列見出し・行番号をクリックすると列全体（`C:C`）・行全体（`3:3`）が式に入ります。Shift+クリックで
  範囲を広げ、続けてクリックすると入れた参照を差し替えます。文字の入力で始めた編集では矢印キー（Shift+矢印で
  範囲）でも選べます。
- F4 で参照の `$` を切り替えます（`A1` → `$A$1` → `A$1` → `$A1`）。
- 参照を入れられる位置でシートのタブをクリックすると、入力を続けたままそのシートに切り替わり、セルをクリックすると
  `Sheet2!B3` のような参照が入ります（Enter で元のシートのセルに確定）。
- 関数名を途中まで入力すると候補と説明が出ます（↑↓で選び、Tab・Enter・クリックで入れる。Esc で閉じる）。関数の
  かっこの中では引数の書き方を出し、いま入力している引数を太字にします。式の中の参照には色の付いた枠が出ます。

## フィルハンドル・下へコピー {#fill}

- **フィルハンドル**: 選択範囲の右下の小さな四角を上下左右にドラッグすると、その方向へ値を広げます。
  `1, 2` → `3, 4, …`、日付は 1 日ずつ（`1/31, 2/28` のように月ずつ並んでいれば月単位）、`項目1` → `項目2`、
  `月` → `火`、それ以外はコピー（Ctrl を押して離すと連続データとコピーが入れ替わります）。
- フィルのあと右下に出るボタン（▼）で、セルのコピー・連続データ・書式のみコピー・書式なしコピー、日付なら
  日・週日・月・年の単位を選んで入れ直せます。右ボタンでドラッグすると、離したときに同じメニューが出ます。
- フィルハンドルをダブルクリックすると、左（なければ右）の列の値が続く行まで下へ広げます。
- **下へコピー**（Ctrl+D）: 選択範囲の 1 行目を下の行へコピーします。式は相対参照をずらし、16 行以上なら
  1 つの共有式として持つので、表の全行（数百万行）に式を入れてもすぐに計算できます。

## 検索・置換 {#search}

- **検索**（Ctrl+F）で表から文字列を探し、**次を検索**（F3）で続きを探します（大文字・小文字は区別しません）。
- **置換**（Ctrl+H）は、選んだ列（または表のすべての列）の文字列を置き換えます。正規表現（置換後の文字列で
  `$1` などの組）、大文字と小文字の区別、セル全体の一致を選べます。

## 書式 {#format}

- **セルの書式設定**（Ctrl+1）: 表示形式（候補から選ぶか書式記号を入力。例を見ながら）、太字・斜体、横の配置、
  塗りつぶしの色、文字の色、罫線（なし・格子・外枠・上・下・左・右。線の種類と色）、**COBOL の型**
  （[固定長ファイル](#fixed)）をまとめて付けます。
- 太字（Ctrl+B）・斜体（Ctrl+I）・塗りつぶしの色・文字の色・罫線・表示形式は 書式 メニューからも付けられます。
  「書式のクリア」で既定に戻します。
- 表示形式は Excel と同じ書式記号（`#,##0`・`0.00%`・`yyyy/m/d`・`ggge年m月d日`・`[赤]` など）です。標準の
  数値は列幅に合わせて丸め・指数表記にし、入らなければ `#` を出します。
- 列全体・行全体を選んで付けた書式は、あとから増えた行・列にも効きます。書式は `.yys` に保存します。

## 絞り込み・並べ替え {#filter}

- 表の列見出しの ▼（データ > 列の絞り込み、Ctrl+Shift+L）で、値の一覧（件数付き）か条件（等しい・含む・
  で始まる・ワイルドカード・より大きい・範囲・上位／下位 N 件・平均より上／下・空など。2 つまで「かつ」・
  「または」）を付けます。条件はいくつの列にも付けられ、「絞り込みの段階」で段階ごとの残りの行数を見られます。
- 並べ替え: ▼ のダイアログか、データ > 昇順／降順に並べ替え・並べ替え（キーを複数）。値の順は Excel と同じです。
- 絞り込み・並べ替えはデータを動かさず、表示する行の並びだけを変えます。値を直したあとは「再適用」
  （Ctrl+Alt+L）。「並べ替えを確定」で表をその順に作り直します。条件は `.yys` に保存します。

## データの整理（重複の削除・列の型） {#data}

- **重複の削除**: 選んだ列の値の組が前の行と同じ行を消します。
- **列を数値に変換**・**列を文字列に変換**: 数値・日付に読める文字列を数値に、数値を文字列にします。
- どれも Ctrl+Z で戻せます。

## 固定長ファイル {#fixed}

IBM COBOL のコピーブック互換のレイアウト定義で、固定長のファイルを読み書きします（マルチレイアウトは対象外）。
基本項目 1 つが表の 1 列になります（見出しは項目の名前。`OCCURS` は `名前(1)`、同じ名前は `名前 OF 親`）。

1. **開く**: ファイル > 固定長ファイルを開く（`.dat`・`.bin` は「開く」・ドラッグ＆ドロップでも）。レイアウトの
   ダイアログで、コピーブックを貼り付けるか「ファイルから読み込む」で読み込み、文字コード
   （[固定長ファイルの文字コード](#charsets)）・レコードの区切り（自動・なし・CR LF・LF・NL）・2 進数の並び
   （ビッグ／リトルエンディアン）を選びます。下の欄にレコード長・項目の一覧（位置・長さ・名前・型）・レコードの数・
   1 件目の値が出るので、確かめてから OK で取り込みます。
2. **作成**: 新しいシートで データ > 固定長のレイアウト を選んでコピーブックを設定すると、項目の列（見出し）が
   できます。2 行目から入力してください。表のあるシートでは、名前の同じ列を項目に結び付けます。
3. **型を見る**: 列見出しに型が、ステータスバーの右にレコード長と、アクティブなセルの列の項目（名前・型・
   何バイト目か）が出ます。
4. **型を選ぶ・変える**: 列のセルを選んで 書式 > セルの書式設定（Ctrl+1）の「COBOL の型」に型を入力するか
   候補から選びます。欄の下に長さ（バイト）と意味が出ます（[COBOL の型の一覧](#cobol-types)）。
   - 範囲を選ぶと、その範囲の列すべてに同じ型を付けます。`OCCURS` の項目は、すべての回の型が変わります。
   - 項目のない列（CSV の表など）に型を付けると、左の列の項目の後ろに項目を足します（名前は列の名前から）。
     固定長でない表の列に型を付けると、そのシートは固定長のシートになります（文字コードは MS932、区切りは CR LF。
     書き出すときに選び直せます）。
   - 型を変えると、コピーブックは yysheet が書き直します（注記・`VALUE`・88 レベルは残りません。`REDEFINES`・
     `OCCURS`・集団項目は残ります）。レコード長と、後ろの項目の位置も変わります。Ctrl+Z で戻せます。
   - 小数部のある数値の型にすると、列の表示形式（自動のもの）を小数部の桁に合わせます（`0.00`）。
5. **入力**: 項目の列のセルには、型に合う値だけを入力できます（[型に合わない入力](#fixed-input)）。英数字の
   項目は、数字だけの値も文字列のまま入れます（`00123` の 0 を残す）。
6. **埋め草（パディング）**: COBOL の `MOVE` と同じく、値を項目の長さまで自動で埋めます。

   | 項目の型 | 埋め方 | 例 |
   |---|---|---|
   | 英数字（`X`・`A`） | 後ろを空白で（`JUSTIFIED` なら前を）。長さはバイト数（漢字は 2 バイト、EBCDIC は SO / SI も数える） | `X(8)` に `ABC` → `ABC␣␣␣␣␣` |
   | 2 バイト文字（`N`・`G`） | 後ろを全角の空白で | `N(4)` に `漢字` → `漢字　　` |
   | `NATIONAL` | 後ろを空白で | |
   | 数値（`9`・`COMP-3`・`COMP` など） | 表示を整数部の桁まで 0 で埋め、小数部の桁まで出す（値は数値のまま） | `9(5)V99` の 42 → `00042.00` |

   入力・貼り付け・式の結果・`CBL.MOVE`・ファイルからの取り込みのどれでも埋めます。セルを編集するときは埋め草を
   除いて見せ、確定すると埋め直します（埋め草は長さの確かめに数えません）。書き出すバイト列は埋める前と同じです。
7. **保存**: ファイル > 固定長ファイルに書き出し（固定長ファイルを開いたときは上書き保存でも）で、文字コード・
   区切り・2 進数の並びを選んで書きます。別の文字コード（MS932 ⇔ EBCDIC）にもできます。桁あふれ・長すぎる
   文字列・文字コードにない文字があれば、数と最初の場所を知らせます。空のセルは英数字・ゾーン 10 進数なら空白、
   パック 10 進数・2 進数なら 0 で書きます。小数部が項目の桁より多いときは、COBOL の MOVE と同じく切り捨てます。
   列を並べ替えたり削除したりしても、レイアウトの項目の順に書きます。`.yys` で保存すると、レイアウトも保存されます。
8. **シートごとのレイアウト**: レイアウト（コピーブック・文字コード・区切り）はシートごとに持ちます。1 つの文書に
   入力ファイルと出力ファイルのように別のレイアウトのシートを並べられます。
   - ファイル > **固定長ファイルをシートとして追加**（マルチレイアウトもあります）で、今の文書に新しいシート
     （名前はファイル名）として取り込みます。データ > 固定長のレイアウト は、今のシートだけに当てます。
   - 上書き保存で「固定長のまま」を選ぶと、**今のシート**を、そのシートを取り込んだファイルへ書きます。ほかの
     シートは、そのシートを選んで同じ操作をします。`.yys` で保存すると、すべてのシートとシートごとのレイアウトを
     まとめて保存します。
   - シートをまたいで送るには [CBL.MOVE](#cbl-move) を使います（`=CBL.MOVE(A2:B100,出力!A2:B100)`）。

- `REDEFINES` する項目は使わず、元の定義で読み書きします。`OCCURS DEPENDING ON` は最大の回数の固定長として
  読みます。15 桁を超える数値は桁を落とさないよう文字列で表示します。数値として読めない項目（壊れたパック
  10 進数など）は `X'404040'` のように表示し、そのまま書き戻します。
- 読み書きの結果は GnuCOBOL と同じになることを確かめています（項目の位置・長さ、値の読み書き）。

## マルチレイアウト {#multi-layout}

1 つのファイルに形の違うレコード（見出し・明細・合計など）が混じっているときは、マルチレイアウトで扱います。
レイアウトを名前を付けて複数登録しておき、**行ごとにどのレイアウトかを指定**します。

- **1 行のデータ長（必須）**: マルチレイアウトでは、最初に **1 行（1 レコード）のデータ長**（バイト）を入力します。
  どの行もこの長さで、レイアウトのレコード長はこれを超えられません（超えるとエラー）。短いレイアウトの行は、
  残りを空白で埋めて書きます。ファイルを開くときも、この長さ（と区切り）で行に分けます。
- **登録**: データ > **マルチレイアウトの設定**。上の欄に 1 行のデータ長を入れ、左の一覧で「追加」してレイアウトの
  名前（例: `HDR`・`DTL`）を付け、右にそのコピーブックを貼り付けるか「ファイルから読み込む」で読み込みます。
  文字コード・レコードの区切り・2 進数の並びはすべてのレイアウトで共通です。下の欄に、レイアウトごとのレコード長・
  項目の数・空白で埋める残りのバイト数（開くときはファイルの行数）が出ます。
- **シートの形**: A 列が「レイアウト」（行のレイアウトの名前）、B 列からが「項目1」「項目2」…（その行の
  レイアウトの 1 つ目・2 つ目…の項目）です。項目の列の数は、いちばん項目の多いレイアウトに合わせます。列見出しと
  ステータスバーには、アクティブなセルの行のレイアウトの項目名と型が出ます。
- **行のレイアウトの指定**: A 列にレイアウトの名前を入力するか（大文字・小文字は区別しません。貼り付けも可）、
  行を選んで データ > **行のレイアウトを指定** で選びます。入力・式の結果・`CBL.MOVE` は、その行のレイアウトの
  型で確かめ、埋め草を付けます。
- **選べるレイアウト**: 行のバイト列（取り込んだ元のバイト、またはレイアウトが決まっている行なら項目を書いた
  バイト列）を、そのレイアウトで**デコードエラーなしで読めるものだけ**を選べます（パック 10 進数・ゾーン 10 進数・
  2 進数の項目が数値として読めないレイアウトは出ません）。「行のレイアウトを指定」の一覧には、選んだどの行も読める
  レイアウトだけが出ます。A 列に読めないレイアウトの名前を入力すると、読めない項目と選べるレイアウトを知らせて
  受け付けません。バイト列のない行（名前だけを入れた行）はどのレイアウトも選べます。
- **レイアウト未確定**: A 列が空か、登録されていない名前の行は「レイアウト未確定」で、**行の背景が赤く**なり、
  A 列に **`#レイアウト未確定`**（登録されていない名前なら `#レイアウト未確定（名前）`）と出ます。
- **開く**: ファイル > **固定長ファイルを開く（マルチレイアウト）** でファイルを選び、レイアウトを登録してから
  取り込みます。取り込んだ行はどれもレイアウト未確定で、項目1 に元のバイト（`X'…'`）、項目2 に文字として
  読んだ内容（レコードの種類の見分けに使えます）が入ります。行のレイアウトを指定すると、元のバイトをその
  レイアウトで読み直します。
- **レイアウトを変える**: レイアウトが決まっている行のレイアウトを別のものにすると、COBOL の `REDEFINES` と同じく、
  今の項目を書いたバイト列を新しいレイアウトで読み直します（戻せば元の値）。未確定に戻すと、元のバイトを項目1・2
  に置きます。手で入力している行（元のバイトのない行）は、名前だけを変えて値はそのままにします。
- **保存**: ファイル > 固定長ファイルに書き出し で、行ごとにその行のレイアウトで書きます（どの行も 1 行の
  データ長。短いレイアウトの残りは空白）。レイアウト未確定の行は、元のバイトがあればそのまま書き、なければ書かずに、行数と最初の行を
  知らせます。`.yys` で保存すると、レイアウトと行のレイアウトも保存されます。
- マルチレイアウトのシートでは、セルの書式設定の「COBOL の型」は使えません（型はレイアウトで決まります）。

## レイアウトカタログ {#catalog}

固定長ファイルのレイアウトを、コピーブックを貼り付ける代わりに**カタログ**（決まったフォルダに置いた定義
ファイル）から読み込み、カタログへ保存できます。

- **ルート**: カタログは 1 つのフォルダ（ルート）の下に置きます。既定は `%APPDATA%\yyeditor\layouts` で、
  設定の `[sheet] layout_catalog` で変えられます（[設定](#settings)。共有フォルダにするとチームで同じカタログを
  使えます）。サブフォルダで分けても構いません。カタログの中の名前は、ルートからの相対パス
  （`受注/ORDER.yyl`）です。
- **置けるファイル**:

  | ファイル | 中身 |
  |---|---|
  | `.yyl`（定義ファイル） | レイアウト（コピーブック）と、文字コード・レコードの区切り・2 進数の並び・説明。マルチレイアウトなら名前を付けた複数のレイアウトと 1 行のデータ長も |
  | `.cpy`・`.cbl`・`.cob`・`.copy` | COBOL のコピーブックそのまま（文字コードなどはダイアログで選ぶ。レイアウトの名前はファイル名） |

- **読み込む**: レイアウトのダイアログ（データ > 固定長のレイアウト、マルチレイアウトの設定、ファイル >
  固定長ファイルを開く）の **カタログから読み込む** で一覧から選びます。絞り込みの欄で名前を絞れ、右に中身
  （レコード長・項目の数・コピーブック）が出ます。ダブルクリックでも読み込めます。
  - マルチレイアウトのダイアログに単一のレイアウトを読み込むと、レイアウトの 1 つとして足します（カタログの
    コピーブックを組み合わせてマルチレイアウトを作れます）。マルチレイアウトの定義なら、すべて入れ替えます。
  - データ > **レイアウトカタログから当てる** でも、選んだ定義を今のシートのダイアログに入れて開けます。
- **保存する**: ダイアログの **カタログに保存** か、データ > **シートのレイアウトをカタログに保存** で、名前
  （相対パス。拡張子がなければ `.yyl`）と説明を入れます。同じ名前があれば、確かめてから上書きします。名前を
  `受注/ORDER.cpy` のようにすると、コピーブックだけを書きます（単一のレイアウトだけ）。
- データ > **レイアウトカタログのフォルダを開く** で、ルートをエクスプローラーで開きます。
- 定義ファイル（`.yyl`）は TOML の文字ファイルで、手で書いても構いません:

  ```toml
  description = "受注ファイル"
  charset = "IBM-930"      # MS932・IBM-930・IBM-939・IBM-1399 など
  separator = "none"       # none・crlf・lf・nl
  little_endian = false
  # data_len = 120         # マルチレイアウトなら 1 行のデータ長（あるとマルチレイアウト）

  [[layout]]
  name = "ORDER"           # マルチレイアウトでは必須
  copybook = """
  01 ORDER-REC.
     05 ORDER-ID  PIC 9(6).
     05 AMOUNT    PIC S9(7)V99 COMP-3.
  """
  ```

## COBOL の型の一覧 {#cobol-types}

「COBOL の型」の欄・コピーブックに書く型（`PIC` と `USAGE` など）です。`PIC` の語は省いても構いません
（`PIC S9(5)` と `S9(5)` は同じ）。`9(5)` は `99999` と同じで、( ) の中は繰り返しの数です。

| 記述例 | バイト数 | 意味 |
|---|---|---|
| `X(10)` | 10 バイト | 英数字 10 バイトの文字列を表す（漢字は 1 文字 2 バイト。足りない分は空白で埋める） |
| `A(5)` | 5 バイト | 英字 5 文字（英字と空白だけ）を表す |
| `X(10) JUSTIFIED` | 10 バイト | 英数字 10 バイトの文字列を表す（右寄せ。足りない分は空白を左に詰める） |
| `N(5)` | 10 バイト | 2 バイト文字（全角）5 文字の文字列を表す（SO / SI なし） |
| `G(5)` | 10 バイト | 2 バイト文字（全角）5 文字の文字列を表す（`N(5)` と同じ） |
| `N(5) NATIONAL` | 10 バイト | UTF-16 の 5 文字の文字列を表す |
| `9(5)` | 5 バイト | 数字 5 文字で十進 5 けたの符号なし整数を表す |
| `9(5)V99` | 7 バイト | 数字 7 文字で十進整数部 5 けた、小数部 2 けたの符号なし数を表す（`V` は位置を取らない小数点） |
| `S9(5)` | 5 バイト | 十進 5 けたの符号あり整数を表す（符号は最後のけたのゾーンに含める） |
| `S9(5)V99` | 7 バイト | 十進整数部 5 けた、小数部 2 けたの符号あり数を表す（符号は最後のけたのゾーンに含める） |
| `S9(5) SIGN LEADING` | 5 バイト | 十進 5 けたの符号あり整数を表す（符号は最初のけたのゾーンに含める） |
| `S9(5) SIGN TRAILING SEPARATE` | 6 バイト | 数字 5 文字と最後の符号 1 文字（+ -）で十進 5 けたの符号あり整数を表す |
| `S9(5) SIGN LEADING SEPARATE` | 6 バイト | 最初の符号 1 文字（+ -）と数字 5 文字で十進 5 けたの符号あり整数を表す |
| `99PPP` | 2 バイト | 数字 2 文字で十進 2 けたに 10 の 3 乗を掛けた符号なし整数を表す（`P` は位置を取らない桁） |
| `VPP99` | 2 バイト | 数字 2 文字で十進小数部 4 けた（有効 2 けた）の符号なし数を表す |
| `9(5) COMP-3` | 3 バイト | パック 10 進数（1 バイトに 2 けた、最後の半バイトが符号）で十進 5 けたの符号なし整数を表す |
| `S9(5) COMP-3` | 3 バイト | パック 10 進数で十進 5 けたの符号あり整数を表す（`PACKED-DECIMAL` も同じ） |
| `S9(7)V99 COMP-3` | 5 バイト | パック 10 進数で十進整数部 7 けた、小数部 2 けたの符号あり数を表す |
| `S9(18) COMP-3` | 10 バイト | パック 10 進数で十進 18 けたの符号あり整数を表す |
| `S9(4) COMP` | 2 バイト | 2 バイトの 2 進数で十進 4 けたの符号あり整数を表す（`BINARY`・`COMP-4` も同じ） |
| `9(4) COMP` | 2 バイト | 2 バイトの 2 進数で十進 4 けたの符号なし整数を表す |
| `S9(9) COMP` | 4 バイト | 4 バイトの 2 進数で十進 9 けたの符号あり整数を表す |
| `S9(18) COMP` | 8 バイト | 8 バイトの 2 進数で十進 18 けたの符号あり整数を表す |
| `S9(4) COMP-5` | 2 バイト | 2 バイトの 2 進数で符号あり整数を表す（PIC のけた数で切り詰めず、-32768〜32767 まで） |
| `S9(9) COMP-5` | 4 バイト | 4 バイトの 2 進数で符号あり整数を表す（PIC のけた数で切り詰めず、-2147483648〜2147483647 まで） |
| `S9(18) COMP-5` | 8 バイト | 8 バイトの 2 進数で符号あり整数を表す（-9223372036854775808〜9223372036854775807 まで） |
| `COMP-1` | 4 バイト | 4 バイトの単精度浮動小数点数を表す（EBCDIC は IBM の 16 進形式、MS932 は IEEE 754） |
| `COMP-2` | 8 バイト | 8 バイトの倍精度浮動小数点数を表す（EBCDIC は IBM の 16 進形式、MS932 は IEEE 754） |
| `POINTER` | 4 バイト | 4 バイトの 2 進数で符号なし整数を表す（`INDEX` も同じ） |
| `ZZZZ9` | 5 バイト | 十進 5 けたの符号なし整数を 5 文字に編集して表す（上の桁の 0 は空白。例: `   12`） |
| `ZZ,ZZ9.99` | 9 バイト | 十進整数部 5 けた、小数部 2 けたの符号なし数を 9 文字に編集して表す（例: `45,678.90`） |
| `ZZ,ZZ9.99-` | 10 バイト | 十進整数部 5 けた、小数部 2 けたの符号あり数を 10 文字に編集して表す（例: `45,678.90-`） |
| `-ZZZ9` | 5 バイト | 十進 4 けたの符号あり整数を 5 文字に編集して表す（負なら先頭に `-`。例: `-7890`） |
| `+ZZZ9` | 5 バイト | 十進 4 けたの符号あり整数を 5 文字に編集して表す（正なら `+`、負なら `-`） |
| `ZZZ9CR` | 6 バイト | 十進 4 けたの符号あり整数を 6 文字に編集して表す（負なら末尾に `CR`。`DB` も同様） |
| `$$$,$$9.99` | 10 バイト | 十進整数部 5 けた、小数部 2 けたの符号なし数を 10 文字に編集して表す（例: `$45,678.90`。`¥` も使えます） |
| `***,**9.99` | 10 バイト | 十進整数部 6 けた、小数部 2 けたの符号なし数を 10 文字に編集して表す（上の桁の 0 は `*`） |
| `99/99/99` | 8 バイト | 十進 6 けたの符号なし整数を 8 文字に編集して表す（例: `26/10/07`） |
| `999B999` | 7 バイト | 十進 6 けたの符号なし整数を 7 文字に編集して表す（`B` は空白。例: `567 890`） |
| `ZZ9.99 BLANK WHEN ZERO` | 6 バイト | 十進整数部 3 けた、小数部 2 けたの符号なし数を 6 文字に編集して表す（0 は空白） |

- **USAGE の意味**: 書かなければ `DISPLAY`（1 けた 1 文字のゾーン 10 進数）。`COMP-3`（`PACKED-DECIMAL`）は
  パック 10 進数（`(けた数 ÷ 2) + 1` バイト）、`COMP`・`COMP-4`・`BINARY` は 2 進数（1〜4 けたは 2 バイト、5〜9 けたは
  4 バイト、10〜18 けたは 8 バイト。PIC のけた数を超える値は上の桁を落とす）、`COMP-5` は同じ大きさの 2 進数で型の
  範囲まで、`COMP-1`・`COMP-2` は浮動小数点（PIC は書きません）。
- **符号**: `S` を付けると符号あり。ゾーン 10 進数の符号は、EBCDIC では最後のけたのゾーンが `C`（正）・`D`（負）、
  MS932 では負の最後のけたを `p`〜`y`（0x70〜0x79）にします。`SIGN LEADING` は最初のけた、`SEPARATE` は別の 1 文字です。
- **数字編集の記号**: `9`（数字）・`Z`（0 なら空白）・`*`（0 なら `*`）・`,` `.`（そのまま入る）・`B`（空白）・
  `0` `/`（そのまま入る）・`+` `-`（符号）・`CR` `DB`（負のとき）・`$` `¥`（通貨記号。続けると移動する）。
- そのほか `SYNC`（2 進数・浮動小数点を境界に揃える）、`JUSTIFIED RIGHT`、`BLANK WHEN ZERO` を型の後ろに書けます。
- 2 バイト文字（`N`・`G`）に `COMP-3` などは付けられません。数字編集は `DISPLAY` だけです。浮動小数点の編集（`E`）
  には対応していません。

## CBL.MOVE（COBOL の MOVE） {#cbl-move}

`=CBL.MOVE(送り出し範囲, 受け取り範囲)` は、送り出し範囲の値を受け取り範囲へ、COBOL の `MOVE` と同じ決まりで
送ります。受け取り範囲は COBOL の型のある列（[固定長ファイル](#fixed)）の範囲です。

- 式は**受け取り範囲の外のセル**に入力します。ふつうは固定長の範囲（レコードの列）の右の、型のない列を使います。
  値は受け取り範囲に置かれ、式のセルには置いた先（`CBL.MOVE → D2:E100（99 行）`）が出ます。例: レコードの
  列が A〜H なら、`J2` に `=CBL.MOVE(A2:B100,D2:E100)`。行ごとに `J2` へ `=CBL.MOVE(A2:B2,D2:E2)` と入力して
  下へコピー（Ctrl+D・フィルハンドル）しても構いません。
- **シートをまたいで**送れます。送り出し・受け取りのどちらも、ほかのシートの範囲にできます（`シート名!A2:B100`）。
  受け取り側のシートのレイアウト（型・文字コード）で送ります。例: 入力のシートの `J2` に
  `=CBL.MOVE(A2:A100,出力!B2:B100)`、または出力のシートの `J2` に `=CBL.MOVE(入力!A2:A100,B2:B100)`。
  ないシートの名前なら `#REF!`。
- 固定長の範囲の外の列は、レコード（書き出すデータ）に入りません。そこだけに式や値がある行は、書き出しでも
  マルチレイアウトの「レイアウト未確定」でもレコードに数えません。
- 受け取り範囲のセルは空にしておきます。値・式があるとき、式のセルが受け取り範囲の中にあるとき、ほかの
  `CBL.MOVE` と受け取り範囲が重なるときは `#SPILL!`（値を消せば置きます）。式を消すと置いた値も消えます。
- `CBL.MOVE` は式の全体として使います（`=IFERROR(CBL.MOVE(…),0)` のように式の中に入れると `#VALUE!`）。
- **行数**が違えば `#VALUE!`。
- **列の数が同じ**なら、列ごとに基本項目の MOVE をします（送り出しの列の型 → 受け取りの列の型）。

  | 送り出し → 受け取り | 結果 |
  |---|---|
  | 数値 → 数値 | 小数点の位置を揃え、小数部の多い桁は切り捨て、整数部のあふれは上の桁を落とす（エラーにしない）。符号なしの項目には絶対値。例: `S9(5)V99` の 12345.67 → `9(3)` は 345 |
  | 数値（整数）→ 英数字 | 送り出しの項目の桁数の数字（上の 0 を含む。符号は付けない）を左詰め。例: `9(5)` の 42 → `X(8)` は `00042` |
  | 小数部のある数値・浮動小数点 → 英数字 | 送れない（`#VALUE!`） |
  | 数字編集 → 英数字・数値 | 英数字へは編集した文字列（` 1,234.50-`）、数値へは編集を外した値 |
  | 英数字 → 数値 | 数字だけの文字列を符号なしの整数として送る（`00123` → `9(5)V99` は 123.00）。数字以外があれば `#VALUE!` |
  | 英数字 → 英数字 | 左詰め（`JUSTIFIED` なら右詰め）。足りない分は空白、長ければ切る |
  | `CBL.LOW-VALUE()`・`CBL.HIGH-VALUE()` | そのまま（項目のすべてのバイトを 0x00・0xFF） |

- **列の数が違えば**、COBOL の集団項目の MOVE と同じく、行ごとに送り出しの項目のバイト列をつなげたものを、
  受け取りの項目をつなげた領域へ英数字として左詰めで送ります（足りない分は空白、長ければ切る）。項目の型では
  変えずバイトのまま送るので、受け取りの数値の項目に数字でないバイトが入ると `X'…'` で表示します（COBOL で
  同じ MOVE をしたときと同じバイトです）。例: `9(5)` の 1 と `X(10)` の `ABC` → `X(10)` は `00001ABC`。
- 送り出しの列に COBOL の型がなければ、値のまま（数値は数値、文字列は英数字）として送ります。送り出しの値は
  受け取り側の文字コードで書きます。
- 送り出しのセルがエラー値なら、そのエラーになります。受け取りの列に型がない・見出し行を含むときは `#VALUE!`。
  送れない値があれば、受け取り範囲のそのセルと式のセルがエラーになります。
- 結果は GnuCOBOL で同じ `MOVE` をした結果とバイト単位で比べて確かめています（16 通り。2 進数は IBM の
  既定の `TRUNC(STD)` と同じく、PIC の桁で切ります）。

## 型に合わない入力 {#fixed-input}

固定長のシートで項目の列のセル（見出し行は除く）に入力・貼り付けると、項目の型に合うかを確かめます。合わない
ときは、式の誤りと同じように「入力が項目の型に合いません」と知らせて、値を入れません（入力した文字列を残したまま
編集を続けるので、直して Enter を押してください。Esc で取り消し）。貼り付けでは、合わないセルが 1 つでもあれば
何も貼り付けず、最初のセルの場所と理由を知らせます。

| 項目の型 | 受け付けない入力 |
|---|---|
| 数値（`9`・`COMP-3`・`COMP` など） | 数字（全角も）・符号（+ -。前でも後ろでも）・小数点・桁区切りの `,` 以外の文字、符号なしの項目に負の数、小数部の桁数の超え（`9(5)V99` に `1.239`）、整数部の桁数の超え（`9(5)` に `123456`）、`COMP-5` の範囲の外 |
| 浮動小数点（`COMP-1`・`COMP-2`） | 数値でない文字列 |
| 数字編集（`ZZ,ZZ9.99-` など） | 数値の項目と同じ（値を入力すると、書き出すときに編集します） |
| 英数字（`X`） | 長すぎる文字列（バイト数。漢字は 2 バイト、EBCDIC では SO / SI も数える）、文字コードにない文字 |
| 英字（`A`） | 英字と空白以外の文字、長すぎる文字列 |
| 2 バイト文字（`N`・`G`） | 全角にできない文字（半角カナなど）、長すぎる文字列（半角の英数字は全角にして書きます） |
| `NATIONAL` | 長すぎる文字列 |

- 空の入力（消す）はどの型でも受け付けます。
- **式（関数）の結果**は、入力をはじくのではなく、式の結果を項目の型で確かめて、合わなければセルにエラー値を
  出します（`#DIV/0!` などと同じく、その式を参照する式もエラーになります）。

  | 式の結果 | セルに出る値 |
  |---|---|
  | 型が違う（数値の項目に数値でない文字列・真偽値、英数字の項目に長すぎる文字列・文字コードにない文字、`PIC A` に英字以外） | `#VALUE!` |
  | 桁・範囲の外（整数部の桁あふれ、符号なしの項目に負の数、`COMP-5` の範囲の外） | `#NUM!` |
  | 小数部が項目の桁より多い（`9(5)V99` に `=10/3`） | 切り捨てた値（`3.33`。COBOL の `COMPUTE` と同じ） |
  | `CBL.LOW-VALUE()`・`CBL.HIGH-VALUE()` | `LOW-VALUE`・`HIGH-VALUE`（どの型の項目でも） |

  型を変えると、式の結果を新しい型で確かめ直します。エラー値のセルは、書き出すと空のセルと同じに書き、
  注意の数に入ります。
- 数値の項目に `X'0012345C'` の形（項目の長さのバイト列）を入力すると、そのバイトをそのまま書きます。

## 困ったときは {#trouble}

- **固定長ファイルの値がずれる**: レコード長（ステータスバーの右・レイアウトのダイアログ）がファイルと合っているか、
  レコードの区切り（なし・CR LF など）と文字コードを確かめてください。末尾にレコードにならないバイトが残ると、
  ダイアログで知らせます。
- **2 進数の値がおかしい**: Windows で作ったファイル（`COMP-5` など）はリトルエンディアンのことがあります。
  レイアウトのダイアログの「2 進数の並び」を変えてください。
- **行が赤い・`#レイアウト未確定`**: マルチレイアウトで、その行のレイアウトが決まっていません。A 列に登録した
  レイアウトの名前を入れてください（[マルチレイアウト](#multi-layout)）。
- **値を入力できない**: 固定長の項目の型に合わない値は受け付けません（[型に合わない入力](#fixed-input)）。
  ステータスバーの右で列の型を確かめるか、セルの書式設定で型を変えてください。
- **`#NAME?` になる**: [関数の一覧](#functions) にない関数です。
- **固定長の列で式が `#VALUE!`・`#NUM!` になる**: 式の結果が項目の型に合っていません（[型に合わない入力](#fixed-input)）。
  COBOL の型のない列の `CBL.LOW-VALUE()`・`CBL.HIGH-VALUE()` も `#VALUE!` です。
- **`CBL.MOVE` が `#SPILL!` になる**: 受け取り範囲に値や式があるか、式のセルが受け取り範囲の中にあります。式は
  固定長の範囲の外の列に書いてください（[CBL.MOVE](#cbl-move)）。
- **yysheet が異常終了した**: `%LOCALAPPDATA%\yyeditor\logs` に `crash-yysheet-日時-番号.log` を残し、その場所を
  知らせます（ヘルプ > **異常終了の記録のフォルダを開く**）。不具合の報告にはこのファイルを添えてください。
  記録を残せずに終わったときも、次の起動でステータスバーに知らせます。
- **ヘルプが白いまま**: WebView2 ランタイムがないときは、本文を文字だけで表示します。
