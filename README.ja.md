# yyeditor / yy アプリケーション

[English](README.md) | 日本語

<img src="apps/yyeditor/res/yyeditor-256.png" alt="yyeditor のアイコン" width="96">

テキストの編集、ターミナル接続、ファイル転送、表データの加工、共有フォルダの整理、Web の閲覧、クリップボードの再利用を行う、Rust 製の Windows アプリケーション群です。巨大なファイルや日本語の文字コード、メインフレームのデータを扱うための機能を備えています。

このリポジトリには、次のアプリケーションと、その共通ライブラリが含まれます。

| アプリケーション | 用途 |
| --- | --- |
| **yyeditor** | 巨大ファイル、日本語テキスト、CSV、バイナリを編集するテキストエディタ |
| **yyterm** | ローカルシェル、SSH、IBM 3270 に接続するターミナル |
| **yysftp** | SFTP / SCP によるファイル・フォルダの転送 |
| **yysheet** | 大量の表データ、数式、COBOL の固定長データを扱うスプレッドシート |
| **yyclip** | テキストのクリップボード履歴、定型文、お気に入りを呼び出す常駐アプリ |
| **yyfilemanager** | ローカル・共有フォルダの同期、検索、重複・古い版の整理 |
| **yybrowser** | 独自のプロキシ設定、広告ブロック、ブックマークを備えたタブブラウザ |
| **yy-agent** | SSH 接続先でファイル操作を行う Linux 用の補助プログラム |

開発環境、ビルド、テスト、内部構成については [DEVELOPER.ja.md](DEVELOPER.ja.md) を参照してください。

## yyeditor — テキストエディタ

ログ、ソースコード、日本語文書、CSV、固定長レコードなどを、同じアプリで閲覧・編集できます。巨大ファイルはメモリマップを利用して開き、行数の集計などをバックグラウンドで進めます。

- **編集**: タブで複数文書を開く、IME 入力、矩形選択、マルチカーソル、Undo / Redo、文字列の変換、重複行の削除。保存後も Undo できます。
- **検索**: インクリメンタル検索、正規表現、置換、全一致箇所の選択、フォルダ内検索（Grep）と結果へのジャンプ。
- **比較**: 開いている2文書を左右に並べ、行を位置合わせして差分を表示。スクロールも連動します。
- **文字コード**: UTF-8 / UTF-16 / UTF-32、CP932、Shift_JIS、Shift_JIS-2004、EUC-JP、EUC-JIS-2004、ISO-2022-JP、各種 EBCDIC など。自動判別、文字コードを指定した開き直し、保存時の文字コード・BOM・改行コードの変換に対応します。
- **CSV / TSV**: 列を揃えた表示、セル間の移動、列の挿入・削除、区切り文字の変換。引用符やフィールド内改行を含む CSV も扱います。
- **バイナリ・固定長**: 16進数表示と編集、Unicode コード値の編集、バイト位置の目盛りを使う固定長表示。
- **ソース・文書の表示**: Rust、C / C++、Python、JavaScript / TypeScript、COBOL、JCL などのシンタックスハイライト、括弧の対応表示、コメント化。Markdown / HTML のプレビューでは Mermaid、KaTeX、d3 の図や数式も表示できます。
- **作業フォルダ**: 複数フォルダのワークスペース、ファイル操作、履歴とブックマーク。Git の変更・差分表示、ステージ、コミット、ブランチ操作、フェッチ・プル・プッシュに対応します。
- **リモート編集**: SSH 接続先の Linux ファイルを開いて保存。外部で変更されたファイルを保存する際は確認します。リモートのワークスペースや Git 操作も利用できます。

EBCDIC は IBM-930 / 939 / 1390 / 1399 などに対応し、改行区切りや固定長レコードを扱えます。外部の対応表を登録すれば、ベンダーの漢字コードや外字も扱えます。JEF・KEIS・JIPS の対応表そのものは同梱していません。

詳しい操作は [yyeditor のヘルプ](crates/yy-win/help/help.md) またはアプリ内の F1 を参照してください。

## yyterm — ターミナルと 3270 端末

タブごとにローカルシェル、SSH セッション、3270 端末を開けます。

- ローカルシェルは Windows の ConPTY を使用。既定では PowerShell 7 を探し、なければ Windows PowerShell、コマンドプロンプトの順で使用します。
- SSH 接続、踏み台・プロキシ、ローカル・リモート・動的ポートフォワーディングに対応します。
- 全角・結合文字、256色・24ビット色、代替画面、マウス操作、ブラケットペースト、IME 入力に対応します。
- スクロールバック、コピー・貼り付け、URL やファイルパスのリンクを利用できます。ファイルのリンクからエディタを開き、SSH タブのフォルダから yysftp を開けます。
- 共通のワークスペースから、選んだローカル・リモートフォルダでターミナルを開けます。

**IBM 3270** は TN3270 / TN3270E、モデル2〜5、日本語 CCSID 930 / 939 / 1390 / 1399 に対応します。直接 TCP、TLS、SSH 経由で接続できます。独自のキー割り当て、画面のキーパッド、Rhai マクロと操作記録、IND$FILE の GET / PUT、3287 プリンター出力、通信トレースと画面の再現も含まれます。

## yysftp — ファイル転送

SSH 接続先のフォルダを、ツリーとファイル一覧で操作する SFTP / SCP クライアントです。

- エクスプローラーからファイル・フォルダをドラッグ＆ドロップしてアップロード。選択した項目をダウンロードできます。
- フォルダ作成、名前の変更、削除などのリモートファイル操作に対応します。
- 転送キュー、進捗・速度表示、一時停止、再開、切断後の自動再接続を備えています。転送状態を記録し、アプリの再起動後にも続きから転送できます。
- 転送先には一時名で書き込み、確認後に本来の名前へ変更します。エージェントを使う場合は、ファイル全体の SHA-256 による照合も行います。
- 転送ログを画面とファイルに残します。

既定では接続先の SFTP / SCP を使用し、yy-agent は配置しません。設定でエージェントを利用する方式に切り替えられます。

## yysheet — 大量データのスプレッドシート

CSV / TSV、独自形式の `.yys`、COBOL のレイアウトに基づく固定長ファイルを読み書きする表計算アプリです。大量の行を扱うため、データを列ごとに保管し、必要な部分を読み込む構成を採っています。

- **表の編集**: セルと数式バーでの入力、IME、複数シート、コピー・貼り付け、行・列の挿入と削除、Undo / Redo、フィルハンドル、検索・置換、行と列を入れ替える転置貼り付け。
- **データ整理**: 複数条件の絞り込み、複数キーの並べ替え、重複の削除、列の型の指定。手入力・貼り付けした範囲もテーブルに変換して絞り込み・並べ替えできます。
- **数式**: 四則演算、セル参照、`SUM`、`COUNT`、`SUMIFS`、`COUNTIFS`、`XLOOKUP`、`ROW`、`AND`、`OR`、`IFS`、`POWER`、文字列関数など。動的配列のスピルや依存関係に基づく再計算に対応します。
- **書式**: 数値・日付・時刻・和暦などの Excel 互換の表示形式、文字色、塗りつぶし、太字・斜体、配置、罫線。
- **区切り文字データ**: 文字コード、区切り文字、見出し、列の型を推定して取り込み。引用符・フィールド内改行に加え、US / RS などの制御コードによる区切りも指定できます。
- **固定長データ**: COBOL コピーブックをもとに項目を列として表示。文字、ゾーン10進数、パック10進数（COMP-3）、バイナリ数値などを編集し、MS932 / EBCDIC で書き出せます。複数レイアウト、レイアウトカタログ、COBOL の MOVE 相当の変換にも対応します。
- **リモートファイル**: 共通のワークスペースから SSH 接続先の表データを開いて保存。既定では SFTP を使い、設定でエージェントも利用できます。

`.yys` は変更部分を追記して保存する独自形式です。Excel と同じ数式・表示形式の一部を実装していますが、対応するファイル形式は `.yys`、区切り文字データ、固定長データです。

詳しい操作と関数一覧は [yysheet のヘルプ](crates/yy-win/help/sheet.md) またはアプリ内の F1 を参照してください。

## yyclip — クリップボード履歴とランチャー

通知領域に常駐し、コピーしたテキストを保存して呼び出すアプリです。他の yy アプリとは独立して動作します。

- 1 MiB 以下のテキストを履歴として保存。終了後も履歴が残ります。
- Control キーを500ミリ秒以内に2回押すと選択画面が開きます。通知領域のアイコンからも開けます。開いた直後は先頭の項目が選択され、そのままキーボードで操作できます。
- 「クリップボード」「定型文」「お気に入り」のタブを、矢印キーや Ctrl+Tab で切り替えられます。
- 履歴や定型文を Enter / ダブルクリックで選ぶと、クリップボードに戻します。
- 定型文は複数行に対応し、最大20件まで登録・編集・削除できます。用途を示すメモを付けられ、クリップボードには本文だけを戻します。
- お気に入りはファイルとフォルダを合わせて最大20件。ファイルは既定のアプリ、フォルダはエクスプローラーで開きます。

画像やファイル一覧など、テキストを含まないクリップボード内容は保存対象外です。操作と保存場所の詳細は [yyclip の README](apps/yyclip/README.md) を参照してください。

## yyfilemanager — 共有フォルダの同期・検索・整理

ローカルフォルダや Windows の共有フォルダを対象に、ファイルの転送と整理を行うアプリです。SSH のファイル転送を行う yysftp とは別に、エクスプローラーでアクセスできる共有フォルダを扱います。

- **同期**: 送り元から送り先への一方向の更新・ミラー同期。実行前に計画を表示し、送り先でも変更されたファイルは衝突として扱います。方向を入れ替えれば、共有フォルダから手元への同期もできます。
- **再開・差分転送**: 切断やアプリ終了後の再開、大きなファイルの変更ブロックだけの転送、転送後の確認、設定に応じたアクセス権のコピーに対応します。
- **検索**: 名前、正規表現、拡張子、サイズ、日時、属性、内容を組み合わせて検索。日本語の文字コードを判別し、Office 文書（docx / xlsx / pptx）や文字を含む PDF も対象にできます。
- **索引と保存**: ファイルの目録、ハッシュ、全文索引を保存して再利用。検索条件の保存、索引の整理、バックグラウンド処理の CPU・メモリ制限を備えています。
- **重複・版の整理**: 内容のハッシュによる重複検出と、名前・日時などからの最新版の提案。拡張子・名前の正規表現で対象を絞り、フォルダやファイルの除外条件を指定できます。
- **削除と復元**: 確認一覧で対象を選び、ローカルではごみ箱、共有では隔離フォルダへ移します。隔離したファイルは記録から復元でき、保持期間を過ぎたものの整理も行えます。
- **定期同期**: 保存したジョブを `--sync` で画面なしで実行でき、Windows タスクスケジューラーに登録できます。

版の判定は推測です。同期・削除の計画を確認して実行します。操作の詳細は [yyfilemanager のヘルプ](crates/yy-win/help/filemanager.md) を参照してください。

## yybrowser — 接続経路を選べるタブブラウザ

Microsoft Edge WebView2 を使い、OS の設定とは別に接続経路を選べるブラウザです。社内ネットワーク、SSH の動的ポート転送、検証用プロキシなどを、プロファイルごとに使い分けられます。

- **接続設定**: OS の設定、直接接続、HTTP / HTTPS / SOCKS プロキシ、PAC を選択。ドメインごとに経路を切り替える規則にも対応します。
- **プロファイル**: プロキシ設定と Cookie・キャッシュ・ログイン状態を分離。別のプロファイルを別ウィンドウで開けます。
- **検証用の接続**: ホスト名を特定の IP・ポートへ転送し、対象のホストと証明書の指紋に限定して開発者用証明書を受け入れられます。
- **Cookie の編集**（開発者用）: 表示中のページに送られる Cookie（HttpOnly を含む）の一覧、追加・編集・削除。期限・Secure・SameSite も設定できます。
- **広告ブロック**: EasyList、EasyPrivacy、AdGuard 日本語フィルタなどで広告・追跡リクエストを抑えます。リストの自動更新、追加、サイトごとの除外、プロファイルごとの有効・無効切り替えに対応します。
- **ブックマーク**: 星ボタンや Ctrl+D で登録。フォルダ管理、編集・並べ替え、他のブラウザ向け HTML のインポート・エクスポートに対応します。ブックマークはプロファイル間で共通です。
- **ダウンロード**: 「ダウンロード」フォルダか指定したフォルダに保存（毎回確かめることも可能）。進み具合の表示、一時停止・再開・中止、一覧（Ctrl+J）。同じ内容（SHA-256 が同じ）のファイルがフォルダにあれば、別名で保存せずに破棄します。
- **履歴**: 閲覧履歴の検索と再表示（Ctrl+H）、期間と種類（閲覧履歴・ダウンロード履歴・キャッシュ・Cookie とサイトのデータ・自動入力）を選んだ閲覧データの消去（Ctrl+Shift+Del）。履歴はプロファイル別です。
- **検索エンジン**: アドレスバーの検索に Bing、Google、Yahoo! JAPAN、DuckDuckGo、Brave Search、Startpage、または任意の URL を選べます。
- **閲覧**: タブ、閉じたタブの復元、ページ内検索、拡大・縮小、印刷、全画面、開発者ツール。

操作と接続設定の詳細は [yybrowser のヘルプ](crates/yy-win/help/browser.md) を参照してください。

## アプリ間の連携と動作環境

GUI アプリは Windows 向けです。yyterm のローカルシェルには Windows 10 バージョン1809以降の ConPTY、yyeditor のプレビューと yybrowser には Microsoft Edge WebView2 ランタイムが必要です。

yyeditor・yyterm・yysftp・yysheet は設定や SSH 接続情報を共用し、`*.yyworkspace` で作業フォルダを共有できます。対応するアプリの実行ファイルを同じフォルダに置くと、エディタからターミナルを開くなどの連携を利用できます。既定の等幅フォント UDEV Gothic は同梱されています。

SSH クライアントは組み込みで、ローカルの `ssh.exe` は使用しません。公開鍵・パスワード・対話式認証、ホスト鍵の確認、踏み台、HTTP / SOCKS プロキシに対応します。選択した場合はパスワードや秘密鍵のパスフレーズを Windows 資格情報マネージャーに保存します。

yy-agent は Linux x86_64 / aarch64 用です。yyeditor のリモート編集では、実行ファイルと同じフォルダの `agents/` にある対応バイナリを接続先へ配置して使います。yyterm の SSH シェルはエージェントなしで接続できます。

設定は主に `%APPDATA%\yyeditor\config.toml`、yyclip の履歴・定型文・お気に入りは `%APPDATA%\yyclip\` に保存します。

yyfilemanager のジョブ・索引・操作記録は共通設定フォルダの `filemanager/`、yybrowser のプロファイルは同じ設定フォルダの `browser.toml` に保存します。ブラウザの閲覧データは `%LOCALAPPDATA%\yyeditor\yybrowser\` にプロファイル別で保存します。

## 現在の主な制限

- yyeditor のリモート編集は、ファイル全体を取り寄せてから開きます。`sudo` による保存には対応しません。
- 大きな UTF-8 以外の文書は、文字コードの変換が完了するまで編集・保存できません。
- yyeditor の CSV モードには、見出し行の固定、並べ替え、フィルタはありません。表として加工する場合は yysheet を使えます。
- yyeditor のプレビューは8 MiBまでの文書が対象です。HTML のスクリプトや d3 のコードブロックは実行されます。
- yyeditor の固定長表示はバイト単位の表示・編集です。COBOL の項目の型を解釈した編集には yysheet を使えます。

- yyfilemanager は双方向の変更を統合する同期には対応しません。画像だけの PDF や暗号化された PDF の内容検索も対象外です。
- yybrowser の接続プロファイルはウィンドウ単位です。広告ブロックには uBlock Origin 独自のスクリプト差し込みなど、未対応の規則があります。
